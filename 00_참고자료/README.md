# 참고자료 폴더 안내

이 폴더는 TraceWave Studio 개발에 참고하는 외부 문헌, 제조사 자료, 도면, 원문 파일과 추출 자료를 보관하는 곳이다. 개발 중 작성하는 설계 문서는 [01_개발문서](../01_개발문서/README.md)에, 제품 구현은 [Code](../Code/README.md)에 둔다.

## 보존 규칙

- 이 폴더 아래의 기존 폴더와 파일 이름을 변경하지 않는다.
- 원문 내용, 상대 경로, 출처, 수집 기록과 해시를 보존한다. 새 설계나 현재 구현에 맞춰 소급 수정하지 않는다.
- 개발 문서의 번호 및 한글 명명 규칙을 참고자료 내부에 적용하지 않는다.
- 자료 묶음을 재분류하거나 자동 정리하지 않는다. 중복처럼 보여도 원문과 추출본, 수집 기록의 역할을 먼저 구분한다.
- 사용자 또는 자료 소유자가 복구한 내용을 임의로 덮어쓰지 않는다.

이 README는 사용자가 요청한 폴더 안내 문서다. 기존 원문을 대신하거나 원문 자료의 검증 완료를 뜻하지 않는다. 자료의 미정값과 물리/제작/측정 검증 상태는 그대로 유지한다.
