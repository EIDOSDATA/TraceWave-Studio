# TraceWave Studio

PCB RF 패턴 안테나 통합 설계 도구의 문서 설계 저장소입니다. 현재는 D0 사용자 검토 단계이며 개발 착수 전입니다.

- [설계 문서 안내](01_Docs/00_RFAD_전체_안내.md)
- [개정 내용과 승인 항목](01_Docs/25_RFAD_문서_검토와_승인.md)
- [wxWidgets/Avalonia 선정과 성능 설계](01_Docs/24_RFAD_GUI_선정과_성능_설계.md)
- [요구사항](01_Docs/03_RFAD_사용자_요구사항.md)
- [요구 및 AC 검증 추적](01_Docs/17_RFAD_요구사항_추적표.md)

GUI는 wxWidgets와 Avalonia만 비교하며 Qt 계열은 제외합니다. 사용자의 문서 검토와 개발 착수 지시 이후 구현 및 성능 실험을 진행합니다. 현재 없는 과거 실행 기록을 제품 구현 또는 검증 합격의 증거로 사용하지 않습니다.

설계는 01_Docs, 원문과 추출 자료는 00_REF에 있습니다. 원본 B는 보존하고 현 설계와 다른 내용은 병합/변경 이유에서 구분합니다.
