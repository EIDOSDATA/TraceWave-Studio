# TraceWave Studio

TraceWave Studio는 PCB 패턴 안테나의 2D 설계, 도면과 제조 파일 출력, 전자기 해석을 연결하는 Windows 데스크톱 프로그램이다. Windows 11에서 wxWidgets 기반 Studio를 실행하고, PCB 해석에 WSL2와 openEMS를 사용한다.

## 개발을 이어갈 때

1. **새 채팅이나 새 PC에서 시작**할 때는 저장소를 받고 인계문을 사용한다. [개발 인계와 복사용 지시문](01_개발문서/09_개발계획/08_새채팅_개발인계.md)
2. **다음 구현**은 동박과 손실 재료를 포함한 일반 PCB의 X/Y 주기 경계다. 항목별 구현 순서, 기존 검증 범위와 완료 판정은 한 작업표에서 관리한다. [다음 작업 순서](01_개발문서/09_개발계획/15_기능채택과_개발검증_순서.md#다음-작업-순서)
3. **R1 수신 검수**는 기능 개발을 마친 개정으로 후보를 만든 뒤 온라인 상태의 별도 클린 Windows/WSL2 PC에서 수행한다. 기존 공개 후보 `r1-rc1`의 개정 및 수신 결과는 310번 기록에 있다. [R1 작업표](01_개발문서/09_개발계획/04_현행버전_남은작업.md), [기존 공개 후보](01_개발문서/07_검증/310_공개_검증후보_배포와_독립수신_인계.md)
