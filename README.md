# TraceWave Studio

PCB RF 패턴 안테나 통합 설계 도구의 문서 설계 저장소입니다. 2026-11-07 사용자가 설계 기준선 3.4를 승인했습니다. D0 문서 승인은 완료되었으며 제품 개발은 착수 전입니다.

- [요구사항](01_Docs/03_RFAD_사용자_요구사항.md)
- [요구 및 AC 검증 추적](01_Docs/17_RFAD_요구사항_추적표.md)

승인된 설계 기준선 3.4의 GUI는 C++ wxWidgets입니다. 일반 편집 화면은 60 fps, 대형 장면은 30 fps를 목표로 하며 유료 GUI 부품을 기본 기능의 필수 의존성으로 사용하지 않습니다. Qt 계열은 제외하고 Avalonia는 과거 검토 이력으로 남깁니다.

성능 예산과 기준 host/fixture는 초기 목표로 채택했고 실제 성능은 미측정입니다. R1은 Windows 11 x64+WSL2를 우선 출시하고 Linux GUI는 후속으로 둡니다. Linux native/headless worker 검증은 유지합니다.

원호/IFA 중심 범위를 유지하며 참조 사례 검증 후 물성이 갖춰진 단일 포트 IFA를 검증하고 원호 검증도 수행합니다. 최초 IFA는 2.400~2.4835 GHz, 폭 40 x 길이 60 mm, 2층 FR-4, 완성 보드 두께 목표 1.0 mm, 양면 완성 동박 두께 목표 각 35 um, 50 ohm SMA 급전을 초기 기준으로 채택했습니다. 상세 조건은 [21번](01_Docs/21_RFAD_사례와_계약.md#ifa-initial-baseline)에 있습니다. 유전율과 손실 등은 사용자가 입력하거나 자료에서 선택하는 변수이며 실제 재료 물성과 제작/측정 조건은 후속 확정합니다. 초기 기준 채택은 제작, 해석 또는 실측 합격이 아닙니다.

미결 사항은 [25번](01_Docs/25_RFAD_문서_검토와_승인.md#remaining-decision-policy)에 개발 전 사용자 승인, 개발 중 기술 선정/검증, 제작/측정/내부 배포 전 확정, 후속 출시 결정으로 정리했습니다. 추천 처리 방향은 채택했으며, 실제 값과 시험 결과는 해당 작업 전에 확정합니다.

배포는 우선 내부 검증용입니다. 전체 문서 기준선은 승인되었고 별도 개발 착수 지시 이후 구현 및 통합 검증을 진행합니다. 현재 없는 과거 실행 기록을 제품 구현 또는 검증 합격의 증거로 사용하지 않습니다.

승인 범위와 잔여 조건은 [25번 승인 기록](01_Docs/25_RFAD_문서_검토와_승인.md#baseline-approval)에, 파일별 식별 정보는 [승인 기록](01_Docs/records/3.4_design_approval.json)과 [승인 반영본 해시](01_Docs/records/3.4_design_manifest.json)에 남깁니다. 해시는 UTF-8/LF 정규화 기준이며 이 기록을 포함한 Git 커밋으로 고정합니다.

설계는 01_Docs, 원문과 추출 자료는 00_REF에 있습니다. 원본 B는 보존하고 현 설계와 다른 내용은 병합/변경 이유에서 구분합니다.
