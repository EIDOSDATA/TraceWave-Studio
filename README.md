# TraceWave Studio

TraceWave Studio는 Windows에서 PCB 안테나를 설계하고, 같은 설계 개정으로 전자기 해석과 도면 출력을 수행하는 데스크톱 프로그램이다. 2D 편집에서 시작해 3D 형상, 정합, 방사 결과와 제조 파일까지 확인할 수 있다.

## 설치와 검수

Windows 11 x64에서는 공개 RC10의 설치 파일과 SHA-256을 내려받는다. 해시를 확인하고 설치 파일을 실행하면 Studio와 기본 Windows openEMS 해석기를 구성한다. 시작 메뉴에서 실행하고 Windows 설정의 설치된 앱에서 제거한다. WSL2는 기존 Linux 해석 환경을 선택할 때 쓴다. [RC10 다운로드](https://github.com/EIDOSDATA/TraceWave-Studio/releases/tag/r1-rc10) [설치와 제거 절차](01_개발문서/08_운영환경/05_윈도우_내부검증_배포.md)

RC10은 별도 Windows PC에서 설치, 실제 해석과 취소, 제거와 재설치를 검수해 R1 내부 수용을 마친 버전이다. 그 소스와 설치 파일, 대표 프로젝트와 결과가 새 버전을 비교할 B0 기준선이다. [RC10 클린 PC 검수](01_개발문서/07_검증/427_알원_알시십_클린피시_수신과_수용.md) [B0 기준선](01_개발문서/07_검증/430_알원_비제로_기준선_확정.md)

## 설치한 Studio에서 첫 프로젝트 열기

1. **파일 > 새 프로젝트**를 선택하거나 기존 프로젝트를 연다. 대역 목표, 기판과 적층, 도체와 급전을 확인하고 저장한다. 재료의 출처와 미정 물성은 다음 세션에서 다시 확인할 수 있다. [목표와 형상 선택](01_개발문서/04_화면설계/10_목표와_형상템플릿_화면.md) [기판과 적층 선택](01_개발문서/04_화면설계/11_제조업체와_적층선택_화면.md)
2. **해석**에서 입력을 검사한다. 누락된 물성이나 급전 연결이 표시되면 해당 입력을 보완한다. 실행이 완료되면 **이 해석의 결과 열기**로 이동한다. 새 작업을 취소한 뒤에도 보존한 원본은 **이전 해석 결과 열기**로 볼 수 있다. [해석과 결과 조회](01_개발문서/05_기능설계/04_해석결과/README.md)
3. **출력**에서 같은 설계 개정의 도면을 미리 보고 파일을 생성한다. 다른 PC에서 편집을 이어가려면 프로젝트 보존 묶음을 만들고 누락 목록을 확인한다. [도면 검수](01_개발문서/04_화면설계/24_기술도면과_스텝검수_화면.md) [보존 묶음과 복원](01_개발문서/04_화면설계/28_보존묶음_복원_화면.md)

## 개발과 재현

- **제품을 다시 만들 때**는 데이터 모델, 서비스 통신, 화면, 해석기, 출력 순으로 계약과 합격 예제를 따라간다. [제품 재현 안내](01_개발문서/03_제품_재현_안내.md)
- **기존 제품을 빌드할 때**는 Windows에서 wxWidgets 편집기와 Python 서비스를 실행한다. [개발 명령](Code/README.md#실행) [기존 GUI 빌드](Code/ui/wxwidgets/README.md)
- **리팩토링을 이어갈 때**는 `main`에서 독립 시제품을 연다. 현재 첫 작업은 Windows 본창과 분리 창에서 실제 한글 입력, 키보드 이동과 내레이터 사용을 검증하는 것이다. [새 채팅 인계](01_개발문서/09_개발계획/08_새채팅_개발인계.md) [시제품 실행](Code/ui/prototype/README.md) [이식 순서](01_개발문서/09_개발계획/07_현행버전_완료후_리팩토링.md)
- **근거를 찾을 때**는 요구사항과 기능 계약에서 화면, 시험, 승인 원문으로 이동한다. 제조사 원문과 당시 실행 결과에는 별도 출처가 있다. [개발 문서](01_개발문서/README.md) [참고자료](00_참고자료/README.md)
