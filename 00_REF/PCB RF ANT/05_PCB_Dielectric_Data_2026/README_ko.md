# PCB 유전율과 적층 자료

수집/정리 기준일: 2026-11-11.

먼저 [전체 자료 안내 엑셀](Excel/00_전체_자료_안내.xlsx)을 연다. 회사별 엑셀은 `Excel/`에 있고, 원문 검색은 [HTML 안내](START_HERE_ko.html)를 사용한다.

- [자료 사용 안내](docs/자료_사용_안내.md): 폴더, 단위, 조건 선택과 내보내기.
- [자료 검토 결과](docs/자료_검토_결과.md): 확인한 범위, 오류/공백, 정리 내역.
- [TraceWave Studio 연결 설계](../../../Code/docs/pcb_material_catalog.md): 사용자 직접 입력, 소재 선택, 제조업체 적층 선택과 현재 구현의 경계.

57,340개 조건별 관측, 36개 회사와 일반 재료 참고 자료 1개 그룹, 1,756개 출처 기록을 보존했다. 새 엑셀은 전체 안내 1개와 회사/참고 자료별 37개로 총 38개다. 행 수는 고유 소재나 독립 측정 수가 아니다. 공식 자료에 값이 있어도 실제 제조 조건과 해석 대역에 맞는지 확인해야 한다.

사람이 보는 엑셀과 프로그램용 JSONL을 분리했다. 원문 PDF/HTML의 바이트는 보존하면서 파일명을 회사와 소재/용도 중심으로 바꿨다. 중복 저장한 데이터 사본은 복구 폴더로 옮겼고 관측 수치는 삭제하지 않았다.

물성 미정값을 0으로 채우거나 다른 시험 조건의 값을 합치지 않는다. 개별 층 두께가 미정인 적층은 그 이유를 표시하며, 제조업체 선택만으로 형상/해석에 필요한 모든 입력이 완비되었다고 간주하지 않는다.
