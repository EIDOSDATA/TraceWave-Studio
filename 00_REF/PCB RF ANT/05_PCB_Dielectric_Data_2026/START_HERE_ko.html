2. 유전율은 필요합니다. 임피던스는 형상과 함께 계산합니다.

RF PCB의 전송선 임피던스를 맞추려면 유전율이 핵심 입력입니다. 통상 제조 조건에 맞는 Dk를 선택하고, 유전체 두께·선폭·간격·동박 두께를 조절하여 목표 임피던스를 계산합니다. 소재의 유전율을 먼저 임의 계산하여 정하는 과정과는 구분해야 합니다. 측정한 위상·지연·공진 특성에서 유전율을 역추정하는 경우에는 실제 단면 치수와 측정법까지 함께 필요합니다.

전송선 관계
Z0 = sqrt((R + jωL) / (G + jωC))
손실이 작을 때는 Z0 ≈ sqrt(L/C)입니다. 유전체는 C와 전파 속도에 영향을 주며, 선폭·층간 거리·동박·주변 도체도 L과 C를 바꿉니다. 따라서 Dk 하나만으로 50 Ω 선폭을 정할 수 없습니다.

FR-4라는 이름에 고정된 Dk 하나를 붙이지 마십시오.

같은 재료 등급에서도 유리섬유 종류와 직조, 수지 함량, 적층 구성, 주파수에 따라 공개값이 다릅니다. Polar는 데이터시트 대표값과 구성별 라이브러리 값의 차이를 glass/resin 비율로 설명하며, prepreg는 압착 중 수지 흐름이 생길 수 있다고 명시합니다. 이 자료집이 제품별 한 줄이 아니라 조건별 여러 행으로 구성된 이유입니다. [Polar AP554]

전송선 εeff공기·기판·솔더마스크 등에 분포한 전계를 반영한 전송선의 유효 유전율입니다. microstrip의 εeff를 소재 εr 입력란에 그대로 넣지 마십시오.

실무 적용 순서

  1. 제조 업체와 적용할 stackup을 선택합니다. 소재명뿐 아니라 사용 층, core/prepreg, 동박, 압착 조건을 맞춥니다.
  2. 실제 유전체 두께를 확인합니다. 동박 포함 core 두께와 유전체 간격은 다릅니다. 여러 prepreg ply의 합계 두께를 각 ply에 중복 입력하지 않습니다.
  3. 제품 등급, glass/RC, 주파수와 시험법을 필터링합니다. 원문이 해당 조건을 밝히지 않으면 제조사의 선택 적층 파라미터와 실제 공급 조건을 확인합니다.
  4. 시뮬레이터의 모델 의미와 맞춥니다. isotropic/tensor, bulk Dk/Design Dk, 주파수 분산, 동박 거칠기 모델을 일관되게 사용합니다.
  5. 선폭·간격·두께로 목표 임피던스를 계산합니다. microstrip, stripline, coplanar, 차동선에 맞는 구조를 사용하고 솔더마스크와 주변 도체를 포함합니다.
  6. 주요 공정 편차를 함께 스윕합니다. Dk뿐 아니라 압착 두께, 에칭 선폭, 도금 동박, 거칠기 변화가 결과에 미치는 영향을 봅니다.
  7. 제조 coupon/실측과 비교합니다. TDR 임피던스와 실제 단면 치수, 필요하면 VNA 위상·삽입손실로 모델의 적용성을 확인합니다.

주파수 한 점의 Dk/Df만으로 광대역 분산 모델 전체가 결정되지는 않습니다. 서로 다른 시험법·구성·개정판의 값을 연결해 가상의 sweep을 만들지 않았습니다. 이 패키지는 공개 측정/설계 파라미터와 원문을 제공하며, HFSS·CST·ADS·Altium 등 각 도구의 재료 모델 설정은 사용 목적에 맞게 선택해야 합니다.

4. 확보 범위와 남아 있는 공백

이 자료집은 확인한 공개 제품 목록, 기술자료 링크, PCB 제조사의 공개 적층/계산기 범위를 폭넓게 수집한 결과입니다. 전 세계 모든 업체, 모든 언어, 모든 과거 개정판, 문의 후 제공하는 문서까지 완전히 수집했다는 뜻은 아닙니다. 원문을 확보한 범위와 수치로 정리한 범위도 다릅니다. PDF에는 가공 조건·비유전율 물성·그래프가 더 들어 있습니다.

원문에서 실제 발견한 주의사항

  • Panasonic R-1755E 일부 두께는 동박 포함입니다. Shengyi SP168GN은 mm 표기와 mil 수치의 단위가 모순되어 thickness_mm를 비웠습니다.
  • AGC Meteorwave 8000의 한 페이지 주파수 열은 40 GHz가 중복 인쇄되어 있습니다. 다른 페이지를 따라 80 GHz라고 임의 교정하지 않았습니다.
  • PCBWay에서 여러 prepreg ply가 공유하는 압착 후 두께는 group thickness로 남겼습니다. 999개 해당 행의 개별 두께를 추정하지 않았습니다.
  • Rogers 일부 공식 선택표와 개별 TDS, JLC 현재/과거 페이지, Fineline HTML/PDF 사이에 값 또는 조건 차이가 있어 출처별로 유지했습니다.
  • Resonac 매뉴얼의 merged-cell과 각주를 독립 대조해 누락 주파수를 복구했습니다. 일반표와 상세표의 범위를 하나로 합치지 않았습니다.
  • JLC API의 226개 PP 행은 원문 조정 두께가 −0.0185 mm입니다. 개별 층의 물리 두께로 사용할 수 없어 thickness_mm를 비우고 source_thickness_mm와 별도 감사표에 보존했습니다. 0.05 mm의 조정 전 값을 임의로 대체 입력하지 않았습니다.
  • JLC 공개 API 응답에서는 비기술적인 작성자/수정자 직원 필드 4개를 제거하고 모든 기술 필드를 보존한 기술 스냅샷을 제공합니다. Copper 행의 Dk placeholder는 유전체 물성으로 추출하지 않았습니다.

출처 표의 archived 여부는 파일/페이지를 보관했다는 의미입니다. 해당 페이지가 원하는 TDS 전체를 포함하는지는 payload_note와 download_status를 확인하십시오. URL의 업로드 연도와 문서 내부 개정일은 같지 않을 수 있습니다.
