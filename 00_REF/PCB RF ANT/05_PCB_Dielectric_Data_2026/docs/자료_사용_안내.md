# 자료 사용 안내

## 먼저 열 파일

1. `Excel/00_전체_자료_안내.xlsx`에서 회사, 소재명, 출처와 검토 사항을 찾는다.
2. `Excel/소재업체/` 또는 `Excel/PCB제작업체/`에서 회사별 엑셀을 연다. 일반 재료 참고값은 별도 참고 자료로 구분한다.
3. 회사별 `조건별 자료`에서 소재명, core/prepreg, 주파수와 두께를 필터링한다. 빈칸과 검토 사유를 함께 읽는다.
4. 수치를 채택하기 전에 출처 ID/URL과 원문 위치를 확인한다. 동박과 전체 적층은 제작업체의 적층 원자료도 확인한다.

회사별 엑셀은 사람이 읽는 보기다. 정규화 자료의 기준은 `data/observations/index.json` 및 그 목록의 JSONL이다. 엑셀을 수정해도 프로그램용 데이터에 자동 반영되지 않는다. 개별 사용자 프로젝트의 수정값과 공개 자료의 원본 값도 구분한다.

## 어떤 값을 골라야 하는가

| 알고 있는 정보 | 다음 확인 |
| --- | --- |
| PCB 제조업체와 주문 적층 ID | 서비스, 공칭 두께, 동박 옵션, 실제 층 순서, 원자재 구성, 개정 |
| 소재 제조사와 제품명 | core/prepreg, 직물과 수지 함량, 두께, 시험 주파수/방법/방향 |
| FR-4라는 분류만 있음 | 실제 소재/제조 조건을 추가로 확보하거나 사용자 가정을 명시 |
| 두께/물성을 직접 입력하려 함 | 원문 값/사용자 값/추정값의 구분과 적용 대역/단위 기록 |

Dk는 상대 유전율, Df는 손실탄젠트다. 둘은 무차원이며 frequency_ghz는 GHz, thickness_mm는 mm다. GHz와 MHz, mm와 mil, 동박 oz와 완성 두께를 같은 단위로 오인하지 않는다.

Process Dk, Design Dk, 전송선의 effective permittivity는 다른 개념이다. 서로 다른 주파수나 시험법의 Dk/Df를 하나의 측정 쌍으로 합치지 않는다. 범위만 있는 값을 평균내거나 빈 손실값을 0으로 채우지 않는다.

## 파일과 폴더

| 위치 | 역할 |
| --- | --- |
| `Excel/` | 회사별 자료, 전체 안내, 제작업체 적층 원자료의 사람용 보기 |
| `originals/회사/` | 이름을 정리한 공식 PDF/HTML/ZIP/도면. 원본 내용 보존 |
| `data/observations/` | 원래 관측 ID와 타입을 보존한 업체별 JSONL |
| `data/fabricator_native_metadata/` | 동박/PP/core를 포함하는 제조업체 원시 적층 기술 데이터 |
| `data/extraction_audit/` | 표 추출/전사 과정의 근거와 원문 셀 |
| `catalog/` | 출처, 제품, 필드 사전, 파일명 변경표, 검토 조건, ZIP 내부 색인 |
| `search_text/회사/` | 회사/소재/문서명이 보이는 PDF 검색용 텍스트. 표 배치/그림의 의미는 원본과 대조 |
| `docs/` | 이번 검토 결과와 상세 수집 메모 |
| `audit/collection/` | 수집 당시의 색인/검사 이력. 현재 경로 안내로 사용하지 않음 |
| `audit/current/` | 이번 전수 검사, 정리/변경/값 보존 근거 |
| `scripts/` | 무결성 검사, 검토 색인 재생성, 선택 관측 내보내기 |

원본 이름은 회사, 소재 또는 자료 범위, 문서 종류, source ID 순서다. 길이 제한 때문에 일부 제목은 줄였으며 전체 제목/URL은 출처 색인에 남긴다. 여러 제품을 담은 자료를 임의의 한 소재로 이름 붙이지 않았다.

## 필요한 데이터 내보내기

자료 폴더에서 Python 3으로 실행한다. 운영 프로그램을 실행하는 명령이 아니라 참조 자료를 검색하는 도구다.

```powershell
python -B scripts/filter_records.py --manufacturer Rogers --product RO4350B --frequency-ghz 10 --output exports/RO4350B_10GHz.csv
python -B scripts/filter_records.py --manufacturer JLCPCB --output exports/JLCPCB_공개관측.csv
python -B scripts/filter_records.py --review-flag invalid_nonpositive_source_ply_value --output exports/개별두께_확인필요.jsonl
python -B scripts/verify_package.py
python -B scripts/build_review_index.py
```

필터가 반환한 행은 해석 적합 판정이 아니다. 주파수 범위를 포함시키는 옵션도 원문 구간을 검색하는 기능이며 보간 기능이 아니다. 빈 CSV 칸은 미정이고, JSONL은 원래 null과 미제공 키까지 보존한다.

엑셀/CSV에서 제품 코드, glass style, 적층 ID는 텍스트로 읽는다. `106`, `1080`, `2116` 같은 glass style을 자동 숫자 변환한 뒤 다른 코드로 다시 저장하지 않는다. 출처와 미정값을 보존하려면 데이터 편집용 입력과 공개 원본을 분리한다.

## 복구와 한계

반복 데이터 사본 41개는 자료 폴더에서 제외하고 저장소의 `Code/.local/dielectric-review/removed_reproducible_copies/`에 격리했다. 같은 위치의 `before_cleanup.tar.gz`는 변경 전 데이터/색인/메모의 압축 백업이다. 이 복구 자료는 정리된 배포 묶음이나 프로그램 런타임의 필수 파일이 아니다.

수치가 같은 자료라도 출처나 시험 조건이 다르면 보존했다. PDF 검색 텍스트는 원본과 동일한 품질의 표가 아니며 저텍스트/이미지 페이지의 자동 추출 한계가 있다. 전체 검토 범위와 남은 공백은 [자료 검토 결과](자료_검토_결과.md)를 따른다.
