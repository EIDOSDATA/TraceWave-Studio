# ROOT 수집 범위와 사용 조건

수집 단계의 상세 기술 메모를 보존한 문서다. 아래 수량과 자체 검사는 당시 담당 범위이며 이번 전수 검토는 [자료 검토 결과](자료_검토_결과.md)를 따른다. 파일 경로는 별도 설명이 없으면 자료 묶음 루트 기준이다. 과거 작업용 스크립트명은 실행 이력이며 현재 실행 파일이 아니다.


수집일: 2026-11-11. 이 작업군은 Doosan, EMC, Kingboard, Ventec, TUC, Resonac, MGC, Sumitomo Bakelite, Chukoh, Nitto, Risho, Nanya New Material(Nouya), Peters와 보조 시험법/설계 문서를 다룹니다.

Doosan 전체 CCL 물성표의 1 GHz/10 GHz 및 IPC/SPDR 별 값을 분리했습니다. 2024-09-30 카탈로그를 보존했습니다. 해당 표는 개별 제품의 모든 유리섬유/수지 함량 구성을 뜻하지 않습니다.

Kingboard는 공식 카테고리에서 연결된 기술자료, Line-up, Processing Guide를 내려받았습니다. Line-up의 core/prepreg, RC, glass, 두께, 1/2/5/10 GHz와 허용차를 분리했습니다. mm와 mil이 반올림되어 다른 경우 원문의 mm를 유지했습니다. 2025 업로드 URL이 2025 문서 개정일을 뜻하지는 않습니다. 일반 데이터시트 중 안정적으로 확인 가능한 전기물성 행도 추출했습니다. 그래프와 복잡한 일반표/종이, CEM 원문은 모두 PDF에 남아 있으며 전체가 정규화된 것은 아닙니다.

Ventec는 제품 목록, 실제 HTML 데이터시트, 원본 PDF와 공정 가이드를 보존했습니다. HTML rowspan/colspan을 복원해 여러 제품 variant, 방법, 주파수, Typical Value를 분리했습니다. Specification 열을 typical 값으로 오인하지 않았습니다. Dk +/- 허용차 및 core/prepreg 구성표를 보존했습니다. 웹 표와 원본 PDF의 각주/리비전이 다르면 사용자가 적용 조건을 확인해야 합니다.

TUC는 공개 제품 페이지의 대표 Dk/Df를 추출했습니다. 상세 Dk/Df, processing 다운로드가 회원 전용 또는 redirect 응답인 항목은 파일을 확보한 것처럼 표시하지 않았습니다. 동일 제품이 여러 카테고리에 노출되는 경우 서로 다른 원문 URL의 관측이 남아 있을 수 있습니다.

Resonac 65쪽 매뉴얼은 파일 경로가 2025년이어도 내용 기준일은 2023년 10월입니다. 일반표와 상세표를 모두 대조했으며 범위는 dk_min/dk_max 및 df_min/df_max에 보존했습니다. 중간값을 만들지 않았습니다. *1 cavity 각주, 세로/가로 병합 셀 및 20/36/50/60 GHz를 독립 QA로 복구했습니다. 두께 선택지가 여러 개인 경우 thickness_choices_mm를 확인하십시오. 원문에 IEC-62610처럼 인쇄된 식별자는 임의 교정하지 않고 reference_standard로 보존했습니다.

Chukoh 제품 치수표의 Df는 상한(<)인 경우가 있습니다. 주파수가 표에 없으면 null로 두었습니다. Nitto는 다공성 polyimide 제품의 10 GHz SPDR 값이며 일반 polyimide 전체를 대표하지 않습니다. Sumitomo는 주파수와 습도/침수 conditioning을 분리했습니다. Risho CS-3396은 같은 재료라도 방법에 따라 Dk가 9.5, 10.2, 11.3, 13.2로 달라지는 원문 사례를 각기 보존했습니다. 서로 다른 방법값을 평균내지 마십시오.

Peters는 공개 solder-resist 기술보고서 PDF와 공개 수치를 보존했습니다. Elpemer 2467의 Dk 1 MHz 값과 Df 1-100 MHz 구간 값은 별도 행입니다. SD 2463 FLEX-HF는 현재 원문 3/10 GHz 수치를 보존했습니다. Taiyo 현행 사이트는 제품 설명은 공개하지만 TDS는 요청 폼을 제공하므로 문의 전송 없이 그 상태를 기록했습니다.

Nan Ya Plastics(대만), Qnity/옛 DuPont의 일부 PDF, CoorsTek 페이지 등은 직접 원문 접근이 실패했습니다. URL과 실패 기록이 catalog에 있습니다. 중국 Nanya New Material(Nouya)는 대만 Nan Ya Plastics와 다른 회사입니다. 두 회사를 병합하면 안 됩니다.

원문 PDF/HTML은 정규화 표보다 더 많은 비유전율 물성, 가공 조건, 그래프를 포함합니다. 수치화하지 못한 항목은 원문을 확인하십시오. 원문 그래프를 임의로 수치 보간하거나 도해를 측정 데이터로 변환하지 않았습니다. 이 컬렉션은 확인한 공개 카탈로그/연결 문서의 수집본이며, 전 세계, 전 개정판, 비공개 제조 조건의 완전성을 보증하지 않습니다.

패키지 경로 안내: 수집 단계의 파일 경로는 catalog/file_path_map.csv에서 최종 경로와 대조할 수 있습니다. 모든 최종 수치 행은 data/observations/의 JSONL과 회사별 Excel, 모든 출처는 catalog/sources.csv 및 .json에 통합되어 있습니다.
