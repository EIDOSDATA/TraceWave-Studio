# PCB 재료와 제조업체 적층 카탈로그 연결 설계

작성일: 2026-11-11 KST. 상태: 자료 정리에 따른 후속 구현 설계. 이 문서의 카탈로그 검색, 가져오기 및 선택 UI는 아직 구현하지 않았다. 승인 기준선 RFAD-D0-3.4의 사용자 물성 입력 원칙을 구체화하며, 승인 원본이나 기존 검증 결과를 변경하지 않는다.

## 목적과 권장 방향

사용자가 기판 외형, 적층과 물성을 직접 입력하거나, 제조업체의 특정 서비스/적층을 선택하여 프로젝트의 시작 입력으로 복사하도록 한다. 소재만 먼저 선택해 직접 적층을 구성하는 경로도 제공한다. 세 경로 모두 동일한 프로젝트 명령, 저장, 스냅샷, CAD 및 solver 계획을 사용한다.

제조업체 선택만으로 유전율, 손실, 모든 치수와 제조 가능성이 확정되지는 않는다. 제공된 값만 채우고 미정 조건은 남긴다. 치수가 완비되면 기판과 적층 형상을 만들 수 있고, 해석에 필요한 물성과 해당 profile의 지원 조건까지 완비되어야 EM 계산을 시작한다. 기판을 선택해도 안테나 패턴이나 접지면을 자동 생성하거나 목표 주파수에 자동 정합시키지 않는다.

자료 원본과 정리 결과는 [PCB 유전율 자료 묶음](../../00_REF/PCB%20RF%20ANT/05_PCB_Dielectric_Data_2026/)을 따른다. 원본 자료의 추출 상태와 프로그램의 해석 지원 여부는 별도 판정이다.

이번 정리의 57,340개 관측은 업체별 JSONL 37개에 원래 ID와 타입을 보존하고, 회사별 엑셀과 전체 안내를 사람용 보기로 제공한다. 프로그램은 엑셀 파일명이나 셀 위치를 계약으로 삼지 않고 `data/observations/index.json`의 버전/해시와 안정 ID를 읽는 가져오기 단계를 둔다. 전체 JSON/CSV 중복본을 프로그램에 내장하지 않는다. 상세 공백과 정리 근거는 [자료 검토 결과](../../00_REF/PCB%20RF%20ANT/05_PCB_Dielectric_Data_2026/docs/자료_검토_결과.md)에 있다.

| 항목 | 현재 구현 | 추가할 기능 |

| 적층 | `stackup`의 역할, 순서, z_min, 실제 두께, 재료 참조 | 제조업체 적층 초안, 두께 기준과 공차, 층별 완성 상태 매핑 |
| 외형 | 직사각형과 원형, 사용자 치수 | 카탈로그 적용 전후 외형 유지 및 제조 제약 검토 |

| PCB EM | 등방성 상수, 유전체와 외측 동박, 최대 8개 물리 층, 단일 포트 | 카탈로그 입력과 capability 검사의 연결 |
| 미지원 물리 | 내부 동박, 마스크/접착층, 분산/이방성 및 다중 포트는 현재 PCB profile에서 미지원 | 명시적 별도 구현과 검증 후 지원 범위 확대 |

현재 소스 계약은 [설계 데이터](design_data.md), [CAD](cad_contract.md), [PCB solver](pcb_solver_contract.md)에 있다. 4층 또는 8층 제조업체 적층을 검색할 수 있다는 사실을 해당 적층의 RF 해석 지원으로 표시하지 않는다. 저장 가능한 도메인 역할과 CAD/EM adapter가 소비 가능한 역할도 구분한다.

## 업체와 자료의 의미

| 개체 | 의미 | 선택 결과 |
| --- | --- | --- |
| 소재 제조사 | Rogers, Isola 등 laminate/prepreg/foil/coating 제조사 | 제품과 구성별 물성 후보 |
| PCB 제조업체 | JLCPCB, PCBWay, OSH Park 등 기판 제작 업체/서비스 | 해당 업체가 공개한 적층/공정 후보 |
| 제품 구성 | 제품명, core/prepreg, 직물, 수지 함량, ply, 경화 두께, 제조 장소 | 같은 제품 내 다른 조건을 구별하는 키 |
| 제조업체 적층 | 서비스, 주문 옵션, 적층 ID/개정, 층 순서와 실제 두께 | 특정 제조 조건의 프로젝트 초안 |
| 물성 관측 | 값과 종류, 주파수/방향/시험법/온도/conditioning, 출처 위치 | 해석 모델 선택의 근거 |

`FR-4`는 분류이며 하나의 물성값이나 단일 제품 ID가 아니다. 제조업체가 같은 재료 계열의 대체품을 사용할 수 있는 경우 공개 보증과 실제 주문 조건을 구분한다. 이름만 비슷한 업체도 병합하지 않는다. 예를 들어 대만 Nan Ya Plastics와 중국 Nanya New Material/NOUYA는 별도 조직이다.

제조업체 공개 계산기의 Dk는 공급사 원재료 시험 Dk와 다른 종류의 값일 수 있다. JLCPCB는 공개 적층의 PP 두께가 압착 후 값이며 Dk는 제조 상황을 반영한 값이라고 설명한다. 따라서 카탈로그에는 `fabricator_calculator`와 `material_test`를 분리해 보존한다. [JLCPCB 공식 적층 설명](https://jlcpcb.com/help/article/multi-layer-pcb-standard-laminated-structures)

## 사용자 흐름

1. `기판 설정`에서 `직접 입력`, `제조업체 적층`, `소재 자료` 중 경로를 선택한다. 기존 프로젝트의 외형과 패턴은 보존하는 것이 기본이다.
2. 제조업체 경로는 업체/서비스, 동박 층수, 완성 두께 목표, 내외층 동박 옵션, 적층 ID/개정 순서로 후보를 줄인다. 공개 자료에 없는 옵션 조합은 만들어 내지 않는다.
3. 층별 표에서 유전체/동박, core/prepreg, 압착 후 두께, Dk/Df 조건과 미정 항목을 확인한다. 총 두께와 포함 범위, 원문 링크, 검색 가능 여부와 현재 해석 지원 여부를 함께 표시한다.
4. 물성마다 실제 사용할 관측 또는 사용자 가정을 선택한다. 다른 주파수의 Dk/Df를 하나의 측정 쌍으로 묶지 않는다. 목표 대역을 입력하면 맞는 조건을 먼저 보여 주되 가장 가까운 주파수를 자동 채택하지 않는다.
5. `적용 미리보기`에서 기존 재료/층/패턴/포트에 대한 변경, 미정값, 미지원 조건, 사용자 수정 항목을 확인한다.
6. 사용자가 적용하면 프로젝트 소유의 재료와 적층 사본을 원자적으로 생성/변경한다. 자료 라이브러리 갱신이 기존 프로젝트를 자동 변경하지 않는다.
7. 치수가 완비된 지원 범위의 입력은 2D/3D 및 STEP으로 확인한다. 해석 계획은 별도 검사를 통과해야 실행한다.

직접 입력은 업체를 강제하지 않는다. 제조업체 자료에서 시작한 후 두께나 물성을 수정하면 `사용자 수정 적층`으로 표시하고 원본 적층과의 차이를 남긴다. 사용자의 수정값을 제조업체가 제공하거나 보증한 값으로 표시하지 않는다.

## Dk/Df 선택 규칙

| 자료 상황 | 가져오기 규칙 |
| --- | --- |
| Dk와 Df의 시험 주파수/방법/구성이 다름 | 각 물성에 독립 조건과 source record를 유지 |
| Process Dk와 Design Dk가 병기됨 | 별도 후보로 표시. 둘의 평균이나 자동 변환 금지 |
| Effective permittivity | 회로 구조에 대한 유효값으로 표시. 벌크 재료 epsilon_r에 자동 대입 금지 |
| 범위/상한/하한만 제공 | 범위와 연산자를 저장. 중간값이나 경계값을 nominal로 자동 생성하지 않음 |
| Typical과 specification이 다름 | 전형값과 보증/규격 조건을 분리. 원문 열 제목 충돌은 검토 대상으로 보존 |
| 주파수/시험법/방향이 미정 | 미정 유지. 출처가 공식이라는 이유만으로 필드를 추정하지 않음 |
| 두께/RC/glass/conditioning이 다름 | 다른 구성으로 분리. 서로 다른 구성을 분산 곡선으로 이어 붙이지 않음 |
| 상충하는 원문/개정 | 어느 값을 채택할지 사용자가 확인. 미해결 충돌은 자동 입력 대상에서 제외 |
| 이방성/자성 재료 | 원본 tensor/방향/mu를 보존하고 현 등방성 PCB profile에 자동 축약하지 않음 |
| 그래프만 있음 | 그래프가 있다는 사실만 저장. 검증되지 않은 곡선 추출값은 측정 표로 취급하지 않음 |

Rogers는 같은 재료도 시험 구성과 주파수에 따라 Dk가 달라질 수 있으며 Design Dk는 별도 회로 기반 방법으로 얻는다고 설명한다. 프로그램은 이를 선택 근거로 제시하되 모든 openEMS 모델에 Design Dk를 무조건 권장하는 규칙은 두지 않는다. roughness가 포함된 추출값인지 확인하고 추후 거칠기 모델과 이중 반영되지 않도록 한다. [Rogers 공식 Dk 설명](https://www.rogerscorp.com/blog/2018/managing-pcb-materials-dielectric-constant-dk)

단일 주파수에서 측정한 값은 자동으로 넓은 `validity_hz` 구간을 갖지 않는다. 예를 들어 10 MHz의 Dk를 2.4 GHz에 쓰려면 별도 근거나 사용자의 명시적 상수 근사 가정이 필요하다. 실제 OSH Park 2층 서비스 설명도 Dk에 10 MHz 조건을 명시한다. 기판 주문 사양으로 유용한 자료와 2.4 GHz의 완비된 RF 물성 입력은 다르다. [OSH Park 2층 공식 사양](https://docs.oshpark.com/services/two-layer/)

R1의 상수 모델은 선택한 Dk/Df, 별도로 정한 적용 대역, 가정과 변환 근거를 갖는 evaluated model이다. 원문 주파수를 지우거나 사용자가 정한 적용 대역을 제조사 보증 대역으로 저장하지 않는다. 누락 Df를 0으로 채우지 않으며 손실 전도도와 사용자 전도도의 의미가 겹치는지 확인한다. 현재 adapter의 중심 주파수 기반 손실 변환과 대역비 제한은 기존 [PCB solver 계약](pcb_solver_contract.md)을 그대로 따른다.

## 두께와 형상 생성 규칙

| 항목 | 저장 및 처리 기준 |
| --- | --- |
| 완성 기판 공칭 두께 | 주문 목표/공차 및 마스크/표면처리 포함 여부를 별도 저장 |
| 층별 실제 모델 두께 | CAD/EM의 authoritative 입력. z_min은 정한 기준면과 층 순서에서 계산 |
| Core | copper 포함 laminate 두께인지 dielectric-only 두께인지 구분 |
| Prepreg | 공급 상태 두께와 압착 후 두께를 분리. 여러 ply 합계인 값을 각 ply에 중복 적용하지 않음 |
| 동박 | base foil, finished copper, 도금 추가량을 구분. 원문이 finished이면 도금량을 다시 더하지 않음 |
| oz 표기 | 원문과 내외층/공정 조건을 보존. 모든 1 oz를 무조건 35 um로 고정하지 않음 |
| Via | 완성 구멍, 도금 두께, tool bore와 패드 참조를 별도로 유지 |
| 마스크 | 기판 위/트레이스 위/사이 두께와 coverage가 다를 수 있으므로 단일 평면 층으로 자동 대체하지 않음 |
| 표면처리/실크 | 해당 형상과 물리 영향의 포함 여부를 기록. 완성 두께에서 임의 역산하지 않음 |

`finished_thickness = sum(modeled_layer_thickness)`는 양쪽의 포함 범위가 같고 빈 공간/추가 피복 여부가 확인된 경우에만 비교한다. 공개 공칭 두께와 층별 합계가 다르면 차이를 표시하고 공차 및 정의를 확인한다. 차이를 코어 한 층에 몰아 넣어 맞추지 않는다. 목표 1.0 mm와 양면 동박 각 35 um만으로 실제 코어 0.93 mm를 확정하지 않는다. 사용자가 가정하면 추정값과 해당 두께 convention을 명시한다.

CAD 생성은 선택된 외곽을 실제 층별 두께로 압출하고, 구리는 기존 패턴의 해당 층에만 생성한다. 원형 PCB라면 같은 원형 외곽을 사용하지만 접지 원판을 자동 추가하지 않는다. 유전율 변경만으로 CAD 치수가 바뀌지는 않는다. 사용자가 별도로 임피던스 선폭 합성 또는 안테나 최적화를 실행해야 해당 치수가 변경된다.

층 교체 시 기존 geometry/layer/material/port UUID 참조를 검사한다. 명시적 대응이 없는 층을 임의의 가까운 층에 붙이지 않는다. 새 z 위치가 급전 gap, via span 또는 pad 연결을 바꾸면 미리보기에 표시하고 적용 전에 해결한다. 현재 프로파일이 표현하지 못하는 실제 층을 삭제해서 통과시키지 않는다. 근사 모델은 실제 구조와 구분되는 별도 분석 정의 및 기록을 필요로 한다.

| MaterialProduct | 안정 ID, 제조사 ID, 제품/variant, family, form, 구성 선택지 |
| PropertyObservation | record_id, property, scalar/range/limit, 원문 단위, SI 값, value_type, 각 물성별 조건, 원문 ID/위치 |
| FabricatorStackup | 업체/서비스 ID, stackup ID/개정, 주문 옵션, 층별 구성/완성 두께/공차, 확인일과 가용 상태 |
| SelectionDraft | 선택 조건, 누락/충돌/미지원 목록, 원본 대비 override, 적용 대상 revision, 변경 미리보기 |
| ProjectMaterialSelection | catalog revision/hash, source record 사본, 선택 이유, 사용자 override, evaluated model, 프로젝트 UUID 매핑 |

관측의 조건에는 Dk/Df 각각의 주파수/범위, 시험법, 방향, 온도, 습도/conditioning, specimen 구성과 원문 한정자가 들어간다. 파싱된 수치와 원문 문자열을 함께 보존한다. 원본 파일 중복을 제거해도 source ID/URL/페이지와 대표 파일 매핑은 남겨 출처가 끊기지 않게 한다.

제조업체 원자료에서 층을 가져오는 adapter는 정규화 유전체 관측만으로 동박과 실제 전체 stack을 재구성하지 않는다. JLC Core 항목의 top/bottom conductor 필드, PCBWay 병합 셀의 그룹 경계와 Wurth native 자료의 층/지역 context를 각각 검사한다. Wurth 수집 raw_fields에는 숫자 접두가 붙은 다른 층/지역 필드가 섞인 행이 있으므로 평탄한 key/value 개수를 독립 층 속성으로 취급하지 않는다. 원 native 문서의 명확한 경계에서 다시 파싱하고 기대 단면과 비교한다.

현재 `materials.source_refs`와 `assumptions` 문자열 목록만으로 전체 구조화 출처를 표현했다고 주장하지 않는다. 새 프로젝트 schema 또는 버전이 있는 attachment 계약을 먼저 정의하고 migration/roundtrip 검증을 추가한다. 추출 데이터의 `simulation_ready`, `dk_input_status`, `review_flags`는 자료 검토 메타데이터다. 선택된 solver profile, 해석 대역과 실제 프로젝트 구조를 검사하기 전에는 실행 가능 판정으로 사용하지 않는다.

현재 수집본에는 Df 미기재 29,562행, 점 주파수 미기재 28,800행, 원문 미보관 241행과 개별 층 두께 미정 1,225행이 있다. JLC API의 비양수 ply 두께 226행과 PCBWay의 복수 ply 합계 999행을 사용자에게 사유와 함께 제시한다. 원본의 `review_flags`가 비어 있어도 MAGTREX 555의 상대 투자율처럼 모델과 맞지 않는 필드가 있을 수 있으므로 자료별 검토 규칙과 adapter capability를 함께 검사한다. 숫자 칸이 채워졌다는 이유로 자동 적용하지 않는다.

입력 경로는 `source_default`, `user_entered`, `estimated` 등 기존 Quantity 상태와 연결하되, 이 상태를 측정 검증 합격으로 해석하지 않는다. 누락, 미지원, 상충값도 기존 상태 계약에 맞게 보존한다. 카탈로그 수정은 원본 선택을 덮어쓰지 않고 `새 자료로 비교`를 통해 별도 프로젝트 revision을 만든다. 내보낸 snapshot은 네트워크나 최신 카탈로그 없이도 같은 해석 입력을 재구성할 수 있어야 한다.

## 서비스와 wxWidgets 구조

GUI는 현재 View + Presentation Model + Service Gateway 패턴을 유지한다. 검색/필터/적용 가능 판정과 단위 변환은 서비스가 맡고 GUI는 목록/필터/층 표/단면 미리보기와 사용자 선택을 담당한다. MCP와 EDA adapter도 동일 계약을 호출한다.

권장 모듈은 카탈로그 읽기 저장소, 조건 검색, 관측 검증, 적층 변환, 적용 미리보기, 프로젝트 변경 명령으로 나눈다. `StudioFrame`에 자료 파서나 제조사별 예외를 추가하지 않는다. 업체별 원문 파서는 오프라인 데이터 빌드 단계에 두고 런타임은 검토된 중립 모델만 소비한다.

검색/상세/미리보기/적용은 서로 다른 작업으로 정의한다. 명칭은 후속 API 계약에서 확정한다. 적용은 기존 `expected_revision`과 `command_id` 원칙을 사용하고 프로젝트 재료/층/참조를 한 번에 검증한다. 중간 실패 시 일부 층만 변경되지 않아야 하며 한 번의 undo로 복원해야 한다. 현재 개별 `material.set`/`layer.set`를 GUI가 순차 호출하는 것만으로 원자적 가져오기가 구현되었다고 간주하지 않는다.

카탈로그 전체 JSON/PDF/HTML을 GUI 시작 시 메모리에 올리지 않는다. 오프라인 자료 빌드에서 인덱스를 생성하고 서비스가 검색 결과와 선택 행만 페이지 단위로 읽는 방식이 적합하다. 첫 구현에서는 읽기 전용 SQLite 인덱스를 권장하며 선택된 자료의 작은 사본만 프로젝트에 저장한다. 이 인덱스는 원문을 대체하는 원본이 아닌 재생성 가능한 파생물이다. native CAD/openEMS import를 카탈로그 검색 경로에 추가하지 않는다.

자료가 없거나 검색이 실패해도 직접 입력과 기존 프로젝트 열기는 동작해야 한다. 원문 열기는 사용자가 선택했을 때 수행하고, 저장된 HTML을 프로그램 권한으로 실행하거나 원문 스크립트를 자동 평가하지 않는다.

## 자료 배포와 갱신

연구용으로 수집한 PDF/HTML과 제품에 재배포할 카탈로그는 구분한다. 파일이 공개 URL에서 다운로드된다는 사실만으로 앱 번들 또는 공개 저장소에 원문 전체를 재배포할 권리가 확인된 것은 아니다. `rights_status`를 별도 관리하고, 초기 내부 검증에는 로컬 자료 경로/해시 참조를 사용한다. 외부 배포에 포함할 메타데이터/원문 범위는 확인된 라이선스와 허용 범위에 맞춘다. 이 문서는 특정 자료의 재배포 허가를 확정하지 않는다.

수집일과 원문 개정일, 제조업체 서비스 확인일을 분리한다. 현재 공개 적층과 주문 가능 여부는 바뀔 수 있으므로 발주 전 업체의 해당 옵션을 다시 확인해야 한다. 과거 프로젝트는 당시 선택된 출처/값/가정으로 재현하며 업데이트를 자동 적용하지 않는다.

## 다음 착수 범위

첫 구현 묶음은 중립 카탈로그 계약, 오프라인 변환과 읽기 전용 검색 서비스다. 소재 제품, 조건별 물성 관측, 제조업체 적층을 구분하고 JSONL 및 검증된 원시 적층 자료에서 SQLite 검색 인덱스를 만든다. 업체/제품/적층/주파수별 검색과 페이지 단위 상세 조회를 제공한다. 파일명이나 엑셀 셀 위치를 안정 ID로 사용하지 않는다.

직접 입력의 기반인 재료 Dk/Df/전도도/유효 대역, 층 두께와 위치/재료 참조, 개별 GUI 편집, 저장/undo/redo/스냅샷은 이미 있다. 이를 유지하면서 자료 검색, 선택 근거와 사용자 수정값의 구분, 일괄 적층 적용 및 미리보기를 추가한다. 첫 묶음에서는 검색 인덱스가 프로젝트를 자동 변경하지 않는다.

첫 묶음의 완료 기준은 다음과 같다.

- 57,340개 관측의 ID, 출처, 원래 타입과 자료 버전/해시를 추적한다. 변환 후 개체 수와 원자료 행수를 별도로 기록한다.
- Df 누락, Dk/Df의 서로 다른 주파수, 범위/상한, JLC 비양수 두께, PCBWay 복수 ply 합계, Wurth 원시 필드의 층 경계 문제를 회귀 사례로 검사한다.
- 전체 자료에서 조건 검색, 상세 조회와 페이지 구분을 검증하고 메모리 사용량과 응답 시간을 측정한다. 검색 성공을 solver 실행 가능 판정으로 취급하지 않는다.
- 카탈로그가 없거나 잘못된 경우에도 기존 프로젝트 열기와 직접 입력을 사용할 수 있다.

이후 구조화된 프로젝트 출처와 원자적 적용 명령을 먼저 완성하고, wxWidgets의 기판 설정과 적용 미리보기를 연결한다. 명확한 치수의 2층 사례부터 CAD/solver까지 검증한 뒤 제조업체와 물리 모델 범위를 넓힌다.

## 구현 순서와 완료 기준

1. 정리 자료의 schema와 source ID를 고정하고 모든 행의 참조/범위/상충 상태를 검사한다. 물성 관측과 제조업체 적층을 분리하는 import fixture를 만든다.
2. 구조화된 프로젝트 선택 provenance와 원자적 적층 적용 계약을 정의한다. 저장/읽기/undo/redo/스냅샷 및 구버전 migration을 먼저 검증한다.
3. 직접 입력을 유지하며 읽기 전용 소재/제조업체 검색과 적용 미리보기를 연결한다. 2층의 명확한 치수 사례부터 지원한다.
4. GUI 층 단면과 CAD/solver capability 차이를 표시한다. 제조업체 다층 자료는 조회 가능하되 현재 미지원 모델은 정확한 사유와 함께 실행을 차단한다.
5. 실제 사용을 결정한 적층과 물성으로 새 IFA snapshot을 만들고 격자/경계/시간 종료 민감도 및 독립 비교를 수행한다. 카탈로그 입력 성공을 RF 정확도 검증으로 세지 않는다.
6. 마스크/내부 동박/분산/이방성/roughness는 각 adapter의 별도 모델과 검증을 추가한 뒤 노출한다. 이후 MCP/EDA 가져오기에도 같은 선택/변환 계약을 사용한다.

필수 회귀 사례는 다음과 같다.

- 제조업체 적층명은 같지만 두께/동박 옵션 또는 개정이 다르면 다른 선택으로 보존한다.
- Dk만 존재하는 행, Df가 다른 주파수인 행, 최대값/범위만 있는 행과 충돌 행은 자동 완비 처리하지 않는다.
- 단일 주파수 관측이 목표 대역 전체를 보증하는 것으로 확장되지 않는다.
- core가 copper 포함인 경우, 압착 전 PP인 경우, 복수 ply 합계인 경우의 이중 계산을 차단한다.
- 사용자 수정값과 출처값, 직접 입력값과 라이브러리값을 저장 후 구분할 수 있다.
- 프로젝트 적용 실패/취소/중복 요청/동시 편집에서 부분 변경이나 중복 재료가 생기지 않는다.
- 자료 업데이트 또는 라이브러리 삭제 후에도 기존 snapshot의 계산 입력을 재현한다.
- 원형/사각 외곽과 기존 패턴 UUID가 유지되고 층 이동에 따른 via/port 연결 변화가 검출된다.
- 미지원 내부 동박/마스크/자성/이방성 입력이 조용히 제거되거나 다른 물성으로 바뀌지 않는다.
- 검색 응답성과 메모리를 실제 데이터 규모로 측정하고 기존 60/30 fps 편집 목표를 방해하지 않는지 확인한다.
