# PCB 제조업체 검색과 적층 선택 화면

작성일: 2026-11-11 KST. 설계 기준선 RFAD-D0-3.4, wxWidgets와 기존 서비스 계약을 사용한다. 유료 GUI 부품은 추가하지 않는다.

## 실행과 진입

```powershell
.\tools\launch_gui.ps1
.\tools\launch_gui.ps1 -Catalog 'C:\자료\catalog.sqlite'
.\tools\launch_gui.ps1 -NoCatalog
```

기본 실행은 존재하는 `Code/.local/pcb-catalog/catalog.sqlite`를 읽기 전용으로 연결한다. 별도 경로는 `-Catalog`, 카탈로그 없이 작업하려면 `-NoCatalog`를 사용한다. 프로젝트를 연 뒤 `설계 > 기판 설정 / 제조업체 자료` 또는 왼쪽 `기판 설정 / 자료 선택` 버튼으로 진입한다. 기존 속성 폼에 적용하지 않은 입력이 있으면 먼저 기존 적용 경로를 수행한다.

층을 실제 프로젝트에 적용하려면 먼저 사각 또는 원형 기판을 생성한다. 기판이 없어도 자료 조회와 후보 검토는 가능하며, 누락된 외형은 미리보기의 적용 차단 사유로 표시한다.

DB가 없거나 손상되어도 직접 입력, 저장, 실행 취소와 다시 실행은 유지한다. 검색 오류를 표시하되 임의의 FR4 물성이나 구리 두께로 대체하지 않는다. 기존 층/재료 속성에서 편집하는 기능도 계속 사용할 수 있다.

## 사용 순서

1. `자료 검색`: 제조업체 적층 또는 물성 관측을 선택하고 업체와 검색어로 조회한다. 결과는 페이지 단위로 가져온다. 상세를 확인한 뒤 `선택 적층과 물성 제안 보기`를 누르면 같은 층에 대응하는 두께와 Dk/Df 제안을 함께 불러온다. 업체명은 자료의 발행자 표기를 사용하며 소재 제조사와 PCB 제작사가 같다는 뜻은 아니다.
2. `층과 연결`: 상단의 `선택 적층의 두께와 물성 제안`에서 층별 두께/Dk/Df 상태를 확인한다. 제안은 최대 8행씩 이전/다음 페이지로 이동하며 행을 선택하면 각각의 시험 주파수, 시험법, 방향과 출처를 확인할 수 있다. `선택 제안 사용`은 새 재료를 등록하고 해당 미연결 유전체 층에 연결한다. 프로젝트에 적용하기 전의 폼 변경이며 기존 층 재료나 직접 입력을 덮어쓰지 않는다. 층 순서는 아래에서 위다. 두께의 빈칸은 미정으로 유지하고 변경값에는 이유를 적는다. 기존 패턴/패드/비아가 참조하는 층은 사용자가 명시적으로 대응한다.
3. `재료 물성`: 제안을 수용하면 이 탭에서 값과 근거를 수정할 수 있다. Dk와 Df는 각각 관측 채택, 사용자 입력, 미정 중에서 선택한다. 전도도는 직접 입력 또는 미정이다. 제안의 손실 모델과 이유는 표시하고 보존하며, 사용할 주파수 범위는 사용자가 명시한다. 기존 직접 입력으로 새 재료를 만드는 경로도 유지한다. 출처 주파수가 가깝다는 이유로 다른 관측을 자동 채택하지 않는다.
4. `급전 좌표`: 적층 변경으로 급전 접면이 달라질 때 명시적인 좌표와 이유를 입력한다. 좌표가 매개변수에 연결된 경우 표시 숫자를 수정하면 원래 결합을 대체한다는 점을 검토한다. 좌표를 수정하지 않으면 기존 결합을 보존한다.
5. `변경 미리보기`: 서비스가 만든 후보 단면, 층 두께/z, 변경 개수, 미정값과 차단 사유를 검토한다. 적용할 수 있는 후보만 `검토한 변경 적용`을 누를 수 있다. 입력을 바꾸면 다시 미리보기해야 한다.

단면은 층을 식별하기 위한 도식이며 두께에 비례하지 않는다. 화면은 서비스의 mm 표시값을 사용하며 z 누적이나 물성 계산을 다시 수행하지 않는다. 공칭 완성 두께와 구성 층 합계의 차이를 임의의 코어 두께에 배분하지 않는다.

제안 표시는 `공개값`, `미정`, `후보 충돌`, `근사 입력 필요`, `자동 제안 미지원`을 구분한다. `근사 입력 필요`의 원문 수치/범위는 참고용이며 선택 제안 사용만으로 실제 입력값이 되지 않는다. 해당 재료에서 직접 값과 근사 이유를 입력해야 한다. 실제 JLCPCB/PCBWay 자료의 대응 Df는 미정으로 남으며, 이를 0이나 다른 소재의 대표값으로 채우지 않는다.

미반영 재료 폼이 있으면 제안 수용을 보류한다. 이미 재료가 연결된 층, 이미 등록한 동일 제안은 자동 교체하지 않는다. 기존 수동 두께 변경은 유지한다. 페이지 이동은 재료 폼, 층 연결과 검토한 미리보기를 바꾸지 않으며 늦게 도착한 이전 선택/페이지의 응답은 폐기한다.

## 보존과 실패 처리

적용은 미리보기한 프로젝트 개정과 사양을 고정한 단일 명령이다. 실행 취소/다시 실행도 전체 선택을 한 번에 되돌린다. 출처 사본과 채택 이유는 프로젝트에 보존되어 카탈로그 없이 다시 열어도 남는다. 기판 외형, 패턴과 net은 선택 기능이 자동 생성하거나 변경하지 않는다.

검색 중 창을 닫거나 검색 조건을 바꾸면 과거 응답을 새 선택에 쓰지 않는다. 적용 중에는 중복 적용과 닫기를 제한한다. 연결이 끊겨 적용 결과가 불명확하면 자동으로 재전송하지 않으며 화면을 닫고 프로젝트를 다시 조회해야 한다.

`적용 가능`은 프로젝트에 저장 가능한 초안이라는 뜻이다. 제작 가능, CAD 접촉 검증, RF 정확도와 해석 준비 완료를 승인하는 표시가 아니다. 후보에 미정 두께/물성이 있으면 저장은 가능해도 후속 CAD/EM 입력 검사는 실패할 수 있다.

현재 프로젝트 512 KiB, 고유 출처 근거 합계 128 KiB, 선택 응답 384 KiB와 적층 조회/제안 128 KiB를 제한한다. 초안으로 변환할 수 없는 업체 자료나 제한을 넘는 구성은 사유를 표시하며 축약된 임의 적층을 자동 적용하지 않는다. 모든 공개 자료가 바로 사용할 수 있는 완성 PCB 구성인 것은 아니다.

기존 용량 문제로 거절되던 대표 JLC 4층/PCBWay 4층의 전체 유전체 제안도 적용/저장/이력/재열기를 확인했다. 미정 동박/두께/Df는 그대로 남기므로 저장 성공은 CAD 또는 RF 실행 가능을 뜻하지 않는다. 새 예산과 공유 출처 형식은 [용량 개선과 후속 검증](capacity_and_followup.md)을 따른다.

## 구조와 검증 재현

화면, 위젯 없는 선택 상태, 비동기 서비스 연결을 분리한다. 모듈은 [코드 구조](code_structure.md), API와 출처/적용 의미는 [PCB 선택 계약](pcb_selection_contract.md)을 따른다.

```powershell
cmake --preset windows-release
cmake --build --preset windows-release
ctest --preset windows-release --output-on-failure
$env:PYTHONPATH = 'src'
$env:RFAD_GUI_EXE = (Resolve-Path 'build/windows-release/bin/tracewave_gui.exe').Path
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p test_gui_pcb_selection_process.py -v
```

실제 프로세스 시험은 작은 검증용 카탈로그로 검색/선택/입력/미리보기/적용, 기존 객체 보존, 이력과 재열기를 검사한다. DB 미설정과 지연 응답도 별도 검사한다. fixture 물성과 두께는 UI 시험용이며 실제 제작 기준이 아니다. 전체 자료의 변환/원자 적용 근거는 이전 [선택 검증 기록](../runtime_profiles/pcb-selection.json)에 보존한다. 최신 GUI 검증 수치와 제한은 [개발 상태](development_status.md)를 따른다.

기존 GUI 검증은 적용 중 부모 닫기 보류와 조회 중 부모 종료의 안전한 순서도 검사했다. 실제 전체 DB의 검색/물성/층 적용도 별도 workspace에서 통과했다. 당시 실행 근거와 소스/바이너리는 [기존 GUI 검증 기록](../runtime_profiles/pcb-selection-gui.json)에 보존한다. 이번 두께/Dk/Df 제안의 최종 시험과 소스/바이너리는 [적층 제안 검증 기록](../runtime_profiles/stackup-suggestions.json)을 따른다.

2026-11-11 실제 Windows 창에서 JLC 6층 후보의 제안 15행을 조회하고 이전/다음 페이지, 두께/Dk 공개값과 Df 미정 표시, 출처 상세, 명시적 제안 수용 후 재료 폼을 확인했다. Prepreg 12의 두께 0.112 mm, Dk 4.29는 공개값이고 Df와 모델 적용 대역은 미정으로 유지되었다. 테스트 workspace의 폼만 조작했으며 프로젝트에 적용하지 않고 창을 정상 종료했다. 확인 크기는 주 창 1348 x 854, 대화 상자 1128 x 794이며 다른 DPI/해상도와 성능 검증을 포함하지 않는다.

선택 후 저장한 프로젝트는 기존 STEP/해석 버튼과 같은 공개 API로 실행된다. [카탈로그 PCB 통합 검증](catalog_pcb_integration.md)의 도구는 같은 불변 스냅샷에서 CAD 생성, STEP, openEMS와 결과 재열기를 검사한다. JLC0206 검증 후보는 치수에 근거가 있어 CAD를 완료했지만 미정 손실/전도도/적용 대역 때문에 EM 실행은 차단된다. 검증 도구도 GUI도 이 값을 자동 보충하지 않는다.

## 수렴 연구 보고서 비교

`해석 > 수렴 연구 보고서 비교`에서 완료된 `rfad.ifa-convergence-run/0.1` JSON을 연다. 사례별 격자/공기 여백/종료 조건/주파수와 기존 판정기의 세부 결과를 읽기 전용으로 표시한다. 파일은 최대 2 MiB, 사례는 18개다. 파일에 기록된 결과를 표시하는 기능이며, 원본 작업 자료의 봉인 검증과 재판정은 연구 도구가 수행한다. 여러 결과의 그래프 중첩, 스냅/치수 편집의 추가 개선은 후속 범위다.
