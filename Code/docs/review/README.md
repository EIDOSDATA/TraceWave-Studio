# 문서 정비와 검토 기록

검토일: 2026-11-16 KST. 대상: 현재 개발 설계 문서, 승인 기준선과 참고 자료의 분류/연결.

## 화면설계서 정비

사용자가 제공한 실제 도구/탐색 화면과 `2c88d26` 이후 작업 트리를 대조했다. [화면 설계 폴더](../screen_design/README.md)에 화면별 기능/입출력/이벤트/전환/예외, 이름/선택, 사용성/접근성 및 기능 개발 중 갱신 규칙을 작성했다. 승인 UI-01~24 전체를 화면과 후속 단계에 연결했다.

10개 DrawIO와 같은 정의의 SVG, 렌더 PNG를 생성했다. 로컬 Edge headless에서 한글 글자의 도형 경계 초과를 검사하고 10개 이미지를 직접 검토했다. 이는 문서 그림 검수이며 실제 Studio의 새로운 GUI 시험 또는 DrawIO 앱의 네이티브 재열기 검증이 아니다. 첨부 화면 2개는 원본 바이트를 보존했다.

재현 명령은 [화면 관리](../screen_design/maintenance.md)를 따른다. 제품 코드는 이 문서 작업의 대상이 아니며 기존 스냅/끝점 작업 트리는 별도 유지한다.

## 전체 문서 정비의 경계

현재 문서의 잘못된 구현 설명과 중복 안내를 수정하고 기능/시스템/분석/운영별 탐색을 제공한다. 승인 원문 `01_Docs`와 승인 해시, `00_REF` 원문/추출 및 과거 `runtime_profiles`는 그대로 보존한다. 당시 기록을 현재 구현에 맞춰 소급 변경하지 않는다.

외부 원문 PDF의 전 페이지/수식 재검증, 납품 물성 확인 또는 실제 RF/제조/측정 수용은 문서 정비와 별도다. 파일을 목록에 분류했다는 사실을 전문 내용 검증으로 보고하지 않는다. 문서별 내용 검토와 원문 파일의 구조/연결 검토 수준은 분리 기록한다.
