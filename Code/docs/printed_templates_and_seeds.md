# 추가 문헌 카드와 조건부 초기 길이

기준일: 2026-11-12 KST. 개발 완료 계획 3번 및 연결된 4번의 일부다. 기존 명시 원호/IFA와 [G031 부분 기하](literature_templates.md)의 생성/검토 hash/원자 적용/출처 보존 경로를 확장했다. 전체 보드, 원문 RF 성능 또는 제조/측정 재현 완료를 뜻하지 않는다.

## 1. 원문과 생성 범위

원문 PDF의 텍스트와 그림을 대조했다. `tools/verify_literature_sources.py --printed`는 bytes/hash/페이지 식별을 재확인하며 그림의 치수 해석이나 물리 정확도를 자동 검증하지 않는다. 원문은 저장소 `00_REF/PCB RF ANT/01_RF_Antenna_Vendor_Guides_CAD/Printed_antenna_geometry`에 있다.

| 카드 ID (version 0.1) | 원문 | 생성 범위 |
| --- | --- | --- |
| `literature.g001_nwp008_monopole` | Nordic nWP008, January 2005, p.1-3, sections 2-4/Figure 1 | 전체 길이/폭을 가진 사각 모노폴 도체 1개. 원문 23 mm는 반올림한 초기 추정이며 폭은 1.5 mm |
| `literature.g008_an1088_ifa_62mil` | Silicon Labs AN1088 Rev.0.1, p.3-5, Figures 2.1/2.2, section 3.1 | 원문 접지 경계 위의 수평/단락/급전 사각 가지 3개 |
| `literature.g009_an1088_ifa_08mm` | 같은 AN1088의 0.8 mm 표기 변형 | 같은 부분 기하, 다른 원문 길이/간격 |

nWP008 SHA256: `3d096d85e2a57ce999a8f6c489f6b156b66cc03d5f25512ebb59b3465da7ccb5`.

AN1088 SHA256: `22ee4e51d53b1c73e1a4e58b4b4d5c23bd5a9c81e2e517faf546d8815a24b536`.

AN1088은 inch의 관측값을 정확한 25.4 mm/inch로 환산한다.

| 입력 | 62 mil | 0.8 mm 표기 변형 | 해석 |
| --- | --- | --- | --- |
| `arm_length` | 0.782 in | 0.860 in | 수평 도체 전체 길이 |
| `arm_width` | 0.039 in | 0.039 in | 수평 도체 폭 |
| `short_width` | 0.040 in | 0.040 in | 단락 가지 폭 |
| `feed_width` | 0.040 in | 0.040 in | 급전 가지 폭 |
| `inner_gap` | 0.109 in | 0.115 in | 단락/급전 가지 내부 경계 간격; 중심 간격이 아님 |
| `arm_clearance` | 0.327 in | 0.311 in | 접지 경계에서 수평 도체의 아래 경계까지 |

AN1088 Figure 2.2(b)는 0.8 mm와 총 0.034 inch(0.8636 mm)를 함께 표기한다. 카드 `source_conflicts`에 그대로 보존한다. 두께를 선택/평균하거나 새 적층으로 생성하지 않는다. 원문의 1 inch 보드 최적화, 접지 크기 변화에 따른 정합 재조정, 비아/마스크/안테나 아래 접지 제외 조건도 보존한다.

모노폴 기준점은 아래 단면의 중심이다. IFA 기준점은 단락 가지 왼쪽과 원문 접지 경계의 교점이다. 사용자가 X/Y를 명시하며 원형/사각 보드 밖 경계는 거부한다. 날카로운 사각 경계를 생성하므로 centerline의 round cap으로 전체 길이가 늘어나지 않는다. 실제 매개변수와 표현식을 생성하므로 이후 직접 편집이 가능하다.

전체 보드/접지/적층/keepout, AN1088 접지 경계 아래의 패드/비아/급전 taper와 전송선, 정합 회로/포트/외함은 생성하지 않는다. 생성한 short 역할만으로 실제 접지 연결을 주장하지 않는다. GUI는 `port:null`이며 기존 급전 편집으로 이어간다. 기존 물성, 미정값, 카탈로그 출처와 사용자 수정값은 유지한다.

## 2. 초기식과 적용 범위

G001에서만 `mode="initial_estimate"`를 지원한다. 원호/IFA의 주파수 자동 RF 합성은 미지원이다. 승인 식 EQ-003/EQ-004의 `c0=299792458 m/s`를 사용하며 모든 단위 환산/계산은 Python 서비스가 수행한다.

| `recipe_id` | 계산 | 범위 |
| --- | --- | --- |
| `ideal_quarter_wave` | `L=c0/(4*f)` | 양의 주파수의 이상적 얇은 자유공간 모노폴/이상적 접지 기준. PCB의 지원 대역이나 공진 예측이 아님 |
| `nwp008_base` | `L=0.75*c0/(4*f)` | 원문 2.45 GHz, 1.6 mm FR4, 전형 Dk 4.4, 폭 1.5 mm와 충분한 접지/균일 FR4 가정 |
| `nwp008_trim20` | 위 기준 길이의 `1.2`배 | 충분한 접지/균일 FR4 조건에서 prototype 절단 조정 여유 |
| `nwp008_trim30` | 위 기준 길이의 `1.3`배 | 작은 접지 또는 가장자리 trace의 prototype 절단 조정 여유 |

nWP008은 반올림한 자유공간 파장 122 mm, 기판 파장 92 mm, 초기 길이 23 mm를 제시한다. 서비스의 정확한 c0 산술은 약 22.9433004 mm이며 20%/30% 여유는 약 27.5319604/29.8262905 mm다. 원문 23 mm를 덮어쓰지 않고 `source_rounded_length_mm`와 계산값을 함께 보존한다. 원문 보정은 주파수 2.45 GHz 및 폭 1.5 mm 밖에서 차단하며 일반 FR4나 다른 주파수로 외삽하지 않는다.

초기식 요청은 기존 후보 입력에 `seed:{recipe_id,frequency,assumption}`을 추가하고 `explicit_inputs.length={source:"initial_estimate"}`를 명시한다. frequency는 기존 Quantity 또는 `{value,unit}`이다. 양수/유한값만 허용하고 가정/사유는 비어 있지 않은 512자 이하다. 명시 기하 모드에서는 seed를 거부한다. GUI에서 조건은 사용자 가정으로 읽고 입력하며, 현재 프로젝트 물성/접지/급전의 적합성을 자동 확인하지 않는다. 원문의 Dk/두께를 현재 기판에 주입하지 않는다.

## 3. 계약과 상태 보존

후보 profile은 `rfad.template-candidate/0.2`, 새 카드 schema는 `rfad.template-card/0.3`, 생성기는 `rfad.printed-reference/0.1`이다. 프로젝트 0.3/origin 0.1 및 기존 카드 0.1/0.2의 읽기 의미와 ID/hash는 유지한다. 새 origin record에만 `mode`와 `initial_estimate`를 추가한다.

`rfad.initial-estimate/0.1` 사본은 요청 원문, recipe/조건, 주파수와 추정 길이 Quantity, c0/반올림 원문 길이, 가정 미확인 상태를 보존한다. 생성 길이는 `status="estimated"`다. 재열기는 현재 카드 조회나 원문 PDF 없이 저장 사본의 고정 버전/산술/최초 객체를 재검사한다. 해시를 다시 계산한 잘못된 추정/원문 사본도 거부한다.

| 상태 축 | 새 후보/생성 당시 상태 |
| --- | --- |
| 기하 | `generated_partial`; 원문 사용/수정/추정 치수를 구분 |
| 초기식 | 계산 요청 시 `estimated_seed`, 나머지 `not_performed` |
| 조건 확인 | `conditions_verified=false` |
| 해석 | `not_performed` |
| 수렴 | `not_established` |
| 실측/제조 | `not_verified` |

목표 연결은 정확한 목표 개정의 출처 사본만 보존한다. 목표 대역을 초기식/solver 입력으로 자동 복사하거나 성능 평가를 수행하지 않는다. 검토 hash 확인/단일 명령 적용/undo/redo/저장/재열기와 이후 직접 편집 상태는 기존 경로를 재사용한다. 256 KiB origin, 512 KiB 프로젝트와 worker 소스 192개 상한을 늘리지 않는다.

## 4. GUI와 후속 범위

`문헌 / 형상 / 초기 후보`에서 카드, 후보 방식, 기존 도체층과 선택 목표를 고른다. 원문 치수는 별도 표시하며 미정 배치를 입력한 뒤 미리 본다. G001 초기 방식에서는 식/범위/가정을 확인하고 주파수를 입력한다. 명시 방식과 초기 방식의 초안은 분리 보존한다. 초기식 선택만 바꾼 초안도 닫기 때 폐기를 확인한다. 방식/식/입력을 바꾸면 이전 검토를 폐기하고 다시 미리 보아야 적용할 수 있다.

사용자 화면 시안을 따라 상단 설계/해석/결과/비교/출력 이동, 왼쪽 프로젝트/레이어, 세로 편집 도구, 가운데 실제 2D/3D 뷰, 오른쪽 속성, 하단 실제 작업 상태를 연결했다. wxWidgets/wxAUI와 기존 사용자 정의 2D, wxGLCanvas/OpenGL 3D를 사용한다. 기판 외곽 체크와 도체층 체크는 2D 표시만 바꾸며 원본/해석 포함 여부를 변경하지 않는다. 유전체 적층은 프로젝트 트리에서 편집한다. 결과/비교/출력은 현재 구현된 해석 그래프/수렴 보고서/STEP 기능으로 연결한다. 측정 비교/일반 다중 결과 비교/추가 출력이 완성된 것으로 표시하지 않는다.

시안 전체 외형, 3D 소형 동시 뷰, 스냅/연관 치수/회전/미러/평면 연산 및 최종 UX/성능 수용은 후속이다. 3번의 목표 제약/연결/DRC/외부 환경과 적층 보강도 남아 있다. RO4350B 국부 방사 도체 손실 변화 2.788446%의 초기 2% 기준과 GHz PTH 독립 물리 정확도는 미확립 상태를 유지한다. 이번 작업으로 새 FDTD/실물 측정 검증을 수행하지 않는다.

검증 결과와 시험 시점은 `runtime_profiles/printed-seeds-workspace.json`에 기록한다. 과거 검증 기록은 변경하지 않는다.
