# 사용자 PCB의 NF2FF 방사 수렴 연구

설계 기준선은 RFAD-D0-3.4다. 승인 원문과 미정 제조/측정 입력은 변경하지 않는다. 이 연구는 [방사 계산](pcb_radiation.md)의 수치 안정성을 확인한다. 계산 완료, 수치 수렴, 전체 에너지 수지, 제조 승인과 실측 정확도는 별개 상태다.

## 독립 비교 조건

선택 설정 `radiation.box_clearance_mm`는 물리 기판/적층의 여섯 면에서 기록 상자까지 요구하는 최소 공기 거리다. 기존 격자의 바깥 방향 면으로 snap하고 격자선을 추가하지 않는다. 실제 거리와 PML 시작면까지의 거리를 `radiation_recording`에 보존한다. PML8과 추가 공기 2개 셀을 침범하면 거절한다. 이 옵션을 생략한 기존 자동 기록 상자와 정규화는 유지한다.

명시적 거리 옵션의 위상 중심은 물리 기판 중심으로 고정한다. 기록 상자마다 위상 중심을 옮기지 않는다. 반지름은 1 m, 외부 매질은 진공이다. theta는 +z 극각, phi는 +x에서 +y 방향이다. [공식 NF2FF 조건](https://docs.openems.de/en/latest/concepts/nf2ff.html)의 방사원 포함, 재료 교차 금지, 균질 매질과 PML 분리를 따른다.

| 축 | 변경 | 계산 전 확인하는 불변 조건 |
| --- | --- | --- |
| 격자 | grid_mm 감소 | 동일 snapshot/물성/급전/종료, 외곽/PML 시작면과 셀 폭, 기록 면, 위상 중심/각도/주파수. 실제 격자점 증가 |
| 기록 상자 | box_clearance_mm 증가 | 전체 격자선/PML/위상 중심/각도 고정. 여섯 면 모두 실제로 확장 |
| 각도 | theta/phi 간격 감소 | 전체 격자/PML/기록 면/위상 중심 고정. 중첩되는 직접 각도 노드 |

각 축은 최소 3수준이다. 모든 계획의 실제 격자/좌표를 재계산해 독립성을 검사한 후 첫 native 계산을 시작한다. 기록 면까지 이동하는 격자 연구나, 공기 여백 변경으로 대신한 상자 거리 연구는 수용하지 않는다.

## 연구 입력과 초기 기준

[연구 manifest](../fixtures/pcb_radiation_convergence_study.json)는 이미 허용된 [RO4350B 탐색 입력](../fixtures/ro4350b_convergence_input.json)을 별도 프로젝트에 적용한다. 납품 물성은 미정으로 보존하고 명시적 근사 재료만 소비한다. 실제 주문/제작 조건을 확정하지 않는다.

- 주파수 2.400/2.44175/2.4835 GHz. 포트 201개 직접 표본과 일치한다.
- 격자 0.50/0.45/0.40 mm, 기록 거리 18/24/30 mm, theta/phi 각각 30/15/5 degree.
- 공기 여백 90 mm, graded air 6 mm/성장률 1.5, PML8, 종료 에너지 1e-5, 최대 100000 단계.
- 세 축 최종 기준을 공유한 9개 행/7개 고유 실행이다. 각도 설정이 다른 사례도 immutable 계획 계약을 따라 별도 실행한다. 다른 계획의 원시 파일을 몰래 재사용하지 않는다.

판정 한계는 실행 전에 고정한다. NP-03의 실현 이득 변화 0.5 dB/효율 변화 2%p를 참조하며 이번 별도 초기 profile은 이득과 실현 이득에 더 엄격한 0.1 dB를 사용한다. 승인 원문의 보편 기준으로 대체하지 않는다.

| 지표 | 초기 한계 |
| --- | --- |
| 공통 노드의 정규화 전력 패턴 최대 차이 | 0.02, 선형 peak 정규화 |
| Prad 스펙트럼 상대 차이 | 0.02, 두 값 중 큰 값 기준 |
| 최대 지향성 변화 | 0.1 dB |
| 최대 이득/실현 이득 변화 | 각각 0.1 dB |
| 효율 차이 | 0.02, 2%p |
| 전체 포트의 복소 S11 최대 차이 | 0.02 |
| 원방 구면 적분과 native Prad의 상대 차이 | 0.03 |
| 수동성 초과 수치 예산 | 0.01, 원시 초과/경고 보존 |
| 포트 파동 항등식 상대 잔차 | 1e-8 |

최소 3수준의 마지막 인접 쌍을 판정하고 앞선 비교도 보존한다. 공통 각도 노드만 비교하며 보간하지 않는다. 좁은 lobe/null과 연속 각도 전체의 정확성을 보증하지 않는다. 마지막 쌍이 충족해도 최종 기준의 전력 예산이 실패하면 전체는 `not_established`다. 임계값을 결과에 맞추어 완화하지 않는다.

## 전력 수지의 범위

같은 직접 포트 주파수에서 `Pref=Pinc*abs(S11)^2`와 `Pinc-Pref-Paccepted` 잔차를 확인한다. 이는 파동 분해의 항등식 검사이며 독립적인 체적 에너지 보존 검증이 아니다. 포트 주파수를 보간하여 수지를 채우지 않는다.

원방 필드에서는 `r^2/(2*Z0)*integral((abs(E_theta)^2+abs(E_phi)^2)*sin(theta), dtheta*dphi)`를 native Prad와 비교한다. theta는 사다리꼴, phi는 마지막-처음 구간까지 주기 합으로 처리한다. phi=360을 중복하지 않는다. [openEMS 임피던스 정의](https://github.com/thliebig/openEMS/blob/master/python/openEMS/physical_constants.py)와 [native field/power 규약](https://github.com/thliebig/openEMS/blob/master/nf2ff/nf2ff_calc.cpp)을 따른다. 현재 펄스 Fourier peak 스펙트럼에 1/2를 적용하며 승인 EQ-016의 RMS 필드에 추가 1/2를 곱하는 계산이 아니다.

단위는 전력 `W*s^2`, 필드 `V*s/m`, 절대 출력 전력은 null이다. `Paccepted-Prad`는 추론 손실이며 도체/유전체 손실의 독립 적분값이 아니다. 음의 추론 손실과 효율 100% 초과를 자르지 않고 `requires_review`도 보존한다. `independent_absorption_power_w_s2=null`, `full_energy_closure=not_evaluated`를 명시한다. 이번 전력 예산 통과를 PHY-054 전체 수용이나 R1 완료로 승격하지 않는다.

## 실행과 재판정

```powershell
$env:PYTHONPATH='src;tests;tools'
.\.venv\Scripts\python.exe -X utf8 tools/verify_pcb_radiation_convergence.py --workspace .local/new-radiation-study --report .local/new-radiation-report.json --catalog .local/pcb-catalog/catalog.sqlite
```

첫 실행은 새 경로를 사용한다. 각 요청의 key/epoch를 먼저 원자 저장해 응답 유실 때 같은 요청을 재조회한다. 완료 기준 사례는 재실행하지 않는다. 실패/취소/interrupted 작업을 새 작업으로 자동 대체하지 않는다.

현재 검증 CLI는 명시적 리터럴 PCB fixture와 출처 기반 선택 입력을 새 연구 프로젝트에 적용한다. 매개변수/확장이 들어간 일반 프로젝트의 연구 생성 GUI와 연구 편집기는 후속이다. 비교기는 봉인된 같은 snapshot과 실제 계획을 입력으로 사용하며 원본 프로젝트를 리터럴로 변환하지 않는다.

`--resume`은 동일 worker/설치에서 완료 자료를 재사용한다. `--reassess-only`는 solver와 카탈로그 없이 원본 snapshot/계획/결과/manifest/12면의 봉인을 확인하고 재평가한다. 제품 Python 소스가 바뀌면 기존 native 재개를 거절하며 새 계산에는 새 경로를 쓴다.

판정은 UUID의 별도 immutable 파일에 입력 참조, 판정기 소스 사본/hash, 기준과 결과를 보존한다. 이전 판정/native 자료는 덮어쓰지 않는다. 진행 report와 `.power.csv`는 갱신 가능한 파생물이며 미평가 흡수 전력은 CSV 빈 칸이다. 종료 코드는 수치 충족 0, 계산 완료/수치 미확립 1, 입력/실행/봉인 오류 2다.

GUI `해석 > 수렴 연구 보고서 비교`는 완료 보고서의 행, 세 축 마지막 비교와 전력 예산을 읽기 전용으로 표시한다. 이 창에서 원시 봉인을 검증하거나 새 계산을 시작하지 않는다. 미완료 보고서를 완료 판정으로 표시하지 않는다.

## 실제 검증 기록

2026-11-11 KST의 실제 RO4350B 탐색 IFA 연구는 9개 행/7개 고유 native 실행을 완료했다. 고유 사례의 기록된 시간 합계는 1432.078초다. 최대 격자점은 1224210으로 기존 1500000 상한 안이다. 마지막 인접 쌍의 세 주파수 최대값은 다음과 같다.

| 축 | 패턴 최대 차이 | Prad 상대 차이 | 최대 실현 이득 변화 | 효율 변화 |
| --- | --- | --- | --- | --- |
| 격자 0.45 -> 0.40 mm | 0.000479052 | 0.00189118 | 0.00580734 dB | 0.0336638%p |
| 기록 거리 24 -> 30 mm | 0.00401799 | 0.000337139 | 0.0150454 dB | 0.0332339%p |
| 각도 15 -> 5 degree | 0.00259429 | 0 | 0.0112815 dB | 0%p |

세 축과 최종 기준 전력 예산은 사전 기준을 충족하여 `numerical_stability=established`다. 최종 구면 적분 오차는 0.490625~0.506502%, 최대 포트 항등식 잔차는 약 2.20e-16이며 수동성 초과는 0이다. 이는 해당 모델/대역/표본에서의 수치 안정성이다. 더 넓은 대역, 다른 PCB나 연속 각도에 그대로 전용하지 않는다.

거친 결과의 실패도 남겼다. 0.50 -> 0.45 mm의 복소 S11 변화 0.0359031과 실현 이득 변화 0.247331 dB는 이번 초기 기준을 넘었다. 30 degree의 구면 오차는 2.400 GHz에서 3.05973%, 중심에서 3.00058%로 3% 예산을 넘었다. 이를 없애거나 임계값을 완화하지 않았다. 최종 수렴은 모든 거친 설정의 사용 가능성을 뜻하지 않는다. 오차가 각도/거리 변화에 따라 단조 감소한다고 가정하지도 않는다.

최종 S11은 약 -3.42548~-2.40070 dB로 기존 -10 dB 정합 목표를 충족하지 않는다. 방사 수렴 통과를 정합 설계 완료로 승격하지 않았다. 실제 납품 유전체/동박의 세 물성은 모두 미정이고 별도 탐색 재료의 미사용 물성도 미정으로 유지됐다.

`--reassess-only`와 완료 연구 `--resume`을 실제 수행했다. native 작업은 전후 7개, 전체 작업 ID 목록도 동일하며 원본 파일 224개와 CSV/hash, 판정 수치가 유지됐다. 이전 판정 3개를 독립 파일로 보존했다. 현재 worker 소스 111개의 hash가 실제 계산 출처와 일치한다.

기존 WSL Python의 h5py/numpy로 `verify_pcb_radiation_faces.py`를 실행하여 7개 사례/84면의 실제 m 좌표를 계획의 mm 격자와 비교했다. 절대 허용치는 1e-12 m다. 주파수는 native NF2FF와 같은 상대 1e-6 범위로 확인하고 실제 관측값을 감사 파일에 저장했다. 모든 FD dataset의 필드가 유한했고 파일 봉인을 읽기 전후 확인했다. 이 감사는 FDTD를 시작하지 않았다.

전체 Windows 회귀는 736개 수집/668개 통과/68개 조건부 스킵, 390.939초다. 이후 HDF 좌표/그림 판정 참조 guard를 포함한 관련 32개가 4.980초에 통과했다. GUI 회귀는 17개 중 13개 통과/4개 조건부 스킵, 148.661초다. 스킵은 별도 CAD 및 실제 WSL GUI 실행 조건이다. 이번 실제 WSL 계산 7개를 이 스킵과 혼동하지 않는다. 최종 표시 숫자를 유효 숫자 5개로 보완한 뒤 CTest 8개를 0.36초에 통과하고 실제 완료 보고서의 9개 행/세 축/전력/미평가 문구를 시각 확인했다. 검증 창은 정상 종료했다.

원시 정밀도는 유지한다. 별도 그림 도구는 불변 판정 파일과 진행표의 hash/내용 일치를 확인한 뒤 기존 CAD 환경의 Matplotlib Agg로 PNG/SVG를 생성했다. 실제 그림도 확인했다. 수치/출처/보고서/그림/실행 파일 hash는 [실행 기록](../runtime_profiles/pcb-radiation-convergence.json)을 따른다. 실제 제작/측정 조건과 독립 흡수 적분의 미정/미평가 상태는 유지한다.
