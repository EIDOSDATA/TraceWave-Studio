# 문서 타당성 검토와 사용자 승인

개정: 3.4 / 2026-11-07 KST / 상태: 설계 기준선 승인 / 개발: 착수 전

## 1. 검토 결론과 범위

PCB 안테나의 단일 의미 모델에서 CAD, 제조 출력, solver 입력과 결과를 파생하는 전체 방향은 설계 기준으로 유지할 수 있다. 다만 이전 문서의 현재 자료 상태, 작업/API 경계, 검증 추적, GUI 선정과 성능 계약에는 수정이 필요했다. 이 내용을 반영한 3.4 전체 문서가 2026-11-07 사용자 지시로 설계 기준선 승인을 받았다. 이번 갱신은 승인 상태와 인계 기록을 반영하며 제품 개발은 착수 전이다.

3.0 개정은 01_Docs의 기존 Markdown 24개와 루트 README를 검토하여 00~22를 수정하고, 원본 B인 23을 보존하며 GUI/성능 24와 이 검토/승인 25를 추가했다.

3.1 개정은 2026-11-07 사용자 결정을 반영하여 GUI를 C++ wxWidgets로 확정하고 일반 편집 60 fps, 대형 장면 30 fps 및 유료 GUI 부품 비필수 방침을 관련 문서에 적용한다.

3.2 개정은 후속 사용자 결정에 따라 성능 예산을 초기 목표로 채택하고 Windows 11+WSL2 우선 출시, Linux GUI 후속 출시, 원호/IFA 중심 R1 범위, 참조 사례 후 단일 포트 IFA 검증과 내부 검증용 배포를 반영한다.

3.3 개정은 사용자 결정에 따라 최초 IFA의 목표 대역/외형/적층 목표/급전과 초기 측정 계획을 초기 검증 기준으로 채택한다. 실제 재료 물성과 상세 제작/측정 조건은 후속 확정하며, 물성은 사용자가 입력하거나 자료에서 선택하는 변수임을 명시한다. 상세 기준은 [21번 IFA 초기 검증 기준](21_RFAD_사례와_계약.md#ifa-initial-baseline)에서 관리한다. 개발 착수 전 상태를 유지한다.

3.4 개정은 미결 사항을 개발 전 사용자 승인, 개발 중 기술 선정/검증, 제작/측정/내부 배포 전 확정, 후속 출시 결정으로 구분한다. 사용자는 추천한 처리 방향을 채택했고 후속 지시로 3.4 전체 문서 기준선을 승인했다. 개발 착수 지시는 별도로 유지한다.

현재 폴더에 원본 A JSON과 과거 review/src/tests/실행 기록은 없다. 기존 보존된 요구의 의미와 ID는 유지하되 원본 A 파일의 현재 바이트 보존 여부를 확인한 것으로 표시하지 않는다.

이번 작업은 문서 읽기, 구조/ID/링크 대조, 현재 추출 자료의 배열/행 수 확인, 공식 기술 문서와 수식 정의 비교다. 제품 코드, 의존성 설치, GUI prototype, CAD export, native EM 또는 실측 검증을 수행한 작업이 아니다. 문서의 설계 상태와 시험 실행 상태를 분리한다.

## 4. 문서 정합성 검사

검사 항목은 문서 집합, Markdown 로컬 링크/명시 anchor, 요구/AC/UI/FN/API/EQ/VT/PAR ID의 중복/누락, 원본 B 보존, AC별 단계 추적, 과거 경로/Qt 채택/상태 표기의 충돌, 수식 표기의 손상, Git 공백 오류다. 외부 source의 과거 ID/URL과 원본 B는 역사 자료로 보존하며 현재 제품 채택이나 실행 합격으로 세지 않는다.

요구 141개, AC 404개, UI 24개, FN 46개, API 30개, EQ 41개, VT 30개, PAR 162개의 안정 ID를 유지한다. 404 AC 중 단계가 혼합된 항목은 독립 subcase로 나누므로 추적 행 수가 AC 개수보다 많을 수 있다. pass는 해당 단계에 필요한 모든 assertion이 실제 실행되어 만족한 경우에만 쓴다. 단순 링크 존재나 정합성 검사 통과는 물리 정확도 증거가 아니다.

마지막 정합성 검사에서 Markdown 26개, 주요 ID와 원문 요구/AC 보존, 로컬 링크와 명시 anchor, 표의 열 수 및 code/math fence를 확인했다. 원본 B는 편집하지 않았고 Git diff가 없다. Git archive의 CRLF와 현재 작업 파일의 LF 차이는 내용 변경과 구분해 검사했다. 검사 개수와 결과는 검토용 package의 검사 기록에도 포함한다. 제품 개발 중에는 같은 검사를 CI의 문서 검사로 편입할 수 있으나 이번 작업에서 제품 코드를 생성하지 않는다.

3.0 개정의 문서 산술은 별도로 6개 assertion을 확인했다. 복소 Z0 전력파와 pseudo-wave의 전력 수지, network-facing 연결 C와 load 반사계수의 구분, N=100/k=90 Wilson 구간을 대조했으며 모두 지정 오차 안에서 일치했다. 이는 해당 입력의 산술 검산이며 EQ 전체, 설치 adapter, native solver, NF2FF 또는 실측 검증 통과가 아니다. EQ-022의 상관 지연 부호도 정의에서 확인했다.

3.1에서 GUI/프레임 목표/유료 부품 비필수 방침을 확정했고 3.2에서 성능 예산의 초기 목표 채택, 출시 순서, R1 범위, 검증 순서와 내부 배포 방향을 추가로 확정했다. 3.3에서는 최초 IFA의 초기 검증 기준을 채택했으며 실제 재료 물성과 상세 제작/측정 조건은 후속 확정한다. 초기 목표 채택은 실측 합격, 최소 사양 보장이나 목표에 맞춘 선제 메모리 할당을 뜻하지 않는다. Linux worker 검증은 Linux GUI 지원 완료가 아니며 후속 GUI 출시 버전을 임의로 R2/R3에 배정하지 않는다. 유료 부품 비필수는 제품 무료 배포나 모든 선택 유료 확장의 금지가 아니다. 사용자는 3.4 전체 문서 기준선을 승인하고 문서 최신화/커밋/푸시를 지시했다. 개발은 이후 착수할 계획으로 현재 제품 구현과 시험은 시작하지 않는다. 이 표는 확정된 방침과 남은 상세 조건을 구분하는 기록이다. 현재 R1 우선 출시는 내부 검증용 첫 릴리스를 뜻하며 외부 공개 출시는 별도 결정이다.

## 6. 미결 사항의 결정 시점과 채택한 처리 방향

추천 방향을 사용하겠다는 사용자 지시에 따라 아래 분류와 처리 방침을 채택한다. 현재 단계에서 선택해야 하는 제품 방향은 이미 DEC-D0-001~006에 반영되어 있다. 남은 실제 수치와 시험 결과를 지금 임의로 채우지 않는다. 전체 문서 기준선 승인은 완료되었고 개발 착수 지시만 별도로 남는다. 모든 제품 시험은 미실행 상태다.

### 6.1 완료된 기준선 승인과 남은 개발 착수 지시

| 항목 | 채택한 추천 방향과 이유 | 현재 상태 |

| 재료/포트/수렴과 정확도 | 명시된 물성 모델과 port별로 손실/전력 수지를 확인하고 mesh/boundary/time 변화와 독립 비교를 수행한다. 수렴과 실제 정확도는 별도로 판정한다 | RF/검증 담당. 해당 비교 시험 전 fixture/허용오차/출처/판정 규칙을 고정. GAP-004/005/011/012/013과 해당 R0/R1 VT 통과 |
| STEP/EDA/CAM | 얇은 동박, via, slot, 층/좌표/단위/net을 실제 출력하고 다른 reader 경로로 재입력해 비교한다. 파일 생성 성공과 내용 검증을 구분한다 | CAD 담당. 해당 출력 profile 제공 전 실제 형상/단면/topology 증거. GAP-002/008 |

| 원본 A의 완전성 | 현재 보존된 141개 요구/404개 AC와 원본 B를 기준으로 추적한다. 원본 A가 회복되면 출처/hash와 137개 원문 계보를 대조한다. 부재한 원본의 완전성은 미확인으로 남긴다 | 문서/데이터 담당. 자료 회복 시 대조. 복구 자체를 전체 개발의 선행조건으로 두지 않으며 충돌이 발견되면 영향 요구/기능의 결정을 재검토 |

### 6.3 제작, 측정 또는 내부 배포 전에 확정할 사항

이 항목들은 지금 소프트웨어 개발을 시작할 수 있는지를 결정하는 선행조건이 아니다. 다만 해당 해석/제작/측정/배포 작업을 수행하거나 검증 완료를 주장하기 전에는 필요한 입력과 증거를 갖춰야 한다.

| 항목 | 채택한 추천 방향과 이유 | 담당, 해당 작업 전 조건 |
| --- | --- | --- |
| 실제 IFA 물성과 적층 | 21의 초기 목표를 유지하고 실제 제조 가능한 재료의 등급/구성, Dk/Df/전도도, 층별 두께/마스크/표면처리와 공차를 확보한다. 일반 물성은 계속 사용자 입력/자료 선택 변수로 둔다 | RF/제작 담당. 탐색 해석은 필수 입력을 명시적 가정으로 완비하면 가능. 실물 재현 해석/비교 전 실제 보드 조건과 근거를 고정하며 미정값을 자동 생성하지 않음 |
| IFA 상세 형상과 제조 | 채택된 40 x 60 mm와 2층 목표 안에서 방사체/short/feed/via/ground polygon/SMA/pi 실장을 구체화하고 선폭은 실제 적층에서 결정한다. 제조 가능성과 전기 연결을 함께 확인한다 | RF/CAD/제작 담당. 발주 전 제조사 적층/공차/제조 출력/부품과 조립 조건 고정. 시료 3장은 초기 계획이며 현재 발주나 구매 지시가 아님 |
| VNA 정합 측정 | R1에서 SMA 기준면의 50 ohm 파일 비교와 원시 S1P 보존을 기본으로 한다. 실제 장비/교정/grid/IFBW/출력/케이블/지그와 반복 조건을 기록한다 | 측정 담당. 측정 전 절차와 불확도 산정 방법/비교 허용오차/판정 규칙 고정. 측정에서 얻은 실제 반복성 등의 수치 근거는 합격 판정 전에 확정. 대역 양끝 포함. S11 목표와 해석 정확도를 별도 판정 |
| 방사와 실물 정확도 | R1 전력/방사/수렴 및 독립 기준군을 유지하고 실제 효율/패턴/이득 검증에는 별도 방사 측정 조건을 사용한다. VNA 결과와 방사 결과의 준비/실행/판정을 분리한다 | RF/측정 담당. 해당 측정 및 capability 승인 전 교정/기준안테나/환경/불확도/독립 비교 자료 확보. OTA 미정은 VNA를 무효화하지 않지만 방사 실측 합격을 허용하지 않음. R1 기본 측정과 PHY-081 조립/환경 검증은 R2 전문 모델 뒤로 미루지 않음 |
| 내부 검증 패키지 | 사용자와 지정한 내부 검증자를 대상으로 포함 부품/버전/notice, 설치/재열기/취소와 알려진 제한을 확인한다. 개발 중간 검토용 빌드와 R1 완료 패키지를 구분한다 | 개발/배포 담당, 사용자 대상 지정. 전달 전 실제 패키지/대상/권리 조건 확인. 필수 R1 검증이 남은 빌드를 R1 완료로 표시하지 않음 |

시험 허용오차는 benchmark의 독립 근거, 수치 오차, 제조/측정 불확도와 사용 목적에서 정하고 결과를 보고 유리하게 변경하지 않는다. 측정 전에 필요한 것은 불확도 산정 방법과 판정 규칙이며 아직 얻지 않은 반복 측정의 최종 불확도 수치를 만들어 요구하지 않는다. 근거가 부족하면 해당 정량 판정을 보류한다. 외부 장비나 시료가 없으면 관련 실물 검증은 미평가로 남기되 독립적으로 가능한 데이터/GUI/CAD/수치 작업은 진행할 수 있다. 기존 필수 AC의 완료 조건을 면제하는 정책이 아니다.

## 7. 이번 개정 후의 사용법

기준선 3.4의 사용자 승인은 완료되었다. 다음 작업자는 5.2의 승인 기록/파일 해시와 16번 인계, 24번 성능 계약 및 6절의 잔여 조건을 확인한다. 별도 개발 착수 지시가 오면 15번 R0 계획을 시작하고 기술 세부를 해당 작업 전에 확정하여 증거를 연결한다. 승인된 요구/범위/성능을 바꾸는 경우 변경 이유와 영향 문서/AC/검증을 기록한다. 현재 문서 마무리와 커밋/푸시는 허용되었으나 제품 개발과 시험은 착수 전이다.
