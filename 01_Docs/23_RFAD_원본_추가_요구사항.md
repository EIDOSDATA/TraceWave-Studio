# PCB RF 패턴 안테나 통합 설계 도구 사용자 요구사항 명세서

**설계 변수부터 전자기장 해석과 제작 산출물까지**

버전 1.0  ·  기준일 2026-11-07 한국시간  ·  제품 요구사항 제안본

사용자가 목표 주파수와 성능, PCB 재질과 적층, 사용 가능한 안테나 공간, 급전 구조와 주변 환경을 지정하여 패턴 안테나를 설계하고, 같은 설계 상태에서 2D 도면, 실제 두께를 가진 3D STEP, PCB 제조 데이터와 전자기장 해석 결과를 얻을 수 있는 프로그램의 사용자 요구사항을 정의한다. 이 문서는 개발 범위와 검수 기준을 합의하는 기준이며 특정 CAD 커널이나 해석기 구현을 강제하지 않는다.

이 문서는 개발 범위를 결정하고 구현 결과를 검수하기 위한 사용자 요구사항 제안본이다. 특정 솔버나 CAD 커널의 채택을 확정하는 구현 명세서는 아니다. 사용자가 직접 요청한 기능과 비교 제품에서 도출한 기능, 실무 신뢰성을 위해 추가한 기능을 구분한다.

## 1 제품 목적과 범위

목표는 PCB 안테나의 치수 계산, 기구 형상, 전자기장 해석, 제작 데이터 사이의 단절을 줄이는 것이다. 사용자는 하나의 프로젝트에서 목표 주파수·성능과 제조 제약을 정하고, 물성을 반영해 설계·검토·수정한 뒤 동일 리비전의 산출물을 얻어야 한다.

| **구분** | **제품 범위** |
| --- | --- |
| 제품 중심 범위 | PCB 도체 패턴, 접지, 기판과 급전을 포함한 안테나 설계, 2D 및 3D 형상 편집, 전자기장 해석, 최적화, 제작 출력과 결과 검증 |
| 확장 범위 | 다중대역, 다중포트, UWB, 배열과 MIMO, 근접장 결합용 루프, 유연 기판, 복합 환경, 공차 및 실측 보정 |
| 형상 지원 원칙 | 템플릿 생성과 임의 형상 설계를 함께 제공하며, 템플릿별 적용 조건과 검증 수준을 명시한다 |
| 주파수 지원 원칙 | Hz 단위의 범용 입력과 대역 프리셋을 제공하되, 실제 계산 가능 주파수와 크기 범위는 솔버 및 검증된 모델 조합으로 결정한다 |
| 완료 판정 범위 | 파일 생성 여부뿐 아니라 설계와의 일치, 재열기, 동박 포함 여부, 해석 설정 추적과 결과의 유효 상태까지 확인한다 |
| 별도 제품 범위 | 완전한 회로 CAD 대체, RF 칩 내부 설계, 자동 인증 판정, 전파 커버리지 및 망 설계는 독립 제품 기능으로 보며 연결 가능성만 유지한다 |

### 핵심 제품 약속

1. 동일한 설계 리비전에서 형상, 물성, 적층, 급전, 환경, 도면, 제조 파일과 해석 결과가 추적 가능해야 한다.

2. 기판과 동박의 실제 물리 치수는 유지하고, 해석에 사용하는 시트 도체, 완전도체 또는 유한 전도도 근사를 별도로 기록해야 한다.

3. 치수 합성값, 해석 결과, 실측값을 구분하고 유효 범위, 미수렴, 오래된 결과와 미지원 기능을 표시해야 한다.

4. 2D 도면과 STEP은 필수 산출물이다. 3D 미리보기나 STL을 제공하는 것만으로 STEP 요구사항을 충족한 것으로 보지 않는다.

5. 안테나 형상 종류, 형상별 자동 합성 가능 범위, 사용자 임의 형상 편집 가능 범위와 솔버가 지원하는 물리 모델을 각각 관리해야 한다.

6. 모든 변수에 숫자를 강제로 입력하게 하기보다, 공통 필수 변수와 선택한 형상 및 해석에서 활성화되는 조건부 변수를 구분해야 한다. 숨겨진 기본값과 지원하지 않는 물성의 묵시적 무시는 허용하지 않는다.

### 요구사항 표기법

| **표기** | **의미** | **해석** |
| --- | --- | --- |
| M | 필수 | 대상 기능이 제품 범위에 들어가는 경우 반드시 충족해야 하는 사용자 요구사항 |
| S | 권장 | 실무 완성도를 높이는 기능이며 선정 릴리스에서 제공 여부를 합의하는 요구사항 |
| C | 선택 | 고급 응용 및 장기 확장 기능으로 별도 투자와 검증이 필요한 요구사항 |

| **출처 유형** | **의미** | **해석** |
| --- | --- | --- |
| U | 사용자 명시 | 사용자가 직접 요구한 설계, 변수 반영, 도면, STEP 및 해석과 이를 만족시키는 직접 조건 |
| B | 비교 검토 | 검토한 프로그램에서 확인한 기능을 바탕으로 본 제품에 제안한 요구사항 |
| P | 추가 제안 | 모델 일관성, 검증, 사용성 및 운영을 위해 추가한 제품 요구사항 |

M S C와 R1 R2 R3는 독립적인 속성이다. 출처 유형 U도 구체적인 검수 방식과 수치까지 사용자가 이미 승인했다는 뜻은 아니다. 이 문서에 제시한 구현 단계와 수치 기준은 개발 착수 시 확정할 제안이다.

### 1.1 공통 입력과 조건부 입력

모든 프로젝트에는 주파수, 보드와 도체 형상, 실제 적층 두께, 유전체 물성, 도체 모델, 접지 및 급전이 필요하다. 거칠기·이방성·케이스·인체·온도·습도·배열·UWB·근접장 결합 등은 사용하는 경우에 활성화한다. 각 항목의 상태는 입력 완료, 출처가 있는 기본값, 사용자 승인 추정값, 미지정, 해당 없음, 해석기 미지원 중 하나로 구분한다.

고급 입력란이 있다는 것만으로 기능을 지원한 것으로 판정하지 않는다. 저장된 값이 선택 솔버와 제조 출력에서 어떻게 사용되는지 표시해야 한다. 미지원 입력을 조용히 무시하거나 임의의 물성으로 대체해서는 안 된다.

### 1.2 물리 모델과 수치 모델

물리 모델에는 실제 선폭·길이·동박 두께·기판 적층·주변 구조를 보존한다. 해석 모델은 솔버가 요구하는 체적, 시트, 완전도체 또는 등가회로 표현을 사용할 수 있다. 각 근사의 적용 객체와 실제 사용한 물성, 지원 조건을 기록한다. 예를 들어 openEMS는 완전도체와 두께 및 도전율을 갖는 전도성 시트를 서로 다른 속성으로 다룬다. [S02](#source-s02)

재료의 유전율과 손실은 이름만으로 확정하지 않는다. 재료 데이터의 시험 주파수·측정 방식·온도·출처를 관리하고, 주파수 의존 입력을 해석기가 사용하는 모델로 변환하는 경우 변환 오차와 유효 대역을 남긴다. [S01](#source-s01)

### 1.3 지원 범위 선언

버전마다 검증한 주파수 범위, 보드·안테나 크기, 레이어 수, 최소 특징 크기, 포트·재료·솔버 조합, 가져오기·내보내기 형식 버전을 공개한다. 임의 형상 편집 가능, 자동 치수 합성 가능, 해석 실행 가능, 수치 검증 완료, 실측 비교 완료는 각각 다른 지원 상태다.

### 2.1 권장 화면 구성

프로젝트 화면은 목표와 설계 버전, 2D 및 3D 편집 화면, 객체·레이어 목록, 선택 항목 속성, 해석 작업과 결과, 검수·출력으로 구성한다. 기본 입력 화면에는 공통 변수만 보이고 선택한 안테나·재료·응용에 따라 추가 입력을 열어준다. 2D 도면의 객체를 선택하면 대응 3D 형상과 물성·해석 역할을 함께 확인할 수 있어야 한다.

## 3 유사 도구 검토와 기능 반영

공식 문서, 공급사 설명과 개발자 저장소의 공개 내용을 기준일에 검토했다. 설치 실행이나 정확도·내보내기 왕복 시험을 수행한 비교가 아니다. 아래의 확인 기능은 공개 문서 범위이며, 반영할 요구사항은 본 제품을 위한 제안이다. 상용 제품의 모듈·라이선스와 실험 프로젝트의 검증 범위는 구분한다.

### 01 openEMS  ·  공개 전자기장 해석 엔진

**확인 기능**  공개 FDTD 해석 엔진으로서 Fairbeam, FreeCAD 연결 도구 및 여러 자동화 프로젝트의 PCB와 안테나 해석에 사용된다. [S15](#source-s15) [S18](#source-s18)

**확인 한계**  엔진 선택만으로 2D 도면, STEP, 제조 데이터 및 전체 사용자 흐름이 완성되지는 않는다. 특정 기본 솔버 채택은 본 문서에서 확정하지 않는다.

반영 제안  해석 엔진을 사용자 프로젝트와 연결하고 계산 방법, 설정, 결과와 검증 상태를 명확히 표시하는 해석 경로를 검토한다.  연결: PRJ-008, NFR-007, NFR-008

### 02 webantenna  ·  개인 공개 브라우저 도구

**확인 기능**  주파수와 재질에서 안테나 후보를 생성하고 PCB용 해석, Gerber와 드릴 및 DXF 출력, VNA 데이터 비교, FreeCAD 매크로 출력을 설명한다. [S14](#source-s14)

**확인 한계**  FreeCAD 매크로 출력과 직접 STEP 출력은 구분해야 한다. 계산식 예상과 FDTD 해석을 같은 검증 수준으로 취급하지 않는다.

반영 제안  다양한 형상의 시작 템플릿, 후보 비교, 제작 묶음 출력과 실측 비교 흐름을 참고한다.  연결: LIB-003, OPT-003, VAL-004, PRJ-008

### 03 Fairbeam  ·  공개 통합 설계 및 해석 앱

**확인 기능**  파라미터 모델링, openEMS 연결, 메시 수렴 검사, 스윕과 최적화, 결과 비교 및 도면과 보고서 출력을 제공한다고 설명한다. [S15](#source-s15)

**확인 한계**  제조 파일은 preview로, VBA 변환은 검증 제한이 있는 것으로 명시되어 있다. STEP 직접 출력은 확인되지 않았다.

반영 제안  실행 전 검사, 실행 이력, 수렴 상태, 비교 및 검증된 산출물의 연결을 참고한다.  연결: PRJ-005, PRJ-007, PRJ-010, OPT-001, NFR-001

### 04 antenna-cad  ·  공개 PCB 설계 자동화 도구

**확인 기능**  주파수와 기판 등 요구사항에서 패치와 배열 PCB를 생성하고 KiCad DRC, openEMS 및 튜닝과 보고서 흐름을 연결한다. [S16](#source-s16)

**확인 한계**  패치와 배열 중심이다. STEP은 KiCad 경유로 설명되며 안테나 동박 포함 옵션을 별도로 검수해야 한다.

반영 제안  단위가 있는 입력, 설계 버전에서 여러 출력 생성, 자동 검수 및 재현 가능한 배치 흐름을 참고한다.  연결: PRJ-002, PRJ-003, OPT-007, OPT-008

### 05 EMStudioFree  ·  공개 FreeCAD 작업 환경

**확인 기능**  요구사항 기반 안테나 형상과 치수 생성, 여러 해석기 연결, 안내식 작업 흐름과 실행 전 자원 검사를 설명한다. [S17](#source-s17)

**확인 한계**  개발자는 교육 및 실험용으로 설명한다. 개별 기준 사례의 통과를 모든 모델의 정확도 보장으로 확대하지 않는다.

반영 제안  지원 기능을 설명하는 해석기 선택, 자원 진단 및 검증 사례의 공개 방식을 참고한다.  연결: LIB-005, PRJ-007, NFR-001, NFR-008

### 06 FreeCAD OpenEMS Export  ·  공개 CAD 및 해석 연결 도구

**확인 기능**  FreeCAD 객체에 재료, 포트, 소자, 경계와 메시 등을 설정하고 openEMS 실행 및 후처리 스크립트를 생성한다. [S18](#source-s18)

**확인 한계**  안테나 사양에서 모든 형상을 자동 합성하는 제품으로 보지 않는다. 일반 STEP와 도면 출력은 FreeCAD 본체 기능과 구분한다.

반영 제안  형상 객체와 물리적 역할의 연결, 급전과 메시의 시각적 검토 및 CAD 편집과 해석 설정의 연속성을 참고한다.  연결: PRJ-001, PRJ-007, PRJ-008

### 07 pyems  ·  공개 Python 해석 인터페이스

**확인 기능**  openEMS의 고수준 인터페이스로 자동 메시, PCB 기반 구조, 매개변수 최적화와 KiCad footprint 생성을 설명한다. [S19](#source-s19)

**확인 한계**  완성된 사용자 GUI나 전체 PCB 제조 프로젝트 출력으로 해석하지 않는다. 직접 STEP 출력은 확인되지 않았다.

반영 제안  매개변수와 형상, 해석 설정 및 PCB 출력의 일관성과 반복 실행 인터페이스를 참고한다.  연결: PRJ-002, PRJ-003, OPT-008

### 08 gerber2ems  ·  기업 공개 PCB 해석 연결 도구

**확인 기능**  Gerber, 드릴, 포트 위치와 PCB 적층 정보를 받아 openEMS 해석 형상을 구성하고 그리드와 후처리를 연결한다. [S20](#source-s20)

**확인 한계**  주목적은 PCB 배선과 신호 무결성 해석이다. 자동 안테나 합성이나 완성된 방사 성능 설계 도구로 분류하지 않는다.

반영 제안  외부 PCB 파일의 층과 재료 정보를 검증하며 기존 설계에서 해석 입력을 만드는 흐름을 참고한다.  연결: PRJ-001, PRJ-003, PRJ-007

### 09 AntennaCAT  ·  연구 공개 설계 및 최적화 도구

**확인 기능**  안테나 계산, CAD 생성, HFSS 실행, 데이터 수집 및 최적화 자동화를 연결한다. [S21](#source-s21)

**확인 한계**  공개 코드와 별도 HFSS 해석 환경을 구분한다. README에 Python 패키지 및 Windows 호환성 개편 공지가 있다.

반영 제안  생성, 계산, 평가의 반복과 후보 이력, 배치 작업 및 최적화 재현 흐름을 참고한다.  연결: OPT-002, OPT-007, OPT-008, NFR-007

### 10 AntennaCalculator  ·  공개 초기 형상 계산 도구

**확인 기능**  주파수, 상대유전율과 기판 두께로 사각 패치 치수를 계산하고 PNG, DXF 및 Gerber를 출력하는 예제를 제공한다. [S22](#source-s22)

**확인 한계**  초기 치수 계산과 full wave 검증을 구분해야 한다. STEP와 자체 full wave 해석까지 통합된 것으로 확인되지 않았다.

반영 제안  소형 계산 모듈도 단위, 적용 조건, 설계 근거 및 출력 검수를 갖도록 한다.  연결: PRJ-003, PRJ-008, LIB-001

**확인 한계**  반원형 기판과 원호형 모노폴은 같은 구조가 아니다. 좁은 대상의 구현을 모든 안테나의 자동 설계 지원으로 확대하지 않는다.

반영 제안  고정된 PCB 외곽과 설치 제약 내에서 안테나와 정합을 함께 탐색하는 제한된 목표 사례를 참고한다.  연결: LIB-001, LIB-003, OPT-002, PRJ-008

### 12 MATLAB PCB Antenna Designer  ·  상용 PCB 안테나 설계 도구

반영 제안  자유 형상과 템플릿의 공존, 적층과 급전의 명시적 편집 및 설계에서 제조로 이어지는 흐름을 참고한다.  연결: PRJ-001, PRJ-002, OPT-002, PRJ-010

### 13 Antenna Magus 및 CST  ·  상용 합성 라이브러리와 정밀 해석 조합

반영 제안  자동 생성된 해석 설정의 확인과 편집, 실행 상태 및 해석 경로 의존성 안내를 참고한다.  연결: PRJ-007, PRJ-008, NFR-007, NFR-008

반영 제안  라이브러리 모델에서 자유 편집으로 이어지는 흐름과 해석 설정의 명시적 관리를 참고한다.  연결: PRJ-001, LIB-003, OPT-002

**확인 한계**  공식 문서는 수평 방향으로 강하게 방사하거나 큰 표면파가 존재하는 안테나에 대한 제한을 명시한다. 일반 3D 안테나 전체에 동일하게 적용하지 않는다.

반영 제안  평면 구조에 적합한 해석 경로를 선택하고 경계와 방사 방향에 따른 적용 제한을 표시한다.  연결: SIM-001, SIM-004, VAL-009

### 23 Qucs RFlayout  ·  공개 RF 회로와 레이아웃 연결 도구

**확인 기능**  Qucs RF 회로에서 지원하는 전송선 구조를 KiCad 레이아웃과 openEMS 스크립트로 내보내는 흐름을 제공한다. [S08](#source-s08)

**확인 한계**  지원 회로 요소의 변환 도구이며 임의 안테나 자동 합성기나 모든 Qucs 요소의 완전한 변환기로 간주하지 않는다.

반영 제안  정합과 급전 회로의 수치 및 기하 모델이 PCB 레이아웃과 해석 입력에서 연결되도록 한다.  연결: FED-005, FAB-001, PRJ-008

### 24 KiCad SI Simulation Wrapper  ·  기업 공개 PCB 해석 자동화 도구

**확인 기능**  KiCad PCB 설계를 openEMS 해석에 맞게 준비하고 반복 작업을 연결하는 기능을 제공한다. [S09](#source-s09)

**확인 한계**  신호 무결성 목적의 PCB 연결 도구다. Gerber 변환 기능을 안테나 형상 합성이나 방사 성능 검증으로 확대하지 않는다.

반영 제안  기존 PCB를 가져온 후 필요한 부분과 적층 및 포트 조건을 명시하고 재현 가능한 실행을 만든다.  연결: FAB-001, PRJ-007, OPT-008

### 25 Palace  ·  공개 FEM 전자기장 해석 엔진

**확인 기능**  3D 병렬 유한요소 해석, 주파수 및 시간 영역 계산, 포트와 적응 메시 및 주파수 스윕 기능을 설명한다. [S10](#source-s10)

**확인 한계**  전자기장 엔진이며 PCB 안테나 도면과 제조 STEP를 완성하는 사용자 앱은 별도로 필요하다. 채택 여부는 후속 기술 검증 사항이다.

반영 제안  해석기별 지원 물리 모델과 수렴 절차를 구분하고 필요할 때 추가 해석 경로를 연결할 수 있게 한다.  연결: SIM-001, SIM-007, NFR-008

### 26 Meep  ·  공개 FDTD 전자기장 해석 엔진

**확인 기능**  분산 및 이방성 재료, 근접장과 원거리장 변환, 스크립트 인터페이스 및 adjoint 기반 역설계 기능을 설명한다. [S11](#source-s11)

**확인 한계**  일반 전자기장 엔진의 기능을 PCB용 급전과 제조 파일의 검증 완료로 간주하지 않는다. 특정 역설계 기능의 PCB 적용은 별도 검증한다.

반영 제안  조건별 물성 지원표와 자동화 인터페이스, 후속 자유 형상 탐색을 검토한다.  연결: MAT-008, MAT-009, OPT-008, OPT-010

### 3.1 비교에서 도출한 제품 방향

안테나 라이브러리와 초기 합성, 자유 형상 CAD, 재료와 주변 구조를 포함한 EM 설정, 최적화, 실측 비교, 제조 출력의 기능을 하나의 프로젝트로 연결한다. 자동 생성의 편의성과 전문가가 조건을 직접 확인·수정하는 기능을 함께 제공하고, 모든 결과가 입력과 해석 방법 및 검증 상태로 추적되도록 한다.

### 5.3 출력에서 반드시 구분할 내용

STEP 형상 교환은 실제 동박을 포함하는지 검수한다. KiCad의 공식 STEP 출력 기능에도 트랙·패드·구리 영역과 내층 구리를 포함하는 선택 항목이 있으므로, 외부 도구를 연결했다는 사실만으로 동박이 포함됐다고 가정하지 않는다. [S05](#source-s05)

도면용 치수·주석은 제조용 구리 패턴과 분리한다. 채워진 도체 영역과 중심선도 다른 출력이다. 상하면의 사람이 보는 도면 방향과 제조 좌표의 미러링 규칙을 구분하며, 모든 산출물에 단위·원점·방향을 기록한다.

제조용 Gerber 레이어만으로 전체 해석 모델을 복원할 수 있다고 가정하지 않는다. Job 또는 동반 명세에 적층과 재료를 전달하고, 주파수 의존 물성·포트·경계·메시는 프로젝트에 보존한다. 제조사에 보낼 설계 적층과 제조사가 최종 승인한 공정 적층도 구분한다.

### 6.1 PRJ 프로젝트와 변경 관리

프로젝트는 형상, 재질, 적층, 급전, 주변 환경, 해석 설정, 결과 및 출력 파일의 관계를 유지해야 한다. 동일한 설계 버전에서 생성한 2D 도면, 물리적 두께를 갖는 STEP, 제조 데이터와 해석 모델을 추적하며, 각 표현에서 적용한 근사와 생략을 명시한다. 목표 주파수와 성능 한계의 정의는 별도 목표 요구사항을 따른다.

<a id="req_PRJ_001"></a>

#### PRJ-001  설계 시작 경로

M 필수  ·  R1  ·  B 비교 검토  ·  [S18](#source-s18) [S24](#source-s24)

사용자는 제공 템플릿, 빈 설계 및 지원되는 외부 CAD 또는 PCB 파일 가져오기를 통해 프로젝트를 시작하고 이후 동일한 편집과 검증 흐름을 이용할 수 있어야 한다.

**검수 기준**  각 시작 경로로 기준 사례를 열어 편집, 저장, 재열기 및 후속 해석 준비가 가능하다. 가져오기에서 누락되거나 변환된 형상, 층 및 속성은 목록으로 표시된다.

<a id="req_PRJ_002"></a>

#### PRJ-002  통합 설계와 산출물 연결

M 필수  ·  R1  ·  U 사용자 명시  ·  [S16](#source-s16)

사용자는 동일한 설계 버전으로 2D 도면, 3D STEP, PCB 제조 파일 및 해석 모델을 생성하고, 각 산출물에 적용된 물리적 두께와 해석상 근사 또는 생략을 확인할 수 있어야 한다.

**검수 기준**  선폭, 패턴 길이, 기판 두께 및 동박 두께를 변경한 기준 사례에서 관련 산출물에 같은 변경이 반영된다. 해석에서 면 도체를 사용하더라도 STEP과 제조 데이터의 지정 동박 두께가 유실되지 않으며 차이를 기록한다.

<a id="req_PRJ_003"></a>

#### PRJ-003  물리량과 표현식의 일관성

M 필수  ·  R1  ·  B 비교 검토  ·  [S16](#source-s16) [S15](#source-s15)

사용자는 매개변수의 물리량, 단위, 유효 범위 및 기본값 출처를 확인하고 단위가 있는 수치 또는 지원 표현식으로 편집할 수 있어야 한다.

**검수 기준**  동등한 GHz와 MHz 입력, mm와 mil 입력으로 동일한 물리 모델이 생성된다. 차원이 다른 연산, 정의되지 않은 변수, 순환 참조 및 유효 범위 밖의 입력은 해당 위치와 이유를 표시한다.

<a id="req_PRJ_004"></a>

#### PRJ-004  결과와 설계 버전의 연결

M 필수  ·  R1  ·  P 추가 제안

형상, 재료, 적층, 급전, 주변 환경 또는 해석 조건을 변경하면 영향을 받는 이전 결과를 현재 설계의 결과와 구분하고 계산 당시의 버전에 연결해야 한다.

**검수 기준**  계산 후 기판 유전율 또는 선폭을 변경하면 과거 결과가 삭제되지 않은 채 이전 버전 결과로 표시된다. 기존 버전을 다시 열면 해당 버전의 입력과 결과 관계를 확인할 수 있다.

<a id="req_PRJ_005"></a>

#### PRJ-005  되돌리기와 설계 후보 관리

M 필수  ·  R1  ·  B 비교 검토  ·  [S15](#source-s15)

사용자는 편집 되돌리기와 다시 실행, 프로젝트 복제, 이름 있는 설계 버전 저장 및 버전 간 차이 비교를 수행할 수 있어야 한다.

**검수 기준**  하나의 후보를 수정해도 다른 후보가 자동 변경되지 않는다. 버전 비교에서 변경된 매개변수, 형상, 물성 및 해석 조건을 식별하며 이전 상태로 복원할 수 있다.

<a id="req_PRJ_006"></a>

#### PRJ-006  이식 가능한 프로젝트 묶음

M 필수  ·  R1  ·  P 추가 제안

사용자는 입력, 원본 참조, 사용 당시의 재료와 라이브러리 값, 형상, 실행 설정, 결과 및 산출물 목록을 포함한 프로젝트 묶음을 저장하고 다른 지원 환경에서 열 수 있어야 한다.

**검수 기준**  별도 시험 환경에서 프로젝트를 열면 외부 파일 누락과 호환성 문제를 진단한다. 명시된 동일 도구 버전으로 재실행한 결과는 기준 사례별 합의된 허용오차로 비교한다. 서로 다른 CPU 또는 GPU 환경의 무조건적인 비트 단위 동일성은 요구하지 않는다.

<a id="req_PRJ_007"></a>

#### PRJ-007  실행 전 검사와 수정 안내

M 필수  ·  R1  ·  B 비교 검토  ·  [S15](#source-s15) [S29](#source-s29)

프로그램은 해석에 필요한 형상, 재료, 급전, 주파수, 경계 및 자원 설정을 실행 전에 검사하고 차단 오류와 경고를 구분하여 위치와 수정 방법을 안내해야 한다.

**검수 기준**  급전 누락, 미할당 재료, 무효 주파수 범위 및 연결되지 않은 급전의 시험 입력에서 해당 문제를 특정한다. 필수 입력이 없는 계산은 시작되지 않으며 경고를 무시한 실행은 기록에 남는다.

<a id="req_PRJ_008"></a>

#### PRJ-008  계산 방법과 데이터 출처 표시

M 필수  ·  R1  ·  B 비교 검토  ·  [S25](#source-s25) [S27](#source-s27)

사용자는 초기 합성식, 근사 해석, full wave 해석 및 실측 데이터를 구분할 수 있어야 한다. 선택한 계산 방법이 지원하지 않는 물성이나 급전은 사용자 모르게 다른 모델로 대체하지 않아야 한다.

**검수 기준**  화면, 데이터 파일 및 보고서에 실제 계산 방법과 데이터 출처가 기록된다. 미지원 조건의 시험 사례에서 실행 차단 또는 명시적인 근사 선택 절차가 작동하며 근사 내용을 확인할 수 있다.

<a id="req_PRJ_009"></a>

#### PRJ-009  원시 결과와 후처리 이력 보존

M 필수  ·  R1  ·  P 추가 제안

사용자는 원시 계산 및 측정 결과를 보존한 상태에서 정규화, 보간, 기준 임피던스 변환 등 지원 후처리를 적용하고 처리 조건을 확인할 수 있어야 한다.

**검수 기준**  후처리 옵션을 변경해도 원본 데이터를 다시 표시할 수 있다. 결과 내보내기에 단위, 기준 및 변환 조건이 포함되며 보간한 지점과 실제 계산 또는 측정한 지점을 구분한다.

<a id="req_PRJ_010"></a>

#### PRJ-010  검증 상태와 보고서 추적

M 필수  ·  R1  ·  P 추가 제안  ·  [S15](#source-s15)

사용자는 계산 종료, 수치 수렴, 적용 범위 적합, 목표 성능 충족, 제조 규칙 충족 및 실측 비교 상태를 별도로 확인하고 보고서에서 해당 설계와 실행을 추적할 수 있어야 한다.

**검수 기준**  미수렴 계산과 목표 미달 계산을 완료된 적합 설계로 표시하지 않는다. 보고서의 각 결과에 설계 버전과 실행 식별 정보가 연결되며 미확인, 실패 및 생략한 검증 항목을 누락하지 않는다.

<a id="group_TGT"></a>

### 6.2 TGT 목표 대역과 설계 조건

통신 방식의 이름을 실제 주파수, 대역폭, 포트 및 성능 조건으로 변환하고 설계의 성공 조건을 먼저 정의한다.

<a id="req_TGT_001"></a>

#### TGT-001  단일 대역과 다중 대역 지정

M 필수  ·  R1  ·  U 사용자 명시

사용자는 시작 및 종료 주파수, 기준 주파수와 샘플링 규칙을 단위와 함께 지정하고 여러 목표 대역을 저장할 수 있어야 한다.

**검수 기준**  Hz와 GHz로 같은 값을 입력한 두 프로젝트의 정규화 값이 같고 역전된 범위와 0 이하 주파수를 거부한다. 다중 대역 계산이 미지원이면 대역 정보를 보존하고 실행 전에 안내한다.

<a id="req_TGT_002"></a>

#### TGT-002  통신 프리셋과 사용자 정의 조건

M 필수  ·  R1  ·  B 비교 검토

사용자는 BLE, Wi Fi, LoRa, UWB, GNSS, 셀룰러 및 사용자 정의 RF 프리셋으로 시작하고 모든 설계 주파수와 목표를 수정할 수 있어야 한다.

**검수 기준**  프리셋의 출처와 버전 및 지역 적용 범위를 표시한다. 프리셋 선택이 인증 적합 판정이나 안테나 성능 보증으로 표시되지 않는다.

<a id="req_TGT_003"></a>

#### TGT-003  전기적 목표의 명시

M 필수  ·  R1  ·  U 사용자 명시  ·  [S03](#source-s03)

사용자는 대역별 반사 특성, 기준 임피던스, 대역폭, 실현 이득, 방사 및 전체 효율 목표를 선택하여 지정할 수 있어야 한다.

**검수 기준**  선택한 모든 목표의 단위, 주파수 조건과 통과 규칙을 저장한다. 계산하지 않은 지표는 합격이 아닌 미평가로 표시한다.

<a id="req_TGT_004"></a>

#### TGT-004  기구와 제조 제약의 동시 지정

M 필수  ·  R1  ·  U 사용자 명시

사용자는 보드 외곽과 안테나 허용 영역, keep out, 층수, 선폭 및 간격 한계와 높이 제한을 설계 제약으로 지정할 수 있어야 한다.

**검수 기준**  초기 합성과 최적화 및 수동 편집에서 동일한 제약을 검사하며 위반 위치와 수치를 표시한다.

<a id="req_TGT_005"></a>

#### TGT-005  급전과 방사 조건의 목표화

M 필수  ·  R1  ·  P 추가 제안  ·  [S03](#source-s03)

사용자는 포트 종류와 정합 기준, 기준 좌표계, 관측 방향 및 편파를 성능 목표에 연결할 수 있어야 한다.

**검수 기준**  포트 기준과 관측 방향이 다른 결과를 비교하면 조건 차이를 표시하고 같은 이름의 지표를 무조건 동등하게 비교하지 않는다.

<a id="req_TGT_006"></a>

#### TGT-006  요구조건 실현 가능성 표시

S 권장  ·  R2  ·  P 추가 제안

프로그램은 선택 템플릿과 보드 제약에서 목표를 충족할 후보를 찾지 못할 경우 원인과 완화 가능한 제약을 제시해야 한다.

**검수 기준**  후보 없음, 계산 실패, 제약 위반과 검증 범위 밖 상태를 구분하며 실행하지 않은 대안을 성능이 검증된 것으로 표시하지 않는다.

<a id="req_TGT_007"></a>

#### TGT-007  응용별 평가 항목 활성화

M 필수  ·  R2  ·  P 추가 제안

UWB, 다중포트, 배열 또는 근접장 결합 응용을 선택하면 해당 평가에 필요한 추가 입력과 검증 절차를 활성화해야 한다.

**검수 기준**  UWB 전송 시간 응답에는 송수신 모델과 기준면을 요구하며 단일 안테나 S11만으로 전송 충실도나 ToF 정확도를 확정하지 않는다.

<a id="req_TGT_008"></a>

#### TGT-008  설계 목표와 결과의 추적

M 필수  ·  R1  ·  P 추가 제안

사용자는 목표 조건에 고유 식별자를 부여하고 각 해석 결과 및 산출물에서 어떤 목표 버전을 평가했는지 확인할 수 있어야 한다.

**검수 기준**  목표를 수정해도 과거 결과의 원래 판정 근거가 보존되고 새 목표로 재평가한 결과를 별도 식별한다.

<a id="group_LIB"></a>

### 6.3 LIB 안테나와 재료 지식 관리

라이브러리는 형상 이름만을 모으는 목록을 넘어 형상 파라미터, 재료, 적용 조건, 설계 근거와 검증 방법을 함께 제공해야 한다. 자유 형상 편집 범위, 자동 합성 가능한 형상 및 검증된 적용 범위를 분리하여 표시한다. 라이브러리 갱신이 이미 저장된 설계를 자동 변경하지 않아야 한다.

<a id="req_LIB_001"></a>

#### LIB-001  안테나 레퍼런스 카드

M 필수  ·  R1  ·  B 비교 검토  ·  [S25](#source-s25)

사용자는 각 안테나 템플릿에서 형상 정의와 파라미터, 원본 출처, 사용 재료와 보드 조건, 급전 방식, 적용 범위 및 검증 사례를 확인할 수 있어야 한다.

**검수 기준**  기준 템플릿에서 원본 치수와 수정 가능한 변수를 구분하고 원본 참조에 접근할 수 있다. 검증 범위를 벗어난 입력은 검증된 설계와 구분하여 표시한다.

<a id="req_LIB_002"></a>

#### LIB-002  재료 데이터 출처와 버전

M 필수  ·  R1  ·  P 추가 제안

사용자는 재료 데이터의 출처, 개정, 적용 주파수와 온도 등 조건, 측정 또는 모델 정보 및 불확실성을 확인하고 프로젝트에 사용한 값을 스냅샷으로 보존할 수 있어야 한다.

**검수 기준**  재료 라이브러리를 업데이트해도 기존 프로젝트의 수치가 자동 변경되지 않는다. 새 데이터 적용을 선택하면 이전 값, 새 값 및 변경으로 영향을 받는 결과가 표시된다.

<a id="req_LIB_003"></a>

#### LIB-003  조건 기반 검색과 추천 근거

M 필수  ·  R1  ·  B 비교 검토  ·  [S25](#source-s25) [S26](#source-s26)

사용자는 안테나 계열, 주파수 조건, 요구 대역폭, 편파, 설치 공간과 보드 조건으로 템플릿을 검색하고 후보가 제시된 이유와 제외된 이유를 확인할 수 있어야 한다.

**검수 기준**  같은 목표에 대해 여러 후보를 표시하고 지원 범위와 제약의 차이를 비교한다. 합성 알고리즘이 없거나 조건을 충족하지 않는 형상을 자동 설계 가능한 후보로 표시하지 않는다.

<a id="req_LIB_004"></a>

#### LIB-004  사용자 템플릿과 사내 라이브러리

S 권장  ·  R2  ·  P 추가 제안

사용자는 자신의 형상과 파라미터 정의, 재료, 적용 조건 및 검증 데이터를 재사용 가능한 템플릿으로 저장하고 개인 또는 선택한 팀 범위에서 관리할 수 있어야 한다.

**검수 기준**  저장한 템플릿으로 새로운 프로젝트를 만들면 원본 템플릿을 변경하지 않고 독립적으로 편집할 수 있다. 수정본의 출처와 버전을 추적하며 제공 라이브러리와 사용자 라이브러리를 구분한다.

<a id="req_LIB_005"></a>

#### LIB-005  검증 사례 카탈로그

M 필수  ·  R1  ·  P 추가 제안  ·  [S17](#source-s17)

**검수 기준**  기준 사례에 입력, 비교 데이터, 평가 지표 및 적용한 허용오차가 함께 제공된다. 일부 사례의 통과 결과가 검증하지 않은 형상과 환경 전체의 정확도 보장으로 표시되지 않는다.

<a id="req_LIB_006"></a>

#### LIB-006  외부 지식과 템플릿 가져오기

S 권장  ·  R2  ·  P 추가 제안

사용자는 외부 템플릿과 참조 자료를 가져올 때 출처, 버전, 사용 조건 및 실행 가능한 코드 포함 여부를 확인할 수 있어야 한다. 참조 자료를 여는 행위가 포함된 스크립트를 자동 실행하지 않아야 한다.

**검수 기준**  코드가 포함된 시험 템플릿은 단순 가져오기만으로 실행되지 않는다. 승인된 실행과 단순 데이터 참조를 구분하며 원본 출처 및 변경 이력을 보존한다.

<a id="group_GEO"></a>

### 6.4 GEO 형상과 PCB 편집

사용자는 안테나, 급전부, 접지, 기판 및 주변 형상을 같은 설계 리비전에서 관리할 수 있어야 한다. 설계·해석·도면·제조 출력 간 의미와 치수의 일관성을 요구하되 특정 CAD 커널, 내부 자료구조 또는 API의 사용은 강제하지 않는다. R1의 검수 기준 보드는 2층 경성 PCB로 제안하며, 추가 층수와 특수 비아는 제품이 선언한 지원 범위에 따라 확장한다.

<a id="req_GEO_001"></a>

#### GEO-001  변수에 따른 형상 생성과 연동

M 필수  ·  R1  ·  U 사용자 명시

사용자는 선폭, 구간 길이, 간격, 반경, 각도, 반복 수 등을 변수와 수식으로 정의하고 수정할 수 있어야 한다. 변수 변경은 같은 설계 리비전의 2D 패턴, 3D 형상, 해석 입력 및 출력 도면에 일관되게 반영되어야 한다.

**검수 기준**  한 길이와 한 선폭 변수를 변경한 기준 모델에서 관련 2D·3D 치수와 해석 입력이 함께 갱신된다. 단위 불일치, 미정의 변수 및 순환 참조는 원인을 표시하고 적용하지 않는다.

<a id="req_GEO_002"></a>

#### GEO-002  사용자 정의 안테나 패턴

M 필수  ·  R1  ·  U 사용자 명시

사용자는 템플릿 이외에 직선, 원호, 원, 닫힌 다각형, 슬롯 및 복수의 독립 도체를 조합하여 안테나와 접지 패턴을 작성하고 편집할 수 있어야 한다. 지원하지 않는 곡선이나 형상 표현은 명시되어야 한다.

**검수 기준**  템플릿을 사용하지 않고 meander와 슬롯을 포함한 패턴을 생성한 뒤 저장·재개방하여 개별 구간을 편집한다. 구리 영역과 빈 슬롯의 구분 및 닫힌 외곽이 유지된다.

<a id="req_GEO_003"></a>

#### GEO-003  치수 및 기하 구속조건

S 권장  ·  R2  ·  P 추가 제안

사용자는 치수, 일치, 수평·수직, 평행, 대칭 및 접선 조건을 부여하고 미구속·과구속·충돌 상태를 확인할 수 있어야 한다.

**검수 기준**  대칭 패턴의 치수를 변경해도 대칭 조건이 유지된다. 서로 모순되는 구속조건을 추가하면 충돌하는 조건을 식별하고 마지막 유효 형상으로 복구할 수 있다.

<a id="req_GEO_004"></a>

#### GEO-004  물리 적층과 레이어별 형상

M 필수  ·  R1  ·  U 사용자 명시  ·  [S35](#source-s35) [S36](#source-s36)

사용자는 지원 층수 범위에서 층 순서, 유전체 두께, 동박 두께 및 도체의 높이를 정의하고 보드 외곽, 내부 절개, 구리 패턴, 접지, 패드, 비아와 keepout을 객체와 레이어별로 관리할 수 있어야 한다.

**검수 기준**  R1 기준 2층 보드에서 각 동박층과 유전체층의 위치·두께 및 보드 전체 두께 정의를 확인한다. 층별 두께 합과 명목 보드 두께가 맞지 않으면 차이를 표시하며 임의 보정하지 않는다.

#### GEO-005  단위·좌표·원점·상하면 일관성

M 필수  ·  R1  ·  B 비교 검토  ·  [S05](#source-s05) [S34](#source-s34)

사용자는 길이 단위, 좌표축, 설계 원점, 제조 원점 및 상하면 방향을 확인하고 이동·회전·미러링·배열을 수행할 수 있어야 한다. 각 출력에 적용한 좌표 변환을 확인할 수 있어야 한다.

**검수 기준**  비대칭 상·하면 표식과 사용자 원점을 포함한 기준 보드를 2D·STEP·PCB 제조 형식으로 출력한 후 대응 좌표를 비교한다. mm와 inch를 전환해도 실제 크기가 보존되며 의도하지 않은 상하면 반전이 없다.

<a id="req_GEO_006"></a>

#### GEO-006  형상 연산과 오류 확인

M 필수  ·  R1  ·  P 추가 제안  ·  [S37](#source-s37)

**검수 기준**  알려진 오류를 넣은 시험 형상에서 문제 위치와 유형을 표시한다. 자동 수정 전후의 주요 치수 및 연결 변화를 기록하고, 오류가 남은 형상을 검증 완료 상태로 표시하지 않는다.

<a id="req_GEO_007"></a>

#### GEO-007  급전·접지·비아 연결 상태

**검수 기준**  기대 연결 관계가 정의된 기준 보드에서 끊어진 급전, 잘못 연결된 접지 및 슬롯을 가로지른 구리를 검출한다. 의도적으로 분리한 도체와 기생 소자를 오류로 확정하지 않는다.

<a id="req_GEO_008"></a>

#### GEO-008  주변 3D 형상의 가져오기와 배치

S 권장  ·  R2  ·  U 사용자 명시  ·  [S37](#source-s37) [S06](#source-s06)

**검수 기준**  외부 STEP 부품을 이동·회전하여 배치하고 재개방 후 위치를 확인한다. 물성이 없는 부품은 미지정 상태로 표시하며, 단순화한 형상과 원본의 대응 관계 및 사용 목적을 확인할 수 있다.

<a id="req_GEO_009"></a>

#### GEO-009  2D 벡터 형상의 가져오기

S 권장  ·  R2  ·  B 비교 검토  ·  [S06](#source-s06)

사용자는 지원하는 DXF 객체를 패턴의 기초 형상으로 가져올 수 있어야 한다. 가져오기 시 단위, 레이어, 폐곡선, 원호 표현 및 미지원 객체를 확인하고 필요한 역할을 지정할 수 있어야 한다.

**검수 기준**  직선·원호·폐곡선을 가진 기준 DXF를 가져와 실제 길이를 확인하고 구리 또는 보드 외곽으로 지정한다. 미지원 엔티티를 누락한 경우 객체 목록과 영향을 표시하며 전체 변환 성공으로 숨기지 않는다.

#### MAT-007  솔더마스크와 표면 층

M 필수  ·  R1  ·  P 추가 제안  ·  [S38](#source-s38)

사용자는 솔더마스크 개구 코팅 접착층 및 표면처리의 적용 영역 두께와 재료를 지정하고 해석 포함 여부를 선택할 수 있어야 한다.

**검수 기준**  표면 층을 추가하거나 제거한 두 상태를 별도 실행으로 비교할 수 있다. 입력했지만 해석에서 생략한 층은 보고서에 표시된다.

<a id="req_MAT_008"></a>

#### MAT-008  주파수 의존 물성

S 권장  ·  R2  ·  B 비교 검토  ·  [S01](#source-s01)

프로그램은 주파수별 물성 곡선을 가져와 지원 분산 모델에 피팅하고 원본 곡선 적용 대역 및 오차를 제공해야 한다.

**검수 기준**  원본과 피팅 곡선 및 합의한 오차 기준의 충족 여부를 확인할 수 있다. 유효 대역 밖 외삽이나 단일 주파수 상수 근사는 명시된다.

<a id="req_MAT_009"></a>

#### MAT-009  이방성과 자기 재료

S 권장  ·  R2  ·  B 비교 검토  ·  [S01](#source-s01) [S46](#source-s46)

프로그램은 지원하는 유전율 이방성 재료 축 및 복소투자율 모델을 저장하고 선택한 해석기로 표현 가능한지 확인해야 한다.

**검수 기준**  이방성 축을 회전한 조건이 해석 입력에 반영된다. 미지원 텐서 성분이나 자기 손실이 조용히 등방성 또는 무손실로 대체되지 않는다.

<a id="req_MAT_010"></a>

#### MAT-010  도체 표면 거칠기

S 권장  ·  R2  ·  B 비교 검토  ·  [S46](#source-s46)

프로그램은 도체 면별 표면 거칠기 모델과 모델별 입력값을 관리하고 지원하는 백엔드에서 손실에 반영해야 한다.

**검수 기준**  모델 이름 계수 적용 면과 지원 여부가 표시된다. 서로 다른 거칠기 지표가 근거 없이 변환되지 않으며 미지원 백엔드는 반영되지 않음을 알린다.

<a id="group_ENV"></a>

### 6.6 ENV 주변 환경과 설치 조건

안테나는 방사체만이 아니라 접지와 기판 케이스 주변 금속 및 설치 위치가 포함된 설계 상태로 관리한다. 환경 변화의 물성 근거가 없으면 실제로 계산하지 않은 효과를 계산한 것처럼 표시하지 않는다.

<a id="req_ENV_001"></a>

#### ENV-001  접지와 레이어별 금지 영역

M 필수  ·  R1  ·  P 추가 제안  ·  [S46](#source-s46)

사용자는 유한 접지의 외곽 분할 슬롯 비아 연결과 레이어별 동박 및 부품 금지 영역을 설정할 수 있어야 한다.

**검수 기준**  상면만 비운 상태와 모든 층을 비운 상태가 구분된다. 유한 접지와 무한 접지 근사 사용 여부가 결과에 표시된다.

<a id="req_ENV_002"></a>

#### ENV-002  케이스와 보호 구조

M 필수  ·  R1  ·  U 사용자 명시

사용자는 케이스 radome 및 보호 덮개의 형상 두께 재료 위치와 안테나 이격거리를 모델에 포함할 수 있어야 한다.

**검수 기준**  R1에서는 치수와 재료가 정의된 간이 형상으로 이격 또는 재료 변경 조건을 비교한다. 상세 외부 CAD 가져오기는 GEO-008의 지원 단계에 따른다. 입력된 케이스가 해석에서 제외되면 제외 사실이 표시된다.

<a id="req_ENV_003"></a>

#### ENV-003  주변 부품과 금속

M 필수  ·  R1  ·  P 추가 제안

사용자는 배터리 실드 디스플레이 커넥터 나사와 주요 부품을 배치하고 재료 및 전기적 접촉을 지정할 수 있어야 한다.

**검수 기준**  물체가 가까이 있는 상태와 접지에 연결된 상태를 별도 모델로 표현한다. 접촉 간극 또는 누락된 재료를 해석 전에 확인한다.

<a id="req_ENV_004"></a>

#### ENV-004  설치 위치와 근접 물체

M 필수  ·  R1  ·  P 추가 제안

프로그램은 브래킷 벽면 금속판 및 다른 기판과의 거리 방향 위치를 시나리오 변수로 관리해야 한다.

**검수 기준**  각 설치 조건의 변환 행렬과 물성이 저장되고 결과 비교표는 변경된 항목을 표시한다. 숨겨진 물체가 자동으로 해석에서 제외되지 않는다.

<a id="req_ENV_005"></a>

#### ENV-005  복수 안테나 배치

S 권장  ·  R2  ·  B 비교 검토  ·  [S03](#source-s03)

사용자는 여러 안테나와 배열 소자의 위치 방향 간격 및 포트 연결을 정의하고 상호 결합을 포함해 해석할 수 있어야 한다.

**검수 기준**  독립 안테나 패턴의 단순 합과 상호 결합을 계산한 결과가 구분된다. 소자별 종단 및 구동 조건이 실행과 함께 저장된다.

<a id="req_ENV_006"></a>

#### ENV-006  온도와 습도 조건

S 권장  ·  R2  ·  P 추가 제안  ·  [S38](#source-s38) [S39](#source-s39)

프로그램은 온도 습도 및 노화 조건에 따른 물성 또는 형상 변화 데이터를 이용해 환경 시나리오를 정의할 수 있어야 한다.

**검수 기준**  계수 또는 측정 데이터의 출처와 유효 범위를 기록한다. 데이터가 없는 환경 효과는 미반영으로 표시하고 임의 계수를 자동 생성하지 않는다.

<a id="req_ENV_007"></a>

#### ENV-007  인체와 팬텀 환경

C 선택  ·  R3  ·  P 추가 제안

프로그램은 인체 근접 분석을 선택한 경우 팬텀 형상 조직 물성 자세 및 이격을 별도의 환경 모델로 관리해야 한다.

**검수 기준**  팬텀의 출처 물성 주파수 범위 모델 단순화와 지원 해석 지표가 표시된다. 단순 근접 분석을 별도의 검증 없는 규제 적합 판정으로 표시하지 않는다.

<a id="req_ENV_008"></a>

#### ENV-008  유연 기판의 변형

C 선택  ·  R3  ·  P 추가 제안

프로그램은 유연 기판의 굽힘 반경 굽힘 축 각도 및 변형 후 적층을 정의하고 평면 설계와 연결할 수 있어야 한다.

**검수 기준**  변형 후 도체와 유전체의 위치 및 연결이 유지된다. 표현할 수 없는 변형 또는 재료 축 변환은 계산 전에 표시된다.

<a id="group_FED"></a>

### 6.7 FED 급전과 정합

포트는 위치뿐 아니라 기준 도체 방향 임피던스 모드 및 기준면을 갖는 해석 조건이다. 정합 회로와 손실 그리고 RF IC 부하 조건을 분리해 관리한다.

<a id="req_FED_001"></a>

#### FED-001  급전 포트 모델

M 필수  ·  R1  ·  B 비교 검토  ·  [S42](#source-s42)

프로그램은 지원하는 lumped microstrip CPW 및 coaxial 포트를 선택하고 모델별 기하와 적용 조건을 표시해야 한다.

**검수 기준**  포트 종류에 따라 필수 입력이 달라진다. 실제 지원하지 않는 포트는 선택 불가 또는 명시적인 대체 모델로 표시된다.

<a id="req_FED_002"></a>

#### FED-002  급전 연결과 방향 검사

M 필수  ·  R1  ·  P 추가 제안  ·  [S42](#source-s42)

프로그램은 급전 도체 기준 도체 포트 극성 방향 및 포트 단면이 모델과 올바르게 연결되는지 검사해야 한다.

**검수 기준**  의도적으로 단선하거나 뒤집은 급전 시험에서 오류 위치가 표시된다. Lumped 근사의 유효 범위를 벗어나는 설정은 경고한다.

<a id="req_FED_003"></a>

#### FED-003  기준 임피던스와 부하

M 필수  ·  R1  ·  B 비교 검토  ·  [S42](#source-s42) [S03](#source-s03)

사용자는 포트별 기준 임피던스 소스 및 부하 임피던스를 지정하고 주파수 의존 모델의 지원 범위를 확인할 수 있어야 한다.

**검수 기준**  50 Ω 기본값은 화면과 보고서에 나타난다. 재정규화 전후 결과와 power wave 또는 voltage wave 정의가 구분된다.

<a id="req_FED_004"></a>

#### FED-004  기준면과 보정

M 필수  ·  R1  ·  B 비교 검토  ·  [S42](#source-s42)

프로그램은 포트 기준면을 지정하고 지원하는 전송선 포트의 기준면 이동 및 deembedding 조건을 기록해야 한다.

**검수 기준**  원본 결과와 이동한 기준면 결과가 보존된다. 보정 길이 방향 전파 모델 및 적용 대역을 확인할 수 있다.

<a id="req_FED_005"></a>

#### FED-005  기본 정합 회로

M 필수  ·  R1  ·  P 추가 제안  ·  [S03](#source-s03) [S45](#source-s45)

사용자는 직렬 병렬 RLC와 기본 정합 네트워크를 연결하고 부품 값에 따른 정합 및 손실 변화를 비교할 수 있어야 한다.

**검수 기준**  매칭 전후 임피던스 S11 및 손실을 같은 기준면에서 비교한다. 정합 개선만으로 방사 효율이 개선된 것으로 표시하지 않는다.

<a id="req_FED_006"></a>

#### FED-006  실제 정합 부품

S 권장  ·  R2  ·  B 비교 검토  ·  [S45](#source-s45)

프로그램은 부품 Q ESR 자기 공진 주파수 공차 및 Sparameter 모델을 사용하고 이상 소자 모델과 구분해야 한다.

**검수 기준**  부품 모델 적용 대역을 벗어나면 표시한다. 동일 정합 회로의 이상 모델과 실제 모델 결과를 비교하고 사용한 부품 revision을 보존한다.

<a id="req_FED_007"></a>

#### FED-007  차동과 복수 포트 구동

S 권장  ·  R2  ·  B 비교 검토  ·  [S03](#source-s03)

사용자는 차동 공통 모드 및 포트별 진폭 위상을 지정하고 필요한 모드 변환과 정규화 조건을 확인할 수 있어야 한다.

**검수 기준**  동시 구동과 한 포트씩 구동한 계산이 구분된다. 각 구동 상태의 종단 진폭 위상 및 모드 기준이 실행 기록에 포함된다.

<a id="req_FED_008"></a>

#### FED-008  NFC 코일과 부하 정합

C 선택  ·  R3  ·  B 비교 검토  ·  [S45](#source-s45)

NFC 기능을 제공할 경우 프로그램은 코일 L R 기생 C 자기 공진 Q 및 reader 또는 tag 부하에 따른 정합을 다뤄야 한다.

**검수 기준**  Loaded Q와 unloaded Q를 구분하고 금속 및 ferrite 영향의 반영 여부를 표시한다. Q의 무조건 최대화 대신 지정 부하와 대역 조건으로 평가한다.

<a id="req_FED_009"></a>

#### FED-009  급전 케이블과 평형 변환 구조

S 권장  ·  R2  ·  P 추가 제안

사용자는 필요한 경우 실제 급전선과 커넥터, balun 및 공통모드 억제 구조를 형상 또는 검증된 회로 모델로 포함하고 이상적인 급전 조건과 비교할 수 있어야 한다.

**검수 기준**  평형 안테나에 연결한 불평형 케이블의 모델링 범위와 접지·차폐 연결을 표시한다. 실제 급전 구조를 포함한 결과와 이상 포트의 결과를 구분하고 케이블 경로 및 길이 변경을 추적한다.

<a id="group_SIM"></a>

### 6.8 SIM 전자기장 해석

해석 설정은 자동화를 제공하되 사용한 물리와 수치 근거를 확인할 수 있게 한다. 메시와 경계 조건의 수렴은 실행 성공과 별도 판정으로 관리한다.

<a id="req_SIM_001"></a>

#### SIM-001  해석 기능 지원 검사

M 필수  ·  R1  ·  P 추가 제안  ·  [S01](#source-s01) [S40](#source-s40) [S42](#source-s42)

프로그램은 형상 물성 포트 경계 및 요구 결과에 대해 선택한 해석기의 지원 여부와 적용 근사를 실행 전에 검사해야 한다.

**검수 기준**  백엔드 변경 시 지원 변환 누락 항목의 보고서를 만든다. 미지원 기능은 조용히 제거되지 않고 실행 가능 여부와 근사 변경이 명확히 표시된다.

<a id="req_SIM_002"></a>

#### SIM-002  자동 메시와 국부 세분화

M 필수  ·  R1  ·  B 비교 검토  ·  [S41](#source-s41)

프로그램은 대역 내 파장과 trace gap via 급전 구조를 고려한 자동 메시 및 사용자 지정 국부 세분화를 제공해야 한다.

**검수 기준**  메시의 최소 최대 크기와 주요 형상의 해상도를 볼 수 있다. 예상 셀 수 및 자원 사용량이 실행 전에 제시된다.

<a id="req_SIM_003"></a>

#### SIM-003  메시 이후 형상 보존

M 필수  ·  R1  ·  P 추가 제안  ·  [S41](#source-s41)

프로그램은 메시 또는 solver 변환으로 가는 도체가 소실되거나 간극이 닫히거나 시트가 누락되는지 검사해야 한다.

**검수 기준**  의도적으로 거친 메시를 적용한 기준 모델에서 소실 또는 잘못된 연결 위치를 검출한다. 원래 CAD와 변환된 해석 형상을 비교할 수 있다.

<a id="req_SIM_004"></a>

#### SIM-004  해석 영역과 경계 조건

M 필수  ·  R1  ·  B 비교 검토  ·  [S47](#source-s47)

프로그램은 외부 매질과 방사 PML 대칭 또는 주기 경계를 정의하고 모델과 경계의 적절한 배치를 검사해야 한다.

### 6.10 OPT 탐색과 최적화 및 실측 비교

사용자는 목표에 맞는 후보를 만들고 비교하는 과정에서 변화시킬 변수, 고정 조건, 제조 제약 및 계산 예산을 명시해야 한다. 최적화 기능은 미달하거나 해석에 실패한 후보를 구분해야 하며, 원본 설계와 실측 데이터를 보존한 상태에서 수정안을 제시해야 한다.

<a id="req_OPT_002"></a>

#### OPT-002  제약을 포함한 자동 최적화

**검수 기준**  보드 경계, 최소 간격 또는 고정 치수를 위반한 후보가 합격 설계로 반환되지 않는다. 목표 미달 시 가장 좋은 유효 후보와 미달 항목을 함께 제공하고 전역 최적을 보장한다고 표시하지 않는다.

#### OPT-003  후보 비교와 다목적 탐색

**검수 기준**  후보별로 달라진 입력과 성능 지표를 표와 그래프로 제공한다. 가중 점수나 정렬 순서가 강제 제약 미달 상태를 합격으로 바꾸지 않는다.

**검수 기준**  원래 측정과 설계가 유지되며 보정 전후 오차와 변경 변수를 확인할 수 있다. 보정에 사용하지 않은 데이터로 별도 검증할 수 있고 특정 시료의 적합을 일반 정확도 보장으로 표시하지 않는다.

#### OPT-007  탐색 이력과 재현

**검수 기준**  학습 데이터의 범위와 버전, 별도 검증 데이터의 오차를 표시한다. 범위 밖 예측은 미검증으로 표시하고 최종 후보는 원래 EM 해석과 제조 제약으로 다시 평가한다. 예측만으로 정밀 해석 완료 상태를 부여하지 않는다.

<a id="req_OPT_010"></a>

#### OPT-010  자유 형상과 역설계 탐색

C 선택  ·  R3  ·  P 추가 제안

사용자는 고정된 템플릿 치수 외에 분기, 슬롯 또는 도체 영역의 형상을 탐색하는 고급 설계 기능을 선택할 수 있어야 한다. 허용 영역과 연결 및 제조 한계를 탐색의 강제 제약으로 지정해야 한다.

**검수 기준**  생성 후보가 편집 가능한 물리 형상으로 저장되고, 급전 연결, 최소 선폭과 간격, STEP 및 제조 출력 검수를 통과한다. 후보의 좋은 S11만으로 이득과 효율까지 합격 처리하지 않으며 독립적인 최종 재해석을 기록한다.

<a id="group_DRW"></a>

### 6.11 DRW 2D 기술 도면과 벡터 출력

도면은 검토와 치수 전달에, 제조 CAM 데이터는 제작에 사용된다. 두 출력의 목적과 포함 요소를 구분한다. τ2D는 프로젝트가 정하는 2D 좌표 및 곡선 변환 허용오차로, 인쇄 장치의 오차나 실제 PCB 제조 공차를 의미하지 않는다.

<a id="req_DRW_001"></a>

#### DRW-001  연관 치수와 필요한 도면 뷰

M 필수  ·  R1  ·  U 사용자 명시

사용자는 상면·하면·단면·상세도와 길이·폭·간격·각도·반경 치수, 기준점 및 주석을 포함한 기술 도면을 작성할 수 있어야 한다. 모델에서 유도한 치수는 모델 변경에 따라 갱신되어야 한다.

**검수 기준**  도면에서 선폭, 급전 갭, 패턴 길이, 기판 두께 및 동박 두께를 확인한다. 해당 변수를 수정하면 도면 수치가 갱신되고 수동으로 덮어쓴 표시는 실제 측정 치수와 구별된다.

<a id="req_DRW_002"></a>

#### DRW-002  PDF·SVG·DXF 출력과 실제 크기

M 필수  ·  R1  ·  U 사용자 명시  ·  [S06](#source-s06)

사용자는 PDF, SVG 및 DXF로 2D 도면을 출력할 수 있어야 한다. CAD 교환용 패턴은 실제 크기 1:1로 출력하고, 문서용 도면은 지정 축척과 용지에 맞게 작성할 수 있어야 한다.

**검수 기준**  10 mm 검증선을 포함한 SVG와 DXF를 독립 뷰어에서 읽었을 때 길이가 τ2D 이내로 보존된다. PDF에는 축척과 100% 인쇄 기준을 표시하고 패턴·치수는 확대 시 판독 가능한 벡터 요소로 출력한다.

<a id="req_DRW_003"></a>

#### DRW-003  레이어와 출력 목적별 요소 선택

M 필수  ·  R1  ·  B 비교 검토  ·  [S05](#source-s05) [S35](#source-s35)

사용자는 구리, 접지, 보드 외곽, keepout, 중심선, 치수와 주석을 선택하여 출력할 수 있어야 한다. 채워진 구리 영역, 구리 경계 및 중심선은 서로 구분하여 내보낼 수 있어야 한다.

**검수 기준**  동일 프로젝트에서 구리 경계만 포함한 DXF와 치수 포함 PDF를 생성한다. 제조용 구리 데이터에 치수 문자·주석선·중심선이 구리로 혼입되지 않으며 출력된 레이어 역할을 식별할 수 있다.

<a id="req_DRW_004"></a>

#### DRW-004  도면 표제란과 적층 정보

M 필수  ·  R1  ·  P 추가 제안  ·  [S36](#source-s36)

사용자는 프로젝트명, 리비전, 단위, 축척, 작성일, 층별 재료와 두께, 적용 공차 및 중요 제작 지시를 도면에 표시할 수 있어야 한다.

**검수 기준**  도면의 리비전·적층·두께가 해당 출력 설계와 일치한다. 재료나 두께가 미정이면 임의 값으로 확정하지 않고 미정 또는 추정 상태를 표시한다.

<a id="req_DRW_005"></a>

#### DRW-005  구멍·슬롯·좌표와 형상 요약표

S 권장  ·  R2  ·  P 추가 제안

사용자는 드릴·슬롯·비아 표, 기준 좌표표 및 선택한 도체의 면적·중심선 길이 등 검토용 요약을 생성할 수 있어야 한다.

**검수 기준**  구멍 수·직경·도금 구분과 좌표표가 모델과 일치한다. 도체 중심선 길이는 전기적 길이나 공진 길이와 구분되어 표시된다.

<a id="group_STP"></a>

### 6.12 STP 실제 두께의 3D 형상과 STEP 교환

필수 STEP 출력은 사용자가 다른 프로그램에서 수작업으로 재모델링하지 않고 얻는 실제 두께의 BREP 솔리드 결과를 뜻한다. 화면용 3D, 삼각형 메쉬 또는 STEP 가져오기만으로는 충족되지 않는다. τCAD는 선언한 지원 형상의 데이터 교환 허용오차다. 잠정 제안으로 단순 검수용 PCB의 τCAD=0.001 mm를 후보로 두되 실제 백엔드·최소 형상·대상 CAD를 검토하여 확정한다. 이 값은 PCB 제조 공차가 아니다.

<a id="req_STP_001"></a>

#### STP-001  BREP 솔리드 STEP의 생성

M 필수  ·  R1  ·  U 사용자 명시  ·  [S37](#source-s37) [S06](#source-s06)

사용자는 실제 설계 치수와 두께를 가진 기판 및 도체 솔리드를 생성하고 STEP로 출력할 수 있어야 한다. 필수 형상은 외부 CAD에서 솔리드로 인식되는 경계 표현을 사용해야 한다.

**검수 기준**  독립 CAD에서 출력 STEP를 열어 기판과 동박을 솔리드로 선택하고 두께·면적·체적을 측정한다. 화면 캡처, 표면만 있는 모델 또는 삼각형 메쉬만 존재하면 필수 출력 검수를 통과하지 못한다.

<a id="req_STP_002"></a>

#### STP-002  안테나·접지·각 층과 부품의 포함

M 필수  ·  R1  ·  U 사용자 명시  ·  [S05](#source-s05) [S34](#source-s34)

사용자는 지원하는 보드 범위의 안테나 패턴, 급전선, 접지, 패드, 동박층, 유전체층, 비아 금속 및 선택한 부품을 STEP에 포함할 수 있어야 한다. 출력 대상을 사전에 확인할 수 있어야 한다.

**검수 기준**  선택한 객체 목록과 외부 CAD에서 확인한 바디 목록이 대응한다. 안테나 구리 또는 접지가 누락된 경우 그 사실을 표시하고 요구된 전체 모델 출력 성공으로 처리하지 않는다.

<a id="req_STP_003"></a>

#### STP-003  분리된 바디·이름·조립 구조

M 필수  ·  R1  ·  U 사용자 명시  ·  [S37](#source-s37)

사용자는 유전체, 안테나 도체, 접지, 비아 및 부품을 구분 가능한 바디와 이름으로 출력하고 외부 CAD에서 개별 선택할 수 있어야 한다. 같은 도체를 병합하는 경우 원래 객체와의 대응 관계와 병합 기준을 확인할 수 있어야 한다.

**검수 기준**  독립 CAD에서 기판·안테나·접지·비아·부품 그룹을 각각 선택하거나 숨길 수 있다. 실제로 연결된 구리의 합집합과 서로 다른 재료의 분리는 유지되며 출력 바디 이름과 대응표를 확인한다.

<a id="req_STP_004"></a>

#### STP-004  두께와 적층 위치의 물리적 일치

M 필수  ·  R1  ·  U 사용자 명시  ·  [S05](#source-s05) [S34](#source-s34)

제조·기계 교환용 STEP의 동박, 유전체 및 선택한 표면층은 설정된 실제 두께와 적층 위치를 반영해야 한다. 표시상 구분을 위한 패드 두께 추가나 구멍 채움은 제조 형상에 알리지 않고 적용되어서는 안 된다.

**검수 기준**  상·하면 동박 각 0.035 mm와 사이 유전체 1.530 mm로 정의한 시험판에서 구리 외면 사이 거리는 1.600 mm이고 각 층 두께는 τCAD 이내로 일치한다. 이 시험의 전체 두께에는 솔더마스크를 포함하지 않는다. 표시용 치수 변경의 적용 여부를 출력 기록에서 확인한다.

<a id="req_STP_005"></a>

#### STP-005  해석용 시트와 제조용 솔리드의 구분

M 필수  ·  R1  ·  P 추가 제안

사용자는 해석을 위한 무두께 도체 시트·PEC 등의 근사와 실제 제조 형상을 구분할 수 있어야 한다. 해석 근사가 제조용 STEP의 명목 동박 두께를 변경해서는 안 된다.

**검수 기준**  동박 두께 35 µm인 동일 설계에서 해석은 시트 근사로 설정하더라도 제조 STEP에는 유한 두께 동박이 존재한다. 해석용 시트 모델을 별도 내보내는 경우 파일 성격과 적용 근사를 명확히 표시한다.

<a id="req_STP_006"></a>

#### STP-006  미지원·누락·단순화 형상의 공개

M 필수  ·  R1  ·  B 비교 검토  ·  [S05](#source-s05) [S06](#source-s06)

사용자는 STEP로 변환할 수 없는 메쉬 부품, 누락된 외부 모델, 곡선 근사 및 선택적으로 생략한 형상을 출력 전에 확인할 수 있어야 한다. 부품 대체와 단순화는 적용 사실을 남겨야 한다.

**검수 기준**  STEP 모델이 없는 메쉬 부품을 포함한 시험에서 누락·대체 목록을 보여준다. 승인하지 않은 대체 형상으로 원본을 조용히 교체하지 않으며 주요 RF 간극이나 치수가 바뀌면 차이를 표시한다.

<a id="req_STP_007"></a>

#### STP-007  지원 STEP 스키마와 수신 CAD 호환성

M 필수  ·  R1  ·  B 비교 검토  ·  [S37](#source-s37)

제품은 지원하는 STEP 스키마, 단위 및 수신 CAD의 검증 범위를 명시해야 하며 지정된 외부 CAD에서 형상과 필수 속성을 재개방할 수 있어야 한다. AP242 우선과 필요 시 AP214 호환 출력을 잠정 제안한다.

**검수 기준**  합의한 독립 STEP 리더에서 기준 파일을 열어 크기·방향·필수 바디·이름·조립 구조를 확인한다. 수신 도구에서 지원되지 않는 속성은 교환 제한 목록으로 제시한다.

<a id="req_STP_008"></a>

#### STP-008  형상 유효성과 내보내기 전후 비교

M 필수  ·  R1  ·  P 추가 제안  ·  [S37](#source-s37)

사용자는 내보내기 전후의 주요 치수, 경계, 바디 누락, 열린 솔리드, 구멍 및 연결 상태에 대한 검증 결과를 확인할 수 있어야 한다. 파일 쓰기 성공과 형상 검증 성공을 구별해야 한다.

**검수 기준**  STEP 재입력 시 주요 치수와 경계 편차가 τCAD 이내이고 기대한 구멍·연결·바디 구성이 유지된다. 면적·체적·중심점은 보조 지표로 비교하며, 합계 일치만으로 국소적인 급전 갭 손실을 통과시키지 않는다.

<a id="req_STP_009"></a>

#### STP-009  비아·도금 구멍의 실제 형상

M 필수  ·  R1  ·  U 사용자 명시  ·  [S05](#source-s05) [S34](#source-s34)

지원하는 비아와 도금 구멍은 선언된 도금 두께, 완성 구멍 치수, 패드 및 연결층을 반영해야 한다. 중공 도금 배럴과 충진 비아를 구분할 수 있어야 한다.

**검수 기준**  R1의 관통 비아 시험에서 구멍이 관통하고 배럴 금속과 연결 패드가 존재한다. 구멍을 메우는 출력 옵션은 명시된 경우에만 적용된다. 블라인드·매립·마이크로비아는 지원을 선언한 단계에서 시작층·끝층을 추가 검수한다.

<a id="req_STP_010"></a>

#### STP-010  STEP와 물성·해석 설정의 대응

M 필수  ·  R1  ·  P 추가 제안  ·  [S37](#source-s37)

사용자는 STEP와 함께 바디 식별자, 재료 연결, 단위, 좌표 변환, 설계 리비전 및 적용 근사를 담은 동반 명세를 내보낼 수 있어야 한다. STEP 교환으로 보존되지 않는 주파수 의존 물성, 포트 및 경계조건은 프로젝트 또는 동반 파일에 보존되어야 한다.

**검수 기준**  STEP의 바디를 동반 명세의 재료와 대응시킬 수 있다. 이름·밀도 등의 기계 재료 속성만 전달된 상태를 εr(f), tanδ(f), 도전율 모델 및 해석 설정까지 전달된 것으로 표시하지 않는다.

<a id="group_FAB"></a>

### 6.13 FAB PCB 도구 연동과 제조 패키지

제조 연동은 선언된 파일 버전과 객체 범위에서 검증한다. R1에는 KiCad의 지원 객체 교환, Gerber X2, 드릴 및 적층 명세를 제안한다. 모든 CAD·PCB 형식을 읽고 쓸 수 있다는 포괄적 약속은 두지 않는다. 제조 DRC, RF 성능 합격, 제조사 최종 적층 승인은 별도의 판정이다.

<a id="req_FAB_001"></a>

#### FAB-001  편집 가능한 KiCad PCB 교환

M 필수  ·  R1  ·  B 비교 검토  ·  [S05](#source-s05) [S34](#source-s34)

사용자는 선언된 KiCad 버전과 객체 범위에서 PCB를 가져오고 내보낼 수 있어야 한다. 트랙, 구리 영역, 패드, 비아, 보드 외곽, 레이어 및 네트는 지원 범위 안에서 편집 가능한 객체로 유지되어야 한다.

**검수 기준**  지원 기준 KiCad 파일을 왕복 변환한 후 필수 객체를 편집하고 주요 치수·연결을 비교한다. 미지원 객체·속성·풋프린트 연결 정보는 변환 전후 목록으로 제공하며 원래 파일 전체가 손실 없이 복원된다고 단정하지 않는다.

**검수 기준**  원본과 독립 제조 뷰어의 결과에서 지정한 RF 중요 치수·구리 경계·연결을 비교한다. 급전 갭 폐쇄, 슬롯 소실 또는 keepout 안의 의도하지 않은 구리를 검출하며 좌표 차이와 위상적 연결 변화를 각각 검사한다.

#### FAB-008  추가 제조 교환 형식

**검수 기준**  출력된 부품 식별자와 값, 실장 상태가 선택 설계의 정합 모델 및 PCB 패드와 대응한다. BOM은 CSV 등 편집 가능한 형식으로 제공하고 부품 모델이 미확정이면 알려야 한다.

### 6.14 VAL 검증과 재현

검증은 수치 수렴 기준 설계 재현 독립 해석 비교 실측 비교를 구분한다. 수용 기준은 대상 형상과 측정 조건에 맞게 합의하고 모든 RF 구조에 대한 정확도 보장으로 확대하지 않는다.

<a id="req_VAL_001"></a>

**검수 기준**  각 사례에 출처 형상 물성 포트 메시 실행 조건과 합의한 수용 기준이 연결된다. 한 사례의 통과를 미검증 형상 전체의 보장으로 표시하지 않는다.

<a id="req_VAL_002"></a>

#### VAL-002  RF 지표 정의 검증

**검수 기준**  입사 1 W 반사 0.25 W 방사 0.6 W인 단일 포트 기준에서 방사 효율 80퍼센트 총효율 60퍼센트가 구분된다. 전력 기준이 모든 출력에서 일치한다.

**검수 기준**  각 실행에 확보한 근거만 표시한다. 동일 솔버의 반복 계산 결과를 독립 검증 또는 실측 검증으로 표시하지 않는다.

#### VAL-004  실측 데이터 가져오기

프로그램은 VNA Sparameter 및 지원하는 방사 패턴 실측 데이터를 가져와 원본과 해석 결과를 같은 좌표에서 비교할 수 있어야 한다.

**검수 기준**  원본 파일 단위 기준 임피던스 측정 날짜와 환경을 보존한다. 주파수 재표본화나 보정 처리는 원본과 구분된다.

<a id="req_VAL_005"></a>

#### VAL-005  측정 기준면과 조건 일치

M 필수  ·  R2  ·  P 추가 제안  ·  [S42](#source-s42) [S44](#source-s44)

프로그램은 실측 비교 시 교정면 케이블 fixture 커넥터 및 주변 환경의 차이를 기록해야 한다.

**검수 기준**  해석과 실측 조건의 불일치 목록을 제공한다. 주파수 이동이나 크기 보정으로 맞춘 결과는 원본 비교로 표시하지 않는다.

<a id="req_VAL_007"></a>

#### VAL-007  강건한 설계 탐색

프로그램은 최적화에서 공차와 환경 시나리오를 평가하고 전기 성능 및 제조 제약을 함께 적용할 수 있어야 한다.

**검수 기준**  미수렴 실패 또는 누락된 계산을 정상 후보로 순위화하지 않는다. 최적 후보도 합의한 검증 기준으로 다시 평가하고 실패한 제약을 표시한다.

<a id="req_VAL_008"></a>

#### VAL-008  실행의 재현 가능성

M 필수  ·  R1  ·  P 추가 제안

프로그램은 모델 물성 포트 메시 solver와 버전 입력 원시 결과 및 후처리 설정을 실행 ID와 함께 보존해야 한다.

**검수 기준**  저장한 실행에서 필요한 입력을 재생성할 수 있다. 수정한 설계의 결과와 과거 설계의 도면 또는 STEP이 같은 revision으로 혼동되지 않는다.

**검수 기준**  시간 제한 종료와 정상 수렴을 구분한다. 재료 외삽 지원하지 않은 효과 또는 검증 범위 밖 사용이 화면과 결과 보고서에 동일하게 표시된다.

### 6.15 NFR 사용 환경과 실행 신뢰성

성능과 운영 요구사항은 기준 하드웨어, 기준 모델 및 지원 범위를 명시하여 검수한다. 초기 Windows 11 x64 지원과 로컬 우선 사용은 제안 사항으로 확정된 사용자 지시가 아니다. 특정 CAD, 프로그래밍 언어 또는 무료 솔버 채택은 이 사용자 요구사항에서 강제하지 않으며, 해석 경로의 설치 및 라이선스 조건을 명확히 표시한다.

<a id="req_NFR_001"></a>

#### NFR-001  계산 큐와 자원 관리

M 필수  ·  R1  ·  B 비교 검토  ·  [S17](#source-s17) [S29](#source-s29)

사용자는 계산을 작업 큐로 관리하고 지원되는 CPU, GPU, 메모리 및 동시 실행 한도를 설정하며 예상 자원과 실제 실행 상태를 확인할 수 있어야 한다.

**검수 기준**  대기, 검사, 전처리, 계산, 후처리, 완료, 실패 및 취소 상태가 구분된다. 과도한 예상 자원 사용을 실행 전에 안내하고 사용자가 대기 작업의 순서를 변경할 수 있다.

<a id="req_NFR_002"></a>

#### NFR-002  실패와 취소 시 데이터 보존

M 필수  ·  R1  ·  P 추가 제안

사용자 취소 또는 해석기 실패가 프로젝트와 완료된 결과를 손상하지 않아야 하며 사용자는 실패 단계, 원인 및 관련 로그를 확인할 수 있어야 한다.

**검수 기준**  무효 입력, 해석기 비정상 종료, 저장 공간 부족 및 사용자 취소 사례를 시험한다. 해당 상태를 구분하고 실패 작업을 성공으로 표시하지 않으며 설계와 완료 결과를 다시 열 수 있다.

<a id="req_NFR_003"></a>

#### NFR-003  자동 저장과 중단 후 복구

M 필수  ·  R1  ·  P 추가 제안

사용자는 프로젝트 자동 저장과 비정상 종료 후 복구를 이용할 수 있어야 한다. 계산 재개는 선택 해석기가 실제로 지원하는 체크포인트 또는 미완료 작업 단위를 기준으로 제공해야 한다.

**검수 기준**  강제 종료 후 마지막 저장 설계와 완료 작업을 복구한다. 해석기 내부 체크포인트가 없으면 미완료 사례를 처음부터 재실행함을 명확히 표시한다.

<a id="req_NFR_004"></a>

#### NFR-004  응답성과 성능 검수

M 필수  ·  R1  ·  P 추가 제안

사용자는 장시간 계산 중에도 프로젝트 열람, 작업 상태 확인 및 취소 기능을 사용할 수 있어야 한다. 편집 응답, 메모리 사용과 계산 성능은 지정된 기준 사례와 하드웨어에서 검수해야 한다.

**검수 기준**  계산 중 UI가 계산 종료까지 잠기지 않는다. 출시 전 정한 기준 사례별로 측정 조건과 결과를 기록하며 임의 크기의 모든 모델에 동일 계산 시간을 보장하지 않는다.

<a id="req_NFR_005"></a>

#### NFR-005  지원 플랫폼과 한국어 사용성

S 권장  ·  R1  ·  P 추가 제안

초기 지원 환경으로 Windows 11 x64와 한국어 사용성을 제안하며, 확정된 지원표에 따라 OS, 화면 배율, 언어, 문자 경로 및 단위 표기를 일관되게 처리해야 한다. 다른 OS 지원 범위는 별도로 표시해야 한다.

**검수 기준**  확정 지원 환경에서 한글 파일명, 공백 경로, 소수점 표기 및 화면 배율 변경을 시험한다. 필수 기능을 키보드로 접근할 수 있고 입력 오류와 상태를 색상만으로 전달하지 않는다.

<a id="req_NFR_006"></a>

#### NFR-006  로컬 사용과 외부 전송 제어

S 권장  ·  R1  ·  P 추가 제안

로컬 우선 사용을 제안하며 사용자는 인터넷 단절 시 가능한 작업과 외부 연결이 필요한 작업을 확인할 수 있어야 한다. 원격 계산 또는 공유를 선택할 때 설계와 측정 파일의 전송 대상 및 범위를 확인할 수 있어야 한다.

**검수 기준**  명시된 로컬 모드에서 프로젝트를 열고 편집하며 준비된 로컬 해석 경로를 사용할 수 있다. 외부 전송을 선택하지 않은 설계 파일을 자동 업로드하지 않으며 원격 실행에 전송한 파일과 대상 기록을 확인할 수 있다.

<a id="req_NFR_007"></a>

#### NFR-007  호환성과 업데이트 관리

M 필수  ·  R1  ·  P 추가 제안

프로그램은 CAD와 해석 커넥터, 재료 라이브러리 및 프로젝트 형식의 버전과 호환성을 확인하고 업데이트가 기존 프로젝트와 결과를 사용자 모르게 변경하지 않도록 해야 한다.

**검수 기준**  누락 또는 호환되지 않는 의존성을 실행 전에 진단한다. 프로젝트 변환 시 변경 내용을 기록하고 원본을 보존하며 기존 결과에 당시 사용한 버전 정보를 유지한다.

<a id="req_NFR_008"></a>

#### NFR-008  해석 경로와 라이선스 조건 안내

M 필수  ·  R1  ·  B 비교 검토  ·  [S27](#source-s27) [S17](#source-s17)

사용자는 선택 가능한 해석 경로와 지원 기능, 필요한 별도 설치 및 라이선스 조건을 확인할 수 있어야 한다. 특정 무료 솔버 채택 여부는 별도 구현 결정으로 남기며 상용 해석 경로를 무료 내장 기능처럼 표시하지 않아야 한다.

**검수 기준**  해석기가 없거나 사용할 수 없는 경우 기능과 원인을 안내한다. 합성만 가능한 상태와 모델 생성 또는 해석 가능한 상태를 구분하고 각 외부 구성요소의 출처와 사용 조건에 접근할 수 있다.

## 7 설계 변수 사전

총 79개 입력 묶음을 정의했다. 하나의 묶음에는 예를 들어 각 층의 두께나 각 선분의 길이처럼 반복 가능한 여러 필드가 포함될 수 있다. 따라서 이 개수는 최종 UI 입력칸이나 데이터베이스 필드 수가 아니다. 변수 사전은 관련 요구사항의 상세 입력 범위를 설명하며, 모든 프로젝트에서 모든 값을 입력하도록 강제하지 않는다.

한 상태가 통과했다고 다른 상태를 자동 합격으로 처리하지 않는다. 예를 들어 해석이 끝났지만 메시 검증을 하지 않았다면 계산 완료와 수렴 미확인을 함께 표시한다. 실측 자료가 없으면 실측 미실시로 남긴다.

### 8.3 수치 기준의 초기 제안

아래 값은 개발 중 사용할 대표 기준 사례에 대한 출발점이다. 산업 표준이나 모든 모델에 대한 정확도 보증값이 아니다. 선정한 솔버·주파수·모델·하드웨어와 기준 데이터를 정한 뒤 계약 또는 릴리스 검수 기준으로 확정한다.

공차 기호 τCAD는 3D 형상 교환의 수치 허용오차, τ2D는 2D 출력의 좌표와 곡선 근사 허용오차, τfab는 실제 제조 치수 공차를 뜻한다. 세 값을 별도로 지정하며, 파일 변환의 작은 오차를 실제 PCB 제작 정확도와 같은 의미로 사용하지 않는다.

| **항목** | **초기 제안** | **적용과 한계** |
| --- | --- | --- |
| 파일 기하 재현 | 대표 PCB 기준 사례에서 길이 및 위치 차이 0.001 mm 이하를 초기 목표로 제안 | CAD 변환의 수치 검수 기준이며 실제 PCB 제조 공차와 구분. 모델 크기와 최소 특징에 따라 합의값 변경 |
| 메시 수렴 | 최소 3개 메시 수준을 기록하고 마지막 단계에서 공진 주파수 변화 1% 이하를 초기 목표로 제안 | 다중 공진 및 넓은 대역은 공진점 하나만으로 판정하지 않고 복소 S 및 방사 지표를 함께 비교 |
| 복소 S 수렴 | 평가 대역의 복소 S 차이 최대 0.02 이하를 초기 목표로 제안 | 깊은 null에서 dB 차이만으로 판정하지 않으며 포트 기준과 샘플 주파수를 맞춤 |
| 방사 지표 수렴 | 최대 실현 이득 차이 0.5 dB 이하와 효율 차이 2%p 이하를 초기 목표로 제안 | 주엽 방향 이동과 패턴 변화도 함께 확인. 물리 정확도를 보증하는 보편 기준이 아님 |
| 재실행 재현 | 같은 모델 설정 및 솔버 버전에서 지정된 수치 허용오차를 충족 | 병렬 연산 순서가 다를 수 있으므로 파일 bit 동일성과 물리 결과의 수치 동일성을 구분 |
| 실측 일치 | 기준 안테나별 측정 불확도와 제작 오차를 근거로 별도 허용치 설정 | 임의의 보편 오차율을 모든 안테나와 재질에 적용하지 않음 |
| UI 응답 | 대표 프로젝트에서 직접 조작 피드백 200 ms 이내를 초기 목표로 제안 | 검증용 하드웨어와 모델 규모를 먼저 고정하고 긴 계산을 UI 응답과 분리 |
| 저장 및 취소 | 저장 성공은 실제 파일 검증 후 표시하고 취소 요청은 즉시 상태에 반영 | 솔버별 중단 가능성 및 저장소와 모델 크기에 따른 제한을 별도 벤치마크로 확정 |

### 8.4 지표 정의를 확인하는 계산 사례

단일 포트의 수동 안테나에서 입사 전력 1 W, 반사 전력 0.25 W, 방사 전력 0.60 W인 검수 데이터를 사용한다. 안테나가 받아들인 전력은 0.75 W이며 방사 효율은 80%, 반사를 포함한 전체 효율은 60%이다. 다중포트에서는 다른 포트로 전달된 전력과 여기·종단을 포함한 별도의 정의를 사용해야 한다. [S03](#source-s03)

S11의 dB 값과 양수로 표시하는 반사손실, 방향성·이득·실현 이득, 방사 효율·전체 효율을 구분해 라벨과 데이터 내보내기를 검수한다. 공진점에서만 값이 맞는지 검사하지 않고 목표 대역과 관측 방향 전체에서 정의가 일관되는지 확인한다.

### 8.5 기준 사례 구성

대표 사례에는 재현 가능한 패치, 유한 접지의 PCB IFA 또는 모노폴, 원호 및 meander, 손실 유전체, 좁은 급전 갭과 비아를 포함한다. R2 이후에는 다중포트·주변 금속·분산 물성·UWB 전달 응답을 추가한다. 비교 데이터에는 독립 솔버 또는 해석식의 적용 한계, 측정 시료와 교정 조건, 제조·측정 불확도를 함께 기록한다. 특정 사례의 일치를 모든 안테나의 정확도로 일반화하지 않는다.

## 10 용어

| **용어** | **의미** |
| --- | --- |
| 합성 | 요구 사양과 설계 규칙으로 초기 안테나 형상과 치수를 생성하는 과정 |
| Full wave | 선택한 수치 방법으로 Maxwell 방정식에 기반한 전자기장 응답을 계산하는 해석 |
| 기판 적층 | 도체 유전체 코팅 및 접착층의 순서 두께와 높이 정보 |
| Dk와 Df | 유전율과 유전 손실 계수를 표현하는 재료 데이터이며 주파수와 시험 조건이 필요함 |
| PEC | 손실이 없는 완전도체 근사로 실제 동박 손실 모델과 구분함 |
| 포트 기준면 | 전압 전류 임피던스 및 S parameter가 정의되는 위치와 참조 조건 |
| 메시 수렴 | 공간 이산화를 세분화하면서 관심 결과 변화가 합의한 범위로 줄어드는지 확인하는 과정 |
| 방사 효율 | 받아들인 전력 중 방사되는 비율로 포트와 손실 정의를 함께 기록해야 하는 지표 |
| 실현 이득 | 정의된 포트 조건에서 재료 손실과 부정합 영향을 포함하는 방향별 이득 |
| STEP | CAD 실체 및 조립 형상을 교환하는 형식으로 지원 프로파일에 따라 데이터 범위가 달라짐 |
| Gerber와 Excellon | PCB 층별 제조 이미지와 드릴 정보를 전달하는 형식 |
| DRC | 선폭 간격 홀 외곽과 연결 등 지정된 설계 및 제조 규칙 위반 검사 |
| Touchstone | 주파수별 네트워크 S parameter와 참조 정보를 교환하는 파일 형식 |
| 오래된 결과 | 현재 설계나 조건이 바뀌어 기존 결과를 그대로 현재 설계에 적용할 수 없는 상태 |
| 강건 최적화 | 명목값뿐 아니라 재료와 제조 및 배치 변동에서 성능을 만족시키려는 최적화 |
