# 계획과 개발 이력

기존 1~13번 개발 순서를 유지한다. 날짜별 실행 기록은 해당 시점의 근거이며 새 수용 합격이 아니다.

[전체 문서](../README.md)

현재는 9번의 [후보 채택과 새 작업 사본](../05_기능설계/06_연구/02_후보채택과_새작업사본.md), 원호/IFA의 명시 계산과 원본 보존, Windows GUI 자동시험 및 실제 IFA 후보의 별도 수동 채택/저장/재열기를 확인했다. [검증 기록](../07_검증/21_후보채택과_원호아이에프에이_검증.md)의 유한 완료 범위와 SMA/실제 설치 환경/수렴/제작/실측 미확립을 구분하며 이후 순서는 기존 10번이다.
