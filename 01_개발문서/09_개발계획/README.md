# 계획과 개발 이력

기존 1~13번 개발 순서를 유지한다. 날짜별 실행 기록은 해당 시점의 근거이며 새 수용 합격이 아니다.

[전체 문서](../README.md)

재개 절차는 [새 채팅 개발 인계](08_새채팅_개발인계.md), 단계별 종료 조건은 [현행 버전의 남은 작업](04_현행버전_남은작업.md)에 둔다. 9번 설치 후보의 대역 판정과 12번 Windows 사용성 검수 후 13번에서 결과를 인계한다. 별도 Windows 수신은 환경 준비 후 검수한다.
