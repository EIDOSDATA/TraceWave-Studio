# TraceWave 기능 채택과 개발 검증 순서

2026-11-22 KST. 이 문서는 비교 기능을 실제 개발 작업으로 옮기는 초안이다. 기능별 원본 명령·분석 방식, 현재 가능한 범위 및 검증 사례는 [CAD](11_캐드와_기계도면_기능대조.md), [EDA](12_전자설계와_제조교환_기능대조.md), [EM](13_전자기해석과_후처리_기능대조.md), [MATLAB과 설계 자동화](14_매트랩과_안테나설계자동화_기능대조.md)에 있다. [제품별 조사 색인](10_비교도구와_기능조사_색인.md)에서 공급사 또는 원 프로젝트 설명으로 이동할 수 있다.

2026-11-23 사용자 결정으로 아래 1~5단계의 잔여 기능 개발과 검증을 마친 뒤 최종 릴리스한다. 외부 환경이 필요한 항목은 미검증 사유를 남기고 나머지 기능 개발을 이어간다.

## 도입 방식과 선후 관계

| 단계 | 제품에서 제공할 작업 | 선행 조건과 첫 인도물 |
| --- | --- | --- |
| 1. 해석 전 검토와 결과 신뢰 | 오류 입력 복귀, 실제 격자·포함 형상 확인, 결과 구성 복제, 값 단위 변경·원문 추적 | 현재 로컬 검토 화면의 원호 및 IFA 캡처, 설정 변경 후 실행 전 재검토, 선택 개정과 준비 입력의 일치를 확인한다. |
| 2. 정밀 PCB 편집과 자동 치수 | 다중 선택 스마트 치수, 구동/참조 치수, 스케치 관계와 자동 구속, 도면 자동 기입과 정렬, 제조 규칙·구리면 보강 | 안정 객체와 기준점, 구속 표현을 먼저 구현한다. 스케치 자동화와 도면 주석은 독립 인도 가능하다. 편집 취소, 재생성, 저장·재열기를 포함한다. |
| 3. 기구·제조 교환 | 조립 STEP, 부품별 단위·배치·갱신, 간섭·간극, 층/넷/포트와 제조 자료 왕복 | 실제 서로 다른 수신 파일과 지원 단위부터 연다. 원본 매핑, 손실 목록, 치수와 배치 오차를 검증한다. 지원한다고 명시할 버전 및 변환 방향을 기록한다. |
| 4. EM 및 회로 적용 범위 | 상세 설치물의 EM 투영, 2포트, 급전·재료·접합, 수렴, 필드와 전력, S2P·정합망·네트워크 처리 | 2포트 수동 선로와 단일 급전 설치 사례를 독립 개발한다. 모델에 맞는 해석해 또는 공개 참조와 비교하고 합격 관찰량을 먼저 고정한다. |
| 5. 후보 합성 및 탐색 자동화 | 다중 대역·목표·제약, 후보 검색, 폐루프 최적화, 공차 등급과 결과 재현 | 고정 단일 목표/구조 하나부터 시작한다. 같은 예산에서 제안 경로와 독립 EM 재계산, 실패·중단 복구를 대조한다. |
| 장기 연구 | 자유곡면·고급 피처, 대규모 배열, 특성/고유모드, 고급 재료·별도 솔버와 계산 환경 | 자료·고정 예제·정확도/비용 비교가 확보된 기능부터 실제 제품 범위로 승격할 수 있다. |
| 외부 연동 또는 선택 | 전문 CAD/EDA의 전체 도면·패널·시스템 회로 기능, 전파·다중 물리·PI와 원시 실측 교정 | 지원 형식, 좌표·단위·포트·기준면, 변환 손실과 도구 버전을 우선 전달한다. 실측은 사용자가 파일과 실험 조건을 보유한 설계에서 선택한다. |

우선순위와 도입 방식은 PCB 안테나 설계자가 사용할 기능을 기준으로 제안했다. 각 세부표의 단계는 해당 행에서 가장 먼저 인도할 범위를 뜻한다. 행에 함께 적은 고급 모드와 별도 솔버의 적용 여부는 각각의 참조 사례로 판단한다. 유료 CAD/EDA 연동에는 먼저 지원 파일 왕복을 쓰고, 직접 연동이 필요하면 공개 API, 사용 가능한 버전, 배포 조건을 확인한다. 오픈소스 라이브러리를 제품에 포함하는 결정은 버전·적용 기능·라이선스·회귀 시험을 정한 뒤 내린다.

## 1단계 진행 현황

2026-11-22 KST. 해석 전 검토에서 격자 상한과 수치 입력 오류의 복귀, 가변 격자, 임계 구간 분할, 정확한 X/Y/Z 좌표와 포함 형상 표시를 구현했다. 저장본 비교 M16은 같은 개수의 객체라도 설명과 속성의 전후값을 보여준다. 프로젝트 속성의 이름과 설명도 좁은 패널에서 읽을 수 있도록 배치했다. [격자와 포함 형상](../07_검증/315_윈도우_해석전검토와_실제격자_검증.md), [저장본 비교와 속성 가독성](../07_검증/316_저장본비교와_속성가독성_검증.md)

RF01/M15의 첫 범위로 해석 조건을 이름으로 보존하고, 과거 결과의 설정을 불러와 현재 입력과 차이를 비교한다. 급전과 설치 상태는 해석 조건의 기준 개정과 함께 기록한다. [저장·재열기와 실행 준비 검증](../07_검증/317_해석조건_저장재사용과_원호아이에프에이_검증.md)

RF03은 급전, 비아와 좌표로 지정한 좁은 간극의 축별 최대 셀 폭과 우선순위를 설정하고 실제 적용 범위를 격자에서 확인한다. [객체별 국부 격자 검증](../07_검증/319_객체별_국부격자_윈도우와_준비_검증.md)

M17은 완료된 PCB 결과의 봉인 설계 개정, 당시 조건, 재료와 급전의 원본 값, 계산 입력 및 출처를 역추적한다. 해석 결과, 공통 결과의 조건 패널, 방사 패턴에서 같은 읽기 전용 화면을 연다. [원호와 IFA 출처 역추적 검증](../07_검증/322_해석결과_출처역추적_검증.md)

### 2026-11-23 후속 보완

이름 있는 조건과 과거 결과를 불러오면 급전, 설치, 정합 값의 차이를 비교한다. 원래 조건을 유지하면서 급전 및 설치 편집으로 이동할 수 있다. 전체 검토는 최초 계획 실패와 별도로 확인한 미정 입력을 같은 목록에 표시한다. 표면 개구와 실제 XY 격자에서 선택한 범위를 국부 격자에 지정하고 급전, 비아, 개구, 지정 간극과 각 축 최소 셀을 찾아볼 수 있다.

실행 중에는 native 로그에서 관측한 최신 시간 단계와 감쇠를 표시하고 완료 결과에서는 보존 로그의 시계열을 확인한다. 중단 시에는 프로세스 종료 확인 또는 보존된 입력을 사용한 처음부터의 재실행을 안내한다. 결과 출처에서 해석에 쓰인 도체와 제조 원본 대응, 봉인된 정밀 편집과 현재 개정의 변경 상태를 조회한다. 인계 묶음은 같은 스냅샷의 해석 조건, 누락, 결과 해시와 주파수별 S11 값을 함께 보존한다. [검증](../07_검증/328_검토와_출처_후속보완_검증.md)

실제 해석 투영 다각형의 같은 높이 도체 간극은 기본 격자 폭의 두 배 안에서 찾아 최근접점, 높이와 통과 XY 셀을 표시한다. 인계 Markdown은 같은 스냅샷의 S11 표본 그림을 포함한다. [실제 격자와 인계 그래프 검증](../07_검증/333_투영도체_간극과_인계그래프_검증.md)

다른 높이의 평면 도체도 실제 소비 위치에서 최근접점을 찾아 XZ 또는 YZ로 확대하고 통과한 XYZ 셀을 표시한다. [층간 간극 검증](../07_검증/339_동박층_간극과_격자셀_검증.md) PTH 배럴의 내경과 외경, 해석용 설치물 상자와 도체를 포함해 간극의 양 끝과 통과 셀을 구한다. 결과에서는 봉인 개정의 부모를 따라 도체의 편집 전후 값과 실행 취소/다시 실행을 조회한다. [배럴 간극과 객체 이력 검증](../07_검증/343_배럴간극과_봉인객체이력_검증.md) 해석 영역의 여섯 외벽에 PML_8, MUR, PEC, PMC를 지정하고 미리보기 및 native XML의 실제 순서를 대조했다. [면별 경계 검증](../07_검증/350_해석영역_면별경계_검증.md) 표면층 타일과 절삭 없는 유전체 체적 사이의 간극을 실제 격자와 대조했다. [표면층과 유전체 간극 검증](../07_검증/356_표면층과_유전체_체적간극_검증.md) 정합 선로에 놓인 현재·새 기준면을 XYZ 좌표와 방향으로 지정해 부호 있는 길이를 적용한다. [좌표 기준면 검증](../07_검증/358_정합선로_좌표기준면_검증.md) 유전체의 비도금 원형 홀, 내부 다각형 절삭과 원호 끝 슬롯의 실제 관통 벽을 간극에 포함했다. [관통 절삭 검증](../07_검증/366_관통절삭_유전체_간극_검증.md) 부분 깊이 절삭과 PTH가 겹치는 단면 및 높이 차를 검사했다. [단면 간극 검증](../07_검증/367_부분절삭과_도금홀_겹침간극_검증.md) PEC/PMC 대칭면을 적용한 도파관 축소 모델의 S11/S21을 전체 모델과 대조했다. [대칭면과 엔진 재개 검증](../07_검증/368_도파관_대칭면과_해석재개_검증.md) 원호와 IFA 단일 급전에서 실행 중단 시점의 native 프로세스 상태를 복구해 연속 실행의 파형과 대조했다. ## 자동 치수의 첫 인도물

1. **스마트 치수**의 첫 범위는 완료했다. 두 홀 중심과 급전 양단의 거리와 방향을 표시하며 참조 치수와 한쪽을 고정하는 구동 치수를 안정 기준 ID와 함께 저장한다. 원호와 IFA에서 재열기와 기존 급전 연결을 확인했다. [검증](../07_검증/324_스마트치수_원호와_역에프안테나_검증.md)
2. **스케치 자동 치수와 구속**의 첫 범위를 완료했다. 선·원호·패드의 기준점과 기판 X/Y축으로 독립 제안을 골라 적용 전후의 국소 자유도와 충돌을 확인한다. 원호 접선, IFA 분기와 급전 연결을 보존하며 저장·재열기한다. [검증](../07_검증/325_스케치자동치수와_구속_검증.md)
3. **도면 자동 치수**의 첫 범위를 완료했다. 외곽 또는 도체층 뷰에서 기준점을 선택하고 보드 외곽, 홀 중심, 원호 반경과 평면 급전 간극을 기입한다. 기준선식·연쇄식·좌표식, 선택 모델 치수, 누락 및 중복 검사와 홀 표를 제공한다. 원호와 IFA에서 같은 원본으로 저장하고 재열기했다. [검증](../07_검증/326_도면자동치수와_홀표_검증.md)
4. **도면 치수 정렬**의 첫 범위를 완료했다. 참조 치수의 선·문자·화살표 간섭을 자동으로 줄이며, 도면에서 옮긴 위치는 종이 좌표로 고정한다. 원호와 IFA에서 저장·재열기 및 PDF/DXF의 치수값·종이 좌표·축척을 대조했다. [검증](../07_검증/327_도면치수정렬과_수동위치_검증.md)

CAD03의 그리기 구속에서 선의 수평·수직, 선과 원호의 끝점 일치, 선분 중점 후보를 저장한다. 관계 적용 뒤에는 저장·재열기, 실행 취소·다시 실행 및 충돌한 편집의 거절을 확인했다. 원호 끝점에서 새 선을 그리면 접선을 제안한다. 보존된 상대 구속에 연결된 도체는 2D에서 함께 이동하고 한 번에 실행 취소할 수 있다. [연동 이동 검증](../07_검증/334_스케치_구속도체_연동이동_검증.md) 끝점 드래그에서 보존된 일치 구속의 기준점만 함께 이동한다. 접한 반대쪽 끝점, 원호 중심과 반경, 다른 구속을 검증한다. [끝점 연동 검증](../07_검증/344_스케치_일치끝점_연동편집_검증.md) 선, 원호, 패드의 저장 구속과 복수 구동 치수를 연립해 원호와 IFA에서 재열기 및 해석 준비까지 확인했다. [연립 풀이 검증](../07_검증/369_구동치수의_연립구속_풀이.md) 다른 곡선 접선 추론은 후속 대상이다. [검증](../07_검증/329_그리기_관계_검증.md)

CAD10과 CAD12에서 열린 원호의 중심선 반경 오프셋과 직선·원형 반복 복사를 추가했다. 원본은 유지하고 복사 배치별로 PTH와 패드를 대응시킨다. CAD09는 선·원호의 교차점 트림과 두 직선을 연결하는 해석형 필렛을 제공한다. [트림·필렛 검증](../07_검증/355_도체_교차점트림과_필렛_검증.md) 선–원호 및 원호–원호 중심선의 접선 필렛을 지원한다. [원호 필렛 검증](../07_검증/362_원호_접선필렛_검증.md) 열린 직선과 원호의 중심선 분할, 시작·끝의 지정 길이 연장 및 원래 급전 보존을 확인했다. [분할·연장 검증](../07_검증/364_직선과_원호의_분할연장_검증.md) 직선과 원형 반복 설정 또는 원본을 변경하면 기존 순번의 객체 ID를 유지하며 재생성한다. [반복 재생성 검증](../07_검증/370_반복패턴_재생성과_연결보존_검증.md) 2D 배선의 경유점과 넷별 간격을 검사하고 같은 개정에서 해당 구리면을 재생성한다. [대화식 배선과 동박 검증](../07_검증/371_대화식배선과_동적구리면_검증.md) 경계까지 자동 연장과 복수 섬 구리면은 남아 있다. [반복 복사와 원호 오프셋 검증](../07_검증/351_직선원형_반복과_원호오프셋_검증.md)

## 3단계 조립과 교환 진행 현황

CAD18은 단일 고체와 한 루트의 조립 STEP을 가져온다. mm와 inch 원본을 보드 좌표로 변환하고 중첩된 반복 부품의 참조와 원본 변환을 보존한다. CAD21은 실제 최소 간극 좌표와 출력에 걸린 중첩 체적을 진단으로 제공한다. 중첩 조립의 말단을 경로로 선택해 XYZ 이동, 원본 보존, 개별 계산 경계 및 간섭을 확인한다. [말단 배치 검증](../07_검증/335_스텝_조립말단_배치검증.md) 같은 말단 원점에 대한 X/Y/Z 고정축 회전과 이동을 조합할 수 있다. [말단 회전 검증](../07_검증/342_스텝_말단회전과_독립_검증.md) 원본 말단의 공유 정의와 조립 계층을 AP242에 포함하고, 재입력한 경로와 개별 위치를 확인한다. [STEP 계층 검증](../07_검증/345_스텝_조립계층_재출력_검증.md) IPC-2581 Rev C는 기존 가져오기 화면의 읽기 전용 검토에서 층과 적층, 논리/물리 넷, 도금 홀과 부품 배치를 확인한다. [공개 원본 검증](../07_검증/348_제조교환_공개원본_읽기검토_검증.md) 말단 원점을 기판의 XYZ 목표점에 맞추고 조립 전체의 변환을 바꿔도 같은 지점에 위치시킨다. [STEP 원점 맞춤 검증](../07_검증/352_스텝_말단원점_기판좌표_검증.md) 두 부품의 선택한 평면을 일치시키거나 원통축을 동축으로 맞출 수 있다. 등록한 단일 고체로 말단 하나를 교체하고 기존 메이트의 면을 다시 연결한다. [면과 축 메이트, 부품 교체 검증](../07_검증/372_부품간_평면과_동축_메이트.md) 혼합 단위 STEP과 반복 하위 조립의 정의 공유는 남아 있다. 게시한 KiCad PCB 패키지에서 IPC-2581 Rev C 및 ODB++ 후보를 별도 ZIP으로 생성하는 CLI를 추가했다. [CAM 후보 검증](../07_검증/357_아이피시와_오디비_출력후보_검증.md) IPC-2581의 단일 직선 프로파일은 현재 외곽을 대조하고 내부 절삭을 적용한다. [프로파일 적용 검증](../07_검증/360_아이피시_프로파일_내부절삭_검증.md) ODB++ ZIP에서도 단일 직선 외곽과 절삭을 같은 방식으로 읽고 적용한다. [ODB++ 보드 검증](../07_검증/361_오디비_보드외곽과_내부절삭_검증.md) 두 제조 형식에서 층과 넷을 지정한 직선 및 원호 배선을 반영하고 KiCad로 재출력했다. [배선과 넷 왕복 검증](../07_검증/373_제조자료_배선과_넷_왕복검증.md) 복합 동박, 적층, 홀, 실장 데이터 전체의 설계 반영과 직접 GUI 출력은 남아 있다. [검증](../07_검증/330_스텝_단위와_간극_검증.md)

## 4단계 EM과 회로 진행 현황

RF27에서 불균일 주파수 축의 S11/S21 등 선택 S 채널에 대한 군지연을 공통 결과 그래프와 표에서 조회한다. EDA33/RF28에서 등실수 Z0의 S 행렬에 대해 최대 특이값과 상호성 잔차도 검사한다. 위상 규약과 표본 누락을 보존하며 기존 결과 파일에 쓰지 않는다. RF13에서는 포트별 정합 선로로 복소 S 자료의 기준면을 바꾸고 새 자료에 조건과 출처를 보존한다. [기준면 이동 검증](../07_검증/336_정합선로_기준면이동_검증.md) RF06에서는 명시한 비균등 주파수에서 raw 과도 전압과 전류를 직접 변환하며 조건과 결과에 주파수 목록을 그대로 보존한다. [직접 표본 검증](../07_검증/338_비균등_직접주파수_표본검증.md) RF13에서 불일치하는 양쪽 2포트 치구를 기존 복소 결합 자료로부터 제거하고, 안쪽 기준면과 세 원본의 출처를 함께 저장한다. [치구 제거 검증](../07_검증/346_양쪽_치구_기준면보정_검증.md) RF27에서는 균일한 복소 대역의 시간 게이트를 적용해 같은 기준면과 주파수 축으로 별도 자료를 저장한다. [원호와 IFA 시간 게이트](../07_검증/349_복소대역_시간게이트_검증.md) RF05에서는 고정한 최대 6개 격자 중 봉인 결과와 예상 메모리 상한으로 다음 실행을 결정한다. [적응 격자 검증](../07_검증/353_격자연구_적응중단과_메모리상한_검증.md) RF18에서 일반 PCB 해석의 단일 주파수와 XY 단면을 지정해 실제 비보간 전기장을 보존하고 조회한다. [지정 단면 검증](../07_검증/363_지정_전기장_단면_검증.md) 사용자 PCB의 두 급전을 같은 격자에서 순차 여기하고 양쪽 전압과 전류로 복소 S행렬 네 성분을 계산했다. [사용자 PCB 2포트 검증](../07_검증/374_다중급전_네이티브_해석검증.md) 이전 풀이의 전계 변화로 선택한 두 구간의 셀 폭을 절반으로 줄여 IFA를 다시 계산했다. [전계 기반 적응 격자 검증](../07_검증/375_전계기반_적응격자_검증.md) 3포트 이상, 주파수별 수렴 분리, 대역별 재료/접합, 자계·체적 필드와 사용자 전력 적분, 게이트 테이퍼와 거리 환산은 남아 있다. [검증](../07_검증/331_복소위상과_군지연_검증.md)

## 5단계 설계 탐색 진행 현황

M08에서 동일 연구에 보존한 복수 목표의 표본 평가로 후보의 우열 그룹을 조회하고 선택한 후보 결과를 연다. 계산 실패 및 미확인 표본은 상태별로 센다. M14에서는 보존한 연구의 원래·정규화 입력과 개정·스냅샷·엔진 해시를 계산 명세 JSON으로 저장한다. 현재 편집이 달라도 보존 개정으로 후보를 다시 구성해 조건, 엔진 및 검토 해시를 대조한다. 이 범위에서는 읽기만 수행한다. [검증](../07_검증/332_목표별_후보순위와_계산명세_검증.md)

목표별 지정 가중치로 합계 점수를 계산하고 기존 우열 그룹을 유지한다. 계산 명세와 같은 개정의 보존 ZIP으로 별도 작업 공간 검토 및 선택 재실행을 지원한다. [가중 순위와 독립 재실행 검증](../07_검증/337_가중순위와_독립재실행_검증.md)

M10은 명시 최소·공칭·최대 카테시안 후보의 공칭점과 모서리 통과율을 비교한다. [공차 모서리 검증](../07_검증/340_설계와_회로_공차모서리_검증.md) M11은 공칭점의 같은 주파수에서 한 축씩 바꾼 S11 dB 변화를 보존 표본으로 비교한다. [공칭점 응답 검증](../07_검증/341_공칭주파수_설계변수_응답검증.md) 같은 주파수에서 두 변수를 함께 바꾼 S11 변화와 단일 변수 변화의 차이를 비교한다. 모든 변수의 최소·공칭·최대 가중치를 명시하면 가정한 이산 독립 분포에서 목표의 통과·실패·미확인 확률 질량을 계산한다. [교호 효과와 이산 공차 검증](../07_검증/347_변수교호와_이산공차_검증.md) M07에서는 봉인된 평가로 후속 후보 한 개를 선택하고 별도 연구로 검토·저장할 수 있다. [후속 후보 검증](../07_검증/354_목표평가_후속후보_검증.md) M01/M02에서 목표 대역과 현재 보드 외곽으로 원호·IFA 초기 치수를 참고한다. [목표 치수 검증](../07_검증/359_설계목표_원호와_역에프_초기치수_검증.md) 후보 조합별 가중치와 출처를 사용해 독립 가정과 다른 결합 분포의 통과 범위를 조회한다. [조합 분포 검증](../07_검증/365_후보조합_공차분포_검증.md) 명시한 접지와 급전 위치를 보존해 원호 또는 IFA의 초기 치수를 계산한다. 봉인한 평가에서 다음 구간을 반복 선택하며 후보별 실제 계산, 공통 예산과 종료 사유를 기록한다. 동일 시료의 공정 치수와 실제 목표 판정은 CSV로 비교한다. 다른 구조의 합성과 실제 생산 로트의 수율 검증은 별도다. [목표 치수, 반복 탐색과 공정 표본](../07_검증/376_요구대역_초기치수와_후속후보_탐색.md)

## 이후 환경이 필요한 독립 검증

- 조립 STEP은 부품 단위, 부품 반복 및 배치가 명시된 수신 CAD 원본과 독립 수신 결과가 필요하다. IPC-2581 Rev C 읽기는 공개 원본을 확보했다. 추가 EDA 교환의 설계 반영과 왕복 검증에는 지원 버전의 물리 넷과 제조 속성을 비교할 별도 수신 경로가 필요하다. 내부 도형 시험과 별도로 기록한다.
- 물리 RF 대조와 실측을 선택한 설계에는 기준면과 포트 정의를 고정한 참조 모델 또는 시료·측정 조건이 필요하다. 온라인 클린 Windows/WSL2의 독립 수신은 [별도의 R1 작업](04_현행버전_남은작업.md)으로 관리한다.
- 본 개발 순서에서 구현된 범위의 재검증은 위의 검증 문서에서 이어간다. 남은 기능은 아래 항목별 채택 상태를 따른다.

## 앞선 판정에서 수정한 부분

- 도면은 선택 뷰의 복수 참조 치수와 개별 모델 치수 불러오기, 간섭에 따른 자동 정렬, 뷰별 수동 위치 보존을 제공한다. [도면 배치](../../Code/src/rfad/domain/drawing_layout.py)
- 일반 사용자 프로젝트도 격자 수준을 최대 6개 지정해 포트·방사와 선택 손실 수렴을 판정할 수 있다. 새 개발은 대역·국부 위치·관찰량에 따라 다음 격자를 선택하거나 추가할 경계를 검토하는 기능이다. [프로젝트 연구 계약](../../Code/src/rfad/application/project_study_contract.py)
- 측정 정렬은 이미 포트 순열, 양의 실수 Z0, 범위 안 복소 선형 보간을 제공한다. 일반 네트워크 편집, 혼합 모드, 치구 제거는 각각 별도 범위다. [정렬 계약](../05_기능설계/04_해석결과/09_측정기록과_정렬비교.md)
- 원호/IFA 특정 사례의 두 소자 정합은 고정 조건에서 탐색하고 검증한 기록이 있다. 새 개발은 일반 설계에 쓸 목적·제약·표준 소자·재개·비교다. [설치 정합 재탐색](../../Code/tools/verify_installed_retuning.py)
- 독립 손실 기능은 이미 지정 형상에서 주파수영역 기록과 저장량을 계산한다. 새 개발은 사용자가 프로브 위치, 선·면·체적, 저장 물리량과 예산을 직접 선택하는 기능이다. [독립 손실 기록](../../Code/src/rfad/application/pcb_power.py)
- 내부 비도금 홀·슬롯·다각형 절삭은 지원하는 일반 EM 조건에서 투영한다. 다음 개발은 독립 손실 모드의 제한, 내부층, 유한 접합과 비아 종류 확대다. [절삭 입력](../../Code/src/rfad/application/pcb_voids.py)
