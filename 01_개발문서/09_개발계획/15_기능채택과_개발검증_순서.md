# TraceWave 기능 채택과 개발 검증 순서

2026-11-23 KST. 이 문서는 비교 기능의 채택 순서와 제품에서 검증한 범위를 기록한다. 기능별 원본 명령·분석 방식, 현재 가능한 범위 및 검증 사례는 [CAD](11_캐드와_기계도면_기능대조.md), [EDA](12_전자설계와_제조교환_기능대조.md), [EM](13_전자기해석과_후처리_기능대조.md), [MATLAB과 설계 자동화](14_매트랩과_안테나설계자동화_기능대조.md)에 있다. [제품별 조사 색인](10_비교도구와_기능조사_색인.md)에서 공급사 또는 원 프로젝트 설명으로 이동할 수 있다.

## 다음 작업 순서

1~5번은 기능 개발, 6번은 개발이 끝난 후보의 배포 검수다. 1~5번의 지원 범위와 실행 증거를 각 기록에 연결했다. 다음은 6번의 새 후보와 별도 온라인 클린 Windows/WSL2 수신 검수다. 감사된 WSL의 9포트 감독 경로와 외부 CAM 수용은 각 기록의 환경 및 원본 조건에서 확인한다.

1. **평면 적층 PCB의 X/Y 주기 및 Floquet 경계.** 403 일차원 격자 회귀와 손실판 Airy 계산을 재현했다. 35 um 동박 패치와 손실 기판에서 X/Y Bloch 인자, 복소 회절 계수, 차수별 전력과 재료별 흡수를 독립 유한요소와 대조했다. 큰 ㄱ자 동박에서 격자 민감성이 남아 있으며 약한 회절 차수와 복잡 형상의 적용에는 사례별 수렴 대조가 필요하다. [403 회귀](../07_검증/403_유전체_격자의_주기_플로케_경계_검증.md) [408 지원 범위와 민감 사례](../07_검증/408_동박_피시비의_이중주기_플로케_검증.md)
2. **일반 도파관 단면의 다중모드.** 단일 외곽과 균질 PEC의 공통 삼각 단면에서 TE/TM 전파 및 소멸 모드, 편파, 축, 기준면과 전력 정규화를 구현했다. 삼각 단면 차단값, 기존 폭 단차와 두 축 단차의 복소 TE/TM 결합을 각각 대조했다. [404 폭 단차](../07_검증/404_직사각_도파관_폭단차의_다중모드_검증.md) [409 독립 검증](../07_검증/409_일반_도파관_단면의_티이_티엠_결합_검증.md)
3. **9포트 이상 PCB 및 분포/모드 급전.** 12포트까지 설계 및 교환, 실제 Windows openEMS 9개 포트의 31주파수 복소 S, 원시 재처리와 Touchstone 재열기를 확인했다. 공간 분포 HDF5로 TE10을 여기해 409의 위상과 대조했다. 저장 PCB 양쪽의 분포 TE/TM 포트를 연결해 Windows native 실행과 독립 Airy 대조를 확인했다. 고정 WSL 감독 경로의 9포트 검수는 별도 수신 환경에서 확인한다. [405 과거 Linux 8포트](../07_검증/405_여덟_급전의_실제_복소행렬과_복원검증.md) [410 Windows 9포트와 모드 원문](../07_검증/410_아홉_급전과_분포_모드_원문_검증.md) [413 저장 PCB 모드 포트](../07_검증/413_저장_피시비의_분포_모드_포트_검증.md)
4. **곡면 전력의 수렴.** 같은 E/H 자료의 삼각화와 같은 곡면의 실제 Yee 격자 세분화를 각각 확인했다. 독립 매끈한 반구 적분과 최종 삼각면의 차이는 0.59% 이내다. 최종 격자 간 반구 전력이 6.36% 변했고 닫힌 면의 순유량도 기록했다. [406 기록장 적분](../07_검증/406_삼각_곡면의_복소장_전력적분_검증.md) [411 구면과 격자별 변화](../07_검증/411_곡면_삼각화와_원래_해석격자의_수렴_검증.md)
5. **특수 패드스택과 패널 교환.** IPC-2581C 원문의 부분층 드릴, 백드릴, 깊이와 안티패드를 보존한 상태에서 90도 반복 패널을 작성하고 보드, 단위, 방향과 6개 배치를 대조했다. 공식 XSD를 통과했다. 비대칭 랜드가 달라지는 CAD 게시의 차단을 유지한다. 공장 CAM 수용에는 수신기와 작업 표준 원본이 필요하다. [407 패드스택 및 ODB++](../07_검증/407_층별_패드스택과_오디비_반복패널_검증.md) [412 IPC 특수 홀 및 패널](../07_검증/412_아이피시_특수_드릴과_반복패널_검증.md)
6. **기능 개발 후 새 후보와 R1 검수.** 기능 변경이 반영된 커밋과 ZIP의 SHA-256을 고정한다. 온라인 상태의 별도 클린 Windows/WSL2 PC에서 내려받아 설치하고, 예제 편집과 저장, 실제 해석과 취소, 결과 재열기, 출력과 복구를 확인한다. 같은 PC에서 수신한 과거 후보의 근거는 해당 빌드에만 적용한다. 최종 R1 수용 뒤 리팩토링에 착수한다. [R1 작업표](04_현행버전_남은작업.md) [배포 검수](05_현행버전_검증선별_기준.md)

각 단계는 지원한 입력, 실제 실행 환경, 독립 비교값과 한계를 해당 검증 기록에 남기고 한국어 커밋으로 `origin/main`에 인계한다. 공장 CAM, 실물 접합 물성 또는 실제 로트 수율처럼 외부 자료가 필요한 판정은 필요한 원본과 조건을 적고 구현 가능한 다음 항목을 진행한다. 실측 비교는 시료와 측정 자료가 있는 프로젝트의 선택 기능이다.

## 도입 방식과 선후 관계

처음 기능을 채택할 때 사용한 단계와 의존 관계다. 각 단계에서 실제로 인도한 범위는 이어지는 검증 현황에 있다.

| 단계 | 제품에서 제공할 작업 | 선행 조건과 첫 인도물 |
| --- | --- | --- |
| 1. 해석 전 검토와 결과 신뢰 | 오류 입력 복귀, 실제 격자·포함 형상 확인, 결과 구성 복제, 값 단위 변경·원문 추적 | 현재 로컬 검토 화면의 원호 및 IFA 캡처, 설정 변경 후 실행 전 재검토, 선택 개정과 준비 입력의 일치를 확인한다. |
| 2. 정밀 PCB 편집과 자동 치수 | 다중 선택 스마트 치수, 구동/참조 치수, 스케치 관계와 자동 구속, 도면 자동 기입과 정렬, 제조 규칙·구리면 보강 | 안정 객체와 기준점, 구속 표현을 먼저 구현한다. 스케치 자동화와 도면 주석은 독립 인도 가능하다. 편집 취소, 재생성, 저장·재열기를 포함한다. |
| 3. 기구·제조 교환 | 조립 STEP, 부품별 단위·배치·갱신, 간섭·간극, 층/넷/포트와 제조 자료 왕복 | 실제 서로 다른 수신 파일과 지원 단위부터 연다. 원본 매핑, 손실 목록, 치수와 배치 오차를 검증한다. 지원한다고 명시할 버전 및 변환 방향을 기록한다. |
| 4. EM 및 회로 적용 범위 | 상세 설치물의 EM 투영, 2포트, 급전·재료·접합, 수렴, 필드와 전력, S2P·정합망·네트워크 처리 | 2포트 수동 선로와 단일 급전 설치 사례를 독립 개발한다. 모델에 맞는 해석해 또는 공개 참조와 비교하고 합격 관찰량을 먼저 고정한다. |
| 5. 후보 합성 및 탐색 자동화 | 다중 대역·목표·제약, 후보 검색, 폐루프 최적화, 공차 등급과 결과 재현 | 고정 단일 목표/구조 하나부터 시작한다. 같은 예산에서 제안 경로와 독립 EM 재계산, 실패·중단 복구를 대조한다. |
| 장기 연구 | 자유곡면·고급 피처, 대규모 배열, 특성/고유모드, 고급 재료·별도 솔버와 계산 환경 | 자료·고정 예제·정확도/비용 비교가 확보된 기능부터 실제 제품 범위로 승격할 수 있다. |
| 외부 연동 또는 선택 | 전문 CAD/EDA의 전체 도면·패널·시스템 회로 기능, 전파·다중 물리·PI와 원시 실측 교정 | 지원 형식, 좌표·단위·포트·기준면, 변환 손실과 도구 버전을 우선 전달한다. 실측은 사용자가 파일과 실험 조건을 보유한 설계에서 선택한다. |

우선순위와 도입 방식은 PCB 안테나 설계자가 사용할 기능을 기준으로 제안했다. 각 세부표의 단계는 해당 행에서 가장 먼저 인도할 범위를 뜻한다. 행에 함께 적은 고급 모드와 별도 솔버의 적용 여부는 각각의 참조 사례로 판단한다. 유료 CAD/EDA 연동에는 먼저 지원 파일 왕복을 쓰고, 직접 연동이 필요하면 공개 API, 사용 가능한 버전, 배포 조건을 확인한다. 오픈소스 라이브러리를 제품에 포함하는 결정은 버전·적용 기능·라이선스·회귀 시험을 정한 뒤 내린다.

## 이후 환경이 필요한 독립 검증

- 혼합 단위의 반복 STEP 조립을 독립 CAD에서 대조했다. [조립 교환](../07_검증/386_혼합단위와_반복조립_교환검증.md) IPC-2581C와 ODB++의 층, 넷, 패드와 홀, 부품 배치 및 구멍 있는 동박을 KiCad에서 재판독했다. [제조 교환](../07_검증/397_제조동박의_면적과_절연구멍_왕복검증.md) 다른 제조사 고유 속성의 호환 판정에는 해당 원문과 수신 도구 버전이 필요하다.
- 물리 RF 대조와 실측을 선택한 설계에는 기준면과 포트 정의를 고정한 참조 모델 또는 시료·측정 조건이 필요하다. 온라인 클린 Windows/WSL2의 독립 수신은 [별도의 R1 작업](04_현행버전_남은작업.md)으로 관리한다.
- 공장 CAM의 패널 수용은 해당 수신 원문과 판독 환경이 확보되면 기록한다. 실물 로트 수율은 시료별 공정 치수와 목표 판정 쌍, 접합 물성은 주파수와 측정 조건이 연결된 원자료가 필요하다.

## 앞선 판정에서 수정한 부분
아래는 첫 기능 조사에서 바로잡은 당시 판정이다. 이후 구현 결과는 위 단계별 검증 이력에서 확인한다.

- 도면은 선택 뷰의 복수 참조 치수와 개별 모델 치수 불러오기, 간섭에 따른 자동 정렬, 뷰별 수동 위치 보존을 제공한다. [도면 배치](../../Code/src/rfad/domain/drawing_layout.py)
- 일반 사용자 프로젝트도 격자 수준을 최대 6개 지정해 포트·방사와 선택 손실 수렴을 판정할 수 있다. 이후 검증한 직전 E장 기반 국부 세분화와 대역별 포트 변화는 4단계 이력에 있다. [프로젝트 연구 계약](../../Code/src/rfad/application/project_study_contract.py)
- 측정 정렬은 이미 포트 순열, 양의 실수 Z0, 범위 안 복소 선형 보간을 제공한다. 일반 네트워크 편집, 혼합 모드, 치구 제거는 각각 별도 범위다. [정렬 계약](../05_기능설계/04_해석결과/09_측정기록과_정렬비교.md)
- 원호/IFA 특정 사례의 두 소자 정합은 고정 조건에서 탐색하고 검증한 기록이 있다. 조사 시 일반 설계의 목적, 제약, 표준 소자, 재개와 비교가 추가 대상으로 제안됐다. [설치 정합 재탐색](../../Code/tools/verify_installed_retuning.py)
- 독립 손실 기능은 이미 지정 형상에서 주파수영역 기록과 저장량을 계산한다. 이후 구현한 E/H 단면과 체적, 삼각 곡면 전력 적분은 4단계 이력에 있다. [독립 손실 기록](../../Code/src/rfad/application/pcb_power.py)
- 내부 비도금 홀·슬롯·다각형 절삭은 지원하는 일반 EM 조건에서 투영한다. 독립 손실 모드와 비아 종류별 판정에는 실제 계산한 입력과 관찰량을 적용한다. [절삭 입력](../../Code/src/rfad/application/pcb_voids.py)
