# 새 채팅 개발 인계

리팩토링 개발 브랜치는 `main`이다. Windows 1단계 수용을 완료했다. 본창과 분리 창의 실제 두벌식 후보창, 분리 창 이동 뒤 후보 위치, 초점 복귀와 UI Automation 및 실제 내레이터를 확인했다. 새 클라이언트의 Windows Python 서비스 연결을 확인했다. B0 원본은 유실되어 복원 및 재생 항목을 종료했다. 최신 공개 RC10 설치본을 기준으로 Windows 기능을 이식 중이다. 게시된 3D 형상과 최신 완료 S11의 화면 재열기를 마쳤다. 개발 PC의 RC6를 제거하고 공개 RC10을 설치했다. 새 화면에서 기존 CAD 작업자로 3D 생성, 실행 중 취소와 재시도, AP242 STEP 게시를 확인했다. 새 화면의 Windows openEMS에서 저장 조건 검토, 실행 승인, 실제 실행과 취소를 확인했다. 과거 RF 결과를 선택해 실제 두 개정의 출처와 S11을 확인했다. PDF 도면, KiCad 보드, Gerber/XNC/Job 생성과 재검수 및 과거 RF의 CSV와 조건 파일 저장을 확인했다. SVG/DXF 기술 도면과 선택한 풋프린트, 과거 RF의 Touchstone, HDF5, 보존 원문 저장을 확인했다. 새 화면에서 실제 두 포트 실행을 완료하고 RC10과 복소 표본을 대조했다. 다음은 새 화면의 전체 S 행렬 보기와 제조 교환 후보 변환이다. [현재 단계와 통과 기준](07_현행버전_완료후_리팩토링.md#지금-이어갈-작업)

## 새 PC 또는 기존 작업 폴더에서 시작

기존 PC의 저장소는 `C:/Users/eidos/GitHub/TraceWave-Studio`다. 이 폴더에서 `git fetch origin`과 `git status --short --branch`로 로컬 변경을 확인한다. 작업 트리가 깨끗하고 `main`이 원격보다 뒤에 있으면 `git pull --ff-only origin main`으로 갱신한다.

새 PC에서는 PowerShell로 다음을 실행한다. 복제 후 시제품 빌드 명령은 저장소 루트에서 실행한다.

```powershell
git clone -c core.longpaths=true --branch main https://github.com/EIDOSDATA/TraceWave-Studio.git "TraceWave Studio"
Set-Location -LiteralPath "TraceWave Studio"
git status --short --branch
```

R1 설치본을 대조할 때는 [427 클린 PC 검수](../07_검증/427_알원_알시십_클린피시_수신과_수용.md)를 사용한다. 403 유전체 격자와 동박 PCB의 독립 계산을 재현할 때는 [수치 환경과 실행 명령](../03_제품_재현_안내.md#기준-계산과-허용-오차)을 따른다. 새 PC에서 과거 실행을 열려면 프로젝트와 외부 작업자가 만든 원본 결과 파일도 옮긴다. [프로젝트 보존과 복원](../05_기능설계/01_프로젝트/02_프로젝트_보존묶음과_편집복원.md)
