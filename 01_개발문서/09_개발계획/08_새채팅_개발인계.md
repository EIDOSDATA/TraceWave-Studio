## 새 PC 또는 기존 작업 폴더에서 시작

기존 PC의 저장소는 `C:/Users/eidos/GitHub/TraceWave-Studio`다. 이 폴더에서 `git fetch origin`과 `git status --short --branch`로 로컬 변경을 확인한다. 작업 트리가 깨끗하고 `main`이 원격보다 뒤에 있으면 `git pull --ff-only origin main`으로 갱신한다.

새 PC에서는 PowerShell로 다음을 실행한다. 복제 후 시제품 빌드 명령은 저장소 루트에서 실행한다.

```powershell
git clone -c core.longpaths=true --branch main https://github.com/EIDOSDATA/TraceWave-Studio.git "TraceWave Studio"
Set-Location -LiteralPath "TraceWave Studio"
git status --short --branch
```

R1 설치본을 대조할 때는 [427 클린 PC 검수](../07_검증/427_알원_알시십_클린피시_수신과_수용.md)를 사용한다. 403 유전체 격자와 동박 PCB의 독립 계산을 재현할 때는 [수치 환경과 실행 명령](../03_제품_재현_안내.md#기준-계산과-허용-오차)을 따른다. 새 PC에서 과거 실행을 열려면 프로젝트와 외부 작업자가 만든 원본 결과 파일도 옮긴다. [프로젝트 보존과 복원](../05_기능설계/01_프로젝트/02_프로젝트_보존묶음과_편집복원.md)
