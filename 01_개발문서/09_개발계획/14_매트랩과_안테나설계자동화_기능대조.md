# MATLAB과 안테나 설계 자동화 기능 대조

2026-11-22 KST. 안테나 전용 앱, PCB와 네트워크 라이브러리, 최적화 도구, 등록한 설계를 검토하고 재현하는 기능을 조사했다. 표의 도입 방향은 개발 제안이다. 상용 제품 설명은 각 행 끝에, TraceWave의 구현 근거는 해당 표 뒤에 연결했다.

[385 검증](../07_검증/385_설치영역과_요구조건_구조제안_검증.md) | 구조별 유효 범위, 초기 치수와 보정 가정을 보여준다. 공개 치수 예제의 단위와 범위 안/밖 결과를 대조한다. |
| 2. 정밀 편집 | M03. 파라미터와 사본 재생성 | 템플릿 입력, 일부 매개변수·출처, 미리보기와 원자 적용이 있다. | 원문 치수, 수정값, 자동 제안값과 현재 형상을 비교하고 형상 변경 전후 구속·급전을 검토한다. 다른 기판의 미정값 처리도 확인한다. |

| 5. 설계 탐색 | M06. 다중 대역·방향 목표 마스크 | 복수 대역 목표와 S11, 방사·총효율, 비대역폭 지표, 관찰 조건이 있다. | 대역별 상·하한, 주파수 마스크, 방향과 편파별 제한, 가중치와 필수조건을 별도로 입력한다. 대역 끝만 위반하는 표본과 관측 누락에서 이유를 표시한다. |
