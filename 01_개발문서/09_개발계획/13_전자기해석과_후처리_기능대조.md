# RF 해석과 결과의 세부 기능

아래에서 "추가"는 현재 사용자 PCB의 정식 입력, 실제 계산과 결과 조회를 잇는 경로가 필요한 기능이다. 단일 포트 참조 계산, 외부 파일 읽기와 연구 전용 코드는 해당 열에 따로 표시했다. 각 행의 마지막 열은 구현 후 확인할 사례다. 이 조사에서 상용 제품을 같은 입력으로 실행한 성능 또는 정확도 데이터는 없다.
