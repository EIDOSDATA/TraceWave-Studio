# TraceWave Studio 기능 격차와 개선 계획

2026-11-22 KST. 비교 기준은 `origin/main`의 `5a0e8c4b487cc2e50ae4f01605ebf14c014889a7`이다. 직전 해석 전 검토 작업은 별도 로컬 작업본으로 대조했다. 앞선 비교표 G01~G35를 모두 이어받았고, 각 항목에 현재 제공 범위, 추가하거나 고칠 작업, 확인할 증거를 적었다. 우선순위는 이 문서에서 제안하며 기존 R1 승인은 별도표로 관리한다. [현행 R1 작업표](04_현행버전_남은작업.md), [기존 Feko 비교와 개발 범위](06_비교분석과_기능개발_범위.md)

## 2026-11-22 세부 기능 재조사

이 문서의 G01~G35는 상위 주제다. 공식 기능 목록을 다시 읽어 선택 치수, 자동 구속, 도면 자동 치수와 배치처럼 구현 및 검증이 다른 동작을 나누었다. 최신 기능별 도입 방향과 시험은 [비교 도구 기능 색인](10_비교도구와_기능조사_색인.md), [기능 채택과 개발 순서](15_기능채택과_개발검증_순서.md)에 있다.

## 착수 순서 초안

| 순서 | 묶음 | 착수 경계와 완료 증거 |
| --- | --- | --- |
| 1 | 해석 전 검토와 설정 재사용 G01~G05 | 로컬 검토 화면을 최종 캡처하고 실행 승인 경로를 확인한다. 이후 지원 중인 고급 설정과 오류의 원인 객체 연결을 확장한다. 같은 개정과 조건으로 계획을 다시 만들고 달라진 입력만 비교한다. |
| 2 | 저장, 출처, 정밀 PCB 편집 G06~G10 | 저장 전후 차이와 가져온 정보의 출처 추적을 먼저 제공한다. 저장되는 스케치 관계와 자유도를 도입한 뒤 피처 재생성과 곡선 편집을 연결한다. 원호와 IFA의 급전 연결, 폭, 간극을 회귀 확인한다. |
| 3 | 설치 CAD와 PCB 인계 G12~G15, G29~G32 | 복수 STEP 가져오기와 강체 배치부터 시작한다. 조립 간섭과 도면은 안정 부품 ID를 사용한다. 제조 규칙과 교환 범위는 실제 예제의 층, 넷, 홀, 원점 대응으로 나눠 확인한다. |
| 4 | 해석 범위와 결과 보강 G16, G18~G25 | 검증 가능한 설치 부품과 2포트 참조부터 독립적으로 착수한다. G16은 G12/G13의 부품 배치에, 고급 급전과 다층/PTH 검증은 해당 전기 모델과 참조에 의존한다. 일반 프로젝트 수렴, 필드 요청, 회로 및 네트워크 검사는 지원 범위부터 연결한다. |
| 5 | 설계 탐색 G26~G28 | 현재 스윕과 검증 지표를 이용해 제한된 목적의 탐색부터 재현한다. 후보 추천을 연결하고, 공차 연구는 근거 있는 범위 또는 분포가 있을 때 실행한다. |
| 6 | 장기와 선택 G11, G17, G33~G35 | 입체 안테나, 대형 구조, 병렬 실행은 대상과 비용을 정한 뒤 평가한다. 실측 교정과 치구 보정은 측정 파일이 있는 프로젝트의 선택 작업으로 둔다. |

의존성이 없는 항목은 같은 순서 안에서 독립적으로 진행할 수 있다. 상세 설치가 필요한 첫 기능은 전체 고체 CAD 편집보다 부품 단위 배치, 간섭, 물성 및 격자 반영에 집중한다. 비교 도구의 지원 기능을 근거로 TraceWave의 구현·검증 단위를 정했다.

## 1. 해석 전 검토와 실행

현재 로컬 작업본은 격자 상한에서 모델 최대 간격으로, IFA 성장률 오류에서 해당 입력으로 초점을 반환한다. 입력을 보존하고 변경 시 검토를 무효화한다. 원호와 IFA에서 실제 openEMS 준비와 검토 화면의 격자선 및 포함 형상을 대조했다. 가변 공기 격자 0.8 mm, 성장률 1.5, 모델 최대 간격 0.5 mm, 외부 여유 10.4 mm, 임계 구간 최소 2분할에서 원호는 X/Y/Z 119/162/45개로 격자점 867,510개, IFA는 122/157/45개로 861,930개였다. 이 대조의 범위는 FDTD 직전 준비까지다. 가독성 수정 뒤 원호와 IFA의 기본 창 및 최소 창을 Windows에서 다시 캡처했다. IFA에서 실행 승인 시 전달된 개정과 준비 격자가 검토 값과 일치했다. [해석 전 검토 검증](../07_검증/315_윈도우_해석전검토와_실제격자_검증.md) [기존 Windows 검토의 공개 기준](../07_검증/314_윈도우_잔여화면과_시간초과_재검증.md), [단일 포트 해석 계약](../05_기능설계/04_해석결과/03_사용자기판_단일포트_해석.md)

## 실제 착수 전에 사용할 기준

- 기존 지원, 로컬 구현, 제품 실행, 수치 검증을 각각 표시한다. 변경 전 원본과 기존 개정·결과를 보존하고, 지원 여부는 설치 가능한 제품에서 확인한 범위로 기록한다.
- 첫 사례, 실패 사례, 저장·재열기 및 이전 개정 호환을 정한다. 수치 기능은 독립 참조와 관찰량, 허용 범위를 실행 전에 정의한다. 화면 기능은 실제 Windows 캡처와 메뉴 진입, 초점·입력 보존을 확인한다.
- R1의 별도 Windows 오프라인 수신 검수는 현행 작업표에 둔다. 기준 PC 성능은 사용자 결정에 따라 R1 승인에서 제외한 상태다. 실측은 해당 설계의 선택 비교이며 제작·측정 조건은 확보 전까지 미정으로 둔다. R1 완료 후 리팩토링 원칙을 적용한다. [R1 잔여 작업](04_현행버전_남은작업.md), [검증 선별 기준](05_현행버전_검증선별_기준.md), [리팩토링 계획](07_현행버전_완료후_리팩토링.md)
