# 현행 버전의 남은 개발 작업

이 문서는 R1 작업 1~13번의 승인 상태와 별도 PC 수신 조건을 관리한다. 현재 개발 브랜치는 `main`이다.

| 상태 | 작업과 판정 근거 |
| --- | --- |
| 공개 설치본 | `r1-rc6`는 Windows 기본 해석과 표준 제거를 제공한다. 개발 PC의 기본 설치에서 편집, 실제 해석과 취소, 출력, 복구 및 제거를 검수했다. [설치와 보존](../07_검증/418_윈도우_표준_앱_제거_검증.md), [설치본 통합 검수](../07_검증/419_알원_설치본의_통합_검수.md) |
| 개발 PC 설치 후보 | RC9는 `40ab200`으로 만든 로컬 Setup.exe다. 개발 PC에서 설치, Windows 해석기 감사 및 결과 화면 전환 시간을 검증했다. [RC9 개정과 해시](../07_검증/423_알원_사용성_후속_수정과_재검수.md#rc9-설치-후보와-결과-전환-계측) |
| 다음 작업 | RC9 이후 `main`의 가독성 및 오류 수정까지 포함할 소스 개정을 고정한다. 그 개정에서 Release GUI와 Setup.exe를 만들고 검증한 해시를 인계한다. [가독성 검수](../07_검증/424_전체화면_가독성_검수와_개선.md), [84개 화면의 문구 재검수](../07_검증/425_화면_구분자와_문구_재검수.md), [후보 생성 절차](../08_운영환경/05_윈도우_내부검증_배포.md#묶음-생성과-검증) |
| 독립 검수 대기 | 별도 온라인 클린 Windows 11 x64 PC에서 같은 설치 파일로 아래 절차를 완료하고 R1 수용을 판단한다. [R1 요구 추적](../07_검증/03_요구사항_추적표.md#ac-trace) |
| R1 수용 후 | 수용한 릴리스를 B0로 고정한다. 리팩토링 착수는 보류한다. [리팩토링 계획](07_현행버전_완료후_리팩토링.md) |

## 다른 Windows PC에서 남은 검수

1. 인계받은 후보 개정과 Setup.exe의 SHA-256을 대조한다. 기본 옵션으로 앱과 Windows 해석기를 설치한다. 시작 메뉴와 Studio 제목 표시줄의 아이콘을 확인한다.
2. 예제를 편집하고 저장한 뒤 새 세션에서 연다. Windows openEMS에서 해석을 완료하고 별도 실행의 취소를 확인한다.
3. 결과와 출처를 다시 열고 도면 또는 보고서를 출력한다. 정상 저장본의 복구까지 확인한다.
4. Windows 설정의 설치된 앱에서 이름, 버전과 아이콘을 확인한다. 창을 닫고 해당 항목에서 제거한 뒤 같은 위치에 재설치한다. 바로가기와 전용 런타임 정리 및 보존한 작업 결과 재열기를 확인한다.
5. 후보 개정과 Setup.exe 해시, 실제 환경, 예제, 결과와 실패 경로를 기록한다. 기존 공개 후보 `r1-rc1`은 기능 확장 이전의 수신 기록으로 인계한다. [이전 공개 후보 검증](../07_검증/310_공개_검증후보_배포와_독립수신_인계.md)

기준 PC의 성능 시험(F0~F5, PERF-001~010)과 재부팅 5회는 2026-11-22 사용자 결정으로 R1 승인에서 제외했다. 별도 PC의 온라인 수신 조건은 2026-11-23에 결정했다. [승인 변경 기록](../07_검증/05_문서_검토와_승인.md)

## 8번 RF 검증의 적용 범위

- **RO4350B.** 사용자는 이 고정 사례에서 임계 구간 7분할과 8분할 사이의 방사 도체 손실 변화 최대 2.788446%를 허용했다. 이 편차를 줄이기 위한 반복 계산은 종료한다. 수치는 수용 전력 대비 방사 도체 손실 두 값의 차이를 큰 값으로 나눈 격자 간 변화다. 당시 정한 2% 기준은 초과했으며, 다른 모델이나 손실 성분에는 기존 기준을 적용한다. 8분할을 고정한 일반 격자 3수준은 별도로 기준을 충족했다. [격자별 판정](../07_검증/307_팔분할_일반격자_손실_수렴검증.md)
- **도금 관통홀(PTH).** 합성 패드, 배럴, 접합층과 지정 급전 모델을 8, 10, 12 GHz의 총 아홉 조건에서 계산해 두 독립 수치 풀이와 표면 손실 적분을 대조했다. 유한 접합층을 모델링하고 단일 국부 급전에서 접합 전력을 대조했다. 원래 분포 급전의 독립 기준과 동일한 조건에서의 정확도는 미평가다. [379 검증](../07_검증/379_비아접합층과_급전전력_검증.md) [접합과 급전의 검증 범위](../07_검증/301_급전격자와_관통홀_표면손실_독립대조.md)

## 완료한 범위와 선택 기능

| 단계 | 확보한 결과 |
| --- | --- |
| 1~3. 연구, 요구 정리, 설계 모델 | 고정 연구와 요구 대조, 공개 자료 기반 내부 설계 범위를 마감했다. 비공개 공정자료 수집은 완료 조건에서 제외했다. [설계 모델 마감](../07_검증/258_공개자료_기반_설계모델_마감.md) |
| 4~7. 편집, 정합, 스윕, 결과 비교 | Windows에서 급전과 양단 도체의 선택 연동, 복소 결과와 기준면, 후보 추적 및 재실행, 방사와 필드 비교를 확인했다. [선택 연동](../07_검증/264_윈도우_급전단자와_진단_선택검증.md), [복소 정합](../07_검증/265_윈도우_복소부하와_외부정합_검증.md), [후보 추적](../07_검증/266_윈도우_스윕후보추적과_독립재실행_검증.md), [설치 결과 비교](../07_검증/267_윈도우_설치결과와_방사필드_비교검증.md) |
| 9. 원호와 IFA | 합성 설치와 이상 정합을 고정한 상태에서 격자와 외부 여백을 각각 대조했다. 전체 비교의 S11 상한은 IFA -13.621461 dB, 원호 -13.682548 dB였으며 두 후보 모두 2.400~2.4835 GHz의 -10 dB 목표를 충족했다. 실제 SMA, 실장과 제작 물성은 미정이다. [대역 검증](../07_검증/311_설치후보_격자와_외부경계_대역검증.md) |
| 10. 도면, STEP, EDA | 같은 개정의 도면과 CAM, 독립 STEP 수신, KiCad와 보존 Altium 재출력의 슬롯 및 속성 손실을 확인했다. 형식, 변환기, 입력 또는 수신 도구가 바뀌면 영향받는 경로를 검사한다. 제조 공정 원점과 원본에 없는 도금 및 넷 정보는 미정이다. [동일 개정 수신](../07_검증/276_동일개정_교환수신_재검증.md), [슬롯과 속성 대조](../07_검증/296_엔씨_슬롯과_원본_대응_검증.md) |
| 11. 측정 비교 | 측정 없는 프로젝트와 과거 합성 보고서의 재열기를 확인했다. 시료 제작, VNA 및 OTA 비교는 사용자가 해당 실물을 평가할 때 선택한다. [측정 비교 검수](../07_검증/298_선택형_측정_과거보고서_재열기.md) |
| 12. Windows 사용성, 복구와 인계 | 실제 두벌식 IME로 프로젝트 이름, 설명과 도체 이름을 조합해 저장·재열기했다. 내레이터 오류 안내와 초점 복귀, 150%에서 100%로 창 이동 및 입력을 검수했다. [현장 검수](../07_검증/309_윈도우_한글입력과_접근성_검수.md) 서비스 종료, 손상, 쓰기 충돌, 디스크 부족 복구, 한글 경로 저장 및 재열기와 EDA/MCP 왕복을 확인했다. 개발 PC에서 프레임 추가 개선과 반복 계측을 종료했다. [Windows 복구 검증](../07_검증/299_윈도우_서비스_종료와_복구_회귀.md) |
