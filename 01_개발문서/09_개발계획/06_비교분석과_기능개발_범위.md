# Feko 비교에서 확인한 기능 개발 범위

비교 분석 시점의 첫 공백은 같은 PCB를 단독으로 계산한 결과와 설치 상태에서 계산한 결과를 비교하는 경로였다. 현행 구현은 하부 개방 유전체 케이스를 기존 3차원 PCB 해석에 포함하고 기판 단독 결과와 비교한다. 상세 STEP과 표면층의 EM 투영은 개발 범위에 남아 있다. 아래 표의 비교 기준은 원문 조사와 대조한 시점의 구현이다. [현행 환경 계약](../05_기능설계/02_설계편집/12_적층과_외부환경.md), [PCB 모델 생성](../../Code/src/rfad/adapters/solvers/openems/pcb.py)

비교 원문은 사용자가 제공한 2026-11-19자 `TraceWave_Studio_vs_Altair_Feko_Gap_Analysis_2026-11-19.md` v1.0이다. 원문 SHA-256은 `a0d44a2c98caf45bc7940a067633252e1267a8c62b62e20052fe3bb782435aed`다. 원문의 조사 기준은 `3c8c6635`, 이번 저장소 대조 기준은 `48f9c90`이다. 원문의 1~6번 제안은 아래의 기존 완료 계획 번호 및 후속 버전으로 연결했다. 두 제품을 같은 모델로 실행해 얻은 성능 또는 정확도 비교 수치는 없다. ### 첫 설치 비교의 합격 근거

1. 프로젝트에서 PCB 단독 개정을 고정하고 동일 급전의 케이스 포함 시나리오를 만든다. 사용자가 선택한 금속 부품의 접지 상태, 재료와 간이화 사유를 기록한다. 미정 물성이 계산에 필요하면 입력 단계에서 멈추고, 명시적으로 제외하면 해당 이유가 결과에 남아야 한다.
2. 봉인한 해석 입력에서 객체 ID, 재료, 좌표, 격자 점유와 공기 영역을 확인한다. 케이스와 부품이 방사 관측면 안에 있고 주요 간극과 마스크 개구를 해석 격자가 분해하는지 확인한다. 표시 정밀도나 가시성만 바꾸면 solver가 소비한 형상 좌표·재료·격자와 포트는 같아야 한다. 전체 계획 해시는 snapshot과 출처도 포함하므로 각 개정의 원래 해시를 보존한다.
3. 동일 주파수, 급전 및 정규화 조건에서 실제 계산 결과를 비교한다. 독립 참조 및 수렴 판단에 사용할 관찰량과 허용 범위는 실행 전에 기록한다. 이격 변화로 공진이 특정 방향으로 움직일 것을 합격 조건으로 강제하지 않는다. 같은 결과를 다시 열어 원래 설계, 계산 조건, 생략 객체와 비교 상태를 확인한다.
