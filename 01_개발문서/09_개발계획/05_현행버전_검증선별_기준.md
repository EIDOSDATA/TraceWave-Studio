# 현행 버전의 검증 선별 기준

2026-11-22 KST. Windows 11 Studio와 WSL2 내부 검증용 후보에 적용한다. 변경한 부분에서 발생할 수 있는 오류를 기준으로 시험을 고른다. 최종 후보 검토 시에는 기존 증거의 입력, 실행 개정과 배포본의 차이를 확인한다. [현행 수용 기준](../07_검증/01_검증과_수용_기준.md)

## 12번 Windows 사용성

| 검사 | 확인할 결과 |
| --- | --- |
| 실제 한글 IME | 객체 이름과 속성값에서 조합을 끝내고 초점을 옮긴 뒤 저장한다. 다시 열면 끝 글자까지 입력한 문자열과 일치한다. |
| 스크린리더와 키보드 | 속성에 잘못된 값을 입력하면 스크린리더가 오류를 읽고 초점이 수정할 입력란으로 돌아간다. 키보드로 값을 바로잡아 저장할 수 있다. |
| 혼합 DPI | 서로 다른 배율의 두 모니터 사이로 편집 창을 옮긴다. 글자와 필수 조작이 잘리지 않고 버튼과 입력란의 표시 위치에서 실제로 조작할 수 있다. |

기준 PC의 성능 벤치마크는 2026-11-22 사용자 결정으로 현행 R1 승인표에서 제외했다. 기존 계측값과 당시 시험 조건은 [개발 PC 검증 기록](../07_검증/291_드래그_부분갱신과_표_지연_검증.md)에 보존한다.

## 정기 실행에서 제외할 일

- 문서 편집은 바뀐 경로, 링크, 요구 ID와 기술 내용의 일치 여부만 검사한다. 문구 수정에 전체 서비스 회귀, CAD 생성, FDTD와 장시간 메모리 계측을 연결하지 않는다.
- 화면 84종의 시안은 구현 기준으로 사용한다. 매 커밋에서 모든 화면을 다시 찍는 작업은 제외한다. 변경한 화면의 실제 상태와 핵심 작업에서 읽기, 키보드 진행, 취소, 복귀가 가능한지를 확인한다.
- 물리 입력이나 독립 비교 기준에 새 정보가 없으면 동일 격자 연구와 튜닝을 반복하지 않는다. 불완전한 문헌, 미정 제작값과 합성 측정 파일은 실제 성능의 합격 근거에서 제외한다.
- 실제 디스크 소진, 물리 전원 차단, 다른 DPI 모니터 이동, VNA/OTA 측정은 해당 보장과 장비가 필요한 검수에 배정한다. 일반 개발 PC에서는 기존의 ENOSPC 주입, 저장 단계별 프로세스 종료와 복구 시험을 사용한다. 물리 전원 차단 보장은 별도 격리 환경에서 증거를 확보할 때까지 미평가다.

## 내부 후보 인계와 R1 최종 판정

13번에서 고정한 설치 묶음을 깨끗한 Windows 환경에서 받아 한글 경로의 예제 열기, 실제 편집과 저장, WSL2 해석 및 취소, 결과와 출처 재열기, 보고서 또는 도면 출력까지 확인한다. 12번 Windows 사용성 결과는 확인한 환경과 함께 인계한다. 같은 빌드와 입력에서 이미 수집한 서비스 회귀와 독립 수신 기록은 재사용하며, 이후 변경이 해당 경로에 미친 영향과 재실행 결과를 연결한다. [서비스 회귀](../07_검증/230_윈도우_전체서비스와_네이티브_회귀검증.md), [한글 입력의 확인 범위](../07_검증/226_윈도우_한글이름과_복구_재검증.md)

형상과 포트의 잘못된 연결, 원본이나 과거 결과의 손실, 취소한 산출물의 정상 게시, 검증되지 않은 수치의 합격 표시는 관련 기능 인계를 차단한다. 수정 후 같은 입력으로 실패 경로와 보존된 정상본을 함께 확인한다. 독립 RF 참조, 제조 적층, 시료, 교정 또는 방사 측정이 필요한 AC는 필요한 증거를 특정해 열린 상태로 둔다. 13번의 R1 전체 판정은 약속한 AC별 기대값, 실제값, 비교 기준, 환경과 근거를 대조한다. 내부 한정판의 범위, 보류 사유 및 누락된 증거를 인계서에 적고 승인 범위 변경은 그 영향과 결정을 별도로 기록한다.
