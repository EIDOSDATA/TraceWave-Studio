PERF-007의 버튼 반응 100 ms와 접수 ACK 200 ms는 각각 p95 목표다. 승인 원문은 지연에 관해 각 fixture에서 timestamp 표본 1000개 이상을 요구한다. 초당 1000행은 F4에 가하는 로그 부하다. 로그 행, 버튼 잠금, 접수, 종료를 한 지연량의 독립 표본처럼 합산하면 p95를 구할 수 없다. 정식 F4 수용 시 실행 전에 측정할 동작과 부하, 지연별 표본 단위와 집계 방법을 고정한다. PERF-006은 2D 편집, 표 스크롤, 일반 3D, 대형 3D 각각에서 30초 이상 연속 조작하고 실제 화면 갱신 간격을 1000개 이상 확보하도록 명시한다. 현재 PC의 60 fps 미달과 기준 PC 미확인 상태는 해당 성능 항목에 기록한다.

## 정기 실행에서 제외할 일

- 문서 편집은 바뀐 경로, 링크, 요구 ID와 기술 내용의 일치 여부만 검사한다. 문구 수정에 전체 서비스 회귀, CAD 생성, FDTD와 장시간 메모리 계측을 연결하지 않는다.
- 화면 84종의 시안은 구현 기준으로 사용한다. 매 커밋에서 모든 화면을 다시 찍는 작업은 제외한다. 변경한 화면의 실제 상태와 핵심 작업에서 읽기, 키보드 진행, 취소, 복귀가 가능한지를 확인한다.
- 물리 입력이나 독립 비교 기준에 새 정보가 없으면 동일 격자 연구와 튜닝을 반복하지 않는다. 불완전한 문헌, 미정 제작값과 합성 측정 파일은 실제 성능의 합격 근거에서 제외한다.
- 실제 디스크 소진, 물리 전원 차단, 다른 DPI 모니터 이동, VNA/OTA 측정은 해당 보장과 장비가 필요한 검수에 배정한다. 일반 개발 PC에서는 기존의 ENOSPC 주입, 저장 단계별 프로세스 종료와 복구 시험을 사용한다. 물리 전원 차단 보장은 별도 격리 환경에서 증거를 확보할 때까지 미평가다.

## 내부 후보 인계와 R1 최종 판정

13번에서 고정한 설치 묶음을 깨끗한 Windows 환경에서 받아 한글 경로의 예제 열기, 실제 편집과 저장, WSL2 해석 및 취소, 결과와 출처 재열기, 보고서 또는 도면 출력까지 확인한다. 키보드로 핵심 경로를 끝내고 실제 한글 자모 조합, 스크린리더의 선택명과 오류 안내를 확인한다. 다중 모니터와 별도 수신 도구의 검수 범위는 사용한 환경과 함께 기록한다. 같은 빌드와 입력에서 이미 수집한 서비스 회귀와 독립 수신 기록은 재사용하며, 이후 변경이 해당 경로에 미친 영향과 재실행 결과를 연결한다. [서비스 회귀](../07_검증/230_윈도우_전체서비스와_네이티브_회귀검증.md), [한글 입력의 확인 범위](../07_검증/226_윈도우_한글이름과_복구_재검증.md)

형상과 포트의 잘못된 연결, 원본이나 과거 결과의 손실, 취소한 산출물의 정상 게시, 검증되지 않은 수치의 합격 표시는 관련 기능 인계를 차단한다. 수정 후 같은 입력으로 실패 경로와 보존된 정상본을 함께 확인한다. 독립 RF 참조, 제조 적층, 시료, 교정 또는 방사 측정이 필요한 AC는 필요한 증거를 특정해 열린 상태로 둔다. 13번의 R1 전체 판정은 약속한 AC별 기대값, 실제값, 비교 기준, 환경과 근거를 대조한다. 내부 한정판의 범위, 보류 사유 및 누락된 증거를 인계서에 적고 승인 범위 변경은 그 영향과 결정을 별도로 기록한다.
