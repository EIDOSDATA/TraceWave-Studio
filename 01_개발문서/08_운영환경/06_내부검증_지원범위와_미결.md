# R1 내부 수용과 검증 범위

Windows 11 x64에서 RC10의 내부 수용을 완료했다. 승인 설계는 RFAD-D0-3.4이며 요구별 수용 범위와 구현 근거를 추적할 수 있다. [요구사항 추적표](../07_검증/03_요구사항_추적표.md) [승인 및 구현 대조](../07_검증/06_승인요구와_구현대조.md)

## RC10에서 확인한 범위

Windows 기본 설치는 서비스와 CAD, 출력 환경 및 Windows openEMS를 구성한다. 개발 PC에서 RC6는 설치와 사용자 작업 보존까지, RC9는 로컬 설치와 결과 전환까지 검수했다. RC10의 온라인 신규 설치, 실제 Windows 해석과 재설치는 별도 Windows 11 x64 PC에서 확인했다. [RC10 클린 PC 검수](../07_검증/427_알원_알시십_클린피시_수신과_수용.md) [설치 파일 수신과 재현 절차](05_윈도우_내부검증_배포.md#별도-클린-windows-pc-온라인-검수)

현행 설계 및 네트워크 자료는 최대 12개 포트를 지원한다. 실제 원문을 재처리해 검산한 집중 급전은 Windows 9개와 이전 Linux 8개이며, 저장한 직사각 PCB 양쪽의 분포 모드는 별도 계산 경로다. [Windows 9포트](../07_검증/410_아홉_급전과_분포_모드_원문_검증.md), [저장 PCB 모드](../07_검증/413_저장_피시비의_분포_모드_포트_검증.md), [Linux 8포트](../07_검증/405_여덟_급전의_실제_복소행렬과_복원검증.md)

RO4350B와 도금 관통홀에서 확인한 범위, 원호와 IFA의 대역 판정, Windows 사용성 검수 및 선택형 실측 비교는 [R1 작업표](../09_개발계획/04_현행버전_남은작업.md)에 정리했다.

새 GUI는 RC10을 B0 기준선으로 사용한다. Windows에서 먼저 검수하고 Linux와 macOS 호환성은 후속 플랫폼 단계에서 확인한다. [B0 기준선](../07_검증/430_알원_비제로_기준선_확정.md) [리팩토링 순서](../09_개발계획/07_현행버전_완료후_리팩토링.md)
