# 내부 검증 지원 범위와 R1 미결

공개 프리릴리스 `r1-rc1`의 고정 개정, ZIP 해시, 기본 수신 결과는 [공개 후보 배포와 인계](../07_검증/310_공개_검증후보_배포와_독립수신_인계.md)를 따른다. 이전 내부 후보의 선택 환경 확인은 [보존 수신 기록](../07_검증/300_윈도우_알원_내부후보_재현과_수신.md)에 있다.

## 기능 개발과 다음 후보 검수

Windows 기본 설치는 서비스와 CAD, 출력 환경 및 Windows openEMS를 구성한다. 개발 PC에서 RC6는 설치와 사용자 작업 보존까지, RC9는 로컬 설치와 결과 전환까지 검수했다. RC10의 온라인 신규 설치, 실제 Windows 해석과 재설치는 별도 Windows 11 x64 PC에서 확인했다. [RC10 클린 PC 검수](../07_검증/427_알원_알시십_클린피시_수신과_수용.md)

현행 설계 및 네트워크 자료는 최대 12개 포트를 지원한다. 실제 원문을 재처리해 검산한 집중 급전은 Windows 9개와 이전 Linux 8개이며, 저장한 직사각 PCB 양쪽의 분포 모드는 별도 계산 경로다. [Windows 9포트](../07_검증/410_아홉_급전과_분포_모드_원문_검증.md), [저장 PCB 모드](../07_검증/413_저장_피시비의_분포_모드_포트_검증.md), [Linux 8포트](../07_검증/405_여덟_급전의_실제_복소행렬과_복원검증.md)

RO4350B와 도금 관통홀에서 확인한 범위, 원호와 IFA의 대역 판정, Windows 사용성 검수 및 선택형 실측 비교는 [R1 작업표](../09_개발계획/04_현행버전_남은작업.md)에 정리했다. 후속 기능과 단계별 완료 조건은 [기능 개발 순서](../09_개발계획/15_기능채택과_개발검증_순서.md#다음-작업-순서)를 따른다.

R1 수신자는 고정한 후보의 개정과 Setup.exe 해시를 기록하고 별도 온라인 클린 Windows 11 x64 PC에서 기본 설치, 예제 검수, 제거와 재설치를 수행한다. [독립 수신 절차](05_윈도우_내부검증_배포.md#별도-클린-windows-pc-온라인-검수)
