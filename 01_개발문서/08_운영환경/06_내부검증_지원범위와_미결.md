# 내부 검증 지원 범위와 R1 미결

Windows 내부 후보에서 확인한 실행 조합과 해당 시점의 검증 근거다. 승인 설계는 RFAD-D0-3.4이며, 내부 R1 승인에는 사용자가 정한 [현행 적용 범위](../07_검증/03_요구사항_추적표.md)를 적용한다. [완료 계획](../09_개발계획/03_개발완료_계획.md), [승인 및 구현 추적](../07_검증/06_승인요구와_구현대조.md)

| 구성 | 당시 배포 묶음에서 검수한 범위 | 검증 근거 |
| --- | --- | --- |
| Windows 11 x64와 CPython 3.12 | 기본 Studio 편집, 스냅, 이름/속성, 명령 이력, 저장/재열기 | [통합 묶음 수신](../07_검증/88_윈도우_통합묶음_수신검증.md), [묶음 설치 안내](05_윈도우_내부검증_배포.md) |

공개 프리릴리스 `r1-rc1`의 고정 개정, ZIP 해시, 기본 수신 결과는 [공개 후보 배포와 인계](../07_검증/310_공개_검증후보_배포와_독립수신_인계.md)를 따른다. 이전 내부 후보의 선택 환경 확인은 [보존 수신 기록](../07_검증/300_윈도우_알원_내부후보_재현과_수신.md)에 있다.

## 기능 개발과 다음 후보 검수

현재 소스의 다중 급전 범위는 최대 8개 집중 급전이다. Windows 서비스에서 준비한 보드를 WSL2에서 풀고 독립 검산한 결과가 있다. [405 검증](../07_검증/405_여덟_급전의_실제_복소행렬과_복원검증.md)

RO4350B와 도금 관통홀에서 확인한 범위, 원호와 IFA의 대역 판정, Windows 사용성 검수 및 선택형 실측 비교는 [R1 작업표](../09_개발계획/04_현행버전_남은작업.md)에 정리했다. 후속 기능과 단계별 완료 조건은 [기능 개발 순서](../09_개발계획/15_기능채택과_개발검증_순서.md#다음-작업-순서)를 따른다.

기능 개발 완료 후 새 후보를 만들고, 해당 후보를 별도의 온라인 클린 Windows/WSL2 PC에서 설치해 예제를 재현한다. 수신자는 후보 개정, 실행 환경, ZIP 해시와 결과를 기록한다. [독립 수신 절차](05_윈도우_내부검증_배포.md#별도-클린-windowswsl2-pc-온라인-검수)
