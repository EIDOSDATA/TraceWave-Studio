## 내부 후보의 검증 결과와 남은 작업

| 단계 | 확인한 범위와 처리 |
| --- | --- |
| 8. RO4350B | 고정 시험의 7/8분할 간 정규화 방사 도체 손실 차이는 최대 2.788446%다. 사용자는 이 사례의 편차를 허용해 추가 계산을 종료했다. 원래 2% 격자 안정성 기준과 당시 미달 판정은 보존한다. [수치 판정](../07_검증/307_팔분할_일반격자_손실_수렴검증.md) |
| 8. 도금 관통홀 | 합성 패드, 접합층과 지정 급전의 손실을 8, 10, 12 GHz의 총 아홉 조건에서 독립적으로 대조했다. 현재 제품의 평면 패드, 단일 전도도 배럴과 간극 급전으로는 같은 물리 조건을 구성할 수 없어 해당 구조의 제품 손실 정확도는 미평가다. [적용 범위](../07_검증/301_급전격자와_관통홀_표면손실_독립대조.md) |
| 9. 원호와 IFA | 합성 설치 모델과 채택한 이상 정합을 유지하고 격자와 외부 경계를 독립적으로 바꿨을 때 2.400~2.4835 GHz 전 대역의 S11이 -10 dB 이하를 유지하는지 확인한다. 기존 재실행 결과는 재사용한다. 실제 SMA, 케이블과 제작 조건은 미정이다. [후보 재실행](../07_검증/303_설치후보_단일축_재실행과_정합대조.md) |
| 10. 도면과 EDA | 같은 개정의 독립 STEP, 도면, KiCad와 CAM 수신은 완료했다. 제조 수신처의 공정 원점이나 파일에 없는 도금, 넷은 실제 인계 시 확인한다. [수신 검증](../07_검증/296_엔씨_슬롯과_원본_대응_검증.md) |
| 11. 실측 비교 | 외부 자료가 있는 프로젝트에서 선택한다. 비교 기능과 측정 없는 프로젝트는 검증했다. [측정 보고서 재열기](../07_검증/298_선택형_측정_과거보고서_재열기.md) |

## 환경 준비 후 공식 검수

- 기준 Windows PC에서 F0~F5와 실제 한글 IME, 스크린리더, 혼합 DPI 검수를 재개한다. F0은 서로 다른 재부팅 직후 5회, F1은 기존 60 fps 기준을 적용한다. 개발 PC에서의 프레임 추가 개선과 반복 계측은 종료했다. [환경별 검수 기준](../09_개발계획/05_현행버전_검증선별_기준.md)
- 별도 Windows/WSL2에서 네트워크 차단 설치, 복구와 내부 수령자의 설계부터 출력까지 재현은 보류한다. 현재 후보는 시험 호스트의 새 경로에서 기본 및 선택 환경을 검증했다. 배포 인계에는 고정 개정, 제3자 고지, R1 필수 조건별 증거와 미평가 범위를 명시한다. [배포 후보 기록](../07_검증/300_윈도우_알원_내부후보_재현과_수신.md)

Linux GUI와 R2/R3, 비평면 3D 안테나 설계 및 해석은 별도 로드맵으로 관리한다.
