## R1 최종 검수에 남은 근거

- 8~11번의 독립 물리·실측 검수에는 RO4350B 국부 방사 도체 손실의 초기 기준 미확립, GHz PTH 독립 정확도, 실제 급전·제작·측정 조건과 관측 원문을 기록한다. 출력 파일과 총 전력 수지의 통과는 각각 해당 항목에 귀속한다.
- 12번 성능의 기준 장비에는 F0 서로 다른 재부팅 5회와 warm p95, F1의 전체 편집 fixture, F2 표시 LOD, F3 1 GiB/8개 복소 곡선, F4 동일 backend 로그 부하, F5 전체 앱 및 두 회수 정책의 검증을 연결한다. [성능 기준과 fixture](../04_화면설계/02_화면_선정과_성능_설계.md)
- 12번 GUI는 84개 설계 시안의 도킹·접근성/IME·DPI·고대비와 실제 기능 흐름별 합격값을 요구 추적에 연결한다. [화면 설계](../04_화면설계/README.md)
- 13번의 내부 묶음은 현재 시험 호스트의 독립 빌드 경로와 새 수신 환경에서 검증했다. 새 Windows 설치 이미지 및 선택 worker 전체 조합, 다른 호스트에서의 재컴파일 재현성, 실제 상류 빌드 원본과 최종 라이선스 검수, R1 필수 AC/VT의 수용 판정을 연결한다. [구현 추적](../07_검증/01_구현감사/03_구현추적.json)

Linux GUI와 R2/R3, 비평면 3D 안테나 설계 및 해석은 별도 로드맵으로 관리한다.
