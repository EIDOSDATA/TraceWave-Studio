# TraceWave Studio 설계 개요

2026-11-22 KST. 승인 기준선 RFAD-D0-3.4의 현행 설계 안내다.

## 목적과 현재 위치

TraceWave Studio는 주파수 목표, PCB 형상, 적층, 재질, 급전과 환경을 하나의 의미 모델로 다루고 2D 편집, CAD 출력과 EM 해석으로 연결한다. 현재 Windows 11과 WSL2를 사용하는 내부 검증용 배포 후보가 있다. [고정 후보의 구성과 수신 검증](07_검증/300_윈도우_알원_내부후보_재현과_수신.md)

[분야별 안내](README.md)에서 담당 설계를 찾을 수 있다. [현행 작업표](09_개발계획/04_현행버전_남은작업.md)에서 9번 원호와 IFA의 대역 검증, 13번 인계와 환경 보류 항목을 확인한다. [구현 감사](07_검증/06_승인요구와_구현대조.md)는 지원 범위와 요구별 근거를 연결한다.

## 범위와 기술 결정

Windows 11 + WSL2를 우선하고 Linux GUI와 R2/R3는 후속으로 둔다. wxWidgets + wxAUI + 사용자 정의 2D DesignCanvas + wxGLCanvas/OpenGL ModelView를 사용한다. Python 서비스가 원본, 명령, 단위, 저장, snapshot과 작업을 소유하며 OCCT 및 openEMS는 별도 worker로 실행한다. 일반 편집 60 fps/대형 장면 30 fps와 메모리 예산은 전체 제품 수용이 끝나지 않은 목표다.

원호/평면 IFA를 우선하며 비평면 3차원 안테나는 장기 로드맵이다. 최초 IFA의 초기 검증 조건과 실제로 남은 물성/실장 조건은 [21번 사례 계약](07_검증/04_사례와_계약.md#ifa-initial-baseline)에 둔다. 초기 후보, 계산 완료, 수렴, 독립 물리 검증, 목표 충족, 제작/실측은 각각의 상태로 유지한다.

요구 141개, AC 404개, UI 24개, FN 46개, API 30개, EQ 41개, VT 30개의 기존 식별자를 유지한다. 현행 명세/구현 계약의 차이는 명시하고 구현 제한을 이유로 수용 기준을 완화하지 않는다. 승인 원문과 records는 [기준선 보관함](12_보관이력/01_승인기준선/01_삼점사/README.md)에 고정했다. 현재 편집본의 번호는 문서 식별자이며 개발 단계 번호와 다르다.

원본 A JSON 등 현재 없는 자료의 바이트 일치를 주장하지 않는다. 00_참고자료의 외부 원문/추출과 Code/runtime_profiles의 과거 실행 기록은 보존한다. 실제 납품, 제작 및 측정 조건은 미정이다. 모델별 허용 편차와 제품 해석기의 한계는 [사례별 판단](09_개발계획/04_현행버전_남은작업.md)에 기록한다.
