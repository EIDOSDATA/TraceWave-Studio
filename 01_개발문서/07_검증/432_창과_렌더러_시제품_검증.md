# 창과 렌더러 시제품 검증

2026-11-25 KST에 `r1-b0`의 제품 개정 `6fd099136d5c8307f784a91383d358802f63d77b`을 기준으로 1단계를 착수했다. R1 수용 문서까지 포함한 `781fdcc4182dd77d51fa06732983e77a00e28cbf`는 `WxWidgets` 보관 브랜치에 고정했다. 두 개정의 기존 `Code` 트리가 동일함을 대조한 뒤 `main`에 독립 시제품을 구현했다. [B0 기준선](430_알원_비제로_기준선_확정.md) [시제품 빌드](../../Code/ui/prototype/README.md)

## Windows에서 확인한 항목

Windows 11 Pro x64 빌드 26300, AMD Radeon `1002:1900`, Windows SDL3 비디오 드라이버와 bgfx Vulkan으로 실행했다. Kitware CMake, Ninja와 MinGW-w64 GCC로 고정 다운로드 원본을 빌드했다. `ctest --test-dir Code/build/shell-prototype --output-on-failure -V`의 `prototype_window_smoke` 1개가 통과했다.

| 시험 | 관찰 결과 |
| --- | --- |
| 기판과 결과 렌더링 | 독립 창에서 원형 PCB 예제와 B0 S11 곡선을 실제 GPU에 제출했다. 본창과 분리 창에서 플롯과 축을 눈으로 확인했다. B0 공개 API 원본과 주파수 및 dB 값 각 31개를 binary64 비트 단위로 대조했다. |
| 키보드와 창 수명 | 실제 키로 `F6` 입력 초점, `F8` 결과 분리, `Alt+F4` 분리 창 닫기, `F7` 다시 열기, `F9` 기본 배치 복원을 확인했다. 자동 검사도 본창과 분리 창의 SDL 이벤트와 그리기 제출을 대조했다. |
| 저장과 다시 열기 | 마우스로 도킹 분할선을 옮겨 배치를 저장했다. 프로세스를 종료하고 새로 시작한 창에서 조정한 패널 너비가 복원됐다. |
| 고배율 및 혼합 DPI | 본창을 150%에서 980 × 680 픽셀로 바꾸고 SDL 픽셀 크기와 bgfx 프레임버퍼 크기를 대조했다. S11 분리 창을 150% 모니터에서 100% 모니터로 이동시키고 새 SDL 디스플레이 ID와 후속 GPU 제출을 확인했다. |
| 한글 입력 경로 | 시스템 Malgun Gothic의 한글 글리프와 메모 칸을 확인했다. 합성 `SDL_EVENT_TEXT_EDITING`은 조합 문자열로 표시됐고, `SDL_EVENT_TEXT_INPUT`은 확정 문자열로 입력됐다. |
| 접근성 노출 | Windows UI Automation에서 기본 창과 시스템 제목 표시줄을 읽었다. 시제품의 메모 필드, 메뉴, 기판·S11 패널 이름과 역할은 UI Automation 트리에 노출되지 않았다. |

## Windows 1단계 수용에 남은 항목

- Microsoft 한국어 IME의 실제 키 조합, 후보창 위치, 확정과 취소를 본창 및 분리 창에서 확인한다. 이번 자동 시험은 SDL 이벤트를 합성했다.
- 화면 읽기용 이름, 역할, 값과 동작을 노출하고 키보드 이동과 함께 재검수한다. [Windows 제품 기준 확인](309_윈도우_한글입력과_접근성_검수.md)

위 두 항목을 통과하면 Windows에서 기존 서비스 연결과 화면 이식을 진행한다. [리팩토링 작업 순서](../09_개발계획/07_현행버전_완료후_리팩토링.md)

## 후속 플랫폼 검수

Windows에서 기능 이식과 배포 검수를 마친 뒤 Linux Vulkan의 X11·Wayland와 macOS Metal을 순서대로 실제 데스크톱에서 확인한다. Wayland는 기본 창 내부 도킹부터 검수한다. 이번 시제품 시험에서 등록된 WSL Ubuntu의 가상 디스크와 macOS 실행 장비는 확보되지 않았다. Linux 데스크톱의 Vulkan과 X11·Wayland, Metal을 지원하는 Mac을 확보하면 해당 플랫폼 검수를 진행한다.
