## 처음 Windows에서 확인한 항목

Windows 11 Pro x64 빌드 26300, AMD Radeon `1002:1900`, Windows SDL3 비디오 드라이버와 bgfx Vulkan으로 실행했다. Kitware CMake, Ninja와 MinGW-w64 GCC로 고정 다운로드 원본을 빌드했다. `ctest --test-dir Code/build/shell-prototype --output-on-failure -V`의 `prototype_window_smoke` 1개가 통과했다.

| 시험 | 관찰 결과 |
| --- | --- |
| 기판과 결과 렌더링 | 독립 창에서 원형 PCB 예제와 B0 S11 곡선을 실제 GPU에 제출했다. 본창과 분리 창에서 플롯과 축을 눈으로 확인했다. B0 공개 API 원본과 주파수 및 dB 값 각 31개를 binary64 비트 단위로 대조했다. |

## 독립 시제품 최초 검수 이후 구현

입력 패널에 `Shift+F8` 분리 동작을 추가했다. 본창과 분리 창은 같은 메모를 사용하고 `Alt+F4`로 분리 입력 창을 닫으면 본창의 메모에 초점이 돌아간다. 입력 이벤트는 메모가 활성화된 SDL 창의 ID와 대조한다. 조합 문자열과 확정된 메모 값은 별도로 유지한다.

Windows에서는 실제 HWND마다 UI Automation 트리를 게시한다. 화면과 같은 이름으로 창 메뉴 및 항목, 기판, S11 결과, 입력 패널과 메모를 찾을 수 있다. 메뉴 펼치기, 표시 상태 전환, 명령 실행과 메모 값 읽기 및 쓰기를 지원한다. `F10`과 방향키로 창 메뉴에 접근한다.

## 같은 실행 파일에서 실제 Microsoft 두벌식 재검수

Windows 화상 키보드에서 두벌식 배열과 `한/영`, `한자` 키를 확인했다. 화상 키보드의 높은 Windows 무결성 수준으로 자동 조작 도구의 접근이 제한됐다. 사용자가 시제품에서 한글 모드를 맞춘 뒤에는 글자 키를 Windows에 보내 Microsoft 입력기가 처리하도록 했다. 아래 관찰값은 실제 Windows 입력기에서 얻었다.

| 창 | 마지막 글자 확정 | 조합 취소 |
| --- | --- | --- |
| 본창 | `g k s r m f` 뒤 메모 값은 `한`이고 화면에는 `글`이 조합 중으로 표시됐다. `Enter` 뒤 값은 `한글`이다. | `F6` 뒤 `r k`로 `가`가 조합되는 것을 확인했다. `Esc` 뒤 조합 표시가 사라졌고 값은 `한글`이었다. |
| 분리 입력 창 | `Shift+F8`로 분리한 뒤 `r j a t n`으로 새 메모 값을 입력했다. 값은 `검`이고 화면에는 `수`가 조합 중으로 표시됐다. `Enter` 뒤 값은 `검수`다. | `F6` 뒤 `d k`로 `아`가 조합되는 것을 확인했다. `Esc` 뒤 값은 `검수`였다. |

## Windows 1단계 수용에 남은 항목

- 본창 및 분리 입력 창에서 Microsoft 두벌식의 한자 후보를 열어 후보창과 편집 캐럿의 위치를 확인한다. 분리 창을 옮긴 뒤 위치와 입력 동작을 재검수한다. 자동화 도구는 한자 키를 지원하지 않았고, 운영체제에 보낸 오른쪽 `Ctrl`로는 후보창이 관찰되지 않았다. 분리 창 제목 영역의 자동화 드래그를 두 번 시도했으나 화면에서 창 좌표가 바뀌지 않았다. 실제 Windows 세션에서 한자 변환과 분리 창 이동을 직접 조작할 수 있을 때 재개한다. 실제 두벌식 검수가 남아 있어 2단계 서비스 연결과 이식 검수는 대기한다. 통과 후에는 431에 고정한 B0 보존 묶음에서 초기 작업 영역을 별도 사본으로 풀고 같은 서비스 명령의 개정, 오류, 취소 및 재시도를 비교한다. 공개 RC10 릴리스에서 설치 파일과 해시를 확인했다. 현재 PC에서 검색한 저장소와 사용자 자료 폴더에서는 고정 보존 ZIP이나 그 안의 초기 작업 영역 ZIP을 찾지 못했다. 2단계 비교는 431에 기록한 SHA-256과 일치하는 보존 자료를 확보한 뒤 실행한다. ## 후속 플랫폼 검수

Windows에서 기능 이식과 배포 검수를 마친 뒤 Linux Vulkan의 X11·Wayland와 macOS Metal을 순서대로 실제 데스크톱에서 확인한다. Wayland는 기본 창 내부 도킹부터 검수한다. 이번 시제품 시험에서 등록된 WSL Ubuntu의 가상 디스크와 macOS 실행 장비는 확보되지 않았다. Linux 데스크톱의 Vulkan과 X11·Wayland, Metal을 지원하는 Mac을 확보하면 해당 플랫폼 검수를 진행한다.
