# 전체 Studio 대형 3D 합성과 표시 품질

2026-11-21 KST. 완료 계획 12번 F2에서 형상 10000개의 실제 Windows Studio를 열고 전체 도킹 상태에서 100만 삼각형 표시 형상을 불러왔다. 2560 x 1600, 120 Hz, 144 DPI의 Intel Iris Xe Graphics에서 OpenGL과 Desktop Duplication의 시각을 대조했다. 실제 3D 캔버스는 1513 x 690이었다.

| 계측 | 표본 | 중앙값 (ms) | p95 (ms) | p99 (ms) | 최대 (ms) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 35초 회전·이동의 실제 합성 간격 | 2187 | 16.63 | 18.09 | 32.86 | 43.41 |
| 3D 회전·이동 입력부터 합성 | 2188 | 14.09 | 21.38 | 22.96 | 27.91 |

합성 간격 14개가 30 fps 목표인 33.33 ms를 넘었다. 입력 2202개 중 14개의 그리기 표식은 합성에서 관찰하지 못했다. 현재 장비와 작업 공간에서는 30 fps 간격 목표의 p95 이내였다. 기준의 1920 x 1080 출력과 이 장비의 결과를 구분한다. 다른 두 합성 실행은 창 전경 조건이 바뀌어 중단했다.

별도 실행에서 전체 맞춤 100만 삼각형, 줌 아웃 103040개, 객체 선택 100만 개, 전체 맞춤 복귀 100만 개를 실제 OpenGL 프레임으로 확인했다. 원본과 저해상도 표시 버퍼는 각각 72000000바이트와 7418880바이트였다. 최초 합성 계측 실행은 후속 표시 품질 검사에서 실패해, 축소 전환을 수정한 뒤 품질 검사를 다시 했다. [실행 기록](147_스튜디오_대형_삼차원_합성과_표시_품질_기록.json)

저해상도 보기는 표시 삼각형 25만 개 이상의 봉인 장면에서 만든다. 원래 정점과의 최대 이동을 픽셀로 환산하고 축소 상태에서만 자동 전환한다. 전환 0.65 px, 복귀 0.8 px를 적용한다. 최대 20만 삼각형 및 원본의 1/3 한도 안에서 생성하며 원본 모델과 선택 계산, STEP 데이터는 유지한다.
