# 일반 PEC 도파관 단면의 TE/TM 다중모드

2026-11-23 KST. Windows x64 CPython 3.12.10과 고정 수치 환경에서 `waveguide-section`의 단면 모드와 개구 정합을 실행했다. 단일 외곽의 두 균질 PEC 도파관이 Z=0에서 연결된다. 좁은 개구는 넓은 쪽 공통 삼각 격자의 일부다. 양쪽 단면이 동일한 직선 도파관도 입력할 수 있다.

## 재현과 계산 명세

```powershell
Set-Location Code
$env:PYTHONPATH = 'src;tests'
$env:OPENBLAS_NUM_THREADS = '1'
$rfPython = '.local/rf-check/Scripts/python.exe'
& $rfPython -c "import json; from test_waveguide_section import rectangular_step; print(json.dumps(rectangular_step([34.5,20.2], [22.3,15.8], [3.2,1.2], 0.54, 14.2e9, 48)))" | Set-Content -Encoding utf8 .local/guide-section.json
& $rfPython -m rfad waveguide-section .local/guide-section.json
& $rfPython -m unittest -v test_waveguide_section test_waveguide_modes
```

- `nodes_mm`은 공통 [x, y] 좌표다. `triangles`은 0부터 시작하는 절점 번호 세 개의 배열, `aperture_triangles`는 그중 좁은 쪽의 삼각형 번호 배열이다. 동일 단면은 모든 삼각형을 지정한다. 두 단면 모두 구멍 없이 연결된 단순 외곽과 일치하는 요소 변을 갖는다.
- `epsilon_r`는 양쪽 공통 균질 매질, `frequencies_hz`는 직접 표본이다. `basis_per_family`는 각 포트의 TE 및 TM에 각각 채택하는 절단 수이며 4~72개다. 결과는 각 계열을 4개 늘려 복소 행렬의 변화를 표본별로 보고한다. 전파 모드 누락과 차단점은 진단한다.
- `reference_offsets_mm`은 두 포트가 접합에서 바깥을 향해 이동한 거리를 [wide, narrow] 순서로 받는다. 결과의 절대 Z 기준면은 [-wide, +narrow]이고, 입사 축은 각각 +Z와 -Z다. 양쪽의 공통 X/Y 좌표와 `exp(-j*omega*t)` 규약을 사용한다.
- 출력은 단면별 절점과 L2 정규화된 TE의 Hz 및 TM의 Ez 형상, 차단 주파수, 전파/소멸 상태, 복소 축 방향 파수와 정규 어드미턴스를 보존한다. 접선 전계 모양을 단위 L2로 만든 뒤 정규 어드미턴스 Y의 실수부를 사용한다. `modal_voltage_v_per_sqrt_w = sqrt(2*Z0/Re(Y))`를 전파 모드마다 기록하고 소멸 모드는 null로 둔다. 행렬의 열은 입사, 행은 출력이다. 입력 해시, 기준면, 에너지 및 상호성 잔차를 반환한다.

선형 삼각 요소의 질량과 강성 행렬을 구성하고 TE는 Neumann 조건의 상수 모드를 제외하며 TM은 Dirichlet 조건을 적용한다. 정규화한 접선 전계 기저를 개구에서 겹쳐 복소 전계 및 자계 경계식을 정합한다. 소멸 모드는 접면 계산에 포함한다. 적용 범위는 균질 무손실 매질과 단일 평면 단차다. 여러 도체 단면의 TEM, 불균질 재료의 혼성모드와 길이가 있는 전이 구조에는 별도 풀이가 필요하다. [일반 도파관 유한요소 연구](https://doi.org/10.1109/TMTT.1969.1126932) [모드 정합과 복소 전력 연구](https://doi.org/10.1109/22.320771)
