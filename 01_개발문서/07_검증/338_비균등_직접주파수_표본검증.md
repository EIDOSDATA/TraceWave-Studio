# 비균등 직접 주파수 표본 검증

검증일 2026-11-23

## 공개 입력과 계산

해석 조건의 직접 주파수 표본 칸에 3~201개의 주파수를 Hz 단위로 오름차순 입력한다. 목록이 있으면 첫 값과 마지막 값이 대역의 시작과 끝이며 표본 수는 목록의 길이다. 비워 두면 기존 균등 표본 설정을 사용한다. 주파수와 대역 상한을 기존 PCB 계약에 맞게 검사한다.

각 복소 표본은 openEMS의 실제 과도 전압과 전류를 그 주파수에서 직접 변환한다. 전력 수지는 NF2FF 기록 주파수가 직접 포트 표본에 있을 때만 준비한다. 무효 순서, 중복 및 끝점 불일치 사례를 거부했다. 기존 균등 목록의 계산과 저장 계약은 계속 지원한다.

## Windows와 실제 WSL

- 원호는 8, 8.17, 9.73, 12 GHz를 지정했다.
- IFA는 2.4, 2.401, 2.444, 2.4835 GHz를 지정했다.
- 각 조건을 저장하고 새 서비스에서 읽었다. 미리보기의 격자와 해석에 사용된 격자가 같았고, 두 원시 포트 변환에서 지정한 네 주파수만 같은 순서로 결과에 보존했다. 해석 결과가 당시의 주파수 목록과 정규화 규약을 확인할 수 있게 했다.
- 제작과 실측 조건은 미정이다. 공진 자동 표본 보강, 더 정밀한 공차 및 실물 대조는 별도로 평가한다.
