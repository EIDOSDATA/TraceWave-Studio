# 부분 절삭과 도금 관통 홀의 유전체 간극

2026-11-23 KST. 해석 전 검토의 간극 목록은 네이티브 입력이 사용하는 치수로 유전체와 표면층을 높이별로 분할한다. 각 단면에서 비도금 절삭, 표면 개구, PTH 외경을 빼고 노출된 직선과 원호에서 최근접점을 찾는다. 내경 안쪽은 보어이며 배럴 자체의 간극은 별도로 계산한다.

| 사례 | 독립 확인값과 관찰 |
| --- | --- |
| 깊이 0.5 mm의 절삭 | Z 0.2~0.4 mm의 내부 상자에서 절삭 끝면 Z 0.5 mm까지 0.1 mm. 통과한 XYZ 셀을 확인했다. |
| 비도금 홀과 PTH 중첩 | 반경 0.5와 0.35 mm, 중심 거리 0.35 mm인 두 원의 교점을 별도 식으로 구했다. 겹친 원 안의 상자에서 밖으로 노출된 벽까지의 거리와 일치했다. |
| Windows에서 WSL2 openEMS 준비 | 원호와 IFA의 비도금 원통 반경 0.75 mm와 양 끝 XYZ를 준비된 XML에서 대조했다. 원호의 Z 범위는 0~1 mm, IFA는 0.035~0.965 mm였다. PTH 입력도 별도로 준비하여 외경 반지름 0.4 mm, 내경 반지름 0.3 mm, 높이 0~1 mm를 셸과 보어의 XML에서 확인했다. 세 준비 입력의 미검사 체적은 0개였다. |

실행 대상은 `test_solver_review_followup`, `test_pcb_voids`, `test_pcb_ifa`, `test_curve_boolean`, `test_drawing_mechanical`이다. 겹친 원 경계는 원을 다각형으로 근사하지 않는다. 완전히 깎인 층은 남은 재료가 없는 것으로 처리한다. 접점에서 경계 연결을 결정할 수 없거나 계산 상한을 넘으면 기존 미검사 체적 수에 포함한다. 부분 깊이와 중첩의 수치 시험은 검토용 프리미티브 입력을 사용했다. 실제 PCB 예제의 검증 지점은 해석 준비와 XML 형상까지다. 이번 거리는 제조 공차나 RF 손실의 측정값이 아니다.
