# 3포트 및 4포트 PCB의 전체 S 행렬

## 사용 방법

설계에서 최대 네 개의 lumped 급전을 추가한다. 각 급전에 양쪽 도체, 접점 좌표, 방향, 실수 기준 저항을 명시한다. 네 급전은 각각 한 개의 전압/전류 측정면을 갖는다. `pcb-multiport`는 현재 프로젝트 개정 JSON 또는 저장된 `.rfad.zip`과 해석 조건을 읽는다. 다음 예에서 OUTPUT은 새 디렉터리이다.

```text
python -m rfad pcb-multiport PROJECT.rfad.zip --settings SETTINGS.json --output OUTPUT
```

고정 WSL2 openEMS 런타임에서 각 급전 쌍의 간극 겹침을 확인하고 모든 접점이 실제 도체와 연결되는지 검사한다. 같은 솔버 격자에 모든 급전의 저항을 넣고, 한 번에 한 급전만 여기한다. 각 주파수에서 포트 저항으로 정규화한 복소 입사파와 출력파를 열별로 수집한다. 구동 전력이 약하거나 행렬이 특이하면 거절하고, 유효한 주파수에서 S A = B의 전체 행렬을 푼다. 각 실행의 XML, 원시 전압/전류, 종료 근거, 공통 격자 해시와 전체 S 행렬이 함께 남는다.

Studio는 1~4포트 Touchstone Full, 명시적 열 대응 CSV 및 공통 복소 HDF5를 읽고 쓴다. Touchstone 1.0의 3/4포트는 주파수별 행 단위 순서를 확인한다. 2.0/2.1 Full에서는 행 우선 순서를 사용하고 2포트만 별도 순서 선언을 적용한다. 일반 복소 결과에서 원소의 행과 열을 선택할 수 있다. 양쪽 2포트 치구 제거와 단일 포트 부하 RLC 결합은 대상 포트 수를 확인한다. [IBIS Touchstone 2.1 형식 규격](https://ibis.org/touchstone_ver2.1/touchstone_ver2_1.pdf)

## 실제 native 계산

기존 원호 예제에서 파생한 26 mm 원형 기판에 분리된 선분 쌍을 추가했다. 두 개정의 8~12 GHz, 직접 31개 주파수, 간격 0.5 mm, 시간 단계 상한 20000, 에너지 비율 0.0001, PML과 기존 급전 모델을 고정했다. 각 포트의 순서는 설계에 저장된 UUID 순서에 따른다.

| 개정 | 순서별 기준 저항 (ohm) | 여기별 종료 단계 | 여기별 감쇠 (dB) | 주파수별 입사행렬 최대 조건수 | 공식 검산의 최대 복소 오차 |
| --- | --- | --- | --- | ---: | ---: |
| 3포트 | 50, 65, 75 | 1120, 1015, 910 | 40.36, 40.82, 40.47 | 1.002860 | 4.75e-16 이하 |
| 4포트 | 70, 50, 65, 75 | 1015, 1190, 1015, 980 | 42.12, 41.98, 40.51, 41.27 | 1.003007 | 5.12e-16 이하 |

일곱 실행이 모두 에너지 종료 기준에 도달했다. 모든 여기의 실제 격자 SHA-256은 `b24fe4cdd010f242d572840c70057abe5ab570004dd2c3d3609e7a0f8b1a32c9`였다. 공식 openEMS `CalcPort`로 각 여기의 전체 파형을 다시 처리하고 행렬을 독립 계산했다. 3포트 279개와 4포트 496개의 복소 S 값이 위 범위에서 일치했다. 서로 맞바꾼 포트 쌍의 최대 복소 차이는 각각 0.005046과 0.005238이었다. 원자료에 상호성을 강제하지 않았다.

두 실제 결과의 `.s3p`와 `.s4p`는 scikit-rf의 `Network`로 열었을 때 전체 행렬과 동일했다. CSV 열 대응을 사용해 재입력한 값도 같았고 HDF5 왕복은 행렬, 기준 저항과 출처를 모두 보존했다. 비상호 4포트 시험에서는 일반 프로젝트 서비스로 가져와 저장한 후 다시 열어 S43의 0.32 + j0.02를 확인했다. 3/4포트를 양쪽 2포트 치구 제거 또는 1포트 RLC 결합에 넘기면 `E_UNSUPPORTED`를 반환했다.

```sh
PYTHONPATH=Code/src:Code/tests RFAD_OPENEMS_NATIVE=1 python -B -m unittest test_pcb_multiport_extended.ExtendedPorts.test_all_excitations_and_official_complex_port_waves
```

별도 필드, 방사 및 독립 전력 기록은 단일 급전 실행에서 제공한다. 여러 여기의 방사장 위상 결합, 5개 이상 포트 및 실제 제작 물성의 확증은 이 검증 범위 밖에 있다.
