# Windows 캔버스 합성 화면 검증

2026-11-20 KST. 12번 F1의 2D 조회 중 확대 동작을 실제 Windows 창에서 계측했다. 제품 `DesignCanvas`를 전용 wxWidgets 창에 띄우고 고정 합성 장면을 입력했다. 모두 4층, 1000 x 700 픽셀, DPI 144이며 출력 화면은 2560 x 1600, 120 Hz였다. 전체 Studio 편집 프로젝트와 표/3D/저장 경로는 이 성능 표본에 포함하지 않았다.

## 표시 시각의 연결

- 평소 확대 입력 처리기에 이벤트를 전달한 직전 QPC를 기록했다. 그리기 마지막에 같은 캔버스 버퍼에 시험 번호를 넣고, Windows Desktop Duplication에서 그 번호를 포함하는 합성 화면의 `LastPresentTime`을 읽었다. 기기 패널의 실제 주사는 별도다. [Windows 화면 시각 명세](https://learn.microsoft.com/windows/win32/api/dxgi1_2/ns-dxgi1_2-dxgi_outdupl_frame_info)
- 시험 창이 전경일 때 고정한 96 x 1 픽셀만 검사했다. 픽셀 자체를 기록하지 않고 입력 번호와 세 시점, 합쳐진 Windows 갱신 수를 보존한다. 입력·그리기·합성 순서가 어긋난 표본은 판독에서 거부한다.
- 초기 wx 타이머의 지연을 확인하고 시험 도구만 8 ms 고해상도 대기 타이머로 바꿨다. 처리 대기 이벤트는 하나로 제한한다. 타이머 기회, 실제 전달, 그리기 및 표시 수를 각각 남긴다. [Windows 고해상도 타이머 명세](https://learn.microsoft.com/windows/win32/api/synchapi/nf-synchapi-createwaitabletimerexw)

## Windows 관찰값

| 구성 | 형상 | 입력 구간 (초) | 전달 입력 | 합성에서 읽은 입력 | 화면 간격 수 | 간격 p95 (ms) | p99 | 최대 | 입력-합성 p95 (ms) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| wx 타이머 진단 | 4096 | 35.01 | 1753 | 1753 | 1752 | 25.81 | 33.63 | 41.49 | 32.08 |
| 고해상도 타이머 대조군 | 256 | 35.00 | 4074 | 3305 | 3304 | 17.18 | 24.91 | 25.63 | 18.53 |
| 고해상도 타이머 표시 상한 | 4096 | 35.00 | 2061 | 2047 | 2046 | 24.86 | 25.30 | 31.99 | 32.85 |

최종 4,096개 실행에서 8 ms 타이머의 실제 기회 간격 p95는 8.60 ms였다. 4,212회 중 2,151회는 입력으로 전달되지 않았다. 전달한 입력 중 13회는 별도 그리기를 관찰하지 못했고, 그린 표식 중 1회는 합성에서 관찰되지 않았다. 256개 대조군의 같은 수치는 각각 145, 5, 764회였다. 한 번호가 합성에서 반복되면 첫 시각만 사용하되, 연속 관찰 번호 사이의 긴 간격은 그대로 포함했다.

최종 4,096개 표본의 갱신 간격 p95는 16.67 ms 목표를 넘었다. 상한 4,096개의 표시 시험이며 F1의 10,000개 2D 형상, 1,000개 매개변수, 100,000개 검색 레코드와 전체 GUI 상호작용은 수용 대상으로 남는다. 표시하지 못한 입력을 0 ms로 계산하지 않는다. 실제 창 관찰과 [이전 wxMemoryDC 비용](53_윈도우_이차원_표시비용_검증.md)은 별도다.

## 재현과 회귀

```powershell
cmake --build build/windows-release --target tracewave_canvas_display_probe
./build/windows-release/bin/tracewave_canvas_display_probe.exe .local/canvas-display.json 4096
.venv/Scripts/python.exe -X utf8 tools/summarize_windows_canvas_display.py .local/canvas-display.json
```

독립 시험 창을 열고 약 35초 동안 확대와 축소를 교대로 입력한다. 다른 창을 활성화하거나 계측 창이 이동하면 해당 실행을 실패로 남긴다. 기존 출력 덮어쓰기 거절, 판독 회귀 3개, Windows GUI 회귀 10개, CTest 13개를 확인했다. [원시 타임스탬프와 실행 기록](56_윈도우_합성화면_실행기록.json)을 보존한다.
