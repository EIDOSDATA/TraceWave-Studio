# 해석 오류의 속성 이동과 조건 복귀

2026-11-22 KST. Windows Release에서 기존 원호와 IFA 프로젝트의 검수 사본을 열고, 각 과거 결과에서 해석 조건을 불러왔다. 주파수 표본 수를 53개, 최대 시간 단계를 24000, 임계 구간 최소 분할을 2로 바꾼 뒤 조건을 검토했다.

| 사례 | 검수 사본의 오류 | 이동 후 키보드 초점 | 수정과 복귀 | 준비 격자선 X/Y/Z 및 격자점 |
| --- | --- | --- | --- | --- |
| 원호 | 기판 유전체의 상대 유전율 미정 | 해당 재료의 상대 유전율 입력 방식 | 직접 입력으로 4.2를 입력하고 변경 적용 후 해석 검토로 복귀 | 119 / 162 / 45, 867,510점 |
| IFA | 단일 급전의 기준 저항 미정 | 해당 급전의 기준 저항 입력 방식 | 50 ohm으로 변경 적용한 뒤 해석 검토로 복귀 | 122 / 157 / 45, 861,930점 |

두 경우 모두 오류가 발생하면 문제 속성으로 이동 버튼에 초점이 놓였다. 버튼을 누르면 트리에서 원래 객체가 선택되고 속성의 미정 입력으로 초점이 이동했다. 돌아온 검토 창에서 앞서 바꾼 세 값과 0.5 mm 모델 격자, 10.4 mm 공기 여유, 0.8 mm 가변 공기 격자, 성장률 1.5 및 2,441,750,000 Hz NF2FF 주파수를 확인했다. 새 개정에서 조건 검토를 완료할 때까지 실행 버튼은 잠겨 있었다.

수정 내용을 저장한 뒤 openEMS/CSXCAD 준비에서 화면의 해석 입력 SHA-256 및 모든 X/Y/Z 격자선을 대조했다. 두 사례 모두 실제 준비 입력이 검토 화면과 일치했다. 원본 프로젝트와 과거 결과 해시를 보존했고, 이번 검증은 FDTD 실행 전 준비까지 수행했다.

| IFA | `d71a7dfdb0c592d48744426f8092b6f32e0b33f1b51e48aab8c8d0c8182337fe` | `0bd998b468cd295055d640a8bea0975a7de0d45d057f921cb26dc58b4617f863` |

Windows Release CTest 13개와 관련 Python 테스트 56개가 통과했다. WSL2 전용 Python 테스트 한 개는 Windows 실행에서 건너뛰었으며, 두 사례의 실제 WSL2 준비는 위 표로 확인했다. 회귀 시험은 층 재료 지정, 재료 유효 대역과 전도도, 동박 두께, 급전 저항·극성 및 급전 영역의 오류 위치를 함께 확인했다.
