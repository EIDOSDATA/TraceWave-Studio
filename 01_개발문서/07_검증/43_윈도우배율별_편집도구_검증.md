# Windows 배율별 2D 도구 검증

2026-11-20 KST. 완료 계획 12번에서 [Studio 화면 계약](../04_화면설계/08_스튜디오_화면계약.md)의 2D 도구막대를 실제 Windows 배율로 검증했다.

200%에서 보존 프로젝트를 열면 선택과 선 버튼의 아이콘 및 라벨이 사라지고 원호 아이콘이 검은 형태로 보였다. 좌표 입력 창은 열렸고 입력 단위와 확인·취소 버튼은 화면 안에 있었다. [200% 결함 재현](02_실행화면/98_이백퍼센트_좌표입력과_도구아이콘_재현.jpg)

2D 도구의 원래 선 도형에서 100%, 150%, 200%에 맞는 투명 비트맵을 만들고 하나의 `wxBitmapBundle`로 native 버튼에 건넨다. 선택 상태에 맞춘 색상은 같은 도형을 해당 색으로 그려 갱신한다. 도구별 색상, 굵기와 현재 도구 안내는 2D 도구막대 쪽이 한 곳에서 설정한다.

| Windows 배율 | 실제 확인 |
| --- | --- |
| 100% | 같은 프로젝트 재열기 뒤 아이콘, 텍스트, 선택 강조, 저장된 속성과 형상 확인. [화면](02_실행화면/101_백퍼센트_편집도구와_재열기.jpg) |
| 150% | 실제 작업 영역에서 선택의 강조와 선·원호의 아이콘 및 텍스트 확인. [화면](02_실행화면/99_백오십퍼센트_선택도구_표시.jpg) |
| 200% | 좁은 배치에서 선택·선·원호 모두 읽을 수 있었다. 원호를 선택해 아이콘, 표시명과 강조를 확인했다. 좌표 입력의 mm/각도와 확인·취소 버튼을 확인한 뒤 Esc로 취소했다. [화면](02_실행화면/100_이백퍼센트_원호도구와_좌표입력.jpg) |

150%의 Windows GUI 회귀에서 6개 아이콘의 투명 마스크와 논리 크기 18 DIP, 현재 도구의 굵기와 도움말, 선/원호 편집 및 저장·재열기를 확인했다. CTest 13개도 통과했다. 시각 검증에 사용한 프로젝트 파일 8개의 SHA256은 전후 동일했다. 검증을 마치고 원래 설정인 150%를 복원했다. [실행 기록](44_윈도우배율별_편집도구_실행기록.json)

이 기록의 배율 검증 범위는 같은 모니터에서 재실행한 2D 도구막대와 원호 좌표 입력이다. 실행 중 모니터 이동, 고대비, 전체 대화상자와 화면의 배율 수용은 별도로 검증한다.
