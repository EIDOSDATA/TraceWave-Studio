# Windows 기판 관통부 해석

2026-11-21 KST. Windows Release Studio와 WSL2 openEMS에서 직사각 PCB의 비도금 원형 홀, 12도 회전한 직선 슬롯과 내부 삼각 절삭을 하나의 설계로 준비하고 해석했다. 급전과 도체의 연결을 유지하고 세 기계 절삭 각각의 내부 검사점에 진공 재료가 적용된 것을 봉인된 준비 산출물에서 확인했다.

실제 Studio에서 해석 중 프로젝트를 저장했고, 서비스 재시작 후 S11 결과와 기계 원본을 다시 읽었다. 비도금 홀과 슬롯의 공구 직경은 미정으로 유지했다. 구리·비아·급전 가까이에 배치하거나 도금 여부를 미정으로 바꾼 입력은 계획 단계에서 거절하는 별도 시험을 통과했다.

원형과 슬롯은 해석형 원통·압출 형상으로, 내부 다각형은 선형 압출로 계산했다. 격자 해상도와 제조 조건, 독립 RF 정확도는 이번 실행과 별개다.
