# Windows 기술 도면 검토와 키보드 생성

2026-11-21 KST. 실제 Windows Studio에서 F6, Shift+F6, End로 설계에서 출력으로 이동했다. Tab과 방향키로 고정할 개정을 선택하고 출력 설정을 지나 검토 동작에 접근했다. 검토 뒤 포커스가 양식 앞쪽으로 돌아가는 동작도 관찰했다.

출력 확인 창에 명시적인 취소 버튼을 두고 초기 Enter는 취소로 처리한다. 파일을 만들려면 생성 버튼을 선택하거나 Alt+G를 사용한다. 실제 최종 창에서 기본 Enter로 검토가 유지되는 것을 확인했다. 같은 검토에서 Alt+G로 출력한 PDF의 원문 서명, 크기 38902바이트와 저장 참조 SHA256을 대조했다. 프로젝트 저장 개정과 앞선 해석 결과 목록이 보존됐다. 출력·재검수·재열기 Windows 회귀와 Release CTest 13개도 통과했다. [실행 기록](201_기술도면_키보드생성_실행기록.json)
