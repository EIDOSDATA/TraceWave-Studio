# 설계 탐색 가중 순위와 독립 재실행 검증

검증일 2026-11-23

## 목표별 가중 순위

후보 순위를 열고 목표별 가중치를 입력한다. 비워 둔 목표는 1을 적용한다. 모든 칸을 비우면 기존 우열 그룹 순으로 표시한다. 가중치를 입력하면 목표 통과율의 가중 평균을 계산한다. 같은 점수에서는 기존 우열 그룹 및 후보 순으로 정렬한다. 표본이 확인되지 않은 후보는 기존과 같이 순위에서 제외하며 상태별 건수를 표시한다. 가중치를 0으로 정한 목표도 미확인 표본 여부는 검사한다.

실제 회로 스윕에서 목표 두 개와 완료 후보 세 개의 보존 평가를 사용했다. 가중치 3과 1의 정규 비율은 0.75와 0.25였다. 해당 후보들의 점수는 1, 0.25, 0.25였고 기존 우열 그룹과 실패 건수가 유지됐다. 가중치 0 및 잘못된 목표 지정도 시험했다. 작업 공간 재열기 후 순위 해시가 일치했다.

## 별도 작업 공간 재검토와 실행

1. 연구의 계산 명세 JSON을 저장한다. 같은 개정의 활성 복원용 프로젝트 보존 ZIP을 만들며 회로 연구는 원문 자료를 포함한다.
2. Code 디렉터리에서 아래 명령으로 새 작업 공간의 원본, 조건, 엔진, 후보 수와 검토 해시를 확인한다. PCB 연구는 고정된 openEMS 환경과 함께 --openems-wsl을 사용한다.
3. 계산을 실행하려면 다른 빈 작업 공간 경로에 --run을 추가한다. 검토와 실행이 모두 새 작업 공간에서 이루어지며 기존 연구에는 접근하지 않는다.

~~~powershell
.venv/Scripts/python.exe tools/replay_sweep.py --recipe recipe.json --archive archive.zip --workspace replay-workspace
~~~

Windows에서 원본 네트워크와 회로를 복원한 뒤 별도 실행을 완료했다. 완료 후보 두 개와 실패 후보 한 개를 분리하고 복소 반사 시험값을 독립 산술 11/29와 대조했다. 사용 중인 작업 공간과 명세 해시 변조를 거부했다. 원래 설계와 연구 이력은 유지했다. 제작과 측정은 미정으로 유지했다.

실제 openEMS WSL 원호 연구도 보존 ZIP에서 별도 복원하고 준비 및 계산했다. 개정 및 검토 해시, 정규 입력, 후보 수와 고정 엔진이 모두 일치했다. 후보 1개가 완료되어 새 작업 공간을 재열기한 뒤 S11 31개를 확인했다.

Windows에서 실제 WSL 후보를 포함한 설계 스윕 회귀 시험 49개가 모두 통과했다.
