# 객체별 국부 격자의 Windows와 실제 준비 검증

2026-11-22 KST. 원호와 IFA의 기존 채택 사본, 별도 중공 PTH 검수 사본에서 국부 격자만 바꿨다. Windows의 해석 전 검토에서 규칙을 편집하고 실제 구간을 해석 격자와 수치 표에서 열었다. 조건에 이름을 붙여 저장하고, 프로젝트를 다시 열어 같은 규칙과 좌표를 읽었다.

| 사례 | 명시한 규칙 | 이전 X/Y/Z | 국부 격자 X/Y/Z | 격자점 |
| --- | --- | --- | --- | --- |
| 원호 | 급전 X 0.18 mm, Y 0.12 mm, 우선순위 35. 인접 간극 Y 0.24 mm, 우선순위 75 | 117 / 157 / 42 | 119 / 163 / 42 | 814,674 |
| IFA | 급전 X 0.18 mm, Y 0.12 mm, 우선순위 35. 인접 간극 Y 0.24 mm, 우선순위 75 | 117 / 157 / 42 | 119 / 169 / 42 | 844,662 |
| 중공 PTH | 비아 X 0.04 mm, Y 0.045 mm, Z 0.12 mm, 우선순위 65 | 63 / 55 / 29 | 81 / 71 / 37 | 212,787 |

원호에서 인접 간극의 Y 50.2~50.8 mm에 상위 규칙이 적용됐다. 이 구간은 4셀이고 실제 최대 폭은 0.15 mm였다. IFA의 Y 50.4~51.6 mm는 8셀, 최대 약 0.16666667 mm였다. 두 경우 모두 나머지 급전 Y 구간의 실제 최대 폭은 0.1 mm였고, 급전 X 구간의 최대 폭은 0.09 mm였다. 결과표에서 겹친 급전 규칙을 선택했을 때 상위 규칙 적용으로 표시됐다. 적용된 간극을 선택했을 때 양쪽 선이 강조되고 Y 수치 표가 첫 셀을 선택했다.

PTH에서 자동으로 선택된 배럴 범위는 X 2.6~3.4 mm, Y 5.6~6.4 mm, Z 0~1 mm였다. 실제 최대 폭은 X 0.0375 mm, Y 약 0.04285714 mm, Z 0.1 mm였다. Z 구간을 열면 XZ 투영과 Z 수치 표를 함께 표시했다.

세 사례의 Windows 표시 해시를 실제 WSL2 openEMS/CSXCAD 준비 입력과 대조했다. 준비 결과의 모든 격자선, 국부 보고서의 경계 인덱스, 셀 수와 실제 최대 폭이 일치했다. 원본 프로젝트의 포인터와 과거 결과의 등록 내역도 일치했다. 검증 범위는 FDTD 실행 전 해석 준비까지다.

IFA를 Windows에서 다시 열어 저장한 조건의 좌표와 재검토 해시를 확인했다. 검수 초안에서만 Y 0~60 mm에 최대 폭 0.001 mm를 지정하자 격자점 상한에 걸렸다. 실행 버튼은 잠겼고 국부 격자 조건 표로 초점이 돌아왔다.

Windows Release CTest 13개와 관련 Python 시험 55개, WSL2 전용 PML 및 도체 연결 준비 시험 한 개를 통과했다. 회귀 시험에서 기본 격자선 보존, 겹침 우선순위와 동률, 사라진 비아 ID, 평면 급전의 국부 규칙 적용 범위 및 기존 격자점 상한을 확인했다. [기능 계약](../05_기능설계/04_해석결과/03_사용자기판_단일포트_해석.md), [개발 순서](../09_개발계획/15_기능채택과_개발검증_순서.md)
