# Windows CAD와 PDF 생성의 고속 로그 취소

2026-11-21 KST. Windows Studio Release에서 OCCT 형상 생성과 PDF 도면 생성을 각각 3회 취소했다. 각 시험에서 먼저 정상 경로로 STEP 또는 PDF를 게시했다. 격리 소스 사본은 후속 worker에서 같은 입력의 실제 형상 생성 또는 PDF 렌더링과 파일 검사를 반복하고, 해당 worker의 표준 오류 파이프에 초당 약 1000행을 보냈다. 원본 제품 소스와 사용자 프로젝트에는 시험 계측을 적용하지 않았다.

시험은 실제 계산 호출이 끝난 기록과 2000행 이상을 확인한 뒤 Studio 취소 버튼을 눌렀다. 가상환경의 Windows 실행기 PID와 실제 계산 프로세스의 부모 PID, Windows Job 회수 기록, 취소된 작업 ID를 대조했다. 세션을 다시 열어 기존 산출물과 저장 개정이 유지되고 취소한 작업의 산출물이 게시되지 않았음을 확인했다. PDF의 저장 원문에는 기존 출처와 미정값이 그대로 있었다.

| 지표 | OCCT 형상 중앙값 / p95 (ms) | PDF 생성 중앙값 / p95 (ms) |
| --- | ---: | ---: |
| 취소 버튼 잠금 | 1.01 / 1.18 | 0.25 / 0.46 |
| Studio 접수 | 43.94 / 48.87 | 96.83 / 111.14 |
| Windows Job 회수 | 7.69 / 10.48 | 10.67 / 10.99 |
| Studio 종료 표시 | 123.56 / 134.92 | 214.90 / 233.96 |

측정한 로그량은 초당 976.49~996.98행이었으며, 여섯 회 모두 접수 200 ms 이내였다. 예비 시험에서 최초 CAD 결과의 STEP 생성과 후속 형상 생성의 작업 종류를 구분하고, 가상환경 실행기와 실제 worker의 부모·자식 관계를 대조하도록 수정했다. 최종 표본은 수정한 시험 도구로 새 작업 영역에서 수집했다.

표본 3회의 nearest-rank p95는 관찰 최댓값이다. 계산 반복과 합성 로그는 시험 도구가 만든 부하다. 작업군별 규정 표본 1000개와 기준 Windows 호스트의 수용은 남는다. PDF 재검수의 취소는 앞선 정상 부하 실측만 포함한다. [정상 부하 취소 검증](232_윈도우_형상과_출력_취소지연_검증.md), [이번 실행 기록](243_윈도우_형상과_도면_고속로그_실행기록.json)
