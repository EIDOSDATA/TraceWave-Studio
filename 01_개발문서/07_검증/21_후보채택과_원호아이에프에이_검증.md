# 후보 채택과 원호/IFA 작업 흐름 검증

작성일: 2026-11-17 KST. 상태: 명시 유한 범위의 소프트웨어 검증 완료. 개발 완료 계획 9번의 유한 소프트웨어 작업 흐름이며 전체 RF/제작/측정 수용 기록이 아니다.

[후보 채택 계약](../05_기능설계/06_연구/02_후보채택과_새작업사본.md), [화면과 전환](../04_화면설계/23_후보채택과_새사본_화면.md), [기존 스윕](../05_기능설계/06_연구/01_명시적스윕과_실행계약.md), [개발 완료 계획](../09_개발계획/03_개발완료_계획.md)을 함께 읽는다. 기존 단계 6~8의 원시 기록과 실행 화면은 수정하지 않는다.

## 1. 확인한 범위

연구 기준 원본과 선택한 순번, 실제 계산을 재사용한 순번을 구분한다. 검토한 후보의 리터럴 매개변수를 새 프로젝트에 한 명령으로 적용하고 원본 프로젝트의 저장 파일, 개정, 실행 취소 이력과 과거 결과를 보존한다. 파생 표현식은 그대로 계산하며 선택 행의 단위와 출처를 계산 재사용 행으로 덮어쓰지 않는다.

새 사본은 채택한 상태를 저장 기준점으로 갖는다. 한 번 실행 취소하면 새 사본 안의 연구 기준 형상으로 돌아가고, 다시 실행하면 선택 값과 채택 출처를 복원한다. 생성 성공 뒤 '새 사본 열기'를 선택해야 현재 Studio 프로젝트가 바뀐다. 응답 미확정 또는 영수증 만료를 미생성으로 단정하지 않으며, 보존 요청 확인 전 재생성을 잠근다.

## 2. 계산 전에 고정한 입력

검증 도구는 [명시 사례 구성](../../Code/tools/tuning_workflow_cases.py), [유한 실행](../../Code/tools/verify_tuning_workflow.py), [채택과 재검산](../../Code/tools/verify_tuning_adoption.py)이다. 기준 파일 [ifa_feed_smoke.json](../../Code/fixtures/ifa_feed_smoke.json)은 수정하지 않고 공개 프로젝트 명령으로 새 검증 프로젝트를 구성한다.

| 항목 | 명시한 조건 |
| --- | --- |
| 공통 PCB | 40 x 60 mm, epsilon_r=4.2, tan_delta=0.018, core 0.93 mm, 동박 35 um. 기존 fixture의 개발 시험 가정 |
| IFA | 기존 급전/단락/접지를 보존하고 방사 도체 길이 24/26/28 mm. 끝 X는 고정 시작 X와 길이의 표현식 |
| 원호 | 합성 반원 중심선 반지름 4.5/5/5.5 mm, 폭 1 mm. 중심 X=25 mm-반지름으로 급전 연결점 (25,52) mm 고정 |
| 원호 급전 | 접지와 패드 사이 명시 1 mm 이상 간극. 실제 SMA, launch 또는 비콘 artwork 재현 아님 |
| 주파수 | 2.4~2.4835 GHz의 양끝을 포함한 정확 51개 표본. 목표도 같은 표본과 포트/이상 간극 기준면 |
| S11 기준 | 표본별 -10 dB 이하. 실패는 실패로 남김 |
| 나머지 목표 | 방사 효율, 총 효율, 비대역폭 한계는 missing/null. 임의 합격 한계 없음 |
| 방사 기록 | 2.44175 GHz, theta/phi 간격 15 deg. 유한 표시 작업 흐름용이며 각도/공간 수렴 검증 아님 |
| 수치 설정 | 0.5 mm 격자, 공기 여백 8 mm, 곡선 허용오차 0.025 mm, 최대 50000 timestep, 에너지 종료 기준 1e-4 |
| 예산 | 초기 3+3 후보 최대 6회 native 계산, 채택 사본당 단일 재검산 최대 2회. 자동 실패 재시도 없음 |
| 후보 선택 규칙 | 51개 유효 표본의 최악 S11이 가장 작은 행, 동률이면 앞 순번. 목표 미달이어도 편집 후보 선택 사유에 미달을 명시 |

위 원호 치수는 명시 개발 시험 입력이다. 초기 합성식이나 권장 치수, G031 또는 nRF 비콘 재현값으로 표시하지 않는다. 원호와 급전은 실제 도체 연결점을 공유하며 화면 시안의 분리된 장식 도형을 RF 원본으로 사용하지 않는다.

원본 프로젝트에는 실제 납품 물성의 별도 미정 재료를 보존한다. 설치 시나리오와 배터리/외함의 위치, 크기, 회전, 재료도 미정이며 include_in_em=false다. 해석 계획은 이 제외를 명시한다. 따라서 설치 환경이 안테나 성능에 주는 영향을 계산했다는 주장은 하지 않는다.

## 3. 검증 기록

- 두 명시 사례의 공개 생성/저장, 여섯 후보의 해석 계획 투영, 급전점 보존과 runtime 없는 재열기 시험 2개 통과, 10.966초.
- 후보 채택 서비스 전용 9개 통과, 31.627초. 선택 원문/단위, 단일 undo/redo, 기존 복소 파일과 회로 사본, 원본 및 미정 물성 보존을 포함한다.
- 별도 경계 검토 10개 통과, 35.225초. journal/디스크 상한의 게시 전 거절, 출처-명령 불일치, 과거 출처 변경과 일반 명령 우회 차단, 게시 직후 응답 장애의 영수증 복구를 포함한다.
- 기존 프로젝트/표현식/스윕/템플릿/물리설정/복소 자료 호환 시험 71개 통과, 25.277초.
- 실제 WSL 후보 계산 6회와 runtime 없는 재열기가 1036.375초에 완료됐다. 아래 6개 결과 모두 S11 목표 미달이며, 계산/저장 작업 흐름 성공과 구분한다.
- null인 기존 후보 출처를 삭제하지 않고 명시적으로 차단하는 서비스 시험 1개가 3.421초에 통과했다. application 모듈만 보완했고 실제 실행 중인 SOLVER 봉인 소스/identity는 같음을 대조했다.
- 채택 사본 두 개의 단일 undo/redo, 저장/재열기와 각각 한 번의 실제 재계산이 286.906초에 통과했다. 선택 원본 대비 S11 복소값 최대 차이는 두 사례 모두 0.0이었다. 사전 고정한 재현 비교 상한 1e-10은 계산 반복 확인이며 물리 정확도 또는 수렴 기준이 아니다.
- 원본 프로젝트 파일은 사례당 81개, 기존 solver 산출물은 186개 바이트 hash가 동일했다. 기존 실행 기록을 새 프로젝트의 검증 상태로 승계하지 않았다.
- 전체 서비스는 1,186개 수집 중 1,087개 통과, 99개 환경 조건 제외, 실패 0개로 1368.715초에 완료됐다. 이 수집 이후의 null-origin 보완은 위 별도 1개 시험으로 구분한다.
- 최종 Windows GUI의 후보 채택 시험 1건, 내부 검사 12개가 15.439초에 통과했다. editor.get와 canvas.get의 실제 시험용 E_IO 응답, F5 복구, 보존 영수증, 두 서비스 세션, 단일 undo/redo와 저장, Python 재열기의 원문 파일 보존을 포함한다.
- 동일 실행 파일의 기존 GUI 회귀 8개가 110.819초에 통과했고 CTest 11개가 0.81초에 통과했다. 최종 실행 파일 SHA256은 `40e98249100fde83c82484a3ba269b37bf354efcfb886a2c06d961372f8f3e4a`다.
- 실제 6회 계산 이후 복제한 별도 작업공간에서 Windows 화면으로 IFA 24 mm 후보를 검토하고 새 사본을 생성했다. 생성 후에도 원본 창 제목은 유지되며, 명시적으로 새 사본을 연 뒤 Ctrl+S, 정상 종료, 새 프로세스 재열기에 성공했다. CAD/openEMS 런타임 없는 재열기다.
- 재열기 후 기존 외부 물체의 위치/치수/회전/재료 미정, 표시/EM/STEP 제외와 원문 사유가 화면에 유지됐다. 수동 검수 후 별도 서비스 읽기에서 원본 두 사례 각 81개 파일과 문서 불변, 새 사본의 saved=current/단일 undo/24 mm 및 파생 끝 X=29 mm, 출처 필드 142개와 미정 Quantity 10개 보존을 확인했다. 이 목록의 완료 시험을 전체 단계 RF 합격으로 읽지 않는다.

| 사례 | 후보 값 | 51개 표본의 최악 S11 | S11 판정 | 편집용 선택 |
| --- | --- | --- | --- | --- |
| IFA | 길이 24 mm | -3.423129 dB | 미달 | 선택 |
| IFA | 길이 26 mm | -1.771030 dB | 미달 | 선택 안 함 |
| IFA | 길이 28 mm | -1.022588 dB | 미달 | 선택 안 함 |
| 원호 | 반지름 4.5 mm | -2.298219 dB | 미달 | 선택 안 함 |
| 원호 | 반지름 5 mm | -3.795360 dB | 미달 | 선택 안 함 |
| 원호 | 반지름 5.5 mm | -5.481961 dB | 미달 | 선택 |

나머지 세 목표 한계는 미정이므로 미평가다. 위 선택은 서로 다른 안테나 사례끼리 순위를 매긴 것이 아니며, 각 사례 안의 명시 유한 후보 중 다음 편집 사본을 정한 것이다.

사전 계획과 개별 후보의 계산/목표 판정은 실행 기록에서 별도로 보존한다. 시험 준비 중의 실패도 삭제하지 않는다. 최초 fixture 계획 점검에서는 시험용 SnapshotRef가 필수 필드를 빠뜨려 실행 전 거절되었고, 이후 기존 전체 SnapshotRef 시험 도우미로 여섯 계획을 확인했다. 독립 경계 시험의 첫 실행은 초기 프로젝트 수에 관한 시험 assertion이 잘못되어 수정했으며 제품 오류와 구분한다.

서비스 초기 구현에서는 canonical content hash와 저장 파일의 raw SHA256을 같다고 비교한 결함을 발견했다. 두 식별자를 각각 보존하고 원문/소유권 대조로 검증하도록 고친 뒤 전용/호환 시험과 실제 계산을 수행했다. GUI 초기 시험의 두 번째 클릭 오류는 비활성 버튼을 활성 버튼 전용 helper로 호출한 시험 결함이었다. 이후 시험은 새 사본 저장 뒤 서비스 재연결이 최초 CLI 프로젝트로 돌아가는 제품 결함을 발견했다. 별도 읽기 검토에서는 새 프로젝트 열기 뒤 속성 조회 실패 시 이전 DTO의 편집을 허용하는 경계를 발견했다. 두 제품 경계는 보강 후 별도 최종 GUI 시험으로 확인했다.

## 4. 여전히 미확립인 항목

이상 급전의 명시 시험을 승인 IFA의 SMA/50 ohm launch/실장/교정 기준면 사례로 대체하지 않는다. 실제 제작 물성, 피복, 부품 패키지, 시료, 케이블/지그/설치 환경, 측정과 불확도 자료는 미확보다. 한 격자와 한 NF2FF 각도 분할의 계산 및 동일 입력 재계산은 격자/경계/각도 수렴이나 독립 실물 정확도 수용이 아니다.

RO4350B 국부 방사 도체 손실 변화 2.788446%와 초기 2% 기준 미확립, GHz PTH 손실의 독립 물리 정확도 미확립을 유지한다. 전력 수지, solver 에너지 종료, 후보 선택 또는 파일 재열기 성공으로 이 상태를 승격하지 않는다.
