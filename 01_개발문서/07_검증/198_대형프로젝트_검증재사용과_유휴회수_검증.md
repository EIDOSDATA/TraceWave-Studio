# 대형 프로젝트 검증 재사용 후 150초 유휴 회수

2026-11-21 KST. 대형 문서의 검증을 같은 SHA256에서 재사용한 서비스와 이전 시험과 동일한 SegmentHeap Studio에서 150초 유휴 전환 30회를 재검증했다. 같은 프로세스 집합에서 형상 10000개, 매개변수 1000개, 100만 삼각형, 1 GiB급 필드 부분 조회 열 회와 복소 곡선 여덟 개를 함께 열었다. [30초 유지 검증](196_대형프로젝트_검증재사용과_유지회수_검증.md)

| 지표 | 실제 Windows 표본 |
| --- | ---: |
| 초기 5회 안정화 합산 private commit 중앙값 | 131.75 MiB |
| 마지막 10회 안정화 합산 private commit 중앙값 | 145.75 MiB |
| 안정화 증가 | 13.99 MiB |
| 열림 중 합산 private commit 관찰 최대 | 358.50 MiB |
| GUI 안정화 핸들 처음 / 범위 / 마지막 | 309 / 307~366 / 366 |
| 유휴 GPU local 최대 / nonlocal 최대 | 23.99 MiB / 0바이트 |

30회 모두 OpenGL 문맥을 해제했고 증가는 32 MiB 이내였다. GUI 핸들의 마지막 10회는 360~366으로 끝났다. 이 증가가 이후 안정화되는지와 기준 호스트 수용은 남는다. 하위 서비스와 런처의 관찰 핸들은 동일했다. 같은 PC의 변경 전 150초 시험은 +22.30 MiB였으나 실행 중의 다른 작업 구성이 달라 변화량 전체를 코드의 효과로 환산하지 않는다. [이전 유휴 시험](192_윈도우_힙과_유휴회수_검증.md)

유휴 반복에 사용한 서비스 사본과 제품의 264개 소스는 줄바꿈을 정규화해 일치했고, 변경한 프로젝트 저장소 소스는 실제 바이트와 SHA256이 일치했다. 별도의 현행 Release에서 같은 서비스로 통합 전환 한 회, 100만 삼각형과 103040개 축소, 선택과 맞춤 시 원본 복귀를 확인했다. [실행 기록](199_대형프로젝트_검증재사용과_유휴회수_실행기록.json)
