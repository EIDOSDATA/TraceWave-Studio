# Windows 복소 부하와 외부 정합 검증

2026-11-21 KST. Windows 11 wxMSW Release와 고정 Python 네트워크 엔진을 사용했다. [정합 입력과 결합 시안](../04_화면설계/13_전체화면목록.json)에 맞춰 부하 자료, 두 기준면과 회로 결과를 연결했다.

- 명시 CSV 열의 25 + j25 ohm 부하, 50 ohm 실수 Z0와 직렬 25 ohm의 작은 회로를 독립 임피던스 및 전력식과 대조했다. 부하 단독의 수용 비율은 4/5다. 결합 입력에서는 반사 1/17, 부하 수용 8/17, 이상 회로 소산 8/17이 나왔다. 능동 부하에서는 유효한 복소 반사와 소산 미평가를 유지했다.
- 실제 Windows에서 저장한 S 자료를 Z로 변환한 뒤 다시 외부 RLC의 부하로 열었다. 정합 전 S11과 결합 S11, 안테나 쪽 부하와 회로 입력의 기준면, 입사전력 대비 회로 손실을 확인했다. 원본과 변환 확인, 결합 후보 취소 및 기존 결과의 재열기를 확인했다.
- 정합 결과를 평가한 목표는 당시 목표 개정, 회로 ID, 원본 부하, 두 기준면과 봉인된 소산 진단을 보존했다. 서비스 재시작 뒤 같은 평가와 CSV 원문을 대조했다. 정확한 요구 표본의 판정, 연속 대역, 실제 제작과 측정의 미평가를 화면과 기록에서 구분했다.

네트워크 서비스 및 수치 회귀 79개(197.958초), Windows GUI 1개(48.797초), Release CTest 13개가 통과했다. [GUI 시험](../../Code/tests/test_gui_network_process.py), [독립 서비스 시험](../../Code/tests/test_network_service.py), [계산 계약](../05_기능설계/04_해석결과/06_공통복소자료와_회로평가.md)
