# Windows Studio의 F6 패널 이동 검증

2026-11-21 KST. 완료 계획 12번 UX에서 실제 Windows Studio의 단축키 바인딩을 재검증했다. 테스트는 프레임이 처리하는 wxEVT_CHAR_HOOK에 F6과 Shift+F6을 전달한다. 프로젝트 트리부터 가운데 작업 영역으로 이동하고, 역방향에서 프로젝트 트리로 돌아오는 포커스를 확인했다.

같은 시험에서 탐색/속성 패널 표시, 넓고 좁은 배치 전환과 작업 초안 유지, 2D 형상 편집, 저장 및 서비스 재시작 후 재열기를 확인했다. Windows GUI 통합 시험 1개, CTest 13개를 통과했다.

키 이벤트는 앱의 Windows 테스트 드라이버가 보냈다. 전체 키보드 조작, 실제 입력기 조합 중 Enter, 스크린리더와 고대비 수용은 남는다. [사용성 검수 표](../04_화면설계/06_사용성과_접근성.md)
