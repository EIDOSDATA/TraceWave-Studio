# Windows R1 검토 후보의 ZIP 재현과 새 경로 수신

2026-11-22 KST. 소스 개정 54b3c081dc8d94bea3e9820ab1909c9ac5c9d2f8와 Windows Release EXE를 고정했다. 표 캐시 시험을 제외하고 복원한 트리에서 다시 링크한 EXE의 SHA-256은 수신 시험에 사용한 EXE와 동일한 018ceb3f49bbc5f35a772e1f34af960240efc80d44754d8c3e58766e880c8024다. CTest 13개가 통과했다.

TraceWave-Studio-internal-windows-x64-54b3c08.zip은 manifest 외 파일 994개와 총 14577076바이트다. 같은 소스, EXE, DLL, 고지, 압축기에서 새 이름으로 두 번 생성한 ZIP이 바이트 단위로 같았다. SHA-256은 6d8a9d53a0f44e1ad02e35ce81961416d7829e2e17f531d2534c9d42fc327a61이다. 묶음 단위 시험 3개를 통과했다.

현재 Windows에서 새 압축 해제 경로, 한글 작업 경로, CPython 3.12.10의 pip 없는 신규 venv와 기본 Windows PATH로 실행했다. 편집, 스냅샷, 저장 후 별도 서비스 세션의 동일 개정 재열기를 확인했다. 이어 수신본 GUI와 Python에서 기존에 고정한 CAD, 도면 환경 및 WSL2를 연결했다. 실제 STEP 표시/취소, PDF 및 재검수, 원형/원호 PCB 해석·취소·재열기의 3개가 135.227초에 통과했다.
