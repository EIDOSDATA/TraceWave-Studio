# 해석 영역의 면별 경계 조건 검증

검증일 2026-11-23

해석 전 검토의 조건 입력에서 X, Y, Z의 끝면마다 PML_8, MUR, PEC 또는 PMC를 선택한다. 저장 조건과 해석 계획이 면별 설정을 보존한다. 격자에서는 PML을 설정한 면의 안쪽 위치를 표시하고 그 외 면은 실제 외곽 위치를 표시한다. 지정한 공기 여유와 격자선을 유지한다.

- 원호와 IFA에서 설정의 저장 및 재열기, Windows 미리보기와 WSL2 openEMS 입력 XML의 면별 값, 격자선과 흡수층 수가 일치했다.
- 원호의 X 최소 면을 MUR로 선택한 실제 해석이 완료됐다. 결과 ID는 fef7ad64-5827-4de1-933e-7493329eb0eb다.
- IFA의 혼합 조건 MUR, PML_8, PEC, PMC, PML_8, MUR로 실제 준비까지 완료했다. 입력 XML에서 여섯 면의 순서를 확인했다. 임의 주기 문자열과 혼합 경계를 포함한 방사 및 손실 수지 설정은 검토에서 차단했다. Windows 회귀 44개와 CTest 14개가 통과했다.

PEC와 PMC는 영역 외벽에 적용한다. 대칭 축소 모델이나 주기 경계를 구성하는 기능과 혼합 경계에서의 NF2FF 및 전력 수지 검증은 이어서 진행한다. 체크포인트 재개는 고정 엔진이 격자, 장, 경계 내부 상태와 누적 기록을 함께 저장하고 복원하는 실행 계약과 연속/재개 결과 대조가 필요하다. 현재 중단한 실행은 봉인된 입력으로 처음부터 다시 실행한다. [openEMS 경계 계약](https://docs.openems.de/en/stable/concepts/bc.html)
