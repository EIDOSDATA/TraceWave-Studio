# 대형 설계 원본 저장 검증

2026-11-21 KST. 완료 계획 12번 F1의 형상 10000개와 매개변수 1000개를 지원하기 위해 정규 개정과 스냅샷의 파일 예산을 24 MiB로 확장했다. 형상 외 설계 객체는 기존 256개 예산을 사용한다. 상태 저널과 일반 artifact는 기존 8 MiB, 단일 RPC 프레임은 1 MiB다.

기존 프로젝트 스키마와 정규 JSON, UUID, SHA256 및 게시 절차를 그대로 사용한다. 열기 요청에서 summary를 지정하면 프로젝트와 개정 식별 정보, 해시 및 저장 개정만 포함한 결과를 반환한다. 기존 인라인 응답은 512 KiB까지 지원한다. 새 한도를 사용하는 자료는 summary 열기와 페이지 표시 계약을 사용한다. 보존 ZIP의 전체 8 MiB 예산은 별도다.

네 도체층에 선과 원호를 배치한 9,175,971 bytes 시험 프로젝트를 저장했다. 사용자 지정 이름과 이름 미정, 도체와 치수 출처, Df 미정값을 포함했다. 공개 저장·열기 작업과 작업 영역 재시작 후 구조 전부가 원본과 같았고, 스냅샷과 개정 파일의 정규 바이트를 대조했다. 매개변수 1000개 참조 사슬의 재계산과 순환 거절, 저장/도메인/저널/RPC/보존 묶음 회귀 93개를 통과했다.

이 단계는 서비스 저장·스냅샷과 열기 영수증을 다룬다. Studio의 페이지 표시와 Windows 화면 계측은 후속 기록에 연결한다.
