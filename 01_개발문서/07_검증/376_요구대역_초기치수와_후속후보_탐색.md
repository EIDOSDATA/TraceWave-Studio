# 요구 대역의 초기 치수와 후속 후보 탐색

2026-11-23 KST. Windows 개발 PC에서 요구 조건으로 치수를 만들고 보존한 후보 평가에서 다음 연구를 생성했다.

## 원호와 IFA 초기 형상

템플릿 후보 화면에서 설계 목표 하나를 선택하고 목표 기반 초기 치수를 켠다. 목표에 저장한 기준 주파수를 사용하며, 기준이 비어 있으면 대역 양 끝의 중간 주파수를 쓴다. 원호는 급전 접속점에서 개방단까지의 길이를 자유 공간 1/4 파장으로 놓고 실제 전개각의 절댓값으로 나누어 반경을 얻는다. IFA는 접지 상단부터 단락 가지를 거쳐 우측 개방단에 이르는 총 경로로부터 수평 방사 가지 길이를 구한다. 사용자가 지정한 선폭, 급전과 단락 위치는 보존한다.

추정 수량에는 계산 근거, 설계 목표 ID와 목표 개정이 붙는다. 검토 후 적용하고 재열기한 뒤 원래 요청과 당시 목표로 수량을 재구성했다. 목표 누락, 기하 조건을 만족하지 못하는 입력, 재료와 급전 조건은 기존 검토 경로에서 확인한다. 이 값은 초기 기하 추정이다. 목표 대역에서의 정합과 방사 판정에는 별도의 계산이 필요하다.

## 완료 연구에서 반복 탐색

연구의 목표별 후보 순위에서 '목표 기반 반복 탐색'을 연다. 횟수, 목표 통과 시 종료, 이전 후속 연구 재개 여부를 정하고 시작한다. 창을 닫으면 실행을 접수한 연구는 유지하고 다음 회차 자동 시작을 멈춘다. 명령행에서도 같은 입력 개정에서 계산을 마친 목표 연구를 고를 수 있다. 다음 명령은 순위와 이웃 후보의 봉인 평가를 읽어 다음 구간을 선택한다. 각 회차에서 양 끝과 중점 세 후보를 실제로 계산한다. PCB 연구에는 설치한 WSL2 openEMS를 사용한다.

~~~powershell
python -m rfad sweep-refine --workspace WORKSPACE --project PROJECT_ID --study STUDY_ID --rounds 2 --openems-wsl --startup-seconds 240
~~~

- 원본 연구, 부모 연구, 선택 축, 중점, 두 평가 SHA-256과 후속 연구 ID를 보존한다. 원본 연구에 선언한 자원 상한으로 후속 탐색 전체의 후보 수, 계산 횟수, 디스크 사용량과 경과 시간을 제한한다. 이미 끝난 원본 연구의 비용은 자체 기록에 있다.
- 같은 입력과 동일한 탐색 횟수로 다시 실행하면 기존 후속 연구를 조회한다. 중단한 후속 연구는 원본과 환경을 확인한 뒤 같은 명령에 `--resume`을 붙여 재개한다. `--until-target`을 지정하면 봉인한 후보 하나가 선택 목표의 모든 표본을 통과했을 때 멈춘다.
- 회로 연구에서 두 번의 후속 계산이 서로 다른 중점을 선택했고, 같은 명령을 다시 실행한 뒤 연구 수와 원본이 같았다. 원본 후보가 이미 모든 목표 표본을 통과한 경우 후속 연구를 생성하지 않았다. 독립 작업 공간에서 목표 템플릿 시험 18건과 회로의 실제 후속 계산 및 재실행 시험을 통과했다.

## 공정 표본

후보 순위의 공차 검토에서 현재 연구 변수 UUID와 단위로 CSV 양식을 저장한다. `sample_id`에는 시료 번호, 변수 열에는 같은 시료에서 관측한 값, 선택 열 `observed`에는 전체 목표의 실제 검사 결과인 `pass` 또는 `fail`을 넣는다. 검사 전 시료는 빈칸으로 둔다. 출처와 원문 SHA-256, 모델과 실제 판정 수, 두 결과의 일치 및 불일치 건수를 별도로 기록한다.

계산점과 대응하지 않는 시료와 RF 평가가 누락된 시료는 모델 판정에서 미확인으로 센다. 외삽과 근접 후보 대입은 하지 않는다. 동일 단위 변환의 부동소수점 차이 1 ULP 이내에서 단 하나의 계산점과 일치해야 한다. 독립 무작위 표집을 명시하고 모든 시료의 실물 판정이 있는 경우 실제 검사 통과율의 양측 95% Wilson 구간을 계산한다.

실제 제조 로트에서 동일 시료 ID로 연결한 공정 치수와 검사 결과 자료는 제공되지 않았다. 모델 판정과 실물 판정의 관계 및 실제 생산 수율 검증은 해당 자료 확보 후 수행한다.

### 합성 시료 독립 계산

두 저항을 동시에 지정한 네 시료 중 두 개는 모델 통과, 한 개는 모델 실패였고 한 개는 계산 격자 밖이었다. 입력한 가상 검사 결과 두 개 통과와 두 개 실패의 95% Wilson 구간은 0.1500389892~0.8499610108이다. 시료 번호 중복, 축 단위 오류, 비유한 값과 잘못된 열 이름을 거절한다. 실제 판정 하나를 비워 두면 표집 구간을 산출하지 않는다.

### IFA 운전 한도와 중단 처리

실제 IFA의 원본 세 후보 다음에 30.5 mm를 선택한 첫 후속 회차의 세 계산을 완료했다. 같은 평가에서 30.25 mm를 선택한 두 번째 회차는 WSL 시작 작업자가 native 계산 이전에 종료되었다. 명시적으로 재개한 뒤 후속 전체의 1300초 예산에 도달해 정지했다. 완료된 원본과 첫 회차, 중단한 시도 및 각 평가 해시가 그대로 남았다.
