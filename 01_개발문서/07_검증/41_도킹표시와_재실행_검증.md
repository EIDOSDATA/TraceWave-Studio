# 도킹 표시와 재실행 검증

2026-11-20 KST. 완료 계획 12번에서 넓은 창과 좁은 창의 [패널 표시 계약](../04_화면설계/08_스튜디오_화면계약.md)을 실제 Windows Studio로 검증했다.

## 재현과 수정

기존 배포본에서 넓은 창의 오른쪽 속성 패널을 닫은 뒤 좁은 창의 탐색/속성 공용 패널을 닫았다. 다시 넓히면 원래 열려 있던 왼쪽 탐색 패널까지 없어졌다. [변경 전 화면](02_실행화면/92_넓은보기_탐색패널소실_재현.jpg)

넓은 보기의 탐색/속성과 좁은 보기의 공용 탐색/속성 표시 선택을 분리했다. 보기 메뉴와 닫기 버튼에서 사용자가 변경한 상태는 Windows 사용자 설정에 저장하고, 선택한 객체를 보여 주기 위한 임시 열기와 작업 탭의 표시 전환은 화면에만 반영한다. 레이어와 하단 패널의 명시적 표시 선택도 같은 설정에서 관리한다.

## 실제 Windows 경로

1. 오른쪽 속성만 닫고 시스템 창 크기 메뉴로 폭을 줄였다. 좁은 창에서는 탐색과 속성이 같은 패널의 두 탭으로 표시됐다. [좁은 보기](02_실행화면/93_좁은보기_탐색속성_공용탭.jpg)
2. 좁은 창의 공용 패널을 닫고 최대화했다. 왼쪽 탐색이 돌아왔고 오른쪽 속성은 닫혀 있었다. [넓은 보기 복귀](02_실행화면/94_넓은보기_탐색복귀와_속성숨김.jpg)
3. 종료 후 같은 프로젝트를 재열기했다. 넓은 보기의 속성 숨김과 좁은 보기의 공용 패널 숨김을 각각 확인했다. [넓은 보기 재실행](02_실행화면/95_스튜디오_재실행_패널숨김.jpg), [좁은 보기 재실행](02_실행화면/96_좁은보기_재실행_공용패널숨김.jpg)
4. 좁은 창에서 보기 메뉴의 기본 패널 배치 복원을 실행했다. 두 탭이 돌아왔고 넓은 창에서도 기본 탐색과 속성이 돌아왔다. 다시 실행해 기본 배치와 저장된 형상을 확인했다. [기본 배치 복원](02_실행화면/97_스튜디오_기본배치_복원.jpg)

Windows 실제 GUI와 서비스의 2D 편집 회귀는 넓은/좁은 배치 전환, F6/Shift+F6 초점, 미적용 한글 속성 초안의 보존, 편집/저장/재열기를 통과했다. 전체 Windows GUI 회귀 7개와 CTest 13개도 통과했다. 수동 검증으로 재열기한 프로젝트의 파일 8개는 전후 SHA256이 일치했다. [실행 기록](42_도킹표시와_재실행_실행기록.json)

이번 변경의 저장 범위는 패널 표시 선택이다. sash 크기, floating 창 좌표, 다중 모니터/DPI 복구 및 합격 성능 수치는 후속 검증 범위다.
