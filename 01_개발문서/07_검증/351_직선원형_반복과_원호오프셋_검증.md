# 직선·원형 반복과 원호 오프셋 검증

2026-11-23 / Windows 개발 PC / 채택 항목 CAD10, CAD12

## 구현과 확인

- 정밀 편집에서 직선 피치 X/Y 또는 원형 중심·각도와 원본을 포함한 개수를 입력한다. 미리보기는 새로 생성되는 형상만 표시한다. 확정은 한 개정이며 실행 취소·다시 실행도 한 번으로 처리한다. 결과 객체 수는 16개까지 허용한다.
- 원호 중심선의 signed 오프셋은 반경에 적용한다. 중심, 시작각, 회전각, 폭, 층과 기존 출처를 보존한다. 급전이나 명시 연결에서 사용하는 원호, 매개변수에 묶인 반경, 중복 원형 배치는 편집 전 검토에서 제한한다.
- 원호 중심 (10, 12) mm의 두 직선 복사 위치는 (14, 11), (18, 10) mm였다. 중심 (5, 5) mm 주위 90도 회전으로 선분 시작점 (1, 2) mm가 (8, 1) mm가 됐다. 원호 반경 20 mm에 +2 mm를 적용하고 저장·재열기해 반경 22 mm와 나머지 속성을 대조했다.
- IFA의 방사 도체를 복제하고 원본 도체, 급전, 기대 연결을 값 단위로 비교했다. PTH는 비아만 선택한 후보를 차단하고, 양쪽 패드를 함께 복사해 새 비아의 패드 ID를 복사된 객체에 연결했다. 원본의 패드 ID와 도금 두께는 그대로였다.
- Windows Python 정밀 편집·스케치 회귀 27건, Windows Release 빌드 및 CTest 14건을 실행했다.

## 남은 범위

패턴은 확정 개정에 독립 형상으로 저장한다. 피치 변경 후 재생성, 일반 곡선 트림과 필렛, 규칙 기반 배선·구리면 재채움은 이어서 구현한다. 사용한 도체와 PTH는 명시 설계 검증 입력이며 실제 제작 조건은 미정이다.
