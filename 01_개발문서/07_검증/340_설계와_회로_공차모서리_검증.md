# 설계와 회로의 공차 모서리 검증

검증일 2026-11-23

설계 매개변수 또는 회로 소자 축에 오름차순 최소·공칭·최대값을 지정하고 카테시안으로 연구를 실행한다. 목표별 후보 순위에서 공차 모서리 비교를 켜면 공칭점과 각 축의 최소 및 최대 조합을 구분한다. 각 목표에서 확인한 표본의 통과율을 비교한다. 어느 모서리라도 계산이 없거나 평가가 미완료이면 전체 모서리 최저값은 미정이다. 입력과 봉인한 후보 평가를 읽는 기능이며 새 계산을 접수하거나 기존 결과를 변경하지 않는다. 공정 분포나 상관관계에 따른 수율은 별도 범위다.

실제 직렬 저항 연구에서 최소 10 ohm, 공칭 20 ohm, 최대 50 ohm으로 확인했다. 엄격한 목표는 공칭 통과율 1이고 최대 저항 모서리에서 0이었으며 완화 목표는 공칭과 두 모서리 모두 1이었다. 실행 전에는 두 모서리를 누락으로 표시하고 최저값을 미정으로 유지했다. 임의 4값 연구는 공차 모서리 보고에서 거부했다. Windows 회귀 시험 24개와 CTest 14개가 통과했다.

두 축의 산술 검증에서 카테시안 9개 중 공칭 순번 4와 모서리 순번 0, 2, 6, 8을 확인했다. 하나를 누락시키면 확인한 세 모서리의 최저값과 전체 모서리의 미확정 상태를 구분했다.

원호의 방사 패턴 선폭 1.0, 1.05, 1.1 mm를 실제 WSL openEMS에서 각각 해석했다. 공칭과 두 모서리 표본의 S11 -6 dB 목표 통과율은 모두 0이었다. 후보 3개가 완료됐고, 공차 조회 전후 원래 설계와 작업 기록이 같았다.

Windows 연구 화면의 회로 스윕, 취소 및 재개, 저장 및 재열기 검증도 통과했다.

IFA에서 같은 선폭 목록을 사용한 시험은 1.0 mm 후보를 완료했다. 1.05 mm 공칭 후보는 최소 XY 셀이 0.5 mm에서 0.025 mm로 줄었고, 실행 시간 한도에서 해석 종료를 확인했다. 최대값 후보는 대기 상태로 보존됐다. 공칭 및 전체 모서리 최저값은 미정으로 유지한다.
