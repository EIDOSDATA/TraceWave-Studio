# 27. 측정 기록과 정렬 비교 검증

2026-11-20 KST. 완료 계획 11번의 Windows Studio와 프로젝트 서비스에서 합성 자료로 원문, 기록, 정렬과 보고서의 경계를 확인했다. 실제 VNA/OTA, 납품 시료, 교정 성적서와 독립 물리 검증은 미확립이다. [서비스 계약](../05_기능설계/04_해석결과/09_측정기록과_정렬비교.md) / [화면 계약](../04_화면설계/26_측정기록과_정렬비교_화면.md)

## 실제 Windows 저장과 재열기

한 개의 합성 기준 자료가 들어 있는 독립 프로젝트에서 합성 Touchstone S1P를 선택했다. 시료와 교정 탭에서 `합성 시험 자료`와 이름, 작성 이유를 명시하고 나머지 조건은 미정으로 뒀다. 검토 탭의 실제 1~2 GHz 곡선과 기록의 미정 표시를 확인하고 원문과 기록을 한 명령으로 적용했다. [시료와 교정](02_실행화면/62_시료와_교정_미정.jpg) / [적용 전 검토](02_실행화면/63_측정자료_가져오기검토.jpg)

기준 기록과 가져온 기록을 선택하고 1포트 대응을 명시했다. 두 곡선을 함께 표시했으며 한쪽 파 정의와 기준면이 미정인 경우 수학적 차이를 만들지 않았다. 표본 3개와 조건 60개의 당시 참조가 들어 있는 비교 보고서를 저장했다. 1648 x 954 창에서는 그래프와 차이 표를 한 화면에 모두 보기 위해 세로 스크롤이 필요했다. 화면 크기별 배치 수용은 12번에서 다룬다. [실제 비교 상태](02_실행화면/64_측정비교와_조건미정.jpg)

`저장됨`을 확인한 뒤 GUI를 종료하고 별도 서비스에서 저장한 개정을 읽었다. 저장 포인터와 현재 포인터, 원문 파일 SHA-256, 기판/도체/급전/물성/목표, 기존 출처를 대조했다. 두 기록과 비교 보고서가 보존됐고 새 원문의 교정 방식은 미정, 기존 기록의 IFBW는 10000 Hz로 확인됐다. 실제 저장된 합성 S1P의 SHA-256은 `b6d2932a948a0142bd316dbfeb6801be330377cfd753f538bc80688960211a70`이다.

새 실행 파일로 프로젝트를 다시 열어 저장된 보고서의 주파수 1/1.5/2 GHz와 수치 미정, 당시 조건 첫 페이지를 확인했다. 기존 비교는 다시 계산하지 않고 저장된 보고서에서 조회했다. [재열기한 보고서](02_실행화면/65_저장후_당시측정보고서.jpg) / [과거 교정 조건](02_실행화면/66_재열기_교정조건비교.jpg)

같은 창에서 합성 기준 자료의 1포트 순열을 검토해 파생 결과를 저장했다. 재정규화와 RI 보간의 수치 검증은 서비스 시험에서 수행했다. 적용 직후 같은 화면에서 수동 새로고침 없이 새 정렬 이력이 나타났고, 보존 곡선과 포트 순열 단계를 열었다. [정렬 후보](02_실행화면/67_명시정렬_후보검토.jpg) / [목록 자동 갱신](02_실행화면/68_정렬후_이력자동갱신.jpg) / [포트 순열 이력](02_실행화면/69_보존정렬_포트계보.jpg)

## 확인한 기능과 제한

- 일반 가져오기와 시료 기록을 함께 저장하는 가져오기, 단일 undo/redo, 원문/정규 HDF5/측정 기록 보존, 512 KiB의 첨부 원문을 확인했다.
- 과거 기록의 원래 개정과 hash를 확인했다. 현재 기하 편집이나 현재 목록 제거 후에도 과거 기록이 처음 고정한 원본을 조회한다.
- 포트 양축 순열, 양의 실수 Z0 재정규화, 실제 주파수의 RI 보간과 결측/외삽 차단, 1001개 표본에서 전체 비교와 과거 조회를 검사했다.
- 소스 로더가 GUI의 `python -m rfad serve` 실행을 지원하도록 보완했다. 새 프로세스에서 capabilities 응답과 과거 프로젝트의 재열기를 확인했다.
- 고급 fixture 보정과 불확도 전파, 실제 케이블/배터리/케이스와 OTA 비교 정확도는 별도 범위다. RO4350B 개별 손실 2.788446%의 초기 2% 기준과 GHz PTH 물리 정확도는 계속 미확립이다.

서비스 113개 수집 중 112개 통과, 실제 WSL 1개 환경 제외다. 보고서 검토 표본 요약과 보존 계보 페이지를 보강한 뒤 측정/실행 경계 집중 시험 23개가 통과했다. 별도 NDJSON/RPC와 source 묶음 시험은 31개 중 29개가 통과하고 외부 CAD 환경 2개를 제외했다. Windows의 기존 복소 자료/다중 결과/스윕 및 조건 페이지 시험 4개가 통과했다. Native CTest, 감사, 링크 검사와 실행 시점별 소스/바이너리/화면 hash는 실행 기록에 정리한다. [기계 판독 실행 기록](28_측정기록과_정렬비교_실행기록.json)
