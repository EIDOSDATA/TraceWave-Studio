## 키보드, 저장과 교환

- 실제 Windows 창에서 격리 프로젝트 설명에 한글 문구를 넣고 Tab, Enter와 Ctrl+S를 사용했다. 원문 설명과 저장 표시를 새 Studio 창의 재열기와 서비스에서 각각 확인했다. 보드, 도체, 물성, 적층, 포트, 목표와 기존 제조 프로필은 그대로였다. Windows 자동 입력 도구가 한/영 전용 키를 전달하지 못해 두벌식 IME 조합은 미평가다.
- Windows GUI/프로세스 18개가 161.498초에 통과했다. 손상 차단 후 별도 본 복원, 저장 전 디스크 부족 및 예약 거절 뒤 재시도, writer 충돌, 프로토콜 종료, 명시/미정 급전, 원본을 보존한 후보 사본, 서비스 재열기를 대조했다.
- 저널, 복구용 편집 ZIP, 실제 서비스 프로세스 종료 후 재생, MCP, 소스 묶음 46개가 97.501초에 통과했다. MCP stdio 시험의 스크립트 위치를 시험 파일에 고정해 저장소 루트와 Code 양쪽에서 실행한다. 실제 KiCad 10.0.8과 공식 MCP SDK를 사용한 별도 보드 수신/재수입 1개가 26.916초에 통과했다.
- Release 빌드의 CTest 13개가 0.69초에 통과했다. 같은 개정에 결합한 EDA 손실 및 독립 리더 범위는 10번 결과를 적용한다. [도면과 STEP/CAM 수신](270_독립스텝과_동일개정_도면캠_검증.md)
