# 복소 대역 시간 게이트 검증

검증일 2026-11-23

네트워크 변환의 S 시간 게이트에서 남길 지연 구간을 ns로 지정한다. 균일한 복소 S 표본 4개 이상과 명시 파, 기준면과 위상 규약을 요구한다. 포트마다 양의 실수 기준 임피던스가 주파수 전역에서 일정해야 한다. 네트워크의 모든 복소 채널에 같은 구간을 적용한다. 시간 간격은 주파수 간격과 표본 수의 곱의 역수이며, 주기는 주파수 간격의 역수다. [NumPy DFT 정의](https://numpy.org/doc/stable/reference/routines.fft.html)

게이트를 적용한 응답은 같은 주파수 축 및 기준면과 함께 별도 자료에 저장한다. 계산에는 유한 대역의 복소 포락선을 사용한다. 비균일 주파수, 누락 표본, 범위 밖 지연은 거부한다. 임의 DC 보간, 공백 표본 채우기, 전파 속도에 따른 거리 환산은 사용하지 않는다. 검토와 저장된 진단에 주기, 시간 간격 및 유지한 지연 표본을 남긴다.

- 독립적으로 합성한 0, 2, 3 ns의 복소 응답을 125 MHz 간격의 표본 8개로 가져왔다. 1.6~2.4 ns 구간으로 두 위상 규약에서 2 ns 성분만 복원했다. 독립 지연식과 소수점 이하 12자리에서 일치했다. 비균일 입력을 거절하고 원본과 HDF5 결과를 저장 및 재열기했다.
- 실제 Windows/WSL openEMS 원호 31점과 IFA 51점의 봉인 결과를 Windows 계산 작업자에 전달했다. 직접 복소 합으로 구한 같은 지연 표본 대비 최대 복소 오차는 각각 1.56e-16과 4.20e-17 이하였다. 지연 격자 간격은 각각 0.241935 ns와 11.7412 ns였다. 원래 결과 바이트와 현재 설계는 그대로 읽혔다.
- Windows GUI에서 시작과 끝을 명시해야 검토가 열리는 것을 확인했다. 복소 자료 및 PCB/CAM GUI 회귀 2개와 CTest 14개가 통과했다.
- 유한 대역과 반복 시간 주기가 결과를 제한한다. 실제 치구, 전자기 파형, 전력 수지나 제작 성능을 이 비교로 판정하지 않는다.
