# 도체 교차점 트림과 필렛 검증

2026-11-23 / Windows 개발 PC / CAD09

- 같은 좌표계와 층의 두 선 또는 원호를 고르고 자를 도체와 남길 끝을 지정한다. 잘리는 끝에서 가장 가까운 내부 교차점을 사용한다. 남는 호의 중심, 반경, 방향과 폭, 절삭 경계의 ID·값을 보존한다.
- 공통 끝점, 같은 폭과 같은 도체 의미를 가진 두 직선은 지정 반경에 접하는 원호를 만든다. 두 직선의 ID 및 먼 쪽 끝을 보존하며 한 번에 적용하거나 실행 취소한다. 접점이 선 범위를 벗어나거나 급전·기대 연결을 수정해야 하는 입력은 차단한다. 보존한 스케치 관계는 기존 검증을 거친다.
- 반경 5 mm의 시계 방향 원호를 X=13 mm 직선으로 잘랐다. 두 교차점 중 남길 끝에 맞는 위치와 원호 각도를 독립 삼각함수로 대조했다. 직선을 자르는 반대 사례에서 시작점 Y=8 mm와 고정 끝점을 확인했다. 재열기 후 동일 형상을 읽었다.
- (10, 8) mm의 직각 모서리에 반경 2 mm 필렛을 적용해 두 접점 (8, 8), (10, 10) mm 및 원호 중심 (8, 10) mm를 확인했다. 초과 반경 차단과 실행 취소·다시 실행에 통과했다.

Windows 정밀 편집·스케치·곡선 회귀 38건과 Windows Release CTest 14건을 실행했다. 곡선이 포함된 필렛, 모따기 및 급전이나 기대 연결에 대한 재연결은 후속 범위다.
