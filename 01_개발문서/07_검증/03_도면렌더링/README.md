# 실제 PDF 산출물 렌더링

완료 계획 10번의 별도 출력 worker가 생성한 실제 PDF 페이지를 Poppler `pdftoppm -png -r 110`으로 렌더링한 증거다. 화면 시안이나 GUI 캡처가 아니다. 생성한 PNG의 글자, 형상, 축척을 다시 합성하거나 보정하지 않았다.

2026-11-17 최종 적층 주석 보완 이후 IFA/원호 PDF 2출력과 2개 별도 재검수를 실행했다. 원본은 9번의 명시 개발 시험 사본이며 -10 dB 미달, 가정 물성과 제작/측정 미정 조건을 유지한다. [검증 기록](../23_연관도면과_스텝재검수_검증.md)에 실행 시점과 독립 수신 검수 미수행 범위를 구분한다.

| 파일 | 내용 |
| --- | --- |
| [IFA 평면도](01_아이에프에이_평면도.png) | 방사 도체 24 mm, 접지 도체 면의 구멍, 실제 1:1 도면과 원본 연관 수치 |
| [IFA 적층 단면](02_아이에프에이_적층단면.png) | Y=30 mm의 실제 X-Z 단면. 도체가 없는 하부 층을 채우지 않고 두께를 과장하지 않음 |
| [원호 평면도](03_원호_평면도.png) | 중심선 R5.5 mm의 시험 원호, 실제 원본 급전과 연관 수치 |
| [원호 적층 단면](04_원호_적층단면.png) | 같은 원본의 X-Z 단면과 값/단위를 같은 행에 보존한 주석 |

PNG의 표시 크기는 종이의 실제 인쇄 축척 검수를 대신하지 않는다. 실제 PDF의 pt/mm 좌표는 별도 parser에서 검사한다. 이 예제의 도체 면 구멍은 보드 재료를 제거하는 NPTH/cutout이 아니다.
