# 저장본 비교와 프로젝트 속성 가독성 검증

2026-11-22 KST. Windows Release와 동일한 제품 객체 파일을 사용한 GUI 검수 빌드에서 저장본 비교 M16과 프로젝트 속성 배치를 확인했다.

| 사례 | 확인한 내용 |
| --- | --- |
| 저장본과 영속 적용 개정 | 파일 메뉴에서 개수가 같은 두 개정을 비교했다. 변경 목록에서 한글 설명의 이전값과 현재값, 같은 도체의 폭 1 mm와 1.2 mm를 확인했다. 변경 행을 선택하면 읽기 전용 상세에서 값을 다시 표시한다. |
| 추가와 삭제 | 같은 개수라도 다른 안정 객체 ID는 추가·삭제로 나타난다. 서비스 시험에서 데이터 조회 전후 journal이 같은지 확인했다. |
| 프로젝트 속성 | Windows 150% 배율의 원호 사본에서 제목, 이름, 설명을 캡처했다. 이름과 설명의 레이블을 필드 위에 배치해 가로 폭을 확보했다. 더 긴 한글 이름을 입력해 자동 줄바꿈을 확인하고 원래 이름으로 되돌렸다. |
| 편집 회귀 | 실제 Windows의 서비스 재시작과 한글 경로 저장, 속성 편집 오류와 이력 시험 2개 및 CTest 13개를 통과했다. |

저장본 비교는 현재 편집기에 적용하기 전인 초안과 영속 적용 개정을 구분한다. 속성 값은 최대 96행과 128 KiB 범위로 읽으며 추가 변경이 있음을 안내한다. [프로젝트 명령과 저장 계약](../05_기능설계/01_프로젝트/01_프로젝트_명령과_저장.md), [개발 순서](../09_개발계획/15_기능채택과_개발검증_순서.md)

최종 Windows Release 실행 파일의 SHA-256은 F8EBF2BB767F7C007A7C3774B232B184E3478C80049752B622AFA279DEB34918이다. 원호·IFA의 격자 검토 및 실제 준비 입력 대조는 [Windows 해석 전 검토](315_윈도우_해석전검토와_실제격자_검증.md)를 따른다.
