# Windows 대형 3D 합성 계측 진단과 통합 회귀

2026-11-21 KST. 편집 우선 시작과 취소 지연 개선을 반영한 Windows Release에서 전체 Studio 도킹과 100만 삼각형 모델의 3D를 실행했다. Intel Iris Xe와 내장 120 Hz 패널은 그대로 두고 Windows 데스크톱 모드와 배율을 바꿨다.

| 데스크톱 | 시험 창 전경 활성화 | DXGI 열림 | 데스크톱 갱신 | 보호 처리 | 표식 판독 |
| --- | --- | --- | ---: | ---: | ---: |
| 1920 x 1080, 100% | 별도 활성화 없이 실행 | 아니오 | 0 | 0 | 0 |
| 1920 x 1080, 100% | Studio 창 활성화 | 예 | 958 | 958 | 0 |
| 2560 x 1600, 150% | Studio 창 활성화 | 예 | 1160 | 1160 | 0 |

DXGI Desktop Duplication의 보호 플래그와 표식 판독 수를 실패 진단에 추가했다. Windows가 보호 플래그를 준 갱신에서는 픽셀 사본을 읽지 않는다. 전경에서 계측기 연결 후 실제 갱신이 왔지만 모든 표본이 보호 처리되어 이 실행의 합성 간격은 미확립이다. 보호 플래그의 원인까지 특정할 수 없다. 앞서 2560 x 1600에서 확보한 35초 합성 간격 p95 18.09 ms는 당시 조건의 기록으로 유지한다. [기존 합성 계측](146_스튜디오_대형_삼차원_합성과_표시_품질_검증.md)

1920 x 1080/100%의 별도 실제 Studio 실행에서는 전체 모델 100만 삼각형, 축소 103040개, 객체 선택·전체 맞춤·복귀 뒤 각각 100만 개를 확인했다. 시험 뒤 데스크톱을 2560 x 1600/150%로 복원했다. 기준 장비와 해상도의 실제 합성 간격에는 보호되지 않은 계측 가능 환경이 필요하다. [이전 기준 크기 시험](206_최종_윈도우_시작과_기준크기_삼차원_검증.md)

편집 우선 빌드와 두 취소 개선을 함께 켠 회귀에서 실제 WSL2 openEMS의 실행 중 취소·이전 결과 재열기, CAD 두 경우, 기술 도면과 영속 출처 확인, WSL 제어·준비, 요구 추적의 총 33개 시험이 통과했다. Release CTest 13개도 통과했다. 이 통합 회귀는 별도의 취소 지연 반복 계측에 합산하지 않는다. [실행 기록](223_윈도우_삼차원_합성진단_실행기록.json)
