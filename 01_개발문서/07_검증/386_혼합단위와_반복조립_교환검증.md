# 혼합 단위와 반복 조립의 STEP 교환 검증

2026-11-23 / Windows / Open CASCADE 7.9 / CADability 1.1.2 / CAD18

## 입력 및 재출력

STEP 설치 부품 가져오기에서 자체 포함 단일 루트의 각 형상 표현이 참조하는 길이 단위를 읽는다. mm와 inch가 한 조립 안에 함께 있으면 원문 단위를 혼합으로 표시하며 각 문맥에서 mm로 환산한다. 인치의 원문 변환 상수도 25.4 mm와 대조한다. 알 수 없는 길이 단위와 잘못된 변환 상수는 적용 전에 원문 오류로 안내한다. 단위 API가 루트의 mm만 반환하는 입력에서도 내부 고체의 인치 문맥을 조회한다. [Open CASCADE STEPControl Reader](https://dev.opencascade.org/doc/refman/html/class_s_t_e_p_control___reader.html)

같은 하위조립 정의를 반복 사용한 원본은 자식 정의와 자식의 상대 좌표를 비교한다. 자식 구성이 같으면 같은 STEP 제품 정의를 재사용한다. 특정 발생에서만 자식을 편집한 경우에는 해당 하위조립을 별도 정의로 재출력한다. 개별 부품의 발생 경로, 원래 파일 및 SHA-256은 sidecar에 기록된다.

## 검증 입력

XCAF로 한 하위조립을 만들고 같은 정의를 X 10과 110 mm 위치에 두 번 배치했다. 하위조립 안의 첫 고체에 독립 inch 문맥을 부여했다. 치수는 1 x 2 x 3 inch다. 두 번째 고체는 2 x 2 x 2 mm이고 조립의 X 40 mm에 놓인다. 하위조립과 보드 배치는 mm다. 설치 위치 Z 12 mm에서 두 번째 하위조립에 있는 작은 고체만 X 5 mm 옮긴 경우도 검증했다.

| 확인 항목 | 원본 또는 기본 출력 | 한 발생의 자식만 이동한 출력 |
| --- | --- | --- |
| 조립 발생 / 말단 발생 / 고유 말단 정의 | 7 / 4 / 2 | 7 / 4 / 2 |
| 하위조립 발생 / 고유 하위조립 정의 | 2 / 1 | 2 / 2 |
| 큰 고체 치수 | 25.4 x 50.8 x 76.2 mm | 25.4 x 50.8 x 76.2 mm |
| 작은 고체 X 하한 | 50, 150 mm | 50, 155 mm |
| 설치 부품 4개의 부피 합 | 196660.768 mm3 | 196660.768 mm3 |

STEP 재입력 후 바운딩 박스를 확인하고 원문 STEP의 NEXT_ASSEMBLY_USAGE_OCCURRENCE에 기록된 두 발생의 자식 제품 번호도 별도로 대조했다. mm로 재출력한 AP242 두 파일은 독립 CADability에서 보드와 설치물을 합쳐 각각 닫힌 고체 7개, 열린 모서리 0개였다. 해당 수신기에서 기본 출력의 큰 고체 X 범위는 10~35.4 mm와 110~135.4 mm였다. 편집 후 작은 고체의 X 범위는 155~157 mm였다. 두 출력에서 제품 이름 inch_block, mm_block도 각 위치의 원래 정의와 일치했다.

CADability 1.1.2는 같은 혼합 단위 원문을 직접 열었을 때 인치 고체를 1 x 2 x 3 mm로 읽었다. 외부 수신기에 전달한 mm 재출력을 독립 검수 결과로 기록한다. 공인 제품의 제작 형상, PMI, 외부 참조 조립, 임의 단위와 색상 전체는 이번 시험 범위 밖이다.

- 기존 부품 교체 저장/재열기와 중첩 조립 보드 내보내기는 빌드와 동시 실행 시 CAD 작업 제한 시간에 걸렸다. 같은 기본 제한과 실제 CAD 엔진으로 두 항목을 다시 실행해 114.827초에 모두 통과했다.
