# IPC-2581C 특수 드릴 원문과 회전 반복 패널

2026-11-23 KST. IPC-2581C 단일 보드 원문에서 반복 패널을 작성하고 같은 명령으로 다시 읽었다. 기존 제조 원본 파일과 보드 Step을 보존한다. 패널에는 별도 Step, Datum, 사각 Profile, StepRepeat와 첫 Content StepRef를 추가한다. 반복 행에는 원본 보드 참조와 정규 XML SHA-256, 두 축의 위치/피치, 반복 수, 회전과 반사를 기록한다. 출력의 단위는 입력 원문을 따른다. [IPC 공식 XSD](https://webstds.ipc.org/2581/IPC-2581C.xsd) [IPC 스키마 확인 범위](https://www.ipc2581.com/ipc-2581-file-validation-tool/)

지원 작성 범위는 직선으로 닫힌 한 보드의 반복이며, X/Y 피치와 0/90/180/270도 회전을 지정한다. 입력 패널 읽기는 명시한 반사 값을 보존한다. 겹치는 경계 상자, 순환/중첩/없는 Step, 남의 출력 덮어쓰기 및 유한 예산을 벗어난 결과를 진단한다.

## 재현과 외부 수신

```powershell
Set-Location Code
$env:PYTHONPATH = 'src;tests'
$python = '.local/rf-check/Scripts/python.exe'

$output = '.local/panel-6.xml'
& $python -m rfad manufacturing-panel $source --output $output --count 2 3 --pitch-mm 30 47 --margin-mm 3 --angle-deg 90

$env:RFAD_IPC2581C_XSD = (Resolve-Path '.local/rf-check/IPC-2581C.xsd').Path
& '.local/ipc-xsd/Scripts/python.exe' -m unittest -v test_ipc_panel test_manufacturing_padstack_panel
```

별도 검증 환경의 lxml과 공식 XSD는 제품 실행 의존성에 포함하지 않는다. 이 개발 PC에는 이전 사례의 KiCad 10.0.8 수신기가 없어 해당 네이티브 재출력 시험 두 건을 제외했다. 제조 공장의 수용은 대상 CAM으로 판독한 레이어 순서, 층간 드릴, 배치 및 방향의 기준값이 확보되면 확인한다. 편집된 특수 패드스택을 CAD에서 다시 생성하는 경로는 공급 변환기가 해당 표현을 보존하고 기존 패드스택 검사를 통과해야 한다. [407 비대칭 패드 게시 검증](407_층별_패드스택과_오디비_반복패널_검증.md)
