# 최신 Windows 전체 서비스와 네이티브 회귀

2026-11-21 KST. F0 편집 우선 시작과 F4 접수·종료 지연 개선을 반영한 소스로 Windows 전체 서비스 회귀를 수집했다. CPython 3.12.10에서 기본 조건으로 1443개를 실행했고 1290개 통과, 환경 제외 153개, 실패·오류 0개였다. 실행 시간은 1896.207초다. [실행 기록](231_윈도우_전체서비스와_네이티브_실행기록.json)

실제 Windows/WSL2, OCCT와 기술 도면을 포함한 통합 회귀 33개, Release CTest 13개를 별도로 통과했다. 네이티브 KiCad·격리 worker가 필요한 교환 시험 51개와 저널·GUI·인계 복구 시험 40개도 확인했다. [통합 회귀](222_윈도우_삼차원_합성진단과_통합회귀.md), [EDA](224_알티움_도금홀과_슬롯_왕복검증.md), [복구](226_윈도우_한글이름과_복구_재검증.md)

공식 MCP Python SDK 1.26.0과 실제 KiCad 10.0.8을 켠 별도 실행에서도 3개가 통과했다. KiCad가 재저장한 보드를 공식 MCP로 가져와 적용하고, 서비스를 다시 열어 원문과 공구 치수 미정값을 확인했다. 각 실행의 환경과 범위는 실행 기록에 담았다. [기존 MCP 왕복 절차](47_키캐드재저장본_엠시피왕복_검증.md)
