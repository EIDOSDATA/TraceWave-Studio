# Windows 급전 단자와 진단 선택 검증

2026-11-21 KST. Windows 11 Pro 빌드 26300, 디스플레이 배율 150%의 개발 PC에서 wxMSW Release, Python 서비스와 native OCCT/OpenGL을 사용했다. [구현 시안 S11.port.terminals](../04_화면설계/03_구현시안/75_포트단자와_연결.png)의 단자 선택과 연결 이동을 주 화면의 속성에 배치했다. 명시 gap의 작은 로컬 검증 설계와 급전 영역이 없는 구버전 형태의 설계를 사용했다.

| 확인 항목 | 실제 동작 |
| --- | --- |
| 트리, 속성과 2D | 급전과 양단의 ID 및 선택된 트리 행을 대조했다. 도체를 고르면 해당 속성과 2D 강조가 바뀌며 도체 속성에서 같은 급전으로 돌아왔다. 명시 좌표가 있는 급전의 2D 마름모를 클릭해 같은 급전 ID를 선택했다. 구버전에서는 미정 사유를 표시하고 표식을 생략했다. |
| 현재 및 이전 3D | 메시를 생성하기 전에는 비활성 사유를 표시했다. 현재 OCCT 메시에서 참조된 양단 source ID를 확인하고 기준 도체를 실제 3D 선택 처리기로 클릭했다. 편집으로 이전 개정이 된 메시에서 클릭해도 선택이 바뀌지 않았고, 3D 갱신 후 다시 열 수 있었다. |
| 진단 | 좌표와 저항이 미정인 사례에 해석 입력 검사를 실행했다. 관련 진단을 선택해 문제 목록의 행에 초점을 주고 Enter로 같은 급전 속성에 돌아왔다. 급전 개정이 바뀐 뒤 이전 진단 이동을 비활성으로 표시했다. |
| 초안과 키보드 | Windows 키 입력으로 도체 이동과 급전 복귀의 초점을 확인했다. 초안 버리기 확인을 거절했을 때 속성 입력과 버튼 초점이 유지됐다. 도면 단자 선택에서 Esc로 나오면 초안, 양단과 개정이 유지되고 단자 선택 버튼으로 돌아왔다. |
| 이력, 저장과 재열기 | 급전 이름 변경을 undo와 redo 한 번씩으로 왕복했다. 저장과 재열기 후 독립 서비스에서 급전, 양단 ID, 출처, 미정 수량, 제작/측정 미정 기록을 대조했다. 원래 봉인 스냅샷과 이전 Touchstone 원문 및 정규 HDF5 바이트가 일치했다. |

최종 빌드에서 급전 2개와 원호, IFA, 평면 편집, 이름, PCB 특징, 2D 캔버스의 Windows GUI 시험 6개가 통과했다. 합산 164.691초였다. Release CTest 13개도 통과했다. 편집 전송, 복소 자료와 solver 계획 회귀 22개 중 실행 환경이 필요한 2개는 건너뛰었으며 20개가 통과했다. [Windows 시험](../../Code/tests/test_gui_port_selection_process.py), [선택 계약](../04_화면설계/05_객체이름과_선택연동.md)

이 기록의 판정 범위는 4번의 정밀 편집과 선택 연동이다. 실제 제작과 측정 조건은 미정이다. 개별 손실, 수렴, RF 목표 및 12번에서 다루는 전체 보조 기술과 DPI 이동은 각 검증 기록에서 판정한다.
