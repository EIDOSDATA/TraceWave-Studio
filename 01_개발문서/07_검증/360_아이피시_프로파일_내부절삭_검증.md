# IPC-2581C 프로파일과 내부 절삭 적용 검증

2026-11-23 / Windows, TraceWave 출력 worker 및 KiCad 10.0.8 / EDA15

## 적용 범위

가져오기에서 단일 보드의 닫힌 직선 프로파일을 찾으면 기존 기판 외곽과 같은 좌표인지 검토한다. 지원하는 내부 절삭은 별도 도형으로 추가하고 적용 전에 누락 항목을 확인하게 한다. 적층·넷·부품·홀의 바이트는 원문에 보존한다. 다중 보드, 패널 반복, 원호가 있는 프로파일은 읽기 검토에 남긴다. 원래 넷과 급전, 외곽과 보드 좌표계는 값이 그대로다.

## 검증 결과

- TraceWave가 게시한 원호와 IFA의 KiCad 보드를 KiCad 10.0.8로 IPC-2581C로 변환했다. 각각 16 x 12 mm와 40 x 60 mm의 외곽을 현재 보드에 다시 대응하고 원문 SHA-256, 급전, 도체, 적층, 재료를 대조했다.
- 별도 Rev C 입력의 내부 직선 절삭 (43, 27)~(46, 29) mm를 검토·적용하고 저장·재열기했다. 새 절삭 좌표와 원본 XML을 확인했다. 자료 손실 확인을 생략하면 적용을 차단했다.
- 미지원 프로파일의 과거 읽기·저장 시험을 다시 실행했다. 실제 Windows worker 기반 제조 교환 시험 3건, Windows Release 빌드 및 CTest 14건을 통과했다.

이 검수는 외곽과 지원 절삭의 왕복 범위다. 전기적 연결, 전체 생산 자료와 수신 EDA의 검증은 추가 범위다.
