## 개발 PC의 수신 결과

원격과 같은 ZIP을 두 개의 새 한글 경로에 풀었다. 외부 DLL을 해시로 대조하고 CPython 3.12.10의 pip 없는 가상환경 및 Windows 기본 PATH로 실행했다. 자동 캔버스 시험은 두 실행 모두 첫 편집 단계에서 서비스 응답 시간이 초과됐다. 대기 목록에서 가장 오래된 요청은 `cad.latest`였다. 각 실패 보고서를 원래 수신 폴더에 보존했다. 공개 `r1-rc1`의 ZIP도 다시 받아 고정 해시를 확인하고 같은 PC의 새 폴더에서 실행했다. 같은 캔버스 단계 1에 도달한 뒤 서비스 응답 시간 초과가 재현됐다.

같은 수신본에서 새 작업 영역으로 `--editor-smoke-test`를 별도로 실행했다. 매개변수 추가, 식 연결과 재계산, 잘못된 입력에서 편집값 보존, 실행 취소와 다시 실행, 저장 후 재시작의 7개 검사가 통과했다. 서비스 세션은 2개였다. 저장 개정과 재열기 개정은 `84fe5dd0-2d42-4476-9dee-abcde784ce0b`, 스냅샷은 `5e696910-ed6b-44db-8503-10a346deef13`이다.

같은 Release 빌드에서 한글 경로의 저장, 스냅샷 및 재열기 검사와 손상된 원문 차단 및 봉인 사본 복구 검사 두 건이 통과했다. Windows 모드 등록과 기준면 이동 검사도 통과했다. 전체 복소 네트워크 GUI 경로는 15개 검사를 진행한 뒤 단계 31에서 전체 시험 시간 300초를 넘겼다. 대기 중인 요청은 `network.preview`였다. 개발 PC 결과에서 이 전체 GUI 경로의 수용은 보류한다.

## 별도 온라인 PC에서 재개할 검수

현재 접근 가능한 별도 클린 Windows 11/WSL2 PC가 없어 독립 수신 및 R1 최종 수용을 보류한다. 해당 PC가 준비되면 온라인에서 후보와 SHA-256을 받고 고정 의존성을 설치한다. 자동 캔버스의 초기 요청, 예제 편집과 저장 및 재열기, WSL2 해석과 다른 실행의 취소, 이전 결과와 출처 조회, 도면 또는 보고서 출력, 정상 저장본 복구를 확인한다. 9포트 감독 경로는 고정 WSL 런타임 감사를 마친 뒤 실제 실행하고, 환경과 원시 재처리 결과를 기록한다.
