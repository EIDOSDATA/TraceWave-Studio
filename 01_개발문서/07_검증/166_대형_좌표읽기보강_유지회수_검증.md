# 3D 좌표 읽기 보강 후 30초 유지 재검증

2026-11-21 KST. 정점과 삼각형을 연속 배열로 읽는 Release에서 대형 프로젝트 전환 30회를 정상 종료했다. 실제 통합 Windows Studio 창에서 형상 10000개, 매개변수 1000개, 100만 표시 삼각형, 필드 단면 열 회와 10만 점 곡선 8개를 매번 열었다. 동일한 서비스와 OpenGL 문맥을 유지하고 대기 프로젝트에 30초 이상 머문 뒤 자원을 기록했다.
