# 대형 설계의 Windows 페이지 표시와 재열기

2026-11-21 KST. 완료 계획 12번 F1에서 4층, 형상 10000개와 매개변수 1000개의 Windows 편집 진입과 저장·재열기를 검증했다. [원본 저장 검증](106_대형설계_원본저장_검증.md)

## 서비스와 Studio

- Studio는 페이지 전송 지원을 확인한 뒤 원본을 응답이나 작업 영수증에 싣지 않는 summary 열기를 요청한다. 과거 서비스에는 기존 단일 조회로 연결한다.
- 편집과 캔버스는 한 응답당 최대 512행과 384 KiB를 반환한다. 프로젝트·개정 ID, 총 행 수, 시작 위치와 다음 위치를 검증한 뒤 화면에 반영한다. 확인이 끝나야 편집을 활성화한다.
- 큰 속성의 선택지도 같은 방식으로 나눈다. 같은 개정의 선택 변경에는 Studio가 기존 탐색 목록을 재사용한다. 도체 아이콘은 장면에서 한 번 색인한다.
- 서비스는 최근에 읽은 한 개정의 원본과 표시 자료를 재사용한다. 새 페이지 연쇄의 첫 요청은 파일을 다시 검증한다. 저장과 명령은 권위 저장소의 검증 절차를 사용한다.

## 검증

실제 Windows Release Studio에서 한글 작업 경로의 형상 10000개와 매개변수 1000개를 열고 프로젝트 속성을 편집했다. 저장과 스냅샷을 거쳐 새 서비스 세션에서 재열었다. GUI가 표시한 형상과 매개변수 수를 확인했으며 생략은 0개였다. 사용자 지정 이름, 이름 미정, 재료의 Df 미정, 도체·매개변수 출처와 원본 저장값을 대조했다. 실제 서비스에서 급전 양극과 기준 도체 선택지를 각각 10000개의 ID와 원래 순서로 전달했다. [원시 실행 기록](108_대형설계_윈도우_재열기_실행기록.json)

Windows 환경 회귀 18개와 CTest 13개를 통과했다. 관련 서비스 회귀 79개 중 78개가 통과했고 별도 PCB 출력 환경을 사용하는 시험 1개는 제외했다. 최초 서비스 실행의 시험 이름 오류를 바로잡은 뒤 해당 범위를 다시 실행했다.

이 기록은 대형 2D 편집 표시와 저장을 다룬다. 성능 시험 및 CAD·해석·복원 묶음의 작업 한도는 각 계약을 따른다.
