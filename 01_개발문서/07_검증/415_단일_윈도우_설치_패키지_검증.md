2026-11-23 KST. Windows 11 x64의 온라인 설치 후보 `r1-rc3`는 제품 ZIP을 `TraceWave-Studio-R1-rc3-Setup.exe`에 내장한다. 다운로드한 실행 파일 하나에서 설치를 시작한다. [후보와 SHA-256](https://github.com/EIDOSDATA/TraceWave-Studio/releases/tag/r1-rc3)

앱 전용 CPython 3.12.10과 WinLibs 자산을 공식 공급처에서 받아 SHA-256을 확인한다. 필요한 DLL 세 개의 해시도 대조한다. 서비스, CAD, 네트워크와 도면/보고서 출력 환경은 고정 wheel 목록으로 설치한다. 시작 메뉴에서 Studio를 열 수 있으며 기본 설치 경로 아래 `Workspace`를 버전별 프로그램 경로와 분리한다. WSL2가 없으면 Windows 기능을 활성화하고 같은 Setup.exe로 재개한다. 전용 Ubuntu 24.04에서 openEMS를 고정 소스로 빌드하고, native 감사에 성공하면 Studio 시작 메뉴에 해석 경로를 연결한다. [설치와 재개 절차](../08_운영환경/05_윈도우_내부검증_배포.md)

## 개발 PC 재현

Windows 11 빌드 26300의 새 한글 경로에서 실제 Setup.exe를 시작했다. 설치 파일이 CPython과 WinLibs를 온라인으로 수신했다. `-WithoutSimulation`으로 고정 CAD/네트워크/출력 설치를 완료했다. CadQuery/OCCT의 STEP 왕복에서 10 x 20 x 1.6 mm와 320 mm^3를 확인했다. 새 환경의 h5py, scikit-rf, SciPy 및 ezdxf, ReportLab, Shapely를 각각 가져왔다. 출력 라이브러리의 DXF·PDF 저장과 재열기를 별도 설치 시험에서 확인했다. 내장 ZIP 해시를 다르게 주면 압축 해제 전에 차단했다. 기존 공개 ZIP의 검증 도구 테스트 4개를 통과했다.

설치된 Studio에서 매개변수 편집, 계산, 잘못된 입력 거절, 실행 취소와 다시 실행, 저장 후 재열기 등 7개를 확인했다. 두 서비스 세션의 저장 및 재열기 개정은 `24135f62-adbf-438e-ac2a-4544e200d7f9`로 일치했다.

같은 Setup.exe를 기본 모드로 재실행하니 기존 `TraceWave-Dev`가 등록됐지만 VHDX 경로가 없어 실행 확인에 실패했다. 설치기는 Windows 준비 완료와 해석 준비 보류를 함께 기록하고 기존 배포를 재등록하지 않았다. 같은 작업 영역에 먼저 둔 검증 파일의 SHA-256이 유지됐다.

## 별도 PC에서 남은 검수

온라인 상태의 별도 클린 Windows 11/WSL2 PC에서 Setup.exe를 기본 옵션으로 실행한다. Windows의 관리자 승인과 재부팅, 필요 시 같은 파일 재실행, 새 전용 Ubuntu 및 openEMS 설치와 native 감사까지 기록한다. 이어 예제 편집, 저장과 재열기, 실제 9포트 해석과 별도 실행의 취소, 결과와 출처 재열기, 도면 또는 보고서 출력, 정상 저장본 복구를 확인한다. 기존 GUI 시간 초과 경로도 재검사한다.
