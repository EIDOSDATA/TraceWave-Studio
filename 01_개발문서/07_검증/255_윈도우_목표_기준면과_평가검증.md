# Windows 목표 기준면과 평가 검증

2026-11-21 KST. Windows 11 Studio의 목표 편집과 복소 결과 평가를 확인했다.

| 실행 | 확인한 결과 |
| --- | --- |
| 목표 편집 및 템플릿 GUI | 직접 입력 목표의 기준면 이름을 적용하고 다시 선택했다. 기존 추정 출처와 1001개 주파수 표본, 프리셋 과거 입력을 유지했다. |
| 복소 결과 평가 GUI | 저장된 목표의 입력 기준면을 고정하고 같은 기준면의 RLC 파생 자료로 평가를 저장했다. 서비스를 재시작한 뒤 프로젝트와 평가를 다시 열어 당시의 목표 원본 및 평가 기준면을 확인했다. |
| 서비스와 domain 회귀 | 자료와 평가 요청이 서로 일치해도 저장된 목표 기준면과 다르면 미평가로 남긴다. 같은 면은 표본 판정을 수행한다. 기준면을 빈칸으로 되돌리거나 실행 취소해도 기존 목표와 출처를 보존한다. |

이름 일치는 자료가 명시한 평가 조건의 비교다. 디임베딩, 기준면 이동, 연속 대역, 독립 RF 정확도 및 실물 측정에는 각각 별도 검증이 필요하다. 검증용 샘플의 제작 및 측정 상태는 미정으로 유지했다.
