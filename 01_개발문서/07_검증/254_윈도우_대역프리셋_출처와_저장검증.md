# Windows 대역 프리셋 출처와 저장 검증

2026-11-21 KST, Windows 11의 Release Studio 및 Python 응용 서비스에서 확인했다. 대역 프리셋은 목표의 주파수와 증거를 지정하는 초안이며, 해당 제품의 급전, 임피던스, 성능 한계와 제작·측정 조건을 별도로 입력한다. [대역 및 원문 근거](../05_기능설계/02_설계편집/06_대역목표_입력계약.md#8-출처와-적용-범위가-확인된-대역-초안)

| 실행 근거 | 확인한 결과 |
| --- | --- |
| 목표 편집 RPC와 저장 재열기 | 7개 항목의 SI 주파수, 발행 판과 적용 범위, 명시 표본 또는 초안 표본 정책을 검사했다. 기존 목표 덮어쓰기와 미지원 판을 거절했다. 수치 변경은 예전 출처와 사용자 변경 사유를 함께 남겼다. |
| 실제 Windows Studio 프로세스 2회 | 네이티브 대역 선택 대화상자를 열고 Bluetooth LE를 선택했다. MHz로 표시한 40개 중심, 독립 목표 적용, 미정 포트·임피던스를 확인했다. 지연 응답 경로도 통과했다. |
| Studio 저장 후 별도 서비스에서 파일 다시 읽기 | 저장 기준점의 대역·표본 배열, 원문 판과 범위, 40개 표본의 출처 및 미정 조건이 현재 원본과 일치했다. 기존 1001개 명시 표본과 추정 출처도 유지했다. |

이 실행은 목표 입력을 검증한다. 해석 작업을 만들지 않았고 수렴, RF 적합성, 제작 및 실물 측정 상태는 미평가다.
