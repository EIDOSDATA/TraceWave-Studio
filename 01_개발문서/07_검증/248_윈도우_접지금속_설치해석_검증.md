# Windows 기준 패드 접지 금속의 설치 해석

2026-11-21 KST. 같은 PCB, 급전, 유전체 케이스의 시험에서 1 x 1 x 1 mm PEC 상자를 급전 기준 패드 위에 놓았다. 이 시험 PCB의 급전 기준 도체는 최상층 직사각 접지 패드다. 비접촉 상태에서 금속 하단은 동박 윗면에서 0.6 mm 위에 있다. 접지 상태에서 금속의 원본 하단은 동박 윗면 1.035 mm이고, 해석 접면은 PCB 전도 시트 평면 1.0 mm다.

| 10 GHz 관찰량 | 비접촉 | 기준 패드 접지 |
| --- | ---: | ---: |
| S11 크기 (dB) | -4.6619 | -4.6490 |
| 방사 효율 | 98.617% | 98.661% |
| 총 효율 | 64.907% | 64.835% |
| 최대 실현 이득 (dBi) | 1.115 | 1.110 |

Windows Studio에서 비접촉 상태를 해석한 뒤 같은 금속의 종류와 하단 Z만 수정해 저장했다. WSL2 openEMS가 접지 상태 계산을 완료했다. 다시 연 Studio에서 이전 개정의 비접촉 결과와 새 접지 결과의 S11 공통 표본, 두 효율, 실현 이득 단면을 비교했다. 원래 금속 ID, 재료 출처, 케이스와 참고 물체의 미정값을 확인했다.

봉인 계획에 접지 대상 패드, 기준 넷, 실제 동박 윗면과 계산 접면을 기록했다. native 준비의 재료 우선순위와 Yee 전기 edge 검사에서 같은 기준 패드에 연결된 노드 9개를 확인했다. 계획 시험에서 동박 윗면에 닿지 않거나 패드 바깥에 놓인 접지 신청을 차단했다. 실제 접촉저항, 유한 전도 금속 손실, 수렴과 실측 정확도는 미평가다.
