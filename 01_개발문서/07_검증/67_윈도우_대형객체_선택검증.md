# Windows 대형 3D 객체 선택 검증

2026-11-20 KST. PERF-F2의 검증된 100만 삼각형 장면에서 클릭 선택 대상을 좁혔다. 파일을 읽고 스냅샷과 바이트를 검증하는 기존 작업 스레드에서 큰 바디의 선택 경계 트리를 만든다. 바디당 2,048개 미만의 삼각형은 기존 경로를 사용한다. 트리는 표시 정점의 경계를 보관하며 최종 선택은 기존 삼각형 투영과 깊이 판정을 호출한다. 숨긴 층, 바디 깊이 동률의 원래 순서 및 병합 바디의 원본 후보 목록을 유지한다. 트리는 메모리에만 있으며 원본 프로젝트, STEP과 표시 파일을 변경하지 않는다.

## 전수 대조

동일한 100만 삼각형 두 바디에 카메라 각도, 화면 이동, 숨긴 층, 배경 위치를 고정한 48개 조회를 두 번 실행했다. 각 실행에서 전수 검사와 트리가 같은 48개 바디 또는 배경을 반환했다. 첫 바디 14개, 두 번째 바디 22개, 배경 12개였다. 단위 시험은 맞닿은 모서리, 겹친 면, 숨긴 층, 회전과 트리 생성 취소도 검사한다.

| 실행 | 트리 준비 (ms) | 전수 검사 p95 (ms) | 경계 트리 p95 (ms) |
| --- | ---: | ---: | ---: |
| 1 | 235.16 | 7.77 | 0.013 |
| 2 | 235.16 | 7.67 | 0.013 |

논리 배열 용량은 두 실행 모두 8,718,520바이트, 노드는 131,070개였다. 트리 준비는 파일 해시와 JSON 읽기 뒤의 추가 CPU 작업으로, 화면 입력 지연에는 포함하지 않았다. 이 시간과 용량은 동일 장면의 계측값이다.

## 실제 Windows 선택

같은 파일의 wxGLCanvas에서 35초 연속 회전·이동 후 위에서 보기로 변경했다. 정상 화면의 wx 마우스 처리기로 첫 바디, 두 번째 바디, 숨긴 두 번째 층, 다시 표시한 두 번째 바디와 배경을 클릭했다. 원본 ID와 미선택 상태가 다섯 번 모두 예상과 일치했다. 입력 처리기는 0.53~5.04 ms였으며 출력 합성까지의 클릭 지연은 별도다. 회전·이동 구간만 집계한 합성 간격 p95는 16.11 ms였다. [기존 대형 장면 합성 검증](63_윈도우_대형장면_합성검증.md)

실제 OCCT Windows GUI 2개, CTest 13개, 합성 판독 및 요구 추적 감사 18개가 통과했다. 대형 장면 재확인과 클릭 선택의 근거다. 표시용 LOD 품질, 기준 장비의 종합 수용과 장시간 회수는 따로 확인한다.
