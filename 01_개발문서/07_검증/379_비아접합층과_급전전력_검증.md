# 비아 접합층과 GHz 급전 전력 검증

## 입력과 계산

해석 전 검토의 조건 입력에서 `PTH 접합층`을 연다. 해석에 포함한 비아의 이름, 낮은 Z 또는 높은 Z 끝, 프로젝트에 등록한 재료, 배럴 안쪽으로 잰 접합층 두께(mm)를 선택한 뒤 추가한다. 같은 비아 끝을 다시 지정하면 해당 행을 변경한다. 다른 쪽 끝에 별도 재료를 쓸 수 있다. 접합층을 지정하지 않은 이전 조건은 종전의 단일 배럴로 계산한다.

저장한 해석 조건의 `via_junctions`는 비아와 재료 UUID, 끝, 두께를 유지한다. 유효 주파수 범위를 벗어난 재료, 미정 전도도, 중복 끝, 남은 배럴이 해상되지 않는 두께를 검토에서 차단한다. 각 접합은 기존 PTH와 같은 환형 단면을 사용한다. 실제 XML에는 해당 두께만큼의 유한 전도 환형 체적을 우선 배치하며 안쪽 구멍은 공기로 유지한다. 접합 양 끝과 중간을 Z 격자에 보존한다. 평면 패드, 물리적 급전 양단, 급전선 임피던스는 기존 설계에서 읽는다.

독립 손실 기록을 켜면 전계와 native 전도 전류의 실수 일률을 quarter-cell 체적 분율로 배분한다. 접합에 대해서는 별도로 재료 전도도와 전계 크기 제곱을 적분하여 0.5% 허용 오차 안인지 검사한다. 접합을 제외한 배럴과 모든 접합의 합이 비아 전체가 된다. 박막 도체는 별도로 적분한다. 실제 급전의 수용 전력은 같은 실행에서 기록한 전압과 전류로 계산한다. 결과의 전력 표는 낮은 Z 끝과 높은 Z 끝의 접합 손실을 구분하고 개별 비아 식별자 및 두 적분값은 독립 손실 원본에 기록한다.

## 재현

고정 Linux openEMS 가상환경에서 저장소 루트를 기준으로 다음을 실행한다. `RFAD_JUNCTION_REPORT` 환경 변수에 파일 경로를 주면 두 계산의 포트 좌표, 재료와 두께, 격자 해시, 51개 S11, 전력과 종료 원인이 JSON으로 남는다.

```sh
PYTHONPATH=Code/src:Code/tests RFAD_OPENEMS_NATIVE=1 python -B -m unittest test_pcb_junctions
```

`pth_loss_numerical_reference.json` 원본의 16 x 12 mm 기판, 1 mm 배럴, 1000 S/m 합성 도체와 `pth_loss_reference_study.json`의 첫 설정을 사용했다. 상단 Z=0.8~1.0 mm만 1000 S/m 또는 100 S/m로 선택했다. 두 경우의 격자 SHA-256은 `1030a0a32657c2ccca424daed933210759086c80c2f7148494d0d27fd9895751`로 같다. 물리적 급전은 (7,6,1) mm에서 (9,6,1) mm까지의 X 방향 50 ohm 간극이다. 목표 감쇠 50 dB에서 각각 7120단계, 56.37 dB와 56.58 dB를 기록했다.

| 주파수 (GHz) | 접합 손실 / 수용 전력 (%), 1000 S/m | 같은 비율 (%), 100 S/m | 전력 수지 잔차 (%), 1000 S/m | 같은 잔차 (%), 100 S/m |
| --- | ---: | ---: | ---: | ---: |
| 10.0 | 0.363242 | 1.248831 | 1.147746 | 1.059174 |
| 10.5 | 0.376014 | 1.287437 | 1.222681 | 1.128178 |
| 11.0 | 0.388443 | 1.323818 | 1.275515 | 1.178384 |

공식 openEMS `CalcPort`의 물리적 단자 전압과 전류로 51개 복소 S11 및 세 주파수의 수용 전력을 따로 계산했다. S11은 상대/절대 오차 1e-10, 수용 전력은 상대 오차 1e-9 이내였다. 두 재료 사이의 최대 복소 S11 차이는 0.00356527이었다. 여섯 접합 표본에서 두 적분의 최대 상대 차이는 2.73e-8이었다. 기존 3% 전력 수지 기준을 여섯 표본 모두 만족했다. 수지 잔차는 수용 전력에서 방사, 유전체, 도체 손실을 뺀 부호 있는 값이다.

두 전도도는 수치 검증용 합성값이다. 이 결과의 검증 범위는 유한 환형 접합의 계산과 전력 배분이다. 구리 도금의 실제 표피 깊이, 패드 퍼짐 전류와 반경 방향 전이 형상, 주파수에 따라 변하는 접촉 물성의 확증에는 그 조건에 대응하는 자료가 필요하다. 실제 제조 물성과 제작 수율은 미정으로 유지한다.

## 재료 출처를 주파수 대역별로 지정하는 경우

조건 입력의 `대역별 재료` 표에서 설계 재료, 사용할 프로젝트의 출처 재료, 시작/끝 주파수(Hz)를 지정한다. 계산 대역 전체를 덮는 단일 구간을 선택하며, 출처 재료에 등록한 유효 대역과 사용 목적별 필수 물성을 다시 검사한다. 다른 대역의 물성은 보간하지 않는다. 비아 접합에도 같은 규칙을 적용한다. 유전체 손실 탄젠트는 각 계산 대역 중심에서 상수 전도도로 환산하는 기존 모델을 사용한다.

여러 구간에 걸치는 조건은 한 번의 FDTD로 실행할 수 없다. `run_pcb_material_bands.py`는 입력 구간들을 분할하고 각 구간에 요청한 직접 주파수가 3개 이상인지 확인한다. 방사를 요청하면 각 구간에 관찰할 주파수가 있어야 한다. 구간이 겹치거나, 물성 공백이 있거나, 출처 재료가 없으면 계획을 중단한다. 맞닿은 경계에서 두 계산이 같은 주파수를 요청하면 두 결과를 각각 기록한다. 압축하거나 위상을 이어 붙이지 않는다. 각 실행의 스냅샷, 출처 재료와 유효 범위, 포트, 격자, 원시 파형, 종료 근거를 보존한다.

```text
python Code/tools/run_pcb_material_bands.py WORKSPACE SNAPSHOT_ID SETTINGS_JSON PREVIEW_JSON
python Code/tools/run_pcb_material_bands.py WORKSPACE SNAPSHOT_ID SETTINGS_JSON RUN_JSON --solve
```

검증에서는 위 합성 PTH의 10~10.5 GHz에 유전체 tan_delta 0.002와 접합 1000 S/m, 10.5~11 GHz에 tan_delta 0.04와 접합 100 S/m를 지정했다. 51개 원래 주파수를 두 번의 독립 계산에 26개씩 배정했고 10.5 GHz의 표본만 두 결과에 있다. 낮은 대역은 7280단계, 56.24 dB, 높은 대역은 6940단계, 55.61 dB에서 종료했다.

| 10.5 GHz의 조건 | 복소 S11 | 유전체 손실 / 수용 전력 (%) | 접합 손실 / 수용 전력 (%) | 수지 잔차 (%) |
| --- | --- | ---: | ---: | ---: |
| 낮은 대역 끝 | 0.765313 - j0.000389 | 0.10349 | 0.37605 | 1.22192 |
| 높은 대역 시작 | 0.761887 - j0.003368 | 2.13064 | 1.22244 | 1.23612 |

각 대역의 두 전력 관찰 주파수에서 3% 기준을 만족했다. 이 예는 출처 물성이 다를 때 같은 주파수에서도 서로 다른 복소 결과가 생길 수 있음을 확인한다. 두 물성표 사이의 분산 또는 공정 원인에 대한 추정은 포함하지 않는다. 단위 및 Linux 실제 계산은 `python -B -m unittest test_pcb_material_bands`로 재현한다.

Windows에서 공개 프로젝트 명령으로 같은 합성 사례를 생성하고 저장한 스냅샷으로 분할 실행 도구를 별도 검증했다. 두 구간 모두 일반 서비스의 계획, 준비, 작업 제출, 결과 봉인을 완료했다. 낮은 대역 결과는 `2c216252-7dc4-4fbf-871e-3b17812d1721`, 높은 대역 결과는 `e83a4c68-21c5-4c22-b22d-cb0f644da5eb`이다.
