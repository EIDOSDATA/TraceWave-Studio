# 빈 Studio 유휴 확인 주기 비교

2026-11-20 KST. [앞선 F0 검증](37_스튜디오_재열기와_유휴성능_검증.md) 이후 동일 Windows 11 PC, 배율 150%, 빈 작업 영역에서 30초씩 다시 측정했다. 기준은 새 도구 아이콘을 검증한 `b5e03a1`이고, 진단에서는 요청과 작업이 없는 빈 창의 서비스 확인 주기만 50 ms에서 250 ms로 바꿨다. 각 빌드와 프로세스의 표본은 [실행 기록](46_유휴확인주기_비교_실행기록.json)에 있다.

| 기준 배포본 첫 구간 | 5.15% | 41.33 MiB | 77.78 MiB |

| 기준 소스로 재빌드, 같은 프로세스 반복 | 0.68% | 39.54 MiB | 76.24 MiB |

진단 빌드로 유휴 CPU 감소가 재현되지 않아 해당 변경을 되돌렸다. 화면 검증 도구 세션을 종료한 뒤 원래 소스로 다시 빌드했다. 기준 소스의 반복값도 달랐으므로 위 수치만으로 타이머와 외부 접근성 처리의 기여를 분리할 수 없다. 각 쌍은 같은 프로세스에서 서로 다른 두 30초 구간을 관찰했다. 화면의 직접 조회는 마지막 표본 뒤에 수행했다.

표본에서 GUI와 하위 프로세스의 private commit은 F0 예산 이내였다. 마지막 구간은 단일 코어의 0.68%로 목표 이내였고 직전 구간은 1.51%였다. 동일 결과의 재현이 필요하므로 1% 유휴 CPU 수용은 미확립이다. 시작 시간, 실제 편집 프레임, 작업 취소 지연 및 여러 Windows 환경은 별도로 검증한다.
