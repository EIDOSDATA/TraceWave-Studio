# Altium의 도금·비도금 홀과 슬롯 재출력 검증

2026-11-21 KST. Studio에서 도금과 비도금 원본 XNC를 생성했다. 두 파일 모두 원형 홀 한 개와 직선 슬롯 한 개를 포함한다. Studio 판독기로 완성 치수, 파일 도금 속성, 객체 ID와 공구 지름 미정값을 확인했다. 별도의 G85 검토 사본에는 슬롯 양 끝의 반원 중심을 mm 절대 좌표와 2.3 고정 자릿수로 기록했다.

Altium Designer Enterprise 26.9.1 CAMtastic의 File > Import > Drill에서 도금과 비도금 사본을 각각 선택했다. Metric, Absolute, 정수 2, 소수 3, 0 생략 없음으로 가져왔다. 두 로그 모두 오류와 경고는 0건이었다. 같은 CAM 문서를 저장하고 닫았다가 열었으며, Save Drill에서 두 레이어를 각각 선택해 빈 시험 폴더로 재출력했다. 수동 원점 보정은 적용하지 않았다. [Altium 가져오기·내보내기 설정](https://www.altium.com/documentation/altium-designer/preparing-for-manufacture/cam/imports-exports)

| 원본 분류 | 원형 홀 중심, 원본 / 재출력 (mm) | 슬롯 시작과 끝 중심, 원본 / 재출력 (mm) |
| --- | --- | --- |
| 도금 | (8, 10) / (7.999, 9.999) | (22.5, 10) - (27.5, 10) / (22.499, 9.999) - (27.499, 9.999) |
| 비도금 | (8, 30) / (7.999, 29.999) | (22.5, 30) - (27.5, 30) / (22.499, 29.999) - (27.499, 29.999) |

두 출력 모두 원형 홀 지름 1.25 mm와 슬롯 폭 1.2 mm를 한 번씩 기록했다. 슬롯은 G85로 남았고 생략된 끝 Y에는 시작 Y가 이어진다. 모든 축의 차이는 재출력 한 자릿수인 0.001 mm였으며 중심 간 5 mm와 완성 슬롯 길이 6.2 mm를 확인했다. [Altium NC 편집](https://www.altium.com/documentation/altium-designer/preparing-for-manufacture/cam/nc-editor)

재출력 두 파일 모두 도금 분류를 담은 `TF.FileFunction`이 없었다. 검토 사본부터 객체 ID를 전달하지 않아 이 경로에서 ID 복원도 미확립이다. Altium 레이어의 이름만으로 실제 도금 속성을 판정할 수 없다. 제품의 Altium 검토용 변환 범위는 비도금 원형 홀로 유지한다. 원본 XNC의 SHA256과 공구 지름 미정값은 시험 후에도 일치했다. 실제 공구 치수, 제조 조건과 별도 원점 비교는 미확립이다. [앞선 Altium 왕복](172_알티움_동박외곽과_비도금홀_왕복검증.md), [실행 기록](225_알티움_도금홀과_슬롯_실행기록.json)

같은 Windows에서 KiCad 10.0.8 네이티브 수신과 별도 PCB parser·writer 환경을 켠 회귀 51개가 통과했다.
