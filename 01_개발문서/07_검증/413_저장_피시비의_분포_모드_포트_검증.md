# 저장 PCB의 분포 모드 포트와 실제 복소 응답

2026-11-23 KST. `pcb-waveguide`에서 저장 개정 JSON 또는 프로젝트 보존 ZIP을 읽어 직사각 공기 도파관 양쪽의 분포 모드 포트 사이에 배치한다. 409의 모드 해를 410의 HDF5 원문으로 내보내면 단면, 좌표, 전파 대역과 해시를 검사한다. 두 포트에서 한 번씩 여기하고 다른 쪽의 입출력을 포함해 복소 2 x 2 S 행렬을 작성한다. 모드 원문 두 개를 실행 폴더에 복사하고 XML에서 실행 폴더 내부의 상대 경로로 참조한다. [409 일반 도파관](409_일반_도파관_단면의_티이_티엠_결합_검증.md) [410 모드 분포와 9포트](410_아홉_급전과_분포_모드_원문_검증.md)

지원 범위는 직사각 보드와 평면 적층, 동박의 전도성 시트와 공기 도파관의 같은 TE/TM 모드 양방향이다. 전계의 횡방향 모드 분포로 여기하고 시험에서 TM의 실수 기준 임피던스를 별도로 적용했다. 외측 동박은 인접 계면에 지정 두께 및 전도도로 배치한다. +Z/-Z 진행 방향, 보드 좌표의 원점, 양쪽 기준면, 모드 편파, 주파수별 실수 기준 임피던스와 단위 전력 규약을 기록한다. 각각의 로그, XML 및 포트 원시 파형의 SHA-256을 보존한다. 기존 집중 급전 정의는 원본에 보존하고 이 실행의 비활성 포트 ID로 기록한다. 서로 다른 모드의 다중 결합과 집중 급전을 같은 작업에 넣는 구성은 현재 지원 범위 밖이다. [openEMS의 일반 도파관 포트](https://docs.openems.de/en/v0.37.0/concepts/ports.html#generic-waveguide-port)

## 실제 Windows 검증

20 x 10 mm 도파관에 1 mm, 상대유전율 2.2, 손실 탄젠트 0.002의 판을 놓았다. FDTD의 유전체 손실은 대역 중심에서 등가 전도도로 구현했고, 독립 Airy 풀이에도 같은 조건을 적용했다. 두 포트의 기준면은 Z=-8 mm, +9 mm다. Windows의 upstream openEMS 0.37.0과 CSXCAD 0.7.0을 사용했다.

| 입력 | 관측 |
| --- | --- |
| TE1 균질 손실판, 10/10.5/11 GHz | 12개 복소 계수의 Airy 절대 오차 최대 0.001392 |
| TM1 균질 손실판, 18/18.5/19 GHz | 같은 양쪽 기준면에서 12개 복소 계수의 독립 Airy 절대 오차 최대 0.007858 |
| TE1 동박 PCB | 같은 기판에 35 um, 58 MS/m, 4 x 4 mm 동박을 추가했다. TE 복소 전달 변화 최대 0.156193, 상호성 잔차 최대 0.000200 |
| 포트 원문 | 직사각 단면 크기가 다르거나 이미 내보낸 E/H 파일의 해시가 다르면 여기 전에 차단하는 시험 통과 |

고정 TE 판의 개정 SHA-256은 `dccafc5e5fa288f4b102470974529e69b8e300469db91ed00db5de5a28ae7144`, 동박 PCB는 `e57c1434924c00812ce3d633faf3eaf66f547fa1f29e2a62a3f779aa97c1c1d1`이다. [재현 입력과 독립 Airy 도구](../../Code/tools/verify_pcb_waveguide_mode.py)

## 재현

410과 같은 Windows native 및 고정 수치 Python 환경을 사용한다. 원래 프로젝트 파일을 별도 보관하고 새로운 결과 폴더에 실행한다.

```powershell
Set-Location Code
$env:PYTHONPATH = 'src;tests'
$env:OPENBLAS_NUM_THREADS = '1'
$numeric = '.local/rf-check/Scripts/python.exe'
$native = '.local/native-win-037/Scripts/python.exe'
$openEms = '.local/openems-win-037/openEMS/openEMS.exe'
& $numeric tools/verify_pcb_waveguide_mode.py create fixtures/pcb_worker_smoke.json .local/pcb-waveguide-cases
& $numeric -c "import json; from test_waveguide_section import rectangular_step; print(json.dumps(rectangular_step([20,10],[20,10],[0,0],0.45,10.5e9,14)))" | Set-Content -Encoding utf8 .local/pcb-mode-section.json
& $numeric -m rfad waveguide-mode-files .local/pcb-mode-section.json --side wide --mode TE1 --frequency-hz 10500000000 --pitch-mm 0.5 --output .local/pcb-waveguide-te
& $native -m rfad pcb-waveguide .local/pcb-waveguide-cases/dielectric.json --settings .local/pcb-waveguide-cases/settings-te.json --mode-files .local/pcb-waveguide-te --executable $openEms --output .local/pcb-waveguide-plate-run
& $native -m rfad pcb-waveguide .local/pcb-waveguide-cases/foil.json --settings .local/pcb-waveguide-cases/settings-te.json --mode-files .local/pcb-waveguide-te --executable $openEms --output .local/pcb-waveguide-foil-run
& $numeric tools/verify_pcb_waveguide_mode.py compare .local/pcb-waveguide-plate-run/result.json --foil .local/pcb-waveguide-foil-run/result.json
```


TM 판은 같은 단면에서 `--mode TM1 --frequency-hz 18500000000`으로 원문을 새로 내보내고, `pcb-waveguide`의 설정 파일은 `settings-tm.json`을 지정한다. `compare`에는 TM 결과만 전달한다.
