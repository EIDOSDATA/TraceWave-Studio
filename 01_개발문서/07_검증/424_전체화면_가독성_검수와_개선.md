# 전체 화면 가독성 검수와 개선

2026-11-24 KST. [승인 화면 목록](../04_화면설계/13_전체화면목록.json), [RC8 화면별 진단](422_알원_알시팔_화면별_사용성_재진단.md), [후속 사용성 검수](423_알원_사용성_후속_수정과_재검수.md)를 기준으로 Windows 네이티브 앱을 실행했다. 검증에는 프로젝트 사본, 별도 작업 경로와 보존된 계산/출력 결과를 사용했다.

## 수정 내용

- 공통 읽기 전용 표에서 오른쪽 클릭 또는 표준 문맥 메뉴 키로 선택 행의 열 제목과 전체 값을 읽거나 복사할 수 있다. 기존 선택, 편집 가능 표의 직접 편집, 더블 클릭 동작을 보존한다.
- 해석 준비에서는 연결 상태와 검사 및 실행 순서를 먼저 표시한다. 작업 및 문제 표는 한국어 상태와 화면 폭에 맞는 설명 열을 사용한다.
- 해석과 연구 주파수에는 Hz, kHz, MHz, GHz 및 기존 숫자만 있는 Hz 입력을 사용할 수 있다. 읽기 편한 표현을 사용하되 입력으로 읽었을 때 원래 수치가 돌아올 때만 단위를 바꾼다. 연구 판정 기준은 포트, 방사, 수치 검증과 손실로 나눴다.
- 문헌 후보는 검토 결과와 차단 이유, 생략과 미정 조건, 가정, 한계, 출처 원문 순서로 표시한다. 보존 결과는 당시 개정과 현재 개정을 구별한다.
- 네트워크에는 응답과 입력 포트를 별도로 표시한다. Smith에서는 입력 임피던스와 어드미턴스 값 및 단위를 펼쳐 읽을 수 있도록 열 폭을 넓혔다. 방사 표는 극각, 방위각 및 상대 위상 열의 이름과 폭을 조정했다. 원본 미선택이나 기록 누락 상태에서는 관련 없는 결과 표, 페이지 이동과 그래프 일부를 접는다.
- 가져오기에서 파일 검토 전에는 적용할 수 없는 포트와 기준 조건을 접는다. 파일에서 확인한 포트만 표시하고 시료 보존을 선택하면 시료/교정 양식을 펼친다. 미선택, 검토 전, 입력 변경 후에는 다음 동작을 안내한다.
- 결과 작업 공간에 설계에서 선택한 급전의 버튼과 설명이 남아 있던 문제를 고쳤다. 자료와 정합 화면의 임피던스는 JSON 배열을 대신해 단위가 붙은 수치와 필요시 허수부를 표시한다. 파 정의, 포트 모드, 전류 방향, 정합 표본 및 VSWR 상태는 한국어로 구분한다.

## Windows 검증

- Windows Release GUI 빌드와 CTest 14건을 통과했다. Hz 단위 및 표시 정밀도 왕복 검사는 기존 프레젠테이션 시험에 추가했다.
- 화면에서 기존 PCB 프로젝트와 이전 해석, 8 GHz Smith 복소수와 단위, 10 GHz NF2FF 절단면과 편파 표, 해석 입력 검사, 문헌 검토의 실제 외곽 초과 차단을 확인했다. 도면, STEP, KiCad, Gerber, 드릴, Job과 인계 탭을 열었다.
- 실제 Windows openEMS 방사 표본 조회 및 재시작, 과거 결과와 Smith/비교/내보내기 재열기, 모드 등록 및 기준면 이동, PCB 카탈로그 선택 및 기존 층 보존, 독립 DRC, 연구 초기 대역 및 물성 누락, PDF 생성 및 재검수 취소와 원문 보존 시험이 통과했다. PCB 선택과 PDF 검수는 초기 병행 시험의 시간 초과 뒤 별도 재시도에서 통과했다.
- 목표 및 템플릿 전체 시험은 이번 수정본과 수정 전 빌드에서 각각 시간 초과가 발생했다. 수정본에서는 문헌 후보의 정상 읽기와 실제 외곽 초과 차단을 직접 확인했다. 1001개 표본이 든 시험 프로젝트의 전체 저장 및 재열기 경로를 단독 재검증해야 한다.
- 복소 자료 전체 가져오기, 정합, 평가, 재열기 시험은 처음 두 번에 시간 제한을 넘겼다. 바깥쪽 제한을 480초로 늘려 원인을 확인하는 단독 재시험에서는 최종 저장과 원문 보존까지 322.088초에 통과했다. 수정 전 빌드의 같은 시험은 316.064초에 통과했다. 정규 시험의 제한은 330초이다. 이 차이는 여러 차례의 독립 성능 측정으로 재확인해야 한다.

## 화면 증거와 재개 조건

- 승인 화면 84개의 이전 Windows 실행 캡처와 이번 작업에서 찍은 124개 상태를 로컬 `화면별_가독성_검수.html` 및 `화면별_캡처_목록.csv` 색인에 넣었다. 그중 수정본 84개 화면의 104개 상태를 수록했다. 같은 화면의 입력 전후, 상세 팝업과 추가 스크롤 상태도 각각 확인할 수 있다.
- 보존한 시험 회로를 실제로 불러와 결합을 계산했다. 부하와 정합 후 기준면, 50 ohm 기준 임피던스, S11과 회로 손실을 읽었다. 변경한 VSWR 열에서 무한대와 능동 표본의 정의 불가가 모두 잘리지 않았다. 최종 빌드에서 사용자 모드 등록 및 기준면 이동 시험도 단독으로 통과했다.
- 검수용 서비스에서 목표 수정이 성공한 직후 응답만 유실시켰다. Windows 앱에서 입력을 유지한 채 재적용을 막고 적용 확인을 안내했다. 적용 확인으로 서비스에 다시 연결해 이미 적용된 개정과 기준면, 변경 사유를 확인했다. 검수용 기준면을 포함하는 개정은 한 개였고 목표 세 건 중 한 건에만 값이 기록됐다.
- 급전 전체 자동 시험은 수정 전과 최종 빌드에서 모두 OS 키 입력으로 기준 도체를 선택하는 단계에서 시간 초과됐다. 최종 빌드에 F6, Tab과 Space를 직접 입력해 기준 도체와 급전을 왕복하고 선택 및 초점이 돌아오는 것을 확인했다. 자동 시험의 3D 및 저장 후속 단계는 키 입력이 전달되는 환경에서 재개한다.
- CAD 작업자가 1428개 삼각형과 STEP를 생성했고 단면 위치 입력이 활성화됐다. 이전 RC8 캡처에서는 CAD 형상이 보였다. 현재 환경에서 수정 전 RC9와 수정본 모두 같은 CAD 원본의 OpenGL 영역이 캡처에 잡히지 않았다. 수정본의 3D 방사 탭에서는 범례와 대표 값 옆에 직전 2D 그림이 남았다. Windows 로컬 그래픽 환경에서 동일 원본을 열어 실제 화면과 캡처를 대조해야 한다.
- Windows 150% 배율의 1129 x 768 창에서 속성이 왼쪽 탭으로 이동하고 정밀 도구와 하단 패널을 접으면 도면 전체가 보이는 것을 확인했다. 고대비, 스크린리더, 출력 실물 및 교정 표준은 해당 환경과 원본이 확보되면 확인한다. 이 검수 기록은 R1 최종 수용의 증거를 보완한다.
