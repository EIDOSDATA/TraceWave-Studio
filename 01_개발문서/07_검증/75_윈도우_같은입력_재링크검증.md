# Windows Release 재링크와 빌드 프리셋 검증

2026-11-20 KST. 계획 13번에서 GNU MinGW Release 실행 파일의 PE 링크 시각을 고정했다. 기존 파일은 링크 시각을 담고 있었다. CMake GNU MinGW 조건에서 PE 시각을 0으로 기록하도록 했다. 별도 실험용 렌더러 계측은 명시 target으로 계속 빌드할 수 있다. 기본 Windows Release 빌드는 등록된 CTest 실행 파일을 모두 준비한다. [GNU PE 링크 옵션](https://sourceware.org/binutils/docs/ld/Options.html)

Windows Release에서 프로그램을 두 번 다시 빌드했다. 두 번째에서 렌더링 소스의 동일한 객체 바이트를 다시 생성해 링크했다. 두 번 모두 PE 시각은 0이었고 실행 파일 SHA256은 아래와 같았다. 기본 프리셋으로 CTest 13개를 통과했다.

```text
128eaf649270bf204d65b5f2e1cb01f234cdcb26a5e06464711ac37f129fb302
```

같은 디렉터리의 동일 입력 재링크 근거다. 별도 소스 경로에서 완전히 새로 빌드하는 경우는 별도 시험으로 다룬다. 실행 파일에서 확인한 기존 빌드 경로 문자열도 별도로 검토한다. [앞선 내부 ZIP의 재포장 근거](73_윈도우_내부묶음_수신검증.md), [실행 기록](76_윈도우_같은입력_재링크실행기록.json)
