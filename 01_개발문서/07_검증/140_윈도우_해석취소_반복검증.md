# 대용량 결과 통합 이후의 WSL 해석 취소 반복 검증

2026-11-21 KST. 완료 계획 12번 F4의 최근 Windows Release에서 동일 openEMS 소스와 해석 설정을 사용해 실제 취소를 6회 반복했다. 구동 상태는 guest의 native 프로세스와 libopenEMS 매핑을 통해 확인했다. 실제 해석 출력에 초당 약 1000행의 합성 로그 부하를 결합했다. 각 실행에서 먼저 완료한 결과를 저장하고, 실행 중인 후속 해석을 Studio에서 취소했다.

| 입력 이후 관찰 시간 (ms) | 최소 | 중앙값 | p95 | 최대 |
| --- | ---: | ---: | ---: | ---: |
| 버튼 비활성화 | 21.33 | 23.83 | 25.46 | 25.46 |
| Studio 접수 확인 | 127.88 | 139.31 | 149.04 | 149.04 |
| 서비스 내부 수신부터 송신 | 103.00 | 116.69 | 126.31 | 126.31 |
| 실제 WSL 종료 확인 | 1405.57 | 1495.32 | 1600.49 | 1600.49 |

6회 모두 작업 취소, 실제 guest 종료 확인, 이벤트 순번 연속성 및 이전 결과 재열기를 확인했다. 이 표본에서 버튼 p95는 100 ms, 접수 p95는 200 ms 기준 이내였다. p95는 nearest-rank이며 6회에서는 최댓값이다. 같은 해석 동작군의 반복 시험이다. F4 전체의 1000개 이상 지연 표본과 기타 작업군 수용은 남는다. [실행 기록](141_윈도우_해석취소_반복실행기록.json)
