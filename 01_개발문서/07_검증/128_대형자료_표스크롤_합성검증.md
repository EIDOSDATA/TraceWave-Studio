# 대형 자료 표 스크롤의 Windows 합성 검증

2026-11-21 KST. 완료 계획 12번 F1에서 형상 10000개, 매개변수 1000개의 저장 개정을 다시 열고 10만 건 카탈로그를 검색했다. 실제 wxListCtrl이 100000번째 행으로 이동한 뒤 35초 동안 Windows 한 행 스크롤 메시지를 받았다. 화면의 시험 표식과 Desktop Duplication의 합성 시각을 대조했다. 시험 표식은 명시적 시험에서만 그리며 그래픽 진단 DLL은 그때 불러온다.

| 최종 계측, 2560 x 1600, 120 Hz, 150% | 관찰값 |
| --- | ---: |
| 스크롤 입력과 합성 화면에 나타난 입력 | 2208 / 1830개 |
| 합성 간격 표본 | 1829개 |
| 합성 간격 중앙값 / p95 / p99 / 최대 | 16.93 / 25.81 / 33.71 / 182.56 ms |
| 60 fps 간격 16.67 ms 초과 | 1154개 |
| 대응 가능한 입력과 합성 사이의 p95 / p99 | 18.27 / 19.20 ms |
| 입력 시점에 첫 표시 행의 내용이 아직 없는 경우 | 242개 |

측정은 Windows 메시지 처리부터 표의 시험 띠가 합성된 시각을 연결한다. 각 행의 내용이 완전히 그려진 시각과 물리 입력 장치 시각은 별도다. 그리기보다 앞선 시각을 가진 표식 4개는 원시 표본에 보존했고 대응 불가로 집계했다. 해당 간격은 다음 대응 표식 사이의 간격에 포함된다. 60 fps 목표는 이 조건에서 미달했다.

초기 기준 실행의 합성 p95는 25.75 ms였다. 셀 문자열을 페이지에 미리 만드는 시험은 p95 33.27 ms였고 안정적인 개선을 보이지 않아 원복했다. 세 실행의 원시 시각과 결과를 보존했다. [실행 기록](128_대형자료_표스크롤_합성실행기록.json)

재현할 때 Windows Release를 `RFAD_GUI_EXE`로 지정하고 `RFAD_TEST_CATALOG_SCROLL_DISPLAY=1`로 `test_f1_view.F1ViewTests.test_windows_saves_and_reopens_all_rows`를 실행한다. 시험 창이 전경에 있는 상태가 필요하다. `RFAD_GUI_TEST_ARTIFACT_DIR`에 저장한 보고서는 `tools/summarize_windows_canvas_display.py --catalog`로 읽는다. 마지막 행과 한글 필터, 출처·미정값, 개정 재열기 역시 같은 회귀에서 확인했다. 기존 Windows PCB 화면 3개, 합성 판독 5개, CTest 13개를 별도로 검증했다.
