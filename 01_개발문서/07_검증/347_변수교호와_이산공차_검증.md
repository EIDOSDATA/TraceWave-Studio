# 두 변수 교호 효과와 이산 공차 검증

검증일 2026-11-23

## 같은 주파수의 두 변수 교호 효과

공칭 결과의 가장 큰 S11 dB가 관측된 직접 주파수를 선택한다. 두 변수가 동시에 바뀐 결과에서 개별 변수의 결과 둘을 빼고 공칭 S11 dB를 더한다. 두 변수의 최소 및 최대를 조합한 네 조건에 대해 같은 쌍의 후보 번호, 교호 효과와 누락 사유를 보존 평가에서 읽는다. 다른 모든 변수는 공칭값을 유지한다. 네 값이 모두 있어야 쌍별 절댓값 최댓값을 표시한다.

독립 직렬 저항의 해석식과 9개 실제 Windows 계산 후보를 대조했다. R1의 값은 10, 20, 40 ohm이고 R2는 12, 25, 60 ohm이다. 네 교호 효과가 독립 식과 소수점 이하 12자리에서 일치했다. 최대/최대 후보가 없을 때 해당 효과와 쌍의 최대가 미정으로 유지됐다. Windows 서비스 재열기에서 같은 보존 결과와 순위 해시를 확인했다.

## 가정한 이산 분포

공차 모서리 순위의 선택 입력에서 모든 변수의 최소, 공칭, 최대 가중치를 지정한다. 가중치 합이 1이 아니면 축별로 정규화하고 후보의 확률은 축별 가중치의 곱으로 계산한다. 모든 목표의 직접 표본을 통과하면 확인 통과로 집계한다. 한 목표라도 실패한 직접 표본이 있으면 확인 실패다. 나머지는 미확인으로 두며, 통과 질량부터 통과와 미확인 질량의 합까지를 범위로 표시한다.

1:2:1 가중치에서 통과 75%, 실패 25%를 확인했다. 최대 후보의 결과가 없을 때 통과 범위는 75~100%였다. 입력하지 않으면 분포를 가정하지 않는다. 결과는 사용자가 가정한 독립 이산 모델에 한정되며 상관된 실제 공정과 제작 수율은 미정이다.
