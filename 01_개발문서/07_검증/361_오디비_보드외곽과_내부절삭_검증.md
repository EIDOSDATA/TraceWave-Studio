# ODB++ ZIP 단일 보드 외곽과 내부 절삭 검증

2026-11-23 / Windows, TraceWave 출력 worker와 KiCad 10.0.8 / EDA16

## 동작

PCB 가져오기에서 ODB++ ZIP을 선택하면 보드 정의, 층과 EDA 자료를 읽는다. 매트릭스와 단일 보드 경로가 일치하는 닫힌 직선 프로파일을 현재 기판의 외곽과 대조한다. 내부 절삭을 검토하고 적용할 수 있으며, 결과 개정에서 원문 ZIP과 해시를 확인할 수 있다. 직선 좌표의 mm 또는 inch를 사용한다. 패널 반복과 곡선 프로파일은 읽기 검토로 남긴다. [ODB++ 형식 사양](https://odbplusplus.com/wp-content/uploads/sites/2/2024/08/odb_spec_user.pdf)

## 검증

- 원호 16 x 12 mm와 IFA 40 x 60 mm에서 KiCad 10.0.8이 생성한 ODB++ 8.1 ZIP을 실제 worker로 다시 받아 외곽을 대조했다. 적용 뒤의 보드 외곽, 도체, 적층, 재료와 급전 및 봉인 원문 바이트를 원본과 비교했다.
- 홀 경계 (43, 27)~(46, 29) mm를 읽고, 패널 반복·곡선 프로파일을 적용 대상에서 제외했다. 경로가 상위 폴더를 가리키는 ZIP 입력을 거절했다.
- Windows 제조 가져오기·내보내기 Python 시험 21건과 Windows Release CTest 14건을 통과했다.

ODB++의 넷, 개별 제조 홀, 부품, 적층과 패널의 설계 반영 및 전체 제조 왕복은 추가 작업이다.
