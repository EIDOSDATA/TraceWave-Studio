## 현재 Windows의 수신 결과

소스는 `665a4a47d6c31620f4912e054a0c79d93c7bf8e6`이다. GUI와 실행 서비스의 소스에는 7959227 이후 변경이 없어 같은 Release EXE를 사용했다. EXE SHA256은 `c1a81cf3ec411f7dded4a77efcd57f62dfb3fbcb0ebbcb14516270956903b8fe`다. 같은 입력에서 ZIP 두 벌을 만들고 전체 바이트가 일치함을 확인했다.

`TraceWave-Studio-internal-windows-x64-665a4a4.zip`은 manifest를 제외한 996개 파일, 14573993바이트다. SHA256은 `b2b69290212a0c34f99616f00361823a275e7201bdb33ac3513f892db499548d`다. 파일별 해시, Git 원본과 설치 정의, 제3자 고지 15개 및 원문 참고자료 제외를 대조했다. CTest 13개와 Windows 묶음·구현 감사·표시 판독 회귀 23개가 통과했다.

현재 Windows에서 한글이 포함된 새 압축 해제 폴더와 CPython 3.12.10의 pip 없는 신규 venv로 화면 편집·저장과 별도 서비스 세션 재열기를 검증했다. 준비한 54개 wheel의 총 크기는 348531790바이트다. Windows의 패키지 인덱스와 캐시를 끄고 로컬 파일로만 설치했다. Windows와 WSL2의 네트워크 차단 수용은 환경 확보 뒤 실행한다.

서비스 editable 설치와 `rfad` 진입점, CAD 44개 wheel의 고정 해시/설치 계획/STEP 왕복, 도면 환경 10개 wheel과 복소 결과 환경 9개 wheel의 의존성을 확인했다. CAD와 도면 설치 보고서의 다운로드 URI는 모두 로컬 파일이었다. 새 설치의 GUI에서 실제 STEP 메시 및 취소·저장·재열기와 PDF 생성 및 재검수 2개가 통과했다. 기존 감사 openEMS 환경을 연결한 원형·원호의 실제 계산·취소·재열기 1개도 통과했다. 새 복소 결과 환경의 HDF5 및 GUI 정합·비교·저장과 재열기 12개가 통과했다.

재부팅과 독립 Windows 수신은 보류했다. 현재 개발 PC의 2D 이동 p95 17.109 ms는 60 fps 목표를 초과했고 표 스크롤의 기존 미달도 남아 있다. 기준 장비에서의 성능 수용과 실제 전원 차단 복구 보장의 증거는 미평가다. 실제 전원 차단 보장 시험을 실행하는 경우 격리 환경을 사용한다. [연속 표시 검증](283_윈도우_연속표시_유효표본_검증.md), [검증 선별과 승인 성능](../09_개발계획/05_현행버전_검증선별_기준.md)
