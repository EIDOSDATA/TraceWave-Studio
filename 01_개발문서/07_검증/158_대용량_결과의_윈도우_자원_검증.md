# 대용량 결과의 Windows CPU 메모리와 GPU 자원

2026-11-21 KST. 실제 Windows Studio의 등록과 새 세션 재열기에서 1075856824바이트의 두 주파수 필드와 복소 곡선 8개(각 100000점)를 다시 확인했다. 두 세션 모두 부분 단면 열 회, 정확 표본의 복소값과 결측 mask, 저장 개정, 파일 해시, 출처 및 제작·측정 조건 미정값이 일치했다.

| 자원 | 등록 및 조회 | 새 세션 재열기 및 조회 |
| --- | ---: | ---: |
| 프로세스 표본 수 | 299 | 168 |
| 표본 간격 중앙값 | 117.58 ms | 118.37 ms |
| 동일 프로세스 집합의 기준 private commit | 108.73 MiB | 107.68 MiB |

두 실행에서 Studio의 DXGI node 0 사용량은 준비 기준, 단면 열 회, 전체 보기와 정확 표본 보기에서 모두 local 18866176바이트(17.99 MiB), nonlocal 0바이트였다. GPU 값은 해당 UI 전환의 관찰값이며 연속 GPU 최고값이나 전체 시스템 GPU 합계는 계측하지 않았다.

Windows가 부모 PID를 재사용하면 이전 프로세스의 부모 기록만으로 자손을 오인할 수 있다. 이번 기록은 부모와 자식의 실제 생성 시각을 확인했고 준비 기준과 처리 구간에서 PID와 생성 시각이 같은 프로세스만 대조했다. Windows 작업 영역 서비스에서 작은 수치 조회용 OpenBLAS 동시 실행 수를 기본 1로 사용했다. 실행 환경에 별도 값이 있으면 해당 값을 유지한다. [계측 원시 기록](159_대용량_결과의_윈도우_자원_실행기록.json), [이전 등록 및 재열기](138_대용량_외부결과_제품검증.md)
