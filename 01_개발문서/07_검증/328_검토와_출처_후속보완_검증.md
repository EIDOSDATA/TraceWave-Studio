# 해석 검토와 출처 후속 보완

2026-11-23 KST. Windows 작업 환경에서 원호 패턴과 평면 IFA의 해석 조건, 격자와 봉인 결과를 사용했다. 제작 및 실측 조건은 미정이다.

## 검증 항목

- test_solver_review_followup은 두 형상에서 이름 붙인 조건의 원래 급전 저항과 현재 미정 상태를 비교한다. 재료와 급전 오류를 한 검토에서 반환하며 조회 전후 journal 상태가 같다. 표면 개구와 좌표로 고른 간극의 실제 셀을 점검하고, 변경된 개구 해시를 거절한다.
- 격자에서 경계와 교차한 셀 및 완전히 포함된 셀을 구분한다. 축별 최솟값으로 계산한 자유공간 Cartesian CFL 값은 openEMS의 실제 시간 단계와 구분해 표시한다.
- openEMS 실제 실행에서 원호는 910 단계에 30.57 dB, IFA는 3915 단계에 33.14 dB로 종료했다. 종료 근거를 포함한 로그 표본은 각각 2개, 17개였다. 원호의 1000 단계 상한과 IFA의 실행 시간 상한을 각각 재현하고 이전 완료 결과가 유지되는지 확인했다.
- 저장본 비교에서 삭제, 빈 값, 미정을 구분한다. 계산에 사용한 도체 폭, 비아 반경, 적층 두께와 제조 원본 및 정밀 편집 참조는 결과의 봉인 개정으로 표시한다.
- 인계 ZIP의 보고서는 같은 스냅샷의 최대 12개 결과를 상세 표시한다. 상세 범위를 넘긴 결과는 전체 목록과 결과 수에 남는다. 주파수별 S11 값은 report.json, 주요 수치와 조건 및 누락은 report.md에 있다.
- 원호의 X/Y/Z 격자선 61/53/30개와 IFA의 117/157/39개에서 표면 개구를 적용한 Windows 검토와 WSL 실제 준비가 같은 격자선, 해시 및 적용 보고서를 반환했다.
- 원호의 완료 결과로 인계 ZIP을 발행한 뒤 별도 ZIP 읽기 경로에서 개정과 계획 SHA-256 및 31개 주파수 표본을 대조했다.
- Windows Release 빌드, 네이티브 CTest 14개, 지정 h5py 및 NumPy 환경의 Python 회귀 시험 37개를 통과했다.

## 남은 검증

- 실시간 감쇠 표시, 비정형 간극 자동 검출, 문서 안의 그래프 렌더링과 명령별 제조 형상 변경 이력은 추가 구현이 필요하다.
- 상용 EDA에서 작성된 제조 데이터와 실물 교정 자료에 의한 독립 대조는 해당 자료를 확보한 설계에서 수행한다. 이번 검증은 내부 원호·IFA 입력과 WSL openEMS 실행으로 했다.
