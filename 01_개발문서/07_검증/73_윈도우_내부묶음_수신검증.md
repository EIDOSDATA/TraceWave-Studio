같은 Windows 호스트의 새 한글 경로에 압축을 풀었다. 별도 Python 가상 환경을 만들고 PATH를 Windows 및 System32로 제한했다. 묶음 안의 실행 파일과 서비스 소스로 Studio를 열어 실제 2D 편집, 저장, 스냅샷과 새 서비스 세션의 재열기를 확인했다. 두 세션의 저장 개정이 같았다. 테스트는 외부 CAD, WSL, 제조사 카탈로그 및 별도 수치 라이브러리 없이 수행했다.

도구 전용 테스트 3개와 요구 추적 감사 14개를 통과했다. 포함 파일을 참조한 증거와 raw SHA256이 같은지 검증했다. 1차 시제품 수신 시험에서는 Windows 환경 변수의 대소문자를 일반 dict에서 보존한다고 가정한 점을 실제 Windows에서 바로잡았다. 교정한 수신 도구로 시제품과 위 최종 묶음을 각각 검증했다.
