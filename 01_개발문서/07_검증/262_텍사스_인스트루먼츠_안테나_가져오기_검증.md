# TI 2.4 GHz 공식 패턴의 Windows 가져오기 검증

2026-11-21 KST. CC2511 USB IFA는 독립 IFA_USB.spl, CC25xx 접힌 다이폴은 CC25xxEM 공식 ZIP으로 읽었다. 별도 교환 worker가 알려진 바이트와 멤버를 확인한다. 두 파일의 inch Gerber 도체 범위를 mm로 대조했다. IFA의 경계 폭·높이는 14.4272 x 5.41528 mm, 접힌 다이폴 독립 파일은 44.6405 x 17.43456 mm다. 이 범위는 파일 전체의 동박 경계이며 다이폴의 IC 연결 패드도 포함한다.

2D 후보에서 상부 동박 대응, 미할당 넷, 좌하단 배치와 원문 생략 확인을 적용했다. 실제 Windows 캔버스에서 도체를 선택해 이동한 뒤 저장하고 서비스를 재시작했다. 같은 편집 좌표로 다시 열렸고 선택 파일을 분리한 뒤에도 프로젝트의 원본 바이트와 parser 근거를 확인했다. 기존 보드, 적층, 재료, 포트, 넷 및 미정 드릴 공구는 그대로였다.

GUI 두 시나리오에 35.277초가 소요됐다. 관련 서비스·형식 검사는 37개 중 36개 통과, 실행 조건 제외 1개다. 결과는 원문 형상과 편집 수명의 검증으로 기록한다. RF 해석, 수렴, 제조 및 실측은 미평가다. [라이브러리 계약](../05_기능설계/05_출력교환/07_제조사_안테나_라이브러리.md)
