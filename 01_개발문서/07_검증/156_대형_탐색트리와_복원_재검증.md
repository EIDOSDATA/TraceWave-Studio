# Windows 대형 탐색 트리와 편집 복원 재검증

2026-11-21 KST. 완료 계획 12번 F1. 18355907바이트의 편집 복원 ZIP을 별도 작업 영역으로 이동했다. 수신 전에 SHA256과 크기, 앞·뒤 전송 구간을 확인했다. 수신 후 snapshot의 봉인 사본과 프로젝트 원본을 송신본과 대조했다. 실제 Windows Studio에서 열고 메타데이터를 적용·저장한 뒤 프로젝트 서비스를 재시작해 다시 열었다. 표시 형상 10000개, 표시 생략 0개, 매개변수 1000개, 저장 개정 일치를 확인했다. 형상, 매개변수, 재료, 확장의 원문과 미정값을 대조했다.

별도 실행에서 대형 설계 약속의 같은 크기와 100000건 카탈로그의 마지막 행, 한글 필터 50000건을 확인했다. 최초 검색 응답은 47.95 ms, 다음 필터는 73.54 ms로 관찰됐으며 단일 기능 시험의 시점이다. 계속 조작하는 동안의 화면 합성이나 입력 지연 p95/p99는 따로 측정한다.

이전 동시 부하에서는 기본 통합 시험이 중간에 종료됐다. 서비스가 마지막 2D 페이지를 보낸 뒤의 GUI 구간을 분리해 계측했으며, 같은 진단 실행에서 캔버스 원문 파싱은 0.024~0.042초, 탐색 트리 재구성은 4.46~11.85초였다. 대형 행을 역순의 고정 위치에 넣어 원래 순서를 보존하고, 같은 프로젝트 개정과 필터에서는 선택 행으로 바로 이동하도록 했다. 기존 프로젝트를 열고 편집·저장·재시작까지 수행하는 시험에는 180초 제한을 적용한다. 실제 사용과 응답 기한은 이 시험 제한과 별개다.
