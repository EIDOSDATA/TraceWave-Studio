# RO4350B 수용 전력 변화와 관통홀 접합 대조

2026-11-22 KST. RO4350B의 저장된 7·8 분할과 합성 관통홀의 패드·접합·급전을 검증했다. 승인 기준과 사용자 제작 조건은 기존 기록을 따른다. [동박 면 임피던스 및 10 GHz 배럴 적분](286_동박_면임피던스와_관통홀_귀환_대조.md)

## 방사 도체 손실 비율이 증가한 구간

봉인 전압·전류를 표에 있는 세 주파수에서 직접 Fourier 합으로 계산했다. `Pacc = 0.5*abs(V)*abs(I)*cos(arg(V/I))`가 보존된 값과 상대 1e-10 이내로 일치했다. 8분할/7분할 수용 전력 비의 자연로그를 전압 크기, 전류 크기와 상대 위상 코사인의 항으로 나눴다. 로그 항에는 100을 곱했고, 전력과 절대 손실 열은 일반 상대 변화다.

| GHz | 로그 전압 항 % | 로그 전류 항 % | 로그 위상 코사인 항 % | 수용 전력 변화 % | 방사 도체 절대 손실 변화 % |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 2.40000 | 0.37500 | -2.32020 | -3.02197 | -4.84582 | -2.17877 |
| 2.44175 | 0.27757 | -2.43464 | -3.01115 | -5.03694 | -2.34327 |
| 2.48350 | 0.17179 | -2.52979 | -2.96933 | -5.18791 | -2.46829 |

세 점에서 수용 전력이 절대 손실보다 더 감소했다. 위상 코사인과 전류 크기의 감소가 정규화 비율 증가를 설명하며, 두 항을 독립 물리 원인으로 보지는 않는다. 두 원시 전압·전류를 공통 종료점 4.218935 ns에서 자르면 수용 전력 변화는 각각 -4.85143%, -5.03582%, -5.17849%였다. 끝부분 제외에 따른 차이는 0.01%p 이내였다. 국부 변화의 기존 최대 2.788446%와 기준 2% 판정은 유지했다.

## 공통 전류 적분면의 영향

전압 적분선은 두 격자 모두 mm 좌표 (9, 50, 0.797)에서 (9, 52, 0.797)까지였다. 전류 파일 헤더는 기본 격자 좌표를 출력하고, native 폐곡선은 같은 인덱스의 Yee dual 좌표에 놓인다. 7분할과 8분할의 실제 폐곡선 y는 각각 50.928571과 50.937500 mm였다.

저장된 rotH에서 원래 폐곡선의 면 플럭스를 구하고, 반 시간 간격의 위상을 맞춰 원시 전류와 대조했다. 세 점과 두 격자의 복소 전류 상대 오차는 최대 0.01784%였다. 공통 면은 y=50.933036 mm, x=[8.964286, 9.035714] mm, z=[0.742571, 0.877355] mm다. 두 폐곡선의 x-z 범위를 모두 담아 여기 edge를 부분 절단하지 않는다. 인접 y 평면을 선형 보간했고, 각 dual 셀에는 공통 면과 겹치는 넓이를 곱했다.

| GHz | 공통 면 수용 전력 변화 % | 원래 면으로 재구성한 변화와 차이 %p |
| ---: | ---: | ---: |
| 2.40000 | -4.85473 | -0.00074 |
| 2.44175 | -5.04680 | -0.00099 |
| 2.48350 | -5.19298 | -0.00125 |

기록된 전자계를 그대로 두고 적분면만 통일했을 때의 영향은 0.002%p 미만이었다. 이 범위에서는 표시 좌표나 적분면 이동으로 수용 전력 격자 차이를 설명하기 어렵다. 다음 비교에서는 급전 주변의 격자와 경계·도체·여기를 분리하고 독립 풀이에서 같은 물리 기준면을 유지한다. 전체 전력 수지와 개별 손실은 각각 판정한다. [원시 포트와 기록 필드 대조 도구](../../Code/tools/verify_ro_port_sensitivity.py)

## 축대칭 유한 패드와 접합

합성 기준 입력은 중공 내벽 반경 0.30 mm, 배럴 외벽 반경 0.40 mm, 패드 외벽 반경 0.90 mm, 높이 1.00 mm다. 위·아래 패드는 두께 0.10 mm씩, 두 접합은 두께 0.05 mm씩 지정했다. 패드와 배럴은 58 MS/m이고 접합은 같은 전도도 또는 그 1/10이다. 양쪽 패드의 외곽 원통에 1 V와 0 V를 가했으며 나머지 경계는 절연이다.

같은 축대칭 전도 문제를 셀 중심 플럭스의 유한체적과 선형 삼각형 약형의 유한요소로 각각 풀었다. 패드의 배럴 바깥 반경 구간, 축 방향 배럴과 접합에는 전류 보존과 Joule 적분으로 저항 하한을 구했다.

| 접합 전도도 비율 | 분석 하한 uOhm | 5120셀 유한체적 uOhm | 10240삼각형 유한요소 uOhm | 수치법 상대차 % |
| ---: | ---: | ---: | ---: | ---: |
| 1.0 | 107.22583 | 115.43392 | 115.17312 | 0.22645 |
| 0.1 | 177.78714 | 186.73490 | 186.64499 | 0.04818 |

320, 1280, 5120셀에서 두 수치법의 차이가 단계별로 줄었다. 모든 경우 단자 전류와 체적 전력의 상대 수지 오차는 5e-12 이내였다. 유한요소 최종 격자에서 접합의 전력 비중은 7.34%와 42.10%였고, 저항은 접합 전도도에 따라 증가했다. 합성 계산의 두 수치법 허용차 0.5%와 보존 검사를 모두 통과했다. 이 저항은 축대칭 DC의 유한 급전면과 접합에 적용한다. GHz의 표피·복사·접합 재료와 실제 포트 기준면에 대한 수용은 열린 상태다. [독립 접합 계산 도구](../../Code/tools/verify_pth_joint_reference.py)

## 실제 native 패드 급전

WSL2의 고정 openEMS/CSXCAD에서 8~12 GHz 31점의 합성 PTH를 실행했다. 선형 격자에서 경계를 명확히 참조할 수 있도록 양극의 위 패드는 직사각형으로 지정했고 음극은 기존 반대쪽 도체에 뒀다. 준비 결과에서 양단과 두 개 이상의 간극 edge, 위 패드·유한 도금 배럴·아래 패드·방사 도체의 같은 연결 성분을 확인했다. 실제 해석은 유한 표본을 기록했다. 별도의 XML 재입력에서 공기 내벽과 58 MS/m 배럴을 확인했다. 이 시험은 지정 합성 모델에서 포트가 물리는 연결과 해석 경로를 검증한다. 실제 접합 모델의 GHz 손실은 독립 정확도 근거가 필요하다. [native 시험](../../Code/tests/test_pcb_native.py)

고정 WSL2에서 위 두 PTH 시험, 기존 중공 배럴의 독립 적분 네 시험과 TE10 두 격자/재후처리를 통과했다. Windows에서는 축대칭 기준 계산을 두 번 실행해 같은 JSON을 얻었다. 포트만 대조할 때는 `verify_ro_port_sensitivity.py <report.json> <workspace>`를 사용한다. 위 공통 면 대조는 같은 명령에 `--common-aperture`를 추가하고 NumPy와 HDF5가 설치된 solver 환경에서 실행한다. 포트·필드 SHA256, 공통 면과 축대칭 격자별 결과를 보존했다.
