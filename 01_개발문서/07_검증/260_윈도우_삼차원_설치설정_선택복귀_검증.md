# Windows 3D 설치 설정의 선택과 복귀 검증

2026-11-21 KST. 실제 Windows Studio와 OCCT/OpenGL에서 표면층과 외부 STEP을 포함하는 표시 메시를 생성했다. 기존 프로젝트 편집의 도체를 선택한 뒤 3D에서 외부 STEP 고체와 솔더마스크를 직접 클릭했다.

- 외부 STEP 클릭은 해당 설치 물체의 이름과 ID로 외부 환경 폼을 연다. 솔더마스크 클릭은 해당 표면층의 이름과 ID로 표면층 입력을 연다.
- 각 폼을 닫은 뒤 2D, 3D, 트리, 속성이 처음 선택한 동일 도체로 돌아왔다. 저장 개정도 유지됐다.
- 외부 STEP 원본 파일의 위치를 이동한 뒤 저장 프로젝트를 다시 열어 원본 바이트, 출처, 미정 물성과 마스크 개구가 유지되는지 확인했다. 별도 STEP 출력 범위와 화면 표시 범위의 독립성도 확인했다.

물리 설정 및 CAD 계획 회귀 19개, 실제 Windows 설치 설정과 IFA 선택 회귀 2개가 통과했다. Windows 시험의 합산 시간은 58.239초였다. 이 기록은 설계 표시와 선택 검증이며 RF 해석과 실물 제조·측정은 미평가다.
