# Windows 방사 관측 목표 검증

2026-11-21 KST, Windows Studio Release와 WSL2 openEMS에서 실제 기록을 확인했다.

| 검증 | 확인한 결과 |
| --- | --- |
| 목표 편집과 저장 | 명시 주파수/방향/편파를 적용하고 하한과 급전 미정을 보존했다. 목표 대역 밖 주파수와 360 deg 방위각을 거절했다. |
| 독립 산술과 결과 서비스 | 선형 전계의 한 원형 성분이 총장보다 약 3.0103 dB 낮음을 확인했다. 영전계 성분은 -Inf, 미기록 각도와 다른 기준면은 미평가로 표시했다. |
| Windows 실제 openEMS와 재열기 | 솔더마스크 없음, 전체 피복 및 개구 적용을 다시 실행했다. 재열기 후 계산 원본의 목표를 선택해 10 GHz, theta 90 deg, phi 0 deg, Etheta 성분의 실현 이득과 시험 하한의 표본 판정을 확인했다. |

시험 하한 -100 dBi는 표시와 판정 흐름을 확인할 목적으로만 사용했다. 기존 목표 출처와 제작·측정 미정을 보존했다. 이 검증의 수치 판정 범위는 한 방향의 실제 기록 표본이며 수렴과 실물 검증은 미평가다.
