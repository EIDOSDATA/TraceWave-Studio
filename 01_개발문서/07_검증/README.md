# 검증과 요구 추적

R1 수용 여부를 판단할 때는 검사한 프로그램의 개정, 설치 방법, 실행한 PC를 함께 확인한다. 개발 PC와 별도 PC에서 확보한 검수 기록과 R1 판정을 아래에서 찾을 수 있다. [R1 작업표](../09_개발계획/04_현행버전_남은작업.md)

## R1 최종 수용에 필요한 기록

1. 인계한 RC10 Setup.exe의 SHA-256과 후보 개정을 [426 검증 기록](426_알원_알시십_후보_생성과_인계.md)에서 대조한다.
2. 인터넷에 연결된 별도 클린 Windows 11 x64 PC에서 기본 옵션으로 설치한다. 시작 메뉴와 제목 표시줄 아이콘, Windows 해석기 준비 상태를 확인한다. WSL2는 기존 Linux 환경을 재현할 때 선택한다.
3. 예제 편집, 저장, 재시작, 실제 Windows 해석 완료와 취소를 실행한다. 보존 결과와 원본 출처를 다시 열고 도면 또는 보고서를 출력한다. 복구 전후의 개정과 결과 해시를 대조한다.
4. Windows 설정에서 제거하고 같은 경로에 재설치한다. 앱 등록, 바로가기, 전용 런타임의 정리와 보존 작업의 재열기를 기록한다. 이 기록으로 R1 최종 수용을 판단한다. [요구별 판정](03_요구사항_추적표.md#ac-trace), [수신 절차](../08_운영환경/05_윈도우_내부검증_배포.md)
