# 검증과 요구 추적

기능의 적용 범위와 수치를 확인할 때는 해당 번호의 검증 보고서를 연다. 각 보고서의 미실행 항목과 판정은 그 시험 개정에 해당한다. 다음 개발 작업은 [기능 개발 순서](../09_개발계획/15_기능채택과_개발검증_순서.md), R1 수신 일정과 환경은 [현행 작업표](../09_개발계획/04_현행버전_남은작업.md)에서 확인한다.

곡면 통과 전력에서는 두 가지 오차를 구분한다. 같은 E/H에서 직사각면과 삼각면으로 계산한 값은 일치했다. 같은 물리적 +Z 단면에서 원래 풀이의 격자를 바꾼 두 결과의 차이는 세밀한 격자를 분모로 26.09%였다. [격자 비교](395_사용자면_전력적분과_폐곡면_검증.md), [삼각면 적분](406_삼각_곡면의_복소장_전력적분_검증.md)

## R1 검수 상태

- 원호와 IFA 설치 후보는 기록된 합성 외함과 이상 정합에서 전 대역 목표를 충족했다. 고정 RO4350B 사례의 7/8분할 편차는 사용자가 허용했다. 실측 자료가 있는 설계에서는 측정 비교를 선택할 수 있다. [설치 후보 대역](311_설치후보_격자와_외부경계_대역검증.md), [손실 편차](307_팔분할_일반격자_손실_수렴검증.md), [선택형 측정](298_선택형_측정_과거보고서_재열기.md)
- Windows의 실제 한글 입력, 오류 안내 및 혼합 DPI 검수는 끝났다. 과거 기준 PC 성능 계측은 실행 기록에 보존한다. [Windows 현장 검수](309_윈도우_한글입력과_접근성_검수.md), [화면별 평가](313_윈도우_실행화면_캡처와_사용성_검수.md), [잔여 화면 재검증](314_윈도우_잔여화면과_시간초과_재검증.md)
- 공개 후보 `r1-rc1`은 당시 개발 PC에서 수신했다. 다음 후보는 기능 개발이 끝난 개정에서 만든다. 인터넷이 연결된 별도 클린 Windows/WSL2 PC에서 설치, 예제 편집과 저장 및 재열기, 해석과 취소, 결과와 출처, 출력과 복구를 확인한다. [이전 후보와 해시](310_공개_검증후보_배포와_독립수신_인계.md), [수신 절차](../08_운영환경/05_윈도우_내부검증_배포.md)
