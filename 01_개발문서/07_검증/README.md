`02_실행화면`에는 실제 Windows GUI를 조작하며 확보한 화면을 보존한다. 설계 시안과 실제 실행 화면을 구분하며, 그림이나 단일 시험 결과를 전체 제품 수용으로 확대하지 않는다.

[03_도면렌더링](03_도면렌더링/README.md)은 실제 출력 worker가 생성한 PDF의 네 페이지다. Poppler 렌더링과 원본 파일의 수치 검사를 GUI 캡처 및 설계 시안과 구분한다.
