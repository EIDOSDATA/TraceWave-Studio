# 후보 조합 가중치로 보는 공차 결과

2026-11-23 / Windows 개발 PC / M10

공차 축이 두 개 이상인 최소, 공칭, 최대 카테시안 연구의 후보 순위에서 후보 조합별 가중치와 그 출처 또는 가정을 입력한다. 후보 목록의 번호로 지정하고 생략한 후보는 가중치 0으로 처리한다. 축별 독립 가중치와는 별도로 조회한다. 보존된 후보의 모든 목표가 통과했는지 확인해 통과, 실패, 미확인의 확률 질량과 목표 통과 범위를 반환한다. 원래 연구와 평가를 변경하지 않는다.

두 직렬 저항의 3 x 3 회로 연구에서 최소-최소와 최대-최대 조합만 2 대 3으로 가정했다. 독립 회로식으로 정한 최소-최소는 통과하고 최대-최대는 실패한다. 결합 분포의 통과 확률은 40%, 실패 확률은 60%였다. 같은 주변 확률의 독립 가정에서는 통과 확률이 16%였다. 최대-최대 평가가 누락되면 미확인 60%, 통과 범위 40~100%가 됐다.

잘못된 후보 번호, 중복, 전부 0, 잘못된 단위·형식, 누락 출처, 축별 가중치와 동시 설정을 거절했다. 연구를 재열기한 뒤 같은 입력의 결과와 응답 해시를 대조했다. Windows Release 빌드와 CTest 14건을 통과했다.

숫자는 회로 시험의 가정이다. 실제 공정의 조합 발생 빈도, 반복 시료 수, 수율의 신뢰구간 검증에는 제조 공정 데이터가 필요하다.
