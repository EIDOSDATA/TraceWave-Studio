# 371. 대화식 배선과 구리면 자동 재채움

## 사용

- 2D의 "배선"에서 다른 넷과의 최소 간격을 mm로 입력한다. 현재 층에서 넷이 지정된 시작 도체를 클릭하고 선폭과 경유점을 지정한다. 커서를 움직이면 선폭이 있는 다음 구간이 보인다. Backspace로 마지막 점을 지우고 Enter로 전체 경로를 적용하거나 Esc로 취소한다. 새 구간은 시작 도체의 넷, 도체층, 재료 참조, 해석 및 출력 포함 상태를 이어받는다.
- 경로는 2~33개 점을 잇는 직선 구간이다. 전 구간의 실제 선폭, 끝단, 도체층을 지나는 비아, 다른 넷과의 거리, 기판 외곽, 해당 층에 적용한 금지 영역과 기계 가공을 검사한다. 위반 시 구간 번호와 대상 또는 원인을 알려 준다. 한 구간이라도 충돌하면 전체 배선이 적용되지 않는다.
- 넷을 지정한 다각형 영역을 선택하고 정밀 편집에서 "구리면 자동 채움"을 선택한다. 다른 넷 및 금지 영역과의 간격, 곡선을 다각형화할 때 허용하는 거리 오차를 입력하고 실제 채운 경계를 검토한다. 원래의 꼭짓점, 기존 구멍과 수량의 출처, 설정을 편집 기록에 보관한다.
- 배선이나 장애물, 금지 영역, 기판 측 조건을 변경하면 그 개정에서 구리면도 다시 계산한다. 배선의 간격이 구리면 설정보다 클 때는 재채운 뒤에도 배선 간격이 확보되는지 검사한다. "구리면 원래 경계 복원"으로 자동 재생성을 종료하고 최초 경계를 다시 편집할 수 있다.

## 검사 방법과 범위

Shapely 2.2.0과 GEOS 3.14.1로 원래 영역에서 각 장애물의 금지 거리를 뺀다. 구멍이 있는 기판 및 금지 영역, 같은 층의 다른 넷과 넷 미지정 도체, 해당 층을 관통하는 비아를 반영한다. 원래 꼭짓점의 수량을 재사용하고 추가한 꼭짓점은 mm로 저장한다. 다각형화 오차를 포함해 실제 장애물과의 거리를 재검사한다. 서로 다른 넷의 자동 구리면이 있으면 상대의 원래 외곽을 금지 경계로 삼는다. 기존 급전 단자가 필요한 동박을 잘라내는 결과는 적용하지 않는다.

현재 저장하는 구리면 한 객체는 외곽 하나, 구멍 8개 이하, 전체 꼭짓점 64개 이하이다. 다른 넷에 의해 구리 섬으로 분리되거나 면적 전체가 제거되면 영역을 나누어 지정하라는 진단이 나온다. 같은 층의 클릭 경유점 배선과 지정한 간격을 검사하며, 장애물을 밀어내는 배선과 층 전환 비아 자동 삽입은 이번 기능 범위 밖이다.

## Windows 검증

- 원호 보드에서 다른 넷과 충돌하는 두 번째 구간, 기판 밖 끝점, 시작 도체를 벗어난 첫 점을 거절하고 개정이 그대로인 것을 확인했다. 유효한 3개 점은 2개 도체로 저장되고 같은 넷과 폭 0.2 mm를 유지했다. 실행 취소 한 번으로 원본과 일치했다.
- IFA 접지면에서 독립된 신호선과의 간격 0.25 mm, 근사 허용값 0.01 mm로 동박을 채웠다. 첫 점 (11, 10) mm에서 (11, 12), (13, 12) mm로 배선하자 두 구간과 접지면이 한 개정에 반영되었다. 해석형 경계 간 최소 거리로 두 구간 모두 0.25 mm 이상임을 별도로 대조했다. 배선 요구 간격을 0.8 mm로 높이면 현재 구리면 간격이 부족하다는 진단을 확인했다.
- IFA에서 취소와 다시 실행, 저장과 서비스 재열기 후에 구리면 경계와 구멍, 급전, 기대 연결을 대조했다. 원래 경계 복원은 채우기 전 다각형과 수량 전체를 되돌렸다.
- Windows Release GUI에서 원래 선을 클릭하고 경유점을 추가한 뒤 Backspace로 되돌리고 두 점을 다시 찍었다. Enter가 보낸 시작 도체, 점 3개, 0.25 mm 간격을 대조했다. 실제 마우스와 키 이벤트를 사용하는 2D GUI 회귀 1개가 90.457초에 통과했다.
- 배선 및 기존 캔버스 서비스 회귀 23개가 통과했다. 구리면 요구 간격 재검사와 기능 조회를 포함한 최종 집중 시험 3개도 통과했다.
- 검증 코드는 `Code/tests/test_interactive_route.py`와 `Code/tests/test_gui_process.py`에 있다. 예제 넷과 수치는 편집 경로를 확인하기 위한 입력이다.
