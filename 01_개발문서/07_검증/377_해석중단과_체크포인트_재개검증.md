# 해석 중단과 체크포인트 재개 검증

2026-11-23 / 단계 1 / Windows 개발 PC의 TraceWave-Dev WSL2

## 사용 조건

준비 단계에서 생성한 pcb.xml을 사용한다. 이번 프로필은 단일 포트 PCB, 단일 계산 스레드, U/I 프로브와 수치로 표현한 재료를 지원한다. 방사 및 필드 기록, 다중 포트, 분산 MPI는 검증 범위 밖이다. 제품 GUI 해석 작업 및 스윕의 재실행은 별도 경로이다.

WSL의 일반 사용자로 실행한다. 검증 환경은 Python 3.12.3, openEMS 0.37.0, DMTCP 4.2.0, 커널 6.18.33.2-microsoft-standard-WSL2이다. openEMS는 ~/rfad-runtime/openems/0.37.0, DMTCP는 ~/rfad-runtime/dmtcp/4.2.0에 설치한다. 개발 PC에서는 빌드한 DMTCP 설치 트리를 이 위치로 복사했다. 새 환경에서 DMTCP를 소스 빌드하면 configure에 이 설치 경로를 지정한다. [DMTCP 소스 및 설치](https://github.com/dmtcp/dmtcp), [DMTCP 시작 옵션](https://dmtcp.github.io/manpages/dmtcp_launch.html), [조정기 명령](https://dmtcp.github.io/manpages/dmtcp_command.html)

## 명령

아래 명령은 저장소 루트의 WSL 셸에서 실행한다. 첫 번째 응답의 job 값을 나머지 명령의 JOB_ID 자리에 넣는다.

~~~sh
python3 Code/tools/pcb_fdtd_checkpoint.py start --xml /path/to/prepared/pcb.xml
python3 Code/tools/pcb_fdtd_checkpoint.py status JOB_ID
python3 Code/tools/pcb_fdtd_checkpoint.py suspend JOB_ID
python3 Code/tools/pcb_fdtd_checkpoint.py resume JOB_ID
~~~

- start는 준비 XML을 보존하고 전용 조정기로 엔진을 시작한다. suspend는 양쪽 프로브가 실제 표본을 기록했는지 확인하고 프로세스 메모리와 열린 파형 파일을 저장한 뒤 엔진을 멈춘다. resume는 저장한 이미지에서 이어서 계산하며 종료 통계와 U/I 파형을 반환한다.
- 같은 사용자의 /var/tmp/tracewave-fdtd-UID/JOB_ID 아래에 입력, 로그, 이미지, 상태와 출력이 있다. 중단 당시의 U/I 파일은 history 아래 시도 번호별로 보존한다. 실패 후 재시도하거나 완료한 작업에 resume를 다시 호출할 수 있다.
- 체크포인트에는 진행 중인 계산 메모리가 들어 있다. 시스템 임시 정리로 작업 폴더나 사용자별 봉인 키가 지워지면 해당 작업을 재개할 수 없다. 입력 및 지문이 유지되는지 확인한 환경에서 바이트 결과를 비교했다. 별도 PC, 다른 WSL 커널, WSL 재부팅 후 복원 검수는 수행하지 않았다.

## 검증

두 실제 PCB 준비 XML에서 검증용 최대 스텝 2700과 종료 임계 1e-18을 사용했다. 같은 입력의 연속 실행과, 파형 기록 중 엔진을 중단한 뒤 별도 CLI 프로세스로 재개한 실행을 대조했다. 시간과 전압 및 전류 표본의 모든 데이터 행이 바이트 단위로 같았다. 두 계산 모두 검증용 최대 스텝에서 종료했다.

| 입력 | 네이티브 셀 수 | 실제 종료 스텝 | 일치한 전압 / 전류 행 |
| --- | --- | --- | --- |
| 원호 | 84252 | 2700 | 271 / 271 |
| IFA | 659525 | 2700 | 56 / 56 |

- 준비 XML, 고정 경로의 openEMS 및 DMTCP 실행 구성, 실제 계산 프로세스에 적재된 공유 라이브러리와 이미지 및 열린 파일 보조 자료를 해시로 대조한다. 작업 상태에는 사용자 전용 키를 사용한 HMAC을 붙인다. CLI는 이미지 경로, 사용자 실행 명령 또는 재개 셸 스크립트를 입력받지 않는다.
- 생성된 작업에서 보조 U 파형에 1바이트를 추가했을 때 재개를 거부했다. 기존 U/I 출력이 그대로였고 원래 보조 파일을 복원한 뒤 같은 이미지로 다시 실행했다. 결과 파일 앞부분도 체크포인트에 저장된 두 파형과 대조한다.
- 회귀 시험은 RFAD_CHECKPOINT_ARC 및 RFAD_CHECKPOINT_IFA에 각각 단일 포트 준비 XML 경로를 지정한 WSL에서 실행한다.

~~~sh
python3 -m unittest discover -s Code/tests -p test_pcb_fdtd_checkpoint.py -v
~~~
