# Windows 키보드와 결과 표시 접근성

2026-11-21 KST. 완료 계획 12번의 실제 Windows Studio에서 150% 배율로 프로젝트 탐색과 속성 입력을 확인했다. Tab으로 탐색 영역에 들어간 뒤 F6으로 편집 화면과 속성으로 이동했다. 접근성 트리에 기본 객체 이름 `선 01`, `선 02`와 속성 이름 `이름`이 표시됐다. 접근성 값 지정으로 한글 이름을 입력하고 변경을 적용한 뒤 Ctrl+S로 저장했다. 창을 닫고 다시 열어 제목, 속성 값, 저장 상태가 일치하는 것을 확인했다.

결과 비교는 색과 함께 네 가지 선 모양, 원과 사각 점을 조합한다. 연속 표본은 하나의 경로로 그려 선 모양을 유지하고 결측과 표본 번호가 건너뛴 위치에서는 연결을 끊는다. 점의 화면 간격을 제한하고 모든 실제 표본의 마커 선택을 유지한다. 원본 곡선 이름 옆의 텍스트와 대용량 결과의 출처 상세에서 선과 점 구분을 읽을 수 있다.

2D 캔버스는 OS 고대비 색을 글자, 선택 테두리, 치수, 끝점, 작업 안내에 사용한다. 비교 그래프와 표는 OS 색 변경에 다시 그린다. 실제 Windows 결과 회귀에서 원본·과거 개정·Smith 차트·곡선 비교·내보내기·재열기와 측정 조건 미정 상태를 확인했다. 별도 기록 필드의 위치·주파수 변경 열 회와 재열기도 통과했다.

한국어 입력기는 설치되어 있었으나 도구의 한/영 전환 시도에서는 조합이 재현되지 않았다. Windows 스크린리더 음성, 앱 실행 전후 실제 대비 테마 변경, 배율이 다른 두 화면 사이 이동은 이 기록의 시험 범위에 포함되지 않는다. [실행 기록](153_키보드와_결과표시_접근성_실행기록.json)
