# 직선과 원호의 중심선 분할 및 연장 검증

2026-11-23 / Windows 개발 PC / CAD09

정밀 편집에서 열린 선 또는 원호 하나를 선택한다. 분할은 시작점 기준 중심선 길이의 비율로 지정하고, 시작 쪽은 원래 ID를 쓴다. 연장은 시작점 또는 끝점에서 같은 직선 또는 같은 원을 따라 지정 길이만큼 진행한다. 원호의 중심, 반경, 방향과 도체 층·넷·재료의 출처를 보존한다. 급전, 기대 연결, 비아 패드 또는 스케치 구속이 직접 참조한 객체는 대상에서 제외한다. 변경되는 치수의 매개변수 연결도 보존한다.

- 길이 5 mm의 직선을 40%에서 나눠 두 끝이 (2.2, 3.6) mm에 놓이는 것을 확인했다. 뒤쪽 끝을 2.5 mm 연장해 (5.5, 8) mm가 됐다.
- 반경 20 mm, 전개각 -130도인 원호를 30%에서 나눠 전개각 -39도와 -91도를 얻었다. 첫 조각의 시작 쪽을 2*pi mm 연장해 시작각 43도와 전개각 -57도를 확인했다.
- 폐곡선을 만드는 연장과 끝점에서의 분할은 차단했다. 원본 ID, 실행 취소·다시 실행과 저장·재열기를 대조했다.
- 원호 기판의 방사 원호와 IFA 방사 직선을 각각 분할했다. 해석 준비 후 원래 급전과 넷, 기대 연결이 일치하고 분할된 두 도체가 실제 계획에 포함되는 것을 확인했다. Windows Release 빌드와 CTest 14건도 통과했다.

경계까지의 자동 연장, 참조를 가진 도체의 재연결과 스케치 일반 연립 구속은 후속 범위다.
