# KiCad 재저장본의 MCP 왕복 검증

2026-11-20 KST. [공식 MCP의 KiCad 보드 발행 검증](39_엠시피와_키캐드_교환_검증.md)을 실제 KiCad 재저장과 MCP 수신·적용까지 이어서 검증했다. 검증에는 독립된 합성 작업 영역을 사용했다.

1. 공식 Python SDK 1.26.0의 stdio 연결로 고정 스냅샷을 검토하고 KiCad 보드를 발행했다. 기존 작업을 재사용하는 요청 키와 별도 재검수를 확인했다.
2. 실제 KiCad 10.0.8의 `pcbnew.LoadBoard`로 발행본을 열고 `SaveBoard`로 한글 파일명의 새 사본에 저장했다. 원 발행본의 바이트와 도체층 2개, 트랙 2개, 비도금 완성 홀 1 mm를 대조했다.
3. 같은 공식 MCP 클라이언트에서 KiCad가 다시 쓴 파일의 SHA256을 선언하고 여러 1 KiB 청크로 보냈다. 기존 격리 reader로 해석한 뒤 F.Cu/B.Cu와 대상 도체층, 넷 이름과 대상 넷의 대응을 요청에서 명시했다. 검토에서 확인한 손실 항목을 해시로 확인하고 검토 해시를 제출해 한 명령으로 적용했다. 같은 적용 키를 재전송하면 처음의 결과를 반환했다.
4. 새 개정을 저장하고 출력 환경 없이 공식 MCP 서버를 다시 실행했다. 원문 수신 기록과 상태를 그대로 읽었다. 별도 서비스 세션으로 저장 개정, 기존 적층과 재료, 원래 홀의 공구 미정과 출처, KiCad 재저장 원문 바이트 및 이전 개정의 원본을 대조했다.

[왕복 통합 시험](../../Code/tests/test_mcp_pcb_exchange_process.py)과 일반 MCP 회귀를 Windows에서 실행해 총 3개가 통과했다. [실행 기록](48_키캐드재저장본_엠시피왕복_실행기록.json)

검증한 범위는 이 합성 PCB의 고정 KiCad 보드 출력, 실제 KiCad 재저장, MCP 수입 대응 및 원문 보존이다. 다른 EDA 파일의 의미 변환, 외부 host별 상호 운용, 제작 및 RF/실측 수용에는 별도 증거가 필요하다.
