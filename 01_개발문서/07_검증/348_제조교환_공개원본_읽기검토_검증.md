# IPC-2581 Rev C 공개 원본 읽기 검토

검증일 2026-11-23

PCB 원문 가져오기에서 IPC-2581 Rev C 읽기를 선택한다. 압축에서 꺼낸 UTF-8 XML 1개를 보존하고 격리 파서로 읽는다. 검토에는 층 기능, 면, 적층 두께, 각 보드 정의의 논리 및 물리 넷, 윤곽, 도금 분류, 홀 및 부품 수가 표시된다. 상세 보고서는 부품 위치, 명시 회전, 홀과 넷의 앞 16개 표본을 원본 단위와 환산값으로 기록한다. 누락된 각도, 도금과 재료는 추정하지 않는다.

- Cadence Allegro Round Test Card의 전체 Rev C XML 3,025,111 bytes를 Windows에서 256 KiB 청크로 전송하고 별도 파서로 읽었다. SHA256은 8d19d1150f03c4e0a63d50ebdc603e3ebd293ff5b5e9aee2be53c18ef04db70e였다. [IPC-2581 Consortium 공개 사례](https://www.ipc2581.com/ipc-2581-revc-test-cases/)
- 별도 Windows .NET XML 판독에서 제조층 17개, 적층층 11개, 논리/물리 넷 각 261개, 부품 42개, 홀 174개와 절삭 11개를 대조했다. 홀 분류는 VIA 108개, PLATED 63개, NONPLATED 3개다. 원문 첫 홀의 0.024 inch 직경은 0.6096 mm, X 1.650 inch는 41.91 mm였다. 적층 전체 0.047 inch는 1.1938 mm였다.
- 입력 보존 후 저장과 재열기에서 원래 바이트, 해시와 읽기 보고서를 동일하게 읽었다. 다른 개정의 XML, 지원 단위가 미정인 보드 및 DTD가 있는 입력은 검토 경계에서 차단한다. 읽기 검토는 현재 설계의 변경을 허용하지 않는다.

Rev C 원본의 구조를 읽는 범위다. 전체 제조 형상과 넷을 편집 모델에 반영하는 기능, 재출력, 독립 제조 도구의 왕복, XSD 전체 적합성 및 실제 제작은 후속 검증으로 남아 있다.
