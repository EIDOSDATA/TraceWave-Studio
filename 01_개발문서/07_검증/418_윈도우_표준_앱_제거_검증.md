# Windows 표준 앱 제거 검증

2026-11-24 KST. TraceWave Studio 단일 Setup.exe가 현재 Windows 사용자에게 앱 이름, 버전, 아이콘, 제거 명령을 등록한다. 같은 설치 경로에 새 후보를 설치하면 같은 항목을 갱신한다. Windows 설정의 설치된 앱 또는 제어판의 프로그램 및 기능에서 제거를 시작한다. [Microsoft의 Windows 앱 제거 안내](https://support.microsoft.com/en-us/windows/apps/uninstall-or-remove-apps-and-programs-in-windows) [수신과 설치 절차](../08_운영환경/05_윈도우_내부검증_배포.md)

제거는 설치 위치의 앱, 전용 Windows 런타임, 설치 캐시 및 해당 시작 메뉴 바로가기를 대상으로 한다. 제거기는 인터넷 연결이나 원래 Setup.exe 없이 실행된다. `Workspace`의 프로젝트와 과거 해석 결과, 사용자 설정, 선택 설치의 WSL 데이터는 보존한다. 같은 경로에 다시 설치하면 작업 영역을 사용한다.

## 실행 기록

- Windows PowerShell에서 한글과 공백을 포함한 경로로 제거 명령을 등록했다. 기존 버전을 유지하는 중간 단계와 새 설치 완료 후 같은 키의 버전 갱신을 대조했다.
- Windows에 등록한 제거 명령을 실행해 앱 등록과 설치 파일을 정리하고 작업 데이터를 보존했다. 내부 연결을 제거하되 연결 대상 자료를 보존했다. 설치 폴더 바로 아래의 경로가 연결일 때는 오류를 표시하고 앱 등록과 설치 파일을 남겼다.
- Windows CTest 14개와 Windows 앱 제거 및 묶음 시험 6개가 통과했다.
- 개발 PC에 RC5 앱 파일과 실제 PCB 결과를 복사한 별도 설치 경로를 만들었다. 새 Setup.exe의 기본 해석 옵션으로 설치해 `windows_ready=true`, `simulation=ready`, `solver_platform=windows`와 Windows 등록 하나를 확인했다. 시험 중 시작 메뉴 갱신과 자동 실행은 생략했다.
- 실제 설치 중이거나 설치된 전용 Python이 살아 있을 때 제거 요청이 거절됐다. 프로세스가 닫힌 뒤 Windows에 등록된 무인 제거 명령을 실행했다. 앱과 전용 런타임, 캐시 및 해당 경로의 등록이 제거됐다. 다른 경로의 실제 시작 메뉴 바로가기와 검증용 WSL 데이터는 보존됐다. 저장한 결과 파일 SHA-256도 `449b273ca63cbffe374d7cac58d0e57d2dce5db544b74641afc346182265f468`로 일치했다.
- 같은 Setup.exe를 같은 경로에 기본 옵션으로 다시 설치해 Windows openEMS 준비와 앱 재등록을 확인했다. 재설치한 서비스에서 과거 결과 `28336273-c9b5-4700-9c35-2ba11c3278c2`를 열고 봉인된 해시를 원본과 대조했다. 검증용 설치를 다시 제거한 뒤 작업 영역과 WSL 데이터만 남았음을 확인했다.

## 후보와 검수 조건

`r1-rc6`의 내장 소스 개정은 `d8fbcc48d23fb86f33785971f443b21106d35c80`이다. Setup.exe는 15,327,744바이트이고 SHA-256은 `a25f101d1e42e7e4b6b89009e72b188cf2b8d9d4edd710837843ab48bfc03bbc`이다. 내장 ZIP의 SHA-256은 `10a55f8bfd30d3cf6a9147b196cd9fd3b32f3e95263d426afa66997c66cd920b`이다. GitHub 게시 자산 두 개를 다시 내려받아 파일의 SHA-256과 태그의 개정을 대조했다. [RC6 설치 파일과 SHA-256](https://github.com/EIDOSDATA/TraceWave-Studio/releases/tag/r1-rc6)

RC6는 Authenticode 서명 없는 검증 후보다. 서명된 외부 정식 배포를 위해서는 게시자 서명 환경이 필요하다. 최종 R1 수용은 별도 온라인 클린 Windows 11 x64 PC에서 설치, 시작 메뉴와 Windows 설정의 표시, 해석과 취소, 제거와 재설치 및 데이터 재열기까지 확인한 뒤 판단한다.
