# Windows PDF 생성 중 취소와 이전 출력 재열기

2026-11-21 KST. 실제 Windows Studio에서 고정 입력을 검토해 PDF를 생성하고 별도 검수 결과를 게시했다. 같은 입력을 다시 검토하여 새 PDF 생성 worker를 소유한 뒤 GUI의 작업 취소 버튼을 눌렀다. 이 경로를 새 작업 영역 세 곳에서 반복했다.

| 회차 | 버튼 잠금 (ms) | Studio 접수 (ms) | native 트리 회수 (ms) | Studio 종료 표시 (ms) |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0.477 | 104.978 | 21.396 | 237.187 |
| 2 | 0.261 | 66.253 | 7.782 | 177.832 |
| 3 | 0.034 | 50.007 | 9.572 | 167.331 |

취소한 작업의 artifact가 게시되지 않았고 이전 PDF와 검수 manifest의 SHA256이 일치했다. 저장한 개정, 원래 설계, 사용한 출처와 미정값을 별도 출력 worker 없이 다시 열어 확인했다. 같은 Release에서 실행 중인 PDF 재검수 취소도 한 번 다시 통과했다.
