# Windows 유전체 케이스 설치 해석

2026-11-21 KST. Windows Release Studio와 실제 WSL2 openEMS에서 같은 PCB와 급전을 사용해 기판 단독 및 하부 개방 케이스의 계산을 완료했다. 시험 입력은 16 x 12 mm PCB, 50 ohm 갭 급전, 8~12 GHz 31표본, 10 GHz 방사 기록, 15도 각도 격자다. 케이스 외형은 20 x 16 x 3.5 mm, 벽과 덮개는 1 mm다. 상대 유전율 3.5와 손실 탄젠트 0.01은 시험용 명시값이다.

| 10 GHz 관찰량 | 기판 단독 | 케이스 포함 |
| --- | ---: | ---: |
| S11 크기 (dB) | -4.4892 | -4.5309 |
| 방사 효율 | 98.917% | 98.326% |
| 총 효율 | 63.733% | 63.686% |
| 최대 실현 이득 (dBi) | 0.232 | 0.606 |

Studio에서 케이스를 추가하고 활성 시나리오를 저장했다. 다시 연 프로젝트에서 두 해석의 원본을 고르고 S11 공통 표본 31점, 두 효율, phi 0도와 90도의 실현 이득 단면을 제공하는 비교 창을 확인했다. 봉인된 native XML에서 케이스 원본 ID를 가진 재료와 상자 다섯 개를 확인했다. OCCT에서 케이스는 하부가 열린 유효 단일 고체이며 체적은 490 mm³다.

저장 전후 PCB, 적층, 도체, 급전, 재료, 출처와 측정 자료를 대조했다. 해석에서 제외한 참고 부품의 물성과 치수는 미정으로 남았고 케이스 입력의 변경 사유를 다시 읽었다. 위 결과는 해당 시험의 수치 계산과 GUI 왕복 기록이다. 제작 물성, 수렴과 실측 판정은 미평가 상태다.
