# Windows 형상 작업 취소와 출력 검증

2026-11-21 KST. CAD 취소 버튼과 메뉴를 먼저 비활성화한다. 작업 ID를 받은 경우 서비스에 즉시 취소를 보내고, 그 뒤 전체 작업 표와 도킹 상태를 갱신한다. 접수 오류가 돌아오면 기존 CAD 상태를 표시하고 취소 동작을 복원한다. 서비스 이벤트가 도착할 때까지 실제 종료를 기다린다.

실제 OCCT를 연결한 Windows Studio에서 STEP 생성, 해시가 일치하는 3D 표시, CAD 중 편집·저장, 다음 작업 취소와 버튼·메뉴 잠금, 이전 산출물 및 재시작 후 3D 복원을 검증했다. 필수 두께가 미정일 때는 CAD 파일과 3D를 게시하지 않았다.

실제 Windows 출력 화면은 외부 프로세스의 도면 생성·재검수, 출력 참조와 원문 재열기를 확인했다. 출력 작업의 실행 중 취소는 별도 서비스 시험에서 응답과 소유 자식 종료를 검증했다. GUI의 CAD 및 출력 작업군별 취소 지연과 지정 로그 부하의 최종 수용은 별도 범위다. [실행 기록](211_윈도우_형상과_출력_취소_실행기록.json), [WSL2 실제 해석 취소](208_최종_윈도우_동시부하_해석취소_검증.md)
