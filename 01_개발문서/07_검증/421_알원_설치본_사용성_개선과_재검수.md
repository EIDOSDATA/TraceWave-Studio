# R1 RC8 설치본 사용성 개선과 재검수

2026-11-24 KST. [R1 RC6 화면별 사용성 진단](420_알원_설치본의_화면별_사용성_진단.md) 및 검수 보고서의 UX-01~UX-10을 Windows 기본 실행 경로에 반영했다. 150% 환경에서 원형 PCB와 기술 도면의 복제본으로 확인했다. 승인 화면 84개, 문헌 원문, 재료 관측 출처, 사용자 저장값과 이전 해석 파일은 보존했다.

## 개선 항목

| 항목 | 반영한 변경 | 검증 근거 |
| --- | --- | --- |
| UX-01 결과 탐색 | 결과 원본의 기본 목록에 현재 개정의 해석 실행과 네트워크 자료를 함께 표시한다. 종류별 건수와 숨긴 자료를 함께 보는 방법을 안내하며 과거 개정과 연구 후보를 선택할 수 있다. 해석 완료 화면의 버튼 및 원문 등록 완료가 해당 결과를 직접 선택한다. 기록 입력과 비교로 이어지는 조작도 제공한다. | 실제 Windows 화면에서 완료된 openEMS 결과로 바로 이동하여 네트워크 표본 31개를 조회했다. 과거 원본 선택, Smith 및 비교, 내보내기 및 재시작 시험을 통과했다. 측정 비교에서 합성 Touchstone 5표본을 등록하자 자료가 자동 선택되고 기록 추가가 활성화됐다. 등록을 한 번의 실행 취소로 되돌린 뒤 원문을 다시 여는 서비스 시험을 통과했다. |
| UX-02 PCB 자료 검색 | 검색 창에서 로컬 SQLite 인덱스를 연결하거나 재료와 층을 직접 입력한다. 사용 가능한 인덱스는 현재 서비스가 읽기 전용으로 연다. 연결 실패 시 기존 인덱스와 프로젝트가 유지된다. | 시험용 인덱스 연결부터 물성 관측 검색 1건, 3층 제안과 적용 전 미리보기까지 실제 화면에서 확인했다. 기존 층 참조와 적용 순서를 검증하는 GUI 시험, 미연결 환경에서 수동 적용하는 시험을 통과했다. |
| UX-03 해석 준비 | 기판과 급전 누락에서 관련 입력으로 이동한다. 종료 및 기록 범위는 조건 검토 전에도 다음 조작을 안내한다. 범위 주파수는 Hz, MHz, GHz로 입력할 수 있으며 격자, 경계와 기록 조건을 읽는 순서를 정리했다. 입력 식별자와 해시는 상세 창에서 복사할 수 있다. | Windows 해석 설정에서 2.4~2.4835 GHz와 2,400,000,000~2,483,500,000 Hz의 같은 범위를 확인했다. 검토 경고의 급전 속성으로 이동하고 격자 값을 유지한 채 돌아왔다. 검토 전 기록 안내, 비용 검토 버튼과 완료 결과 직접 열기도 확인했다. 새 원형 기판의 물성 및 급전 누락은 실행에 앞서 차단하는 GUI 시험을 통과했다. |
| UX-04 데이터 가독성 | 네트워크, Smith, 편파, RLC, 적층에 짧은 숫자와 단위를 적용했다. 인계 요약에서 개정과 원본 해시를 따로 조회한다. 표에 표시하는 숫자를 줄여도 저장 및 교환의 원래 정밀도는 유지한다. | 실제 150% 화면의 네트워크 표와 결과 상태를 확인했다. 원시 RF 비교, 네트워크 내보내기, GUI 표시 단위 및 결과 모델 시험을 통과했다. 0 크기와 무한값의 해석은 상세 영역에 남는다. |
| UX-05 출력과 검수 | 기본 이력은 현재 출력 형식만 보여 주며 전체 형식 전환, 개정 표시, 완료 파일 및 폴더 열기를 제공한다. | 실제 PDF 출력과 새 읽기 검수, PCB/CAM과 KiCad 교환 및 재시작 시험을 통과했다. STEP 파일 열기는 Windows 앱 선택 창까지 확인했다. |
| UX-06 설계 규칙 | 규칙 판정을 결과 유형으로 필터링한다. 미평가 사유에서 제조 규칙 편집을 열고 연결 성분을 설계 화면에서 강조한다. | 규칙, 연결 검사, 출처 및 저장 후 다시 열기 GUI 시험을 통과했다. |

## 3D 계측

Windows 150% 배율에서 동일한 원형 PCB 복제본과 YZ 단면 X = 0 mm를 사용했다. 파일 검증에서 첫 OpenGL 프레임까지는 앱의 3D 로그에 기록한다. 이 시간은 백그라운드 CAD 생성 전체를 포함하지 않는다. 탭 전환 값은 작업 공간 선택 처리에 걸린 시간이다.

| 실행 조건 | 첫 3D 프레임 | YZ 단면 표시 | 3D에서 결과로 |
| --- | --- | --- | --- |
| 별도 통합시험 종료 후 | 248 ms | 8 ms | 처음 4,476 ms |
| 통합시험 및 새 CAD 갱신과 겹친 세션 | 복원 296 ms, 갱신 3,068 ms | 11 ms | 처음 9,746 ms, 다시 전환 423 ms |

단독 실행의 첫 결과 이동 중 새 위젯 구성에 3,731 ms, 표시 설정에 0 ms가 기록됐다. 첫 작업 공간 구성 지연은 남아 있고 사용자는 상태 표시줄에서 준비 중임을 확인할 수 있다. 더 큰 기판 및 다른 GPU에서 응답 예산을 평가하려면 동일 조건의 반복 측정이 필요하다.

## 실행 확인과 재개 조건

- Windows Release 빌드와 CTest 14건, Python RPC 및 결과, 측정, 출력 이력 시험 41건을 통과했다. GUI 통합시험은 PCB 카탈로그, 문헌 후보, 규칙, 해석 누락, 과거 결과, RLC, 스윕, 출력과 CAM을 포함했다. RC6 스윕 자동시험의 환경 식별자는 그리드 시험에서 실제 연결된 Windows 런타임 계약을 따르고, 이상 회로 후보에서 솔버 미사용을 계속 확인한다.
- 공식 제조업체 인덱스는 재배포 조건과 출처가 확정되면 후보에 고정할 수 있다. 이번 검수는 시험용 인덱스와 층 직접 입력으로 진행했다. 서비스가 재시작되면 설치 환경에서 지정했거나 다시 연결한 인덱스를 사용한다.
- 교정된 VNA 원문, 시료, 교정 및 기준면 정보가 준비되면 실제 조건 비교를 수행한다. 직접 여는 파일의 뷰어 동작은 PC의 파일 연결에 따른다. 개선 전 전체 화면 점수와 비교할 재채점은 84개 화면을 다시 확인한 뒤 수행한다.
- 독립된 온라인 클린 Windows x64 PC에서 실제 사용자 설치, Windows 기본 해석, 시작 메뉴, 작업 영역 보존 및 표준 제거를 검수한 뒤 R1 수용을 결정한다. 리팩토링은 최종 수용 이후에 시작한다.
