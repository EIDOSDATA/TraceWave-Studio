# 스냅과 끝점 편집 검증

검증일: 2026-11-17 KST. 대상: `8dd2fcf` 이후 보존된 정밀 편집 변경과 이번 검토 보완. 완료 계획 4번의 첫 구현 단위다.

## 구현과 보존

같은 층의 보이는 선/원호 끝점과 표시 격자에 스냅하고, 선택한 선/원호의 시작점 또는 끝점을 편집한다. 드래그 중에는 표시 후보만 바뀌고 확정 시 서비스 명령 하나로 게시한다. 원호는 중심/반지름/회전 방향과 반대 끝점을 유지한다. 참조된 좌표/각도를 직접 입력으로 바꾸지 않는다. 단위, 출처, 미정 적층과 최초 템플릿 사본은 기존 계약을 따른다.

검토에서 원래 점으로 다시 스냅하거나 원호의 같은 방향으로 드래그할 때 불필요한 변경 명령을 보내는 경우를 발견했다. 같은 기하 후보는 원본과 이력을 변경하지 않고 종료하도록 보완했다. 최종 보완 후 재검증 결과는 아래에 별도로 기록한다.
