# 대형 3D 화면 범위와 합성 검증

2026-11-21 KST. 완료 계획 12번 F2에서 선택 인덱스가 검증한 바디의 경계를 OpenGL 그리기에도 사용한다. 평행 투영한 경계가 부동소수점 여유까지 포함해 화면 밖인 경우 GPU에 삼각형을 제출하지 않는다. 경계가 화면과 만나는 바디는 모든 삼각형을 유지한다. 경계 인덱스가 없는 바디는 기존 경로를 사용한다. 봉인 메시와 선택 원본, 표시 재질, CAD 출력은 그대로 사용한다.

실제 Windows wxGLCanvas에서 100만 삼각형의 두 바디를 열었다. 전체 보기, 화면 밖으로 이동, 전체 보기 복귀 순서에서 OpenGL 제출 수는 1000000 / 0 / 1000000개였다. 숨긴 층과 배경을 포함한 실제 클릭 5개에서 원래 선택 대상을 확인했다. 경계에 접할 때 바디를 유지하는 조건도 CTest로 검증했다. [실행 기록](118_대형장면_범위최적화_실행기록.json)

| 실제 Windows 표시 경로 | 계측 결과 |
| --- | --- |
| 1920 x 1080, Iris Xe/OpenGL, 120 Hz 출력 | 35초, 실제 합성 간격 3933개 |
| 회전과 이동 합성 간격 | p95 16.15 ms, p99 17.08 ms, 최대 21.25 ms |
| 30 fps 간격 33.33 ms 초과 | 0개 |
| 별도 Windows 자원 실행 | 18개 표본, private commit 최대 217.26 MiB, GPU shared usage 최대 165.57 MiB |

정점 버퍼는 두 바디의 72000000바이트를 한 번 전송했다. Windows 출력에서 그려진 번호의 실제 합성 시각을 수집했다. 프레임 및 GPU 자원은 제품 ModelView가 실행된 계측 창에서 얻었다. 별도 다중 해상도 LOD와 전체 Studio 도킹 부하까지 포함한 F2 수용은 남는다. 과거 장면, 이전 렌더 기록과 물리 원본은 그대로 보관한다. [이전 실행](63_윈도우_대형장면_합성검증.md)
