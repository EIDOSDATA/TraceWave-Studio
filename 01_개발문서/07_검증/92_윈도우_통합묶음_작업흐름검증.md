# Windows 통합 묶음 작업 흐름 검증

2026-11-21 KST. 완료 계획 13번에서 `c253881` 수신본의 실제 Windows Studio로 설계와 결과 분석을 다시 검증했다. 제품 EXE와 서비스 코드는 같은 ZIP에서 가져왔다. Windows와 System32만 실행 경로에 두고 시험마다 별도 작업 영역을 사용했다. [기본 수신 검증](88_윈도우_통합묶음_수신검증.md)

| 작업 흐름 | 수신 환경 | 확인 |
| --- | --- | --- |
| 목표와 문헌 카드 | 기본 CPython | 다중 목표, 템플릿 명령, 저장 개정 및 출처 보존 |
| 목표 제약, 연결과 DRC | 기본 CPython | 변경과 저장 후 원래 출처 및 미정 수량 대조 |
| 이름과 정밀 편집 | 기본 CPython | 검토 무효화, 원자 이력, 미정 보존 및 재열기 |
| 설계 스윕과 회로 후보 | 고정 복소 계산 환경 | 미리보기, 취소, 재개, 저장과 재열기 |
| 과거 결과와 Smith 비교 | 고정 복소 계산 환경 | 개정·표시 단위·마커, 비교 내보내기와 원본 보존 |

기본 CPython을 사용한 첫 실행에서 설계 GUI 시험 세 개가 통과했다. 스윕과 Smith 비교는 HDF5 원문을 준비하는 단계에서 `E_CAPABILITY`를 반환했다. 별도 CPython 3.12.10 환경에 배포 소스의 고정 목록으로 패키지 9개를 설치한 뒤 두 GUI 시험을 다시 실행해 모두 통과했다. 설치 계획의 wheel SHA256, `pip check`와 고정 정의에 기록한 라이선스 고지 파일 57개의 바이트를 대조했다. [고정 목록](../../Code/runtime_profiles/python-network-windows-x64.txt), [실행 기록](93_윈도우_통합묶음_작업흐름_실행기록.json)
