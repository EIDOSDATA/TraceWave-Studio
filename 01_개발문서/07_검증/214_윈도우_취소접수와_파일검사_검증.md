# Windows 동시 부하의 취소 접수와 파일 검사 개선

2026-11-21 KST. 해석 취소 요청은 기존의 정규 상태, 영수증, 현재 포인터를 같은 transaction에 게시한다. 잠금 범위, 파일 SHA256과 쓰기·동기화·재읽기 절차를 유지했다. journal URI 검증과 실제 경로 검사를 분리해 읽기와 쓰기 직전에 같은 경로를 반복 검사하던 부분을 줄였다. 취소는 새 대기 작업을 만들지 않아 소유 worker의 기존 취소 신호만 사용한다.

같은 Windows Release에서 서비스 대조판과 시험판을 여섯 번씩 교차했다. 옆 Studio는 형상 10000개, 매개변수 1000개, 100만 삼각형 및 1 GiB급 필드·복소 곡선을 열고 전환했다. 실제 WSL2 openEMS와 초당 약 1000행의 계측용 로그가 붙은 두 번째 해석을 취소했다. 각 실행의 종료와 이전 해석 결과, 저장 개정 및 재열기를 실제 원문으로 대조했다.
