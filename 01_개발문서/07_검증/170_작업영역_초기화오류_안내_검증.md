# Windows 작업 영역 초기화 오류 안내 검증

2026-11-21 KST. Studio가 첫 프로젝트 서비스 응답을 받기 전에 작업 영역을 열 수 없는 경우, 작업 영역 무결성, 저장 경로와 접근 권한, 다른 writer의 잠금, 초기 설정을 코드에 따라 안내한다. 로그에서 정해진 오류 코드만 사용한다. 서비스의 일반 로그와 송수신 형식은 기존 경로에서 처리한다.

실제 Windows에서 손상시킨 봉인 파일은 E_HASH와 원본 보존 안내를 표시했다. 손상 원문에 쓰기 없이 보존 사본을 복구해 동일 설계를 재열었다. 기존 개정, 재료, 적층, 급전, 확장, snapshot을 대조했다. 다른 서비스가 사용하는 동일 작업 영역은 E_CONFLICT와 잠금 안내를 표시했다. 기존 writer에서 설계 원문을 다시 읽었다.
