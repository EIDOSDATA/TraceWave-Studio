# Windows 관통부와 제조 규칙 검증

2026-11-21 KST. 실제 Windows Studio의 목표 제약과 연결 검사에서 비도금 홀을 추가한 기판을 열었다. 다른 두 도체는 각각 1.0 mm 폭이며 시험 규칙은 최소 폭 0.8 mm를 요구한다.

- 실제 Windows 검사 보고서에서 도체와 떨어진 홀이 두 최소 폭 판정을 바꾸지 않는 것을 확인했다. 원본을 저장하고 다시 열어 같은 판정을 확인했다.
- 서비스 시험에서 원형 홀을 한 도체의 가장자리에 걸치도록 변경했다. 절삭된 도체의 국부 폭만 미평가가 됐고 다른 도체는 기존 판정을 유지했다.
- 카탈로그 규칙의 원문 식별자, 미정 드릴 공구와 재료 손실, 기존 목표와 기판 스냅샷을 보존했다.

사용자가 입력한 제조 한계에 대한 형상 검사다. 실제 공구, 제조 공차 및 납품 가능 여부는 미평가다.
