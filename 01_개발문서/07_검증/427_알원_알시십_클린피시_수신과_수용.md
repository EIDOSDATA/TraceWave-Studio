## 제거와 재설치

첫 시험은 Windows 설정의 설치된 앱에서 제거기를 열고 Windows에 등록된 무인 제거 명령으로 완료했다. 앱 등록, 시작 메뉴 바로가기, `Versions`, 전용 Python과 설치 캐시가 정리됐으며 `Workspace`가 남았다. 같은 Setup.exe를 같은 경로에 재설치한 뒤 844개의 상대 경로, 크기와 SHA-256이 제거 전후와 재설치 후에 모두 일치했다. GUI에서 저장 설명과 31개 해석 표본, 출처를 다시 열었다.

## SBOM과 라이선스 원문

RC10의 내장 manifest와 15개 고지·소스 목록의 SHA-256을 대조했다. 실행한 기본 설치에서 서비스, CAD, 출력, Windows openEMS 가상환경의 배포판 83건을 조사하고 고정 요구 버전과 일치함을 확인했다. 설치의 `METADATA`, `RECORD`, 라이선스 원문과 네이티브 파일의 경로 및 해시를 기록했다. 설치 파일에서 원문을 찾지 못한 scikit-rf, OCP proxy, openEMS와 CSXCAD는 해당 릴리스 소스의 원문을 참조했다. OCP의 OCCT 라이선스와 예외 문서도 대조했다. [구성명세](428_알원_알시십_소프트웨어_구성명세.json)

이 SBOM은 같은 Setup.exe를 설치해 수신한 증거다. [CycloneDX 1.6 공식 스키마](https://cyclonedx.org/docs/1.6/json/) 검증을 통과했다. 상류 번들 내부의 전체 의존 그래프와 WinLibs MCF 바이너리의 정확한 원본 커밋은 미확정으로 표시했다. 공개·상용 배포의 라이선스 판단은 해당 배포 범위가 정해졌을 때 별도로 검토한다.

## R1 판정

**R1 최종 수용 대기.** 남은 항목은 Windows 설정에서 시작한 대화형 제거를 확인 창부터 완료까지 검증하는 일이다. 이후 같은 경로에 재설치해 원본을 재열고 B0를 확정한다. 기준 PC 정량 성능과 재부팅 5회는 사용자 결정으로 R1 승인 항목에서 제외됐다. 기존 WSL2 환경과 실제 제작·교정·측정은 해당 사례의 선택 검증으로 관리한다.
