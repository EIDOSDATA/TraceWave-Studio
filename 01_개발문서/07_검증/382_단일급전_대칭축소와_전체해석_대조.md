# 단일 급전 PCB의 대칭 축소와 전체 영역 대조

## 입력과 해석

사용자 PCB의 단일 급전 해석 조건에서 전체 영역 또는 X, Y축에 수직인 PEC 대칭면과 위치를 선택한다. 대칭면은 양 단자의 중점을 지나고 급전 방향에 수직이어야 한다. 실제 도체 다각형에 같은 층, 두께, 전도도와 재료의 반사 상대가 있는지 검사한다. 양 단자의 반사 상대, 도체 연결 성분, 기판 경계, 양끝 경계 조건과 전체 격자선의 반사 위치도 대조한다.

해석에는 좌표가 증가하는 쪽의 절반을 남긴다. 단자 극성을 뒤집어도 같은 쪽 영역을 사용한다. 절반 간극에 두 셀 이상이 필요하다. 반사된 쪽의 단자를 대신하는 단자가 PEC 경계의 Yee 격자점에 있고 나머지 실제 단자가 남은 도체에 연결되어 있는지 준비 시 검사한다. 반영역의 급전 저항은 원래 저항의 1/2이다. 전압의 복소 스펙트럼을 2배로 환산하고 전류는 동일하게 두어 전체 급전의 S11과 입력 임피던스를 반환한다. 원본 단자, 저항, 스냅샷과 사용자 기준면은 전체 모델 값으로 보존한다. 모델 검토에서 직접 투영한 도체와 대칭으로 나타낸 상대 도체의 ID를 확인할 수 있다.

## 봉인된 openEMS 비교

WSL2 TraceWave-Dev의 고정 openEMS 0.37.0 worker로 동일한 16 x 12 mm 시험 기판을 두 번 준비 및 해석했다. 50 ohm gap은 X=7~9 mm, 대칭면은 X=8 mm이다. 주파수 8~12 GHz 31점, 모델 최대 격자 간격 0.5 mm, 곡선 허용값 0.025 mm, 목표 에너지 비 1e-5를 사용했다. 기판과 도체의 물성은 시험 입력이다.

| 항목 | 전체 영역 | PEC 반영역 |
| --- | ---: | ---: |
| X/Y/Z 격자선 | 57/49/28 | 29/49/28 |
| 격자점 | 78204 | 39788 |
| 급전 저항 (ohm) | 50 | 25 |
| 종료 스텝 | 1085 | 1085 |
| 종료 감쇠 (dB) | 51.51 | 51.52 |

반대쪽 절반을 남기는 별도 진단에서는 최대 임피던스 차이 9.71623 ohm과 최대 S11 차이 0.0135379가 관찰되어 제품은 검증한 좌표 증가 쪽을 선택한다.

원시 전압과 전류를 주파수별로 후처리한 전체 두 결과의 최대 절대 복소 S11 차이는 0.000150904, 입력 임피던스 차이는 0.0181493 ohm이다. 이 사례의 회귀 허용값 0.03과 1 ohm을 모두 만족했다. 비대칭 도체, 다른 재료, 다른 외벽, 잘못된 면 좌표와 실제 Yee 격자선 불일치도 검사했다. X축 공개 worker 재검은 155.969초에 통과했다. 기판과 급전축을 Y로 돌리고 양 단자의 극성을 바꾼 경우도 168.296초에 통과했다. Y축의 전체/절반 격자선은 49/57/28 및 49/29/28, 종료는 모두 1085 스텝, 최대 절대 복소 S11 차이는 0.000150887이며 임피던스 차이는 0.0181306 ohm이다. Windows의 대칭, PCB 해석 및 격자 검토 관련 시험 26개도 통과했다. 재현 시험은 `Code/tests/test_pcb_symmetry.py`이다. WSL의 native 시험에는 `RFAD_OPENEMS_NATIVE=1`과 고정 solver 가상환경이 필요하다.

## 적용 범위

현재는 균일한 적층, 양쪽으로 분리된 평면 도체, 단일 차동 간극과 S11/입력 임피던스를 지원한다. 비아, 설치물, 표면층, 기계 절삭, 대칭면을 가로지르는 도체, 가변 또는 국부 격자, 다중 포트와 필드/방사 기록에 대한 절반 모델은 별도 검증이 필요하다. 단일 선 급전은 Yee 전기장 격자선에 놓이고 자기 벽은 엇갈린 자기장 격자면에 있다. PMC 모드에 올바른 대칭 쌍급전 또는 분포 급전과 정규화를 연결하는 작업은 남아 있다. 도파관의 별도 PMC TE10 시험은 [368번 기록](368_도파관_대칭면과_해석재개_검증.md)에 있다.
