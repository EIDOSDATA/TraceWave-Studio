# PTH 배럴 간극과 봉인 객체 이력 검증

검증일 2026-11-23

## 실제 해석 형상 간극

해석 격자의 진단 목록에 PTH 배럴과 해석에 포함된 설치물 상자를 추가했다. 기본 모델 격자 폭의 두 배 안에서 양 끝점과 XY 또는 XYZ 통과 셀을 표시한다. 동심 배럴의 보어에 여유가 남는 경우, 도금과 접하는 패드, 높이가 다른 상자와의 대각선 간극, 투영이 겹치는 수직 간극을 수치로 검사했다. 격자 준비에서 PTH 시험 입력의 내경 반지름 0.3 mm, 외경 반지름 0.4 mm를 실제 소비 모델과 일치시켰다. 양단에 닿은 패드는 간극 목록에 표시하지 않았으며, XY와 Z 격자선은 native 준비 산출물과 일치했다.

진단은 모델 메시에 전달한 형상의 기하 거리를 검사한다. 작업물의 가공 공차, 전기적 절연 기준과 손실 시험은 입력에 없으므로 미정이다. 보드 절삭면, 표면 코팅 및 일반 BREP는 이 간극 계산 범위에서 제외된다.

## 봉인 객체 이력

결과의 해석 입력과 출처에서 도체 또는 급전 단자 도체를 선택한 뒤 편집 이력을 읽는다. 객체가 실제로 바뀐 개정의 변경 전후 속성과 편집 명령, 실행 취소 또는 다시 실행을 확인한다. 큰 속성은 정규 바이트 수와 SHA256으로 식별한다. 앞선 개정이 저장소에 없거나 이력 페이지가 남은 상태를 구분한다. 매개변수와 다른 대상의 이력은 이 도체의 원본 필드가 직접 달라진 경우에만 나타난다. 봉인 뒤에 적용한 편집은 당시 객체 이력에 포함하지 않는다.

Windows 서비스에서 원호와 IFA의 작성, 실행 취소, 다시 실행, 별도 개정 저장, 재열기, 페이지 연결을 시험했다. Windows 기본 빌드, CTest 14개와 Python 회귀 8개를 통과했다.
Windows에서 접수하고 WSL openEMS로 완료한 원호 결과 3bbf5cf9-8e40-46bf-8695-bbb7e83e81be와 IFA 결과 c41a9f2e-beb2-4a45-a7a4-a746b765ea34를 확인했다. 결과가 생긴 뒤 객체 편집을 취소한 현재 개정을 저장하고 Windows 서비스에서 다시 열었다. 원호에서는 폭의 출처, IFA에서는 패드 크기의 출처가 봉인 개정의 값으로 남았다. 미리보기와 native 준비의 세 격자축이 일치했다.
