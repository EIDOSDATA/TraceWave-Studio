# 필드 조회의 봉인 원문 중복 읽기 검증

2026-11-21 KST. 완료 계획 12번 F3의 보존 결과 조회는 정규화 원문을 한 번 읽고 SHA256을 확인한다. 같은 응답에서 확인한 결과를 분석 계획 대조와 복소 투영에 함께 사용한다. 복소 투영은 기존 물리·단위·파 규약 검사를 계속 적용한다. 다음 조회에서는 저장소와 파일 해시를 다시 검사한다.

실제 openEMS의 고정 자료에서 정규화 원문 249299바이트를 한 번만 읽는지 확인했다. E/J/rotH의 원본 3개와 단면 27개를 대조하고, 이전 결과·출처·제작 및 측정 미정값을 보존하는 서비스 회귀 29개를 통과했다. 실제 Windows 결과 GUI 2개에서 2개 주파수의 단면 10회, 과거 원문 비교와 저장·재열기를 통과했다.

변경은 조회 한 건의 중복 파일 읽기와 JSON 파싱을 제거한다. 별도의 시간 개선율은 계측하지 않았다. 원시 필드의 검증 절차와 파일 상한을 유지한다. 1 GiB 필드와 10만 점 복소 곡선 8개, 전체 메모리 수용은 후속 시험 범위에 남는다. [이전 필드와 상한 검증](119_심화해석_필드단면_검증.md)
