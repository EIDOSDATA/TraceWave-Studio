# 최대 8개의 PCB 집중 급전과 복소 행렬

2026-11-23 KST. 일반 PCB 프로젝트의 포트 접수, 해석 검토, 저장 및 네트워크 등록 범위를 2~8개로 확장했다. 포트마다 실제 단자 형상과 실수 기준 저항을 확인한다. 같은 격자에서 각 포트를 한 번씩 여기하고 나머지는 자신의 기준 저항으로 종단한 뒤, 복소 입사파 행렬 A와 출력파 행렬 B로 S A = B를 푼다.

8포트 결과에는 176개 여기별 원문과 원문 목록, 정규 결과, Touchstone이 있다. 파일 개수 상한은 포트 수에 따라 계산하며 파일별 및 전체 바이트 상한과 해시 검사는 유지한다. 실제 338,072바이트 작업 요청을 WSL 감독기가 256 KiB 제어 파일 상한 때문에 시작 전에 차단하는 것을 확인했다. 감독기의 작업 요청에만 기존 worker와 동일한 4 MiB 상한을 적용하고 작은 제어 파일에는 기존 상한을 적용했다. 복소 자료 가져오기에서 CSV는 8포트의 주파수 및 복소 수치 129열을 받을 수 있고 Windows 대화상자의 열/포트 입력과 표시 길이를 조정했다.

Windows의 네트워크 및 계약 회귀는 35개가 통과했고 조건부 Linux 네이티브 시험 한 개는 위의 실제 Windows/WSL 작업과 별도로 기록했다. Windows GUI는 빌드됐으며 실제 8포트의 계획부터 재열기는 GUI와 같은 공개 서비스 API에서 확인했다. 적용 대상은 8개까지의 집중 급전이다. 9개 이상과 분포/다중모드 포트의 PCB 여기 모델은 후속 범위다.
