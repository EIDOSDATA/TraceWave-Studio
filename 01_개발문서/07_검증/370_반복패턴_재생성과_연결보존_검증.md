# 370. 직선과 원형 반복의 재생성

## 동작

- 정밀 편집에서 직선 반복 복사 또는 원형 반복 복사로 만든 사본은 원본과 연결된다. 원본의 좌표, 길이, 반경과 같은 기하를 바꾸면 같은 개정에서 사본을 다시 계산한다. 다른 반복의 사본을 원본으로 사용한 경우에는 먼저 상위 반복을 계산한다.
- 반복에 속한 사본을 선택하고 직선 반복 설정 편집 또는 원형 반복 설정 편집을 열면 저장된 개수와 피치 또는 회전 중심과 간격을 불러온다. 실제 결과를 미리 보고 적용한다. 원본과 순번이 같은 사본은 UUID와 이름을 유지한다. 개수를 줄였다가 늘려도 같은 순번의 UUID가 복원된다.
- 포트, 기대 연결 또는 외부 비아가 사용하는 사본을 움직이거나 삭제하는 갱신은 차단한다. 반복 연결 해제를 선택하면 현재 형상을 유지한 채 사본을 따로 편집할 수 있다.
- 과거 버전의 독립 복사는 원본을 편집해도 종전 동작을 유지한다. 사본이 보존된 과거 반복은 반복 설정 편집으로 연결할 수 있다. 독립적으로 변경한 과거 사본을 덮어쓰지 않도록 현재 값과 보존 사본을 비교한다.
- 원본과 사본을 합한 기존 상한은 16개다. 원본 및 복사본을 추가, 변경, 삭제한 기록은 앞선 출처 기록과 별도로 보존된다.

## 검증

Windows Release에서 정밀 편집 대화상자를 빌드하고 링크했다. 서비스 공개 진입점으로 아래 항목을 검사했다.

| 사례 | 검증 |
| --- | --- |
| 직선 | X 피치 3 mm의 3개를 4 mm의 4개로 변경했다. 원본 X를 2 mm 옮기면 첫 사본 시작점은 (7, 2) mm가 된다. |
| 원형 | 중심 (5, 5) mm에서 간격 75도의 3개를 60도의 4개로 변경했다. 원본 이동 후 첫 사본 위치를 독립 계산한 회전 좌표와 대조했다. |
| 공통 이력 | 4개에서 2개로 줄인 뒤 4개로 복구해 UUID를 대조했다. 연결된 사본 직접 이동 차단, 원본 이동의 취소 및 다시 실행, 연결 해제 후 원본과 사본의 독립 이동, 저장 후 재열기를 확인했다. |
| 기존 사례 | 선과 원호를 함께 반복하고 원호 반경을 편집하는 사례와 IFA 및 도금 비아와 패드를 함께 복사하는 기존 시험을 통과했다. |

회귀 시험은 `Code/tests/test_precision_service.py`에 있다. `test_edit_pattern_count_pitch_and_source_keep_copy_ids` 한 시험 안에서 직선, 원형 양쪽을 수행했다.
