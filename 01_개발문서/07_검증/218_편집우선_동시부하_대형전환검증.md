# 편집 우선 Windows Studio의 동시 부하 대형 전환

2026-11-21 KST. 편집 우선 시작을 넣은 Studio를 열고 형상 10000개, 매개변수 1000개, 100만 삼각형, 1 GiB급 필드의 부분 조회 10회와 10만 점 복소 곡선 8개를 함께 사용했다. 다른 Studio에서 실제 WSL2 해석·취소를 반복하며 대형 프로젝트와 대기 프로젝트를 오갔다. 이번 검증은 F4의 파일 검사와 종료 대기 수정 전 서비스로 동시 부하를 만들었다.

30초 유지 30회에서 OpenGL 문맥이 모두 유지됐다. 본체와 하위 프로세스의 안정화 private commit은 초기 5회 중앙값 205.70 MiB, 마지막 10회 216.79 MiB로 증가량 11.10 MiB였다. 열림 중 관찰 최대는 359.94 MiB였다. 안정화 GUI 커널 핸들은 첫 346개에서 마지막 341개로 내려왔다. GPU nonlocal 사용량은 모든 표본에서 0바이트였다.
