# 389. 인접 격자 수준의 주파수별 포트 변화

## 조회

프로젝트 연구의 진행 화면에서 두 격자의 주파수별 포트 변화를 연다. 완료한 인접 격자를 선택하면 실제 저장한 주파수, 복소 S11의 차이 크기, 복소 임피던스 차이의 크기(옴), 명시한 S11 허용값 이내 여부를 볼 수 있다. 위상을 포함해 |S11(a) - S11(b)|를 계산한다. 서로 다른 주파수나 출처를 보간해서 비교하지 않는다. 두 결과의 해시와 원래 설계 및 해석 조건을 확인한다. 선택 표본의 변화량과 공진 위치의 수렴 판정은 별개다.

## 기존 RO4350B 연구 재열기

Windows에 보존한 2.4 ~ 2.4835 GHz 연구의 세 완료 결과를 현재 공개 RPC로 조회했다. 연구 개정은 3e763f0d-7402-4b8c-aa7b-7c343e6040c1, 복소 반사 변화 허용값은 0.02, 공통 주파수는 201개다. 두 번 조회한 전후 journal 내용 해시가 같았다.

| 격자 (mm) | 허용값 이내 | 최대 복소 S11 변화량 | 최대 임피던스 변화 (옴) |
| --- | ---: | ---: | ---: |
| 0.50 / 0.45 | 0 / 201 | 0.0359031120 | 3.6426229 |
| 0.45 / 0.40 | 201 / 201 | 0.0012757589 | 0.1337340 |

불균일 주파수 회귀에서는 기존 축을 그대로 돌려주고 한 주파수의 위상 변화만 허용값을 넘는지 확인했다. 허용값과 정확히 같은 변화량은 기준 이내다. 판정 결과와 원본 파형을 새로 저장하지 않으므로 이 기능 이전에 만든 연구도 조회할 수 있다.

Windows 통합 빌드와 CTest 14개가 통과했다. 고정한 동일 소스로 프로젝트 연구, 격자 비교와 템플릿 회귀 64개도 통과했다. 작업 중인 소스에서 앞선 실행 한 번이 준비 작업 ID를 얻지 못해 실패했고, 동일 입력을 동결한 소스에서 단독 및 묶음으로 다시 실행해 확인했다.
