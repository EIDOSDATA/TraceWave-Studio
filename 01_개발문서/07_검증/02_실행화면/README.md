# 실제 Windows 실행 화면

이 폴더는 개발 중 실제 Windows GUI를 조작하고 캡처한 검증 증거를 보관한다. 화면 설계용 그림은 `04_화면설계`에서 관리하며, 이 폴더의 이미지를 시안이나 RF 성능 합격 증거로 사용하지 않는다.

2026-11-17 실행은 [Studio와 정밀 편집 검증](../08_스튜디오와_정밀편집_검증.md)을 따른다. JPEG는 캡처 도구가 반환한 화면 원본이다. 설명용 재합성이나 글자/형상 보정을 하지 않았다. 창 크기는 캡처 픽셀 기준이며 모든 DPI, GPU, 접근성 조건의 수용을 뜻하지 않는다.

01~03은 격리한 편집 시험 프로젝트이고, 04~06은 두 사각 도체를 같은 net에 둔 CAD 선택 시험 프로젝트다. 07은 [공통 외형 검증](../10_화면시안_공통외형_검증.md)의 화면 배치용 명시 기하이며 원호 급전이 미연결이고 RF 설계가 아니다. 08은 G031 카드의 원호/stub 부분 기하이고 임의 반지름 12 mm 검토 기판은 원문 전체 PCB 재현이 아니다. 실제 제작 재료나 안테나 성능을 나타내는 데이터가 아니다. 기존 출처/미정값과 저장/재열기의 보존 판정은 이미지의 모양 대신 검증 기록의 원본 데이터 비교를 따른다.

09~14는 [공통 복소 결과 검증](../11_공통복소결과와_회로평가_검증.md)의 수식 시험 프로젝트다. 1/1.5/2 GHz에서 0.1 + j0의 원본과 이상 직렬 저항을 사용하며 실제 안테나 측정이나 새 FDTD를 수행한 자료가 아니다. 각 캡처의 실행 파일/해시는 [기계 기록](../12_공통복소결과와_회로평가_실행기록.json)으로 구분한다. 표본 통과를 연속 대역/수렴/물리 정확도 합격으로 읽지 않는다.

15~22는 [설계 스윕 검증](../13_설계스윕과_연구_검증.md)의 실제 이상 저항 계산 및 실행 전 설계/수치 연구다. 1~2 GHz의 201개 표본을 사용하며 50 ohm/100 ohm/0.05 kohm 후보의 원문/중복/결과를 남긴다. 원본과 과거 snapshot, 복소 JSON/HDF5, 미정 제작/측정 조건의 저장/재열기는 이미지 외에 서비스로 바이트/hash를 대조했다. 캡처별 실행 파일과 후속 보완의 시점은 [실행 기록](../14_설계스윕과_연구_실행기록.json)으로 구분한다. 이 화면의 곡선은 실제 FDTD나 안테나 실측이 아니다. 별도 실제 WSL 한 후보 검증은 같은 단계 기록에서 분리한다.

캡처 도구가 반환한 JPEG에는 제목 표시줄과 native 입력을 포함해 일부 작은 글자의 획이 얇거나 끊겨 보이는 현상이 있다. 이 손실 압축 이미지만으로 실제 화면의 글꼴 결함 여부나 전체 가독성 수용을 확정하지 않는다. 원본 바이트를 유지하고 실제 형식에 맞는 `.jpg` 확장자를 사용한다.

23~32는 [다중 결과 검증](../17_다중결과_표시검증.md)의 실제 보존 PCB 해석 자료다. 원래 workspace를 격리 복사해 조회했고 새 FDTD나 측정을 실행하지 않았다. 23은 중간 빌드 `93b7ccfd...`, 24~32는 최종 시각 검토 빌드 `3833cf41...`이다. 이후 재링크한 `43b36d6e...`는 기존 문헌 시험의 화면 이동 기대값만 보강한 빌드다. [실행 기록](../18_다중결과_표시_실행기록.json)에 캡처/바이너리 해시와 시점을 보존한다. 2.4 GHz의 방사 효율 98.79385%와 총 효율 53.900538%는 해당 탐색용 모델의 계산값이며, 사용자가 제작할 안테나의 합격값이 아니다. 원본 프로젝트/해석 산출물/hash와 제작/측정 null은 저장·재열기 후 별도로 대조했다.

33~38은 [독립 참조 검증](../19_독립참조와_유한검증.md)에서 새로 계산한 고정 PEC 다이폴의 실제 기록을 `639fd7ee...` 빌드로 읽은 화면이다. 원래 계산 workspace는 그대로 두고 복사본에서 저장/재열기와 CSV 내보내기를 확인했다. 초도 이상 모델 비교, 격자 변화 관찰, 일반 수렴과 실측은 서로 다른 상태이며 제작/측정은 null이다. 과거 판정의 당시 단계 표기를 현재 읽기 모델에 맞춰 다시 쓰지 않는다.

39는 계획 행의 결과 안내 문구만 보완한 최종 `d7d64a58...` 빌드의 재열기다. 계획 조회를 과거 판정으로 자동 대체하지 않는다. 해당 캡처와 후속 보존 대조는 앞선 33~38의 실행 파일 해시를 덮지 않고 별도로 기록한다.

40~44는 [9번 후보 채택 검증](../21_후보채택과_원호아이에프에이_검증.md)의 당시 Windows 화면이다. 원래 캡처 바이트와 당시 검증 기록을 바꾸지 않고 이 안내에 경로만 연결했다.

45~48은 [10번 도면/STEP 검증](../23_연관도면과_스텝재검수_검증.md)의 `b38e5fe4...` 빌드에서 직접 조작한 화면이다. 원래 출력 workspace의 별도 사본에서 PDF 생성/재검수, 보존 STEP의 3D 표시와 새 reader 검수를 실행했다. 새 FDTD 또는 실물 제조/측정을 수행한 화면이 아니다. PDF 파일 자체의 렌더링은 [03_도면렌더링](../03_도면렌더링/README.md)에서 따로 보존한다.

49는 초기 선택 안내를 보완한 `d547a9d0...` 빌드의 runtime 없는 새 Windows 프로세스다. 현재 입력/출력을 선택하지 않은 상태를 같은 문구로 안내하고 기존 기록은 계속 조회할 수 있다.

50은 `91f990d6...` 최종 빌드에서 같은 보존 PDF를 다시 연 화면이다. 제외된 `실물 배터리·외함 미정`의 snapshot 당시 이름과 원문 제외 사유를 표시한다. 새 reader나 생성 worker 없이 조회했으며 4개 프로젝트의 원본 문서, 현재/저장 개정, 이력, 과거 solver 결과 및 기존 프로젝트 파일 322개의 바이트 불변을 별도로 비교했다.
