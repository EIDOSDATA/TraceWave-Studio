# 실제 Windows 실행 화면

이 폴더는 개발 중 실제 Windows GUI를 조작하고 캡처한 검증 증거를 보관한다. 화면 설계용 그림은 `04_화면설계`에서 관리하며, 이 폴더의 이미지를 시안이나 RF 성능 합격 증거로 사용하지 않는다.

2026-11-17 실행은 [Studio와 정밀 편집 검증](../08_스튜디오와_정밀편집_검증.md)을 따른다. JPEG는 캡처 도구가 반환한 화면 원본이다. 설명용 재합성이나 글자/형상 보정을 하지 않았다. 창 크기는 캡처 픽셀 기준이며 모든 DPI, GPU, 접근성 조건의 수용을 뜻하지 않는다.

01~03은 격리한 편집 시험 프로젝트이고, 04~06은 두 사각 도체를 같은 net에 둔 CAD 선택 시험 프로젝트다. 07은 [공통 외형 검증](../10_화면시안_공통외형_검증.md)의 화면 배치용 명시 기하이며 원호 급전이 미연결이고 RF 설계가 아니다. 08은 G031 카드의 원호/stub 부분 기하이고 임의 반지름 12 mm 검토 기판은 원문 전체 PCB 재현이 아니다. 실제 제작 재료나 안테나 성능을 나타내는 데이터가 아니다. 기존 출처/미정값과 저장/재열기의 보존 판정은 이미지의 모양 대신 검증 기록의 원본 데이터 비교를 따른다.

09~14는 [공통 복소 결과 검증](../11_공통복소결과와_회로평가_검증.md)의 수식 시험 프로젝트다. 1/1.5/2 GHz에서 0.1 + j0의 원본과 이상 직렬 저항을 사용하며 실제 안테나 측정이나 새 FDTD를 수행한 자료가 아니다. 각 캡처의 실행 파일/해시는 [기계 기록](../12_공통복소결과와_회로평가_실행기록.json)으로 구분한다. 표본 통과를 연속 대역/수렴/물리 정확도 합격으로 읽지 않는다.

15~22는 [설계 스윕 검증](../13_설계스윕과_연구_검증.md)의 실제 이상 저항 계산 및 실행 전 설계/수치 연구다. 1~2 GHz의 201개 표본을 사용하며 50 ohm/100 ohm/0.05 kohm 후보의 원문/중복/결과를 남긴다. 원본과 과거 snapshot, 복소 JSON/HDF5, 미정 제작/측정 조건의 저장/재열기는 이미지 외에 서비스로 바이트/hash를 대조했다. 캡처별 실행 파일과 후속 보완의 시점은 [실행 기록](../14_설계스윕과_연구_실행기록.json)으로 구분한다. 이 화면의 곡선은 실제 FDTD나 안테나 실측이 아니다. 별도 실제 WSL 한 후보 검증은 같은 단계 기록에서 분리한다.

캡처 도구가 반환한 JPEG에는 제목 표시줄과 native 입력을 포함해 일부 작은 글자의 획이 얇거나 끊겨 보이는 현상이 있다. 이 손실 압축 이미지만으로 실제 화면의 글꼴 결함 여부나 전체 가독성 수용을 확정하지 않는다. 원본 바이트를 유지하고 실제 형식에 맞는 `.jpg` 확장자를 사용한다.
