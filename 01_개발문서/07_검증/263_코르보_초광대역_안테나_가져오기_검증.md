# Qorvo WB003 초광대역 패턴의 Windows 가져오기 검증

2026-11-21 KST. WB003.zip과 내부 Mini-Hoe_Antenna_Gerbers.zip을 각각 실제 Windows Studio에서 가져왔다. 별도 교환 worker가 3개 동박 Gerber의 단위, 바이트와 SHA256을 확인하고 안테나, 상면 CPW 접지, 하면 접지를 7개 편집 영역으로 만들었다. 상면 도체 둘은 같은 기존 동박층, 하면 접지는 별도 동박층에 명시 대응했다.

원문 안테나의 clear 영역을 보존했다. 안테나 스텁과 CPW 접지의 원래 상면 교집합은 0.8 mm²로, 경계는 원본 원점 기준 X 6.35~7.15 mm, Y 17~18 mm다. 소프트웨어는 겹침을 이동하거나 자동 정리하지 않았다. 원본 외곽의 18 x 26 mm 경계와 비아 도면은 보고서에 보존했으며 작업 중인 기판의 외곽, 홀·도금, 포트·넷 또는 재료를 자동 교체하지 않았다.

두 시나리오에서 원문 전송과 읽기, X/Y·회전 및 생략·겹침 확인, 2D 후보 적용을 확인했다. native 캔버스에서 방사체 영역을 선택해 이동한 후 저장하고 서비스를 재시작했다. 이동 좌표가 복원됐고 선택 파일을 분리한 뒤에도 저장소의 업체 원문과 보고서 바이트를 다시 대조했다. 기존 보드, 물성, 급전, 넷과 미정 드릴 공구가 유지됐다.

최종 Windows 실행은 제조사 9개 시나리오와 기존 KiCad/CAM 회귀 1개를 포함해 182.653초였다. 서비스·형식 검사는 46개 중 44개가 통과했고 2개는 실행 조건에서 제외됐다. CTest 13개가 통과했다. WB003 채널 5는 제조사 예제의 범위다. 독립 RF 해석, 수렴, 제조와 실측은 미평가다. [라이브러리 계약](../05_기능설계/05_출력교환/07_제조사_안테나_라이브러리.md)
