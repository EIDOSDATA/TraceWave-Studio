# Windows 저장 실패, 손상 차단과 재열기

2026-11-21 KST. 격리된 Windows 작업 영역에서 봉인한 설계 파일을 손상시켰다. 실제 Studio가 편집 화면을 열지 않았고 오류를 보고했다. 손상된 바이트, 프로젝트 참조와 기존 snapshot에 자동 덮어쓰기가 발생하지 않았다. 시험의 보존 사본을 복원한 뒤 실제 Studio에서 같은 프로젝트를 저장·재시작·재열기했고 형상, 재료, 적층, 포트, 확장과 snapshot을 대조했다. 작업 영역 시작 중 파일 무결성 검사에 실패한 경우 GUI에 표시된 상태는 서비스 연결 종료였다.

Windows의 실제 저장 요청에서는 상태 파일을 게시하기 전에 ENOSPC를 주입했다. 이전 정상 저장 개정을 보존했고 같은 편집을 수동 재시도해 저장 및 재열기를 확인했다. 별도의 Windows 저널 시험에서는 payload 쓰기 후, 교체 직전, 교체 직후 세 지점에서 실제 서비스 프로세스를 종료했다. 앞의 두 경우 이전 개정이 남았고, 교체 후에는 새 개정과 영수증이 함께 재열렸다. 쓰기 잠금도 해제됐다.
