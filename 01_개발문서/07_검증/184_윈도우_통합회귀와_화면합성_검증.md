# Windows 통합 회귀와 화면 합성 검증

2026-11-21 KST. Windows Studio와 별도 OCCT, 도면 교환 및 WSL2 openEMS 실행 환경을 연결했다. GUI 43개를 한 차례 실행해 38개가 통과했다. 보관 필드의 별도 환경 조건으로 1개를 제외했다. 복소 결과, 카탈로그 두 흐름과 면·패드·비아의 구간은 시험 종료 시간에 도달했다.

시험 전용 종료 시간을 복소 결과 300초, 카탈로그 및 기본 도형 180초로 두고 같은 검사의 네 흐름을 다시 실행했다. 저장·재연결과 모든 원본·조건 검사가 통과했다. 재실행 전체는 129.42초였다. 제품의 응답 제한과 성능 합격값에는 [성능 설계](../04_화면설계/02_화면_선정과_성능_설계.md)를 적용한다. 1 GiB 외부 필드의 Windows 조회·재열기는 [대용량 자원 검증](158_대용량_결과의_윈도우_자원_검증.md)에 기록했다.

서비스 전체 회귀는 수집 시점의 1437개 중 1286개 통과와 환경 제외 151개를 기록했다. 감사, Altium 검토 사본과 대용량 자료를 확인한 후속 묶음은 21개 중 19개 통과 및 환경 제외 2개였다. Release CTest 13개도 통과했다.

전체 도킹 상태의 2D 확대 시험을 따로 시도했다. Windows Desktop Duplication이 두 실행의 합성 갱신 8216개와 9447개를 모두 보호 콘텐츠로 표시했다. 같은 창의 그리기 표식이 합성과 대응된 표본을 얻지 못했다. 기존 관찰의 확대, 이동, 드래그와 표 스크롤 수치를 그대로 기록한다. 60 fps와 같은 호스트의 입력-화면 수용은 미확립이다. [2D 이동·드래그 기록](111_대형설계_이동과_삼차원_검증.md), [서비스 및 GUI 결과](185_윈도우_통합회귀와_화면합성_실행기록.json)
