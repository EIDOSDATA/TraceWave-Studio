# Studio 재열기 상태와 빈 화면 성능 검증

2026-11-20 KST. 완료 계획 12번에서 Windows 프로젝트 열기 상태와 [빈 Studio 성능 기준](../04_화면설계/02_화면_선정과_성능_설계.md)을 검증했다.

## 프로젝트 열기와 복구 안내

- 프로젝트를 여는 중 속성과 2D 표시의 같은 개정이 도착할 때까지 편집을 잠그고 `프로젝트 불러오는 중`을 표시한다. 요청이 끝났는데 두 개정이 맞지 않으면 F5로 원본을 다시 읽으라는 안내를 표시한다.
- Windows 편집 회귀에서 로딩과 동기화 실패를 각각 재현해 두 상태의 문구와 잠금을 확인했다. 실제 창에서는 앞 단계에서 수신한 합성 검증 프로젝트를 새로 열어 저장된 이름, 형상과 편집 도구가 복구된 것을 확인했다. [Windows 재열기 화면](02_실행화면/91_스튜디오_복원프로젝트_준비완료.jpg)

Windows 서비스 연동 GUI 회귀 7개와 CTest 13개가 통과했다. 계측 도구는 기존 출력 파일의 덮어쓰기와 다른 프로그램의 PID를 거절했다.

## F0 유휴 계측

[계측 도구](../../Code/tools/measure_windows_idle.ps1)로 준비된 빈 Studio와 Python 서비스 등 하위 프로세스를 30초간 측정했다. CPU 시간 합계를 관찰 경과 시간으로 나눠 논리 코어 하나 기준으로 환산했다. 메모리는 최초, 5초 간격 및 마지막 표본에서 관찰한 private commit 최대값이다. 동일 Windows 11 Pro build 26300, i7-1365U, Intel Iris Xe, 2560 x 1600 / 120 Hz 환경에서 각 실행의 바이너리와 원시 표본을 [실행 기록](38_스튜디오_재열기와_유휴성능_실행기록.json)에 남겼다.

| 실행 | GUI private commit | 하위 포함 private commit | 논리 코어 1개 기준 CPU |
| --- | ---: | ---: | ---: |
| 변경 전, 화면 조회 후 | 40.76 MiB | 75.00 MiB | 21.35% |
| 변경 전, 창 직접 조회 없이 | 40.59 MiB | 76.48 MiB | 22.71% |
| 버튼 색 조회 최적화 진단본 | 41.26 MiB | 78.60 MiB | 25.66% |
| 최종 변경, 창 직접 조회 없이 | 41.43 MiB | 78.44 MiB | 28.07% |

- 이 PC의 네 실행에서 PERF-003의 GUI 150 MiB와 하위 포함 300 MiB 예산 이내였다. PERF-008의 CPU 1% 기준은 네 실행 모두 미달했다. 최종 화면은 계측을 끝낸 뒤 확인했다. [유휴 계측 화면](02_실행화면/90_스튜디오_빈화면_유휴계측.jpg)
- 별도 스레드 표본에서 Windows UI 자동화와 시스템 테마 접근 경로를 관찰했다. 버튼 색 조회를 줄인 진단본에서는 CPU 감소를 확인하지 못했고 빈 화면에서 비활성 선택 버튼의 색이 달라졌다. 해당 변경을 되돌렸다. 자동화 조회를 생략한 실행에서도 높은 CPU가 관찰됐다. 원인별 기여율은 미확립이다. [색 갱신 진단 화면](02_실행화면/89_빈스튜디오_색갱신진단화면.jpg)
- 최초 도구 실행에서 PowerShell의 집계 자료형 때문에 CPU와 private commit 값이 잘못 기록됐다. 집계 및 유효성 검사를 수정한 뒤 다시 수집했다. 30초 경계 전에 마지막 표본을 얻던 경우도 수정했다.
- PERF-001/002 시작 시간, F1~F5, DPI/IME/고대비 및 GPU 메모리를 별도로 검증해야 한다. 이 기록에는 화면 표시 프레임이나 일반 편집 60 fps, 대형 장면 30 fps의 판정이 없다.

재현은 Code에서 새 빈 작업 영역으로 Release Studio를 실행하고 서비스가 준비된 뒤 아래 명령을 실행한다. 창의 수동 및 UI 자동화 조회는 수집이 끝난 뒤 수행한다. 출력 파일과 PID는 실행마다 지정한다.

```powershell
./tools/measure_windows_idle.ps1 -StudioProcessId <PID> -Output .local/idle-sample.json -DurationSeconds 30
```
