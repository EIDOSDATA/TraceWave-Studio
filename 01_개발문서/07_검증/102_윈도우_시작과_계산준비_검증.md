# Windows 시작과 계산 소스 준비 검증

2026-11-21 KST. 완료 계획 12번 F0에서 계산 소스의 첫 봉인을 프로젝트 복구와 병행했다. 일반 프로젝트 열기와 저장은 작업 영역의 영속 상태가 준비되면 동작한다. 새 계산은 기존과 같은 소스 수집, 실제 로딩 원문과의 대조, 파일과 설치 환경 검사를 거친 뒤 진행한다. 준비 실패 시 과거 자료를 읽을 수 있으며 새 계산은 오류를 반환한다. 서비스 종료에서는 준비 스레드를 회수한다.

같은 Windows Release EXE와 CPython을 사용했다. 시험군마다 별도 작업 영역에서 준비 실행 1회와 warm 측정 20회를 진행했고 매 쌍의 순서를 교대했다. 두 번째 실행군은 새 작업 영역을 사용하고 첫 쌍의 순서를 바꿨다. 두 실행군은 같은 Windows 부팅 세션에서 수집했다. 첫 화면은 첫 2D canvas paint이며 새 프로젝트 준비는 첫 화면과 명령 활성화를 모두 확인한 시점이다.

## 제품 회귀

두 수명 회귀에서 소스 준비를 지연시킨 상태로 새 프로젝트를 만들고 저장했다. 준비가 끝나기 전에는 새 계산 식별 조회가 대기했고, 준비 실패 후에도 작업 영역을 읽었다. 실제 Windows에서는 저장·재열기 두 사례와 실제 WSL2 해석 취소·이전 결과 재열기를 포함해 표시 전송과 GUI 시험 5개를 통과했다.

실제 계산·원본 봉인과 서비스·RPC·작업·구현 감사 회귀 81개 및 CTest 13개도 모두 통과했다.
