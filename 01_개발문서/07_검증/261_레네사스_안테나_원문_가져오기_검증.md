# Renesas 원본 패턴의 Windows 가져오기 검증

2026-11-21 KST. AN-B-027의 전폭 IFA, 축소 IFA 1·2, 단층 IFA와 ZOR를 실제 Windows Studio에서 각각 열었다. 단층 IFA는 DXF 직접 선택, 나머지 4종은 공식 ZIP 선택을 사용했다.

각 예제에서 원본 SHA256, 층·미할당 넷과 원점 대응, 손실 확인, 2D 후보 적용, native 캔버스의 선택과 이동, 저장, 서비스 재시작 후 같은 편집 형상의 복원을 검증했다. 원래 선택 파일을 제거한 뒤 프로젝트 저장소에서 보존한 바이트와 parser 보고서를 읽었다. 기존 보드, 재료, 적층, 포트, 넷, 확장 기록과 미정 공구를 가진 홀이 유지됐다. 새 동박은 미할당 넷, 재료 미지정, EM 포함 꺼짐으로 생성됐다.

Windows 실행 5개 시나리오의 합산은 85.769초다. 서비스에서는 공식 ZIP과 개별 DXF의 같은 레이어·영역 결과, 원문 해시 불일치 거절, 생략 미확인과 외곽 초과 차단을 확인했다. [라이브러리 계약](../05_기능설계/05_출력교환/07_제조사_안테나_라이브러리.md)
