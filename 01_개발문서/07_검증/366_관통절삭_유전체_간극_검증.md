# 관통 절삭을 포함한 유전체 간극 검증

2026-11-23 / Windows 개발 PC와 WSL2 openEMS / RF04

해석 전 검토가 비도금 원형 홀, 내부 다각형 절삭, 원호 끝 슬롯의 실제 관통 벽을 유전체의 간극 경계에 포함한다. 관통부 내부는 유전체 포함 판정에서 뺀다. 슬롯의 두 직선과 양쪽 반원을 사용해 절삭 재료 안쪽의 인공 경계를 제거한다. 비교 대상과 가장 가까운 두 점과 통과 셀을 기존 격자 화면에서 확인한다.

| 독립 기하 시험 | 간극 mm |
| --- | --- |
| 외곽 반경 2 mm 원통과 X=2.4 mm 면 | 0.4 |
| 반경 0.5 mm 관통 홀 안의 가장 먼 상자 모서리 (0.2, 0.2) mm | 0.5 - sqrt(0.2^2 + 0.2^2) |
| 폭 1 mm 슬롯의 직선 벽과 중심에서 0.2 mm 떨어진 상자 면 | 0.3 |
| 반경 0.5 mm 슬롯의 원호 끝과 가장 먼 상자 모서리 (-0.35, 0.1) mm | 0.5 - sqrt(0.35^2 + 0.1^2) |
| 내부 사각 절삭과 시험 상자의 최근접 두 벽 | 0.2 |

원호의 (3, 2) mm와 IFA의 (32, 12) mm에 지름 1.5 mm의 비도금 홀을 두고 실제 검토 및 준비 XML의 위치, 반경, 높이를 대조했다. 두 기판 모두 이 홀에 따른 유전체 간극 누락이 0건이며 읽기 검토로 프로젝트 기록이 변하지 않았다. 관련 Python 16건과 Windows Release CTest 14건을 통과했다.

부분 높이 절삭, 겹치는 PTH 보어와 다른 재료의 복합 체적은 별도 처리 범위다. 여기서의 거리는 해석에 전달한 형상의 기하 간극이다.
