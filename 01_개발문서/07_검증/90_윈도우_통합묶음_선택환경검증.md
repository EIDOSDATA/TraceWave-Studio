# Windows 통합 묶음 선택 환경 검증

2026-11-20 KST. 완료 계획 13번의 `c253881` 통합 묶음에서 기본 CPython과 함께 같은 호스트에 별도로 설치된 OCCT 및 WSL2 openEMS를 연결했다. 수신 코드에 전달한 WSL 현장 감사 파일을 기존 승인 환경의 파일과 SHA256으로 대조했다. [기본 수신 검증](88_윈도우_통합묶음_수신검증.md)

| 실제 Windows 시험 | 결과 |
| --- | --- |
| 필수 치수가 미정인 CAD 입력 | STEP 파일과 표시 메시 게시를 차단했다. |
| OCCT와 wxGLCanvas | STEP 출력과 3D 표시, 편집·저장, 취소 뒤 이전 산출물 재열기를 확인했다. |
| WSL2 openEMS | 31개 표본의 이전 결과를 보존했다. 다음 해석의 guest 연결과 실행을 확인한 뒤 취소했고, 종료 확정 상태와 서비스 재시작 뒤 이전 결과를 대조했다. |

세 시험이 105.737초에 통과했다. WSL 취소 버튼 상태 변경은 25.73 ms, 서비스 접수는 251.17 ms, 종료 관찰은 1691.98 ms였다. 이 표본의 서비스 접수는 F4의 200 ms 목표를 초과했다. 해당 실행 동안 전체 서비스 회귀가 별도 프로세스에서 진행 중이었다. 실해석과 고속 로그를 함께 적용하는 반복 계측 및 새 Windows 설치 이미지의 선택 환경 설치는 별도 검수 범위다.
