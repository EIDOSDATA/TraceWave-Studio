# Windows 취소 종료의 화면 표시 지연 검증

2026-11-21 KST. CAD와 출력의 상태 조회는 평상시에 200 ms, 취소 응답을 기다리는 동안 50 ms 간격을 사용한다. 단일 미응답 조회 제한을 유지하며 CAD 조회 오류는 200 ms 간격에서 재시도한다.
