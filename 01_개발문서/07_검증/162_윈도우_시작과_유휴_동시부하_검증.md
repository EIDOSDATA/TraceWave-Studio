# Windows 시작과 빈 작업 영역 유휴 재검증

2026-11-21 KST. 20회 시작 계측은 다른 전체 Studio의 대형 장면/결과 반복과 Windows 회귀가 진행 중인 상태에서 수행했다. 같은 부팅에서 빈 작업 영역을 사용했다. 첫 화면은 실제 2D 그리기, 편집 준비는 신규 프로젝트 명령 활성화의 QPC를 기준으로 삼았다.

| --- | ---: | ---: | ---: |
| 첫 2D 화면 | 1.860초 | 6.395초 | 13.085초 |
| 새 프로젝트 편집 준비 | 2.066초 | 6.395초 | 13.085초 |

동시 부하에서 warm 목표 1.5초와 2초를 초과했다. 서비스 병렬화 비교의 별도 실행에서는 첫 화면 p95 1.770초, 편집 준비 p95 1.976초였다. 서로 다른 Windows 재부팅 후의 첫 실행 5회는 진행하지 않았다. [기존 시작 비교](142_윈도우_첫화면과_편집준비_검증.md)
