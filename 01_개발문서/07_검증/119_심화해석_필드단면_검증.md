# 심화 해석 필드 단면 검증

2026-11-21 KST. 완료 계획 12번 PERF-F3에서 결과 화면이 기존 심화 계산의 봉인 필드 파일을 읽을 수 있도록 보강했다. 심화 격자 상한은 300만 점이다. 결과 조회는 실제 원시 파일당 64 MiB 상한, 봉인 길이와 SHA256, HDF5 자료형과 Yee 좌표·주파수·결과 소유권을 검사한다. 한 번의 단면 조회는 최대 4096점이다. 이 제한은 서비스와 HDF5 읽기 직전 모두 적용한다. 기존 계산 설정과 저장 원본은 유지했다.

HDF5 회귀에서는 512 x 192 x 28 격자, 기록 주파수 1개, 복소64 성분 3개의 합성 필드 배열을 실제 파일로 읽었다. 배열 크기는 63 MiB다. 선택한 2 x 2 단면의 복소수 4개를 대조했고, 98304점을 요청하는 단면은 원본 배열을 읽기 전에 거절했다. 이 시험은 파일 읽기와 자원 상한을 검증한다.

현재 Windows Studio에서 기존 openEMS 봉인 E/J/rotH를 열어 두 기록 주파수의 관심 영역을 10회 조회했다. 서비스 재시작 후 같은 응답과 좌표, 원본 해시, 프로젝트 개정, 제작·측정 미정값을 확인했다. 이전 결과 비교와 조건 페이지를 포함한 결과 GUI 3개, 실제 HDF5/기록 필드 서비스 14개가 통과했다. 새 FDTD 계산은 수행하지 않았다. [이전 실제 필드 기록](65_실제_필드단면_검증.md)

1 GiB 단일 필드 파일과 10만 점 복소 곡선 8개는 여전히 별도 보강이 필요하다. 현재 worker의 파일/패키지 봉인과 복소 표본 상한에서 이 입력을 받을 수 없다. PERF-F3 전체 메모리 수용도 남는다. [성능 설계](../04_화면설계/02_화면_선정과_성능_설계.md)
