# Windows 실행 화면 캡처와 사용성 검수

2026-11-22 KST. TraceWave Studio의 실제 Windows 11 라이트 화면을 [승인 시안 84개](../04_화면설계/13_전체화면목록.json)와 대조해 가독성, 사용성, 공통 테마를 검토했다. 기준 소스는 f85766e다. 검수는 150% 배율의 일반 창과 폭 1020 DIP의 작은 창에서 진행했다. 빈 작업 영역, 편집과 3D 생성이 가능한 IFA 사본, 보존 해석 사본, 합성 측정 사본을 사용했다. 목표 설정의 응답 미확정 상태는 별도 사본의 서비스 응답을 제어해 재현했다.

## 실행 화면 대응

84개 시안의 ID를 화면별 평가 HTML과 CSV에 모두 기록했다. 표에는 가독성, 사용성, 테마별 관찰 사항과 대응되는 실제 캡처가 있다. 배포물은 로컬 검수 자료로 제공한다. 파일 선택 창에 표시된 다른 Windows 폴더 내용은 자료에서 제외했다. 프로젝트의 원래 개정과 결과는 별도 사본에서 읽었다. 승인 시안과 과거 R1 프리릴리스는 각각 기존 이력을 사용한다.

- 설계 화면의 3D 형상과 구리층 표시를 실제 CAD 생성 뒤 확인했다. 3D 형상의 절단 전용 시안(S12.section)과 통합 채택 이력(UI24.history)은 해당 전용 화면을 확인하지 못했다.
- 저장본과 복구 후보, 스냅과 끝점 편집, 목표 기준과 이력, 문헌 후보의 실제 적용 전 미리보기, 해석 자원 및 기록 출력, 수렴 보고서, 급전의 단자와 기준면, 출처와 가정은 현재 화면에 대응하는 범위로 기록했다. 열린 창과 각 별도 시안의 전체 동작을 구분한다.
- 서비스 응답 미확정은 검수용 오류를 사용했다. 대화상자에서 미확정 상태가 표시되고 재적용이 비활성인 것을 확인했다. 실제 데이터 손상이나 복구를 유발하지 않았다.
- 해석 화면 일부는 기록 유무가 다른 보존 결과를 조회했고 측정 보고서는 합성 자료다. 실제 제작이나 측정의 판정을 추가하지 않았다.

- 네이티브 CTest 13개를 통과했다. 타깃 변경, DRC, 보존 복소 값과 Smith 및 원본 비교에서 서비스 재열기와 저장 원본을 대조했다.
- 목표·템플릿 지연 회귀는 현행 실행과 기준 실행에서 모두 GUI 대기 시간 초과가 발생했다. 시간 초과 위치가 달랐다. 지연 없는 목표·템플릿 흐름은 통과했다.


- 최종 Release의 SHA-256은 1361de91c85650a61b64c88f6794b666a0145c609bdaf257ff986d9e45dca416이다. 명령 찾기에서 원호를 검색하고 실행해 원호 그리기 모드로 들어갔다. 새 안테나 생성이나 원호 적용 전에 검수를 끝냈다.
- 64점 좌표 편집, 적층과 외부 STEP 재열기, 도면 생성 취소와 재검수 취소를 확인했다. 기록 필드의 서로 다른 주파수에서 실제 ROI 10회 조회와 재열기 뒤 원문 확인을 통과했다. 실제 화면에는 요청한 단면의 1024개 성분 표본이 표시됐다.
- 면, 패드 및 비아 전체 흐름 시험은 기준 실행에서 서비스 응답 시간 초과, 수정 실행에서 GUI 대기 시간 초과가 발생했다. 두 실행 모두 해당 시험 전체를 완료하지 못했다. 형상 입력 대화상자의 표시와 취소는 실제 창에서 따로 확인했다.

로컬 검수 묶음은 기준 또는 개별 변경 전 56장과 변경 후 128장, 승인 시안의 84행 평가표를 포함한다. 25행은 개선, 44행은 실행 화면 검수, 13행은 부분 대응, 2행은 전용 화면 미확인으로 표시했다. 이 분류는 화면 확인 범위를 나타낸다.
