# Windows 본드플라이 공급·경화 두께 검증

2026-11-21 KST. Windows Release Studio에서 본드플라이의 공급 두께 0.24 mm와 경화 두께 0.15 mm를 서로 다른 시험 수량으로 입력했다. WSL2 openEMS에서 같은 PCB와 급전의 표면층 제외 상태와 본드플라이 포함 상태를 실행했다. 두 결과를 재열기한 뒤 S11·효율·방사 단면을 비교했다.

공급과 경화 두께 및 각 입력 출처를 저장 후 대조했다. 봉인된 준비 산출물에는 본드플라이의 계산 구간 1.0~1.15 mm와 해당 재료 ID가 있다. 계획 시험은 공급 두께만 미정으로 변경해도 계산 체적이 동일함을 확인했다. 경화 두께가 미정이면 실행을 차단하고, 같은 피복의 보조층이 높이 방향으로 중첩되면 진단한다.

이 시험은 외면에 명시 배치한 보조 유전체 모델이다. 재료명이나 공급 두께에서 실제 적층 조건을 추정하지 않았다. 납품 재료의 수치와 실측 정확도는 미평가다.
