# 도면 자동 치수와 홀 표 검증

2026-11-23 KST. 원호와 IFA 검증 사본에서 도면에 사용할 참조 치수를 설정하고, 고정 개정에서 기입한 값과 설정을 저장한 프로젝트를 다시 확인했다.

## 검증 입력과 Windows 조작

- 원호는 20 mm 원형 기판, 중심선 반경 2 mm, 명시 급전 간극 2 mm, 비도금 홀 두 개를 사용했다.
- IFA는 40 x 60 mm 기판, 명시 급전 간극 2 mm, 비도금 홀 두 개를 사용했다. 선택 도체층에는 원호가 없다.
- 출력의 기술 도면에서 현재 개정을 고정했다. 자동 치수에서 도체층과 왼쪽 홀 중심을 선택했다. 원호는 기준선식, IFA는 좌표식을 사용했다.
- 원호는 모델 반경, 신호선 길이와 저장된 구동 급전을 불러왔다. IFA는 방사선 길이와 저장된 구동 급전을 불러왔다. 홀 표를 켜고 도면에 적용했다.
- 치수 검사와 홀 표를 열고 치수 설정을 프로젝트에 적용했다. 상단의 저장으로 저장됨을 확인했다. 각 Windows 프로세스를 종료하고 다시 시작해 새 고정 개정으로 별도 설정 입력 없이 같은 값을 재검토했다.

| 사례 | 기입 | 누락 | 병합 중복 | 대상 없음 | 홀 표 |
| --- | ---: | ---: | --- | --- | ---: |
| 원호 | 7 | 0 | 2건, 모델 반경과 기존 급전 구동 | 0 | 2행 |
| IFA | 6 | 0 | 1건, 기존 급전 구동 | 1건, 선택 뷰에 원호 없음 | 2행 |

홀 표의 중심 좌표는 왼쪽 기준 홀 대비 (0, 0)과 (6, 0) mm다. 완성 지름은 모두 1.2 mm이며 비도금 원본과 미정 공구를 그대로 표시했다. 홀 표는 미리보기에서 이름이 붙은 별도 페이지로 선택할 수 있다.

## 재입력과 원본 대조

- 두 사례에서 기준선식과 연쇄식의 기준 차이, 좌표식, 존재하지 않는 기준점과 모델 치수, 급전 좌표 누락, 도면과 1:1 제조 형상 옵션의 분리를 확인했다.
- PDF, SVG, DXF를 두 사례에서 각각 생성했다. 별도 reader가 표시 글자, 좌표, 선·원호 경계와 홀 표를 다시 읽었다. 원호 PDF는 봉인된 별도 Windows 출력 worker로도 발행했다. sidecar에 저장된 검토 설정과 전체 고정 원본을 대조했다.
- 프로젝트 저장·재열기와 설정의 실행 취소·다시 실행에서 기판, PCB 홀, 적층, 도체, 포트, 연결과 기존 스마트 치수를 대조했다. 도면 변경 전후의 실제 PCB 해석 입력도 일치했다.
- Windows Release 빌드와 CTest 14개, 관련 Python 회귀 105개, 문서 링크 검사를 통과했다. 시험 코드는 [도면 자동 치수 시험](../../Code/tests/test_drawing_annotations.py)에 있다.

현재 자동 치수 대상은 기판 외곽과 도체층 뷰다. 치수선 겹침 완화와 수동 위치 보존은 도면 치수 정렬 작업에서 다룬다. [연관 도면 계약](../05_기능설계/05_출력교환/04_연관도면과_출력재검수.md), [후속 개발 순서](../09_개발계획/15_기능채택과_개발검증_순서.md)
