# 공칭 주파수에서 설계 변수의 S11 응답 검증

검증일 2026-11-23

목표별 후보 순위에서 공차 모서리 비교를 사용한다. 공칭 후보의 유한 S11 직접 표본 중 dB 값이 가장 큰 주파수를 찾는다. 다른 축은 공칭에 고정하고 한 축의 최소와 최대를 적용한 후보에서 같은 주파수의 차이를 구한다. 양쪽 차이가 확인된 축은 입력 범위 안에서 가장 큰 절대 변화 순으로 비교한다. 해당 주파수의 유효 표본이 부족하면 미정으로 표시한다. 개별 축 결과는 실제로 명시한 변화 범위에 대응한다.

- 직렬 저항 공칭 20 ohm 시험에서 기준 반사 계수 14/59, 최소 10 ohm에서 19/109, 최대 50 ohm에서 11/29를 사용해 1 GHz의 dB 차이를 독립 산술과 대조했다. Windows Python 시험 24개가 통과했다.
- 보존한 실제 원호 선폭 1.0, 1.05, 1.1 mm 후보의 복소 S11을 직접 읽어 계산했다. 공칭 12 GHz에서 -1.144264751 dB였으며 최소와 최대 선폭의 변화는 각각 +0.141473566 dB와 -0.023019870 dB였다. 조회 전후에 연구 기록이 일치했다.
- 통계 민감도, 변수 간 상호 작용, 공정 분포와 실제 제작 및 실측 조건은 별도 범위다.

방사선 X 끝점 30, 31, 32 mm를 각각 계산한 IFA의 복소 표본을 직접 읽었다. 공칭의 2.4835 GHz에서는 -1.776675709 dB였고 최소와 최대 끝점의 차이는 각각 -0.706084836 dB와 +0.461077757 dB였다. 공칭 실행이 시간 한도로 종료된 별도 선폭 시험은 공칭 응답과 전체 모서리 최저값을 미정으로 표시했다.
