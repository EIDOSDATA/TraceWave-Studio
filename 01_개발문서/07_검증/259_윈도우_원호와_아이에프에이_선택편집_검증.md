# Windows 원호와 IFA 선택 및 정밀 편집 검증

2026-11-21 KST, Windows Release Studio와 로컬 OCCT 및 wxGLCanvas/OpenGL을 사용했다. 두 설계의 원본은 이미 연결된 도체와 명시적인 시험용 급전을 가진다. 기판, 적층, 재료와 RF 실장 입력은 원래 시험 범위를 유지했으며 실제 제작·측정은 미정이다.

| 사례 | 확인한 동작 |
| --- | --- |
| 원형 기판의 연결 원호 | 2D에서 원호를 클릭한 뒤 선폭을 1.0 mm에서 1.4 mm로 변경했다. 잘못된 0 mm 후보를 거절하고 한 번의 실행 취소와 다시 실행을 확인했다. |
| 접지와 단락이 연결된 평면 IFA | 방사선 길이를 26 mm에서 27 mm로 변경했다. 3D에서 병합된 도체를 클릭한 뒤 원본 선택 목록에서 방사선을 이름으로 골랐다. |
| 이전/현재 3D 및 재열기 | 편집 뒤 이전 개정의 3D 클릭이 현재 선택을 바꾸지 않으며 갱신 안내가 남았다. 갱신한 메시를 클릭해 2D, 트리, 속성의 동일 원본 ID를 대조했다. 저장·재열기 뒤 새 치수와 바뀌지 않은 기판, 포트, 도체, 출처 및 원래 스냅샷 해시를 확인했다. |
| 비도금 홀 선택 | 기능 적용 뒤 홀의 속성 선택과 2D 강조를 같은 ID에 유지했다. 기존 기능 편집의 이력과 저장·서비스 재시작도 확인했다. |

이 실행은 형상, 입력 오류 복귀와 선택 연동을 검증한다. 해석 수렴, RF 목표 도달, 실제 제작·측정은 미평가다. 지원하는 다른 보기와 환경의 전체 4번 수용은 [단계별 남은 작업](../09_개발계획/04_현행버전_남은작업.md)에 둔다.

정밀 편집 서비스 회귀 20개, 기존 이름·평면 편집과 native CAD 회귀 4개가 통과했다. 최종 빌드에서 원호, IFA, 캔버스·좁은 창과 비도금 홀을 포함한 Windows GUI 시험 4개가 77.659초에 통과했다.
