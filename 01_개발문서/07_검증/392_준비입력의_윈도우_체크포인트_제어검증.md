# 준비 입력의 Windows 체크포인트 제어 검증

2026-11-23 / RF17 / Windows, WSL2 TraceWave-Dev, openEMS 0.37.0, DMTCP 4.2.0

## 사용 순서

1. WSL 해석 환경을 설정한 Studio에서 사용자 PCB 프로젝트를 열고 "설정 및 해석 실행"을 선택한다.
2. 급전 한 개를 사용하고 방사, 전기장/자기장 및 전력 수지 기록을 끈다. "체크포인트용 단일 스레드"를 선택한 후 검토를 실행한다. 격자와 포함 형상을 확인한 뒤 "체크포인트 입력 준비"를 누른다.
3. 준비 단계에서 게시한 XML의 설계 개정, 준비 계획 ID와 SHA-256을 확인한다. "새 엔진 시작"을 누르면 별도 WSL 작업 번호가 생긴다. "상태 확인"으로 현재 상태를 읽는다.
4. "체크포인트 기록 후 정지"를 누르면 실제 전압/전류 표본을 확인한 뒤 엔진과 열린 파일을 보존한다. "기록에서 재개"는 같은 설치와 봉인 이미지를 확인하고 이어서 계산한다. 종료 코드, 시간 단계와 전압/전류 표본 수가 표시된다.
5. 창을 닫은 뒤 해석 결과 탭의 "체크포인트 작업"에서 표시 중인 결과의 원래 준비 계획이나 프로젝트의 다른 준비 계획을 고른다. 같은 입력의 작업 목록과 WSL 폴더를 다시 확인할 수 있다. 통상 프로젝트 해석 결과는 "검토한 조건으로 실행"에서 생성한다.

## 실행 경계

- 서비스는 프로젝트가 소유한 준비 계획 및 원래 설계 개정을 조회한다. 원래 준비 manifest에 적힌 XML과 봉인된 파일의 SHA-256, 크기, 역할을 대조한다. XML과 엔진 해시가 동일한 프로젝트/준비 계획에 해당하는 작업만 조회한다.
- Windows는 프로그램에 포함한 도구와 고정된 배포판/일반 사용자로 실행한다. 로컬 Windows 드라이브에 설치한 코드와 작업 폴더, WSL의 기본 드라이브 마운트를 사용한다. 도구는 XML 요소와 수치, 단일 급전 U/I, 자원 상한 및 원래 엔진의 SHA-256을 시작 전에 다시 검사한다. 기존 377의 이미지와 보조 자료 봉인, 라이브러리 확인 및 재시도 이력이 적용된다.
- 최초 실행 프로세스를 별도 감독 프로세스가 기다려 실제 종료 코드를 보존한다. 종료 코드를 확인할 수 없거나 비정상 종료된 경우에는 종료 미확인으로 표시한다. 파형 파일이 남았다는 이유로 완료를 판정하지 않는다.
- 이 실행은 U/I 시간 파형용 독립 작업이다. 일반 프로젝트 계산의 S 파라미터 게시, NF2FF, 필드 및 수렴 판정은 기존 해석 작업에서 처리한다. 체크포인트 생성과 재개는 377에 기록한 전용 설치가 필요하다.

## 검증

- 1개 스레드와 2개 스레드, 다중 급전, 방사, 필드, 전력 수지의 입력 적격성 분기를 검사했다. 비정상 종료 코드 및 종료 코드 기록 누락은 통계 파일이 있어도 완료로 표시되지 않았다.
- 실제 WSL 원호 및 IFA의 연속 실행과 복원 후 실행의 U/I 데이터 행을 바이트 단위로 대조한 기존 시험은 506.371초에 통과했다. 체크포인트 보조 파일을 변조한 시도는 거부됐고 원래 바이트를 복원한 뒤 재시도했다. 원호와 IFA 입력의 강제 최대 스텝 및 표본 수는 377을 따른다.
- 원호 프로젝트의 공개 snapshot/plan/prepare를 거쳐 봉인된 단일 스레드 XML 10,959바이트를 Windows 연결에서 실행했다. XML SHA-256은 5eb71d0885686230e8a5dd342e7bee9040fdab06d91054e77cb0b32905fe27f3이다. 잘못된 XML 해시로 시작하는 요청과 다른 프로젝트 번호를 이용한 조회를 각각 거부했다. 정지, 재개, 재조회 뒤 1,960 스텝, 전압 246개, 전류 246개였으며, 같은 XML을 별도 폴더에서 연속 실행한 두 파형의 모든 시간 및 값이 바이트 단위로 일치했다.
- 원호 프로젝트 사본에서 이름을 바꾸어 현재 설계 개정을 갱신한 뒤 같은 준비 ID를 열었다. 원래 설계 개정, XML 참조 및 해시가 그대로였다. 봉인 XML 사본에 한 바이트를 추가하면 서비스가 E_HASH로 차단했다.
- 같은 원호로 새 엔진을 자연 종료시킨 뒤 늦게 정지를 요청한 경우도 확인했다. 이미 끝난 1,960 스텝 및 각 246개 표본이 정상 종료로 유지됐고 중단 이미지를 새로 만들지 않았다.
- Windows Release에서 IFA 프로젝트의 조건 검토와 체크포인트 입력 준비 버튼을 누른 뒤 별도 창의 시작, 상태 확인, 체크포인트 정지, 재개, 상태 재조회를 수행했다. 일반 프로젝트 해석 결과는 새로 게시되지 않았다. 재개한 엔진은 최대 4,000 스텝에서 끝났고 전압 112개와 전류 112개의 시간/값이 별도 연속 실행과 바이트 단위로 모두 일치했다. 개정 변경 후 원본 재조회, XML 변조 거부 및 적격성 시험을 포함한 2개 시험이 790.953초에 통과했다. 최대 스텝 도달은 수렴 합격을 뜻하지 않는다.
