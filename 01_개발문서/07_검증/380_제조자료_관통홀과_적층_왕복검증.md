# 제조 자료의 관통 홀, 원형 패드와 적층 왕복 검증

2026-11-23 / Windows / KiCad 10.0.8 / EDA15, EDA16

## 적용 범위

PCB 파일 가져오기의 대응 화면에서 "원문 원형 패드와 관통 홀 적용"과 "원문 도체 및 유전체 층 두께 적용"을 각각 선택한다. 지원하는 층과 넷에 대상을 지정한 다음 변경 목록과 원문 손실을 확인하고 적용한다. 두 선택의 기본값은 해제다. 가져온 원문은 기존 게시 파일과 별도 개정에 보존한다.

- IPC-2581 Rev C의 양극성 도체층에서 사전에 정의된 원형 Pad, 관통 DRILL Span에 선언된 완성 지름과 도금 상태를 읽는다. 패드와 홀의 원문 padstack, 위치 및 넷이 일치할 때 연결한다. 단일 StackupGroup의 원문 순서와 두께를 사용한다. [IPC-2581 스키마](https://webstds.ipc.org/2581/)
- ODB++에서는 BOARD/SIGNAL 층의 양극성 원형 P와 BOARD/DRILL의 P를 읽는다. 넷과 핀 그룹은 EDA의 FID C/H를 실제 층 파일의 특징 번호로 따라간다. 관통 범위와 도구표의 도금 구분 및 완성 지름이 일치해야 한다. KiCad 10.0.8 파일의 FINISH_SIZE와 layer_dielectric 단위는 실제 제조 ZIP과 대조했다. 다른 생산자의 적층 속성에는 이 해석을 적용하지 않는다. [Siemens ODB++ Design Format 8.1](https://odbplusplus.com/wp-content/uploads/sites/2/2024/08/odb_spec_user.pdf)
- 적층은 현재 설계와 도체층 및 유전체층의 순서가 같고 기존 층들이 연속일 때 반영한다. 아래 기준면을 고정하고 위쪽 각 층의 아래 면 위치를 다시 계산한다. 기존 ID, 층 이름과 재료 참조, 유전율 및 손실값을 유지한다.
- 기재되지 않은 공구 지름과 배럴 도금 두께는 미정으로 유지한다. 모든 도체층의 실제 원형 패드가 같은 위치, 넷, 지름으로 홀에 연결된 경우에만 단일 KiCad 관통 패드로 재출력한다. 비대칭 패드, 블라인드 홀, 슬롯, 임의 마스크 개구, 부품 핀 소유권과 내부 특수 도형은 이 경로의 검증 범위 밖이다. STEP 배럴 실체 및 RF 손실 계산에는 독립적인 물성이 필요하다.

## 독립 프로그램 왕복

40 x 60 mm IFA의 외부 KiCad 보드에 아래 시험 형상을 추가했다. 원문에서 IPC-2581C와 ODB++를 각각 만들고 두 수신 형식에서 도체, 홀과 적층을 적용했다. 잘못된 층 대응은 원본 변경 전에 거부됐다. 반영 직전 수신 설계의 코어 두께를 0.83 mm로 바꾸어 실제 변경과 역명령 복원을 대조했다.

| 독립 입력 | 보드 중심 좌표 mm | 대조한 값 |
| --- | --- | --- |
| 도금 관통 홀 | 17, 18 | 완성 지름 0.60 mm, 위아래 패드 지름 1.80 mm, 동일한 IFA 넷, 패드 2개 연결 |
| 비도금 관통 홀 | 23, 21 | 완성 지름 1.10 mm, 패드 0개, 넷 미할당 |
| 상면 원형 패드 | 27, 24 | 지름 1.40 mm, IFA 넷 |
| 적층 | F.Cu / core / B.Cu | 두께 0.035 / 0.930 / 0.035 mm |

저장된 모델의 패드 3개와 홀 2개를 재열었다. KiCad에 보드를 전달한 뒤 IPC 입력에서 IPC 및 ODB, ODB 입력에서 IPC 및 ODB로 교차 재출력했다. 네 조합에서 원, 관통 홀과 적층 값을 확인했다. 시험값은 합성 설계이며 실제 보드 제작 또는 측정 조건을 확정하지 않는다.

Windows의 test_manufacturing_contacts가 실제 교환 worker로 두 원문을 업로드한 뒤 봉인, 미리보기, 적용, 스냅샷 게시 및 KiCad를 통한 재출력까지 273.946초에 통과했다. 업로드 당시 원본 파일을 다시 읽어 바이트가 같은지 확인했다. 관통 배럴의 도금 두께가 미정인 모델에서도 교환 미리보기는 명시된 패드와 완성 홀 개구를 그린다. 전용 CAD 환경의 test_cad_pcb_features 7건도 통과했다.
