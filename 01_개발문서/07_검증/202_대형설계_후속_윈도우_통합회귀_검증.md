# 대형 프로젝트 보강 후 Windows 통합 회귀

2026-11-21 KST. 대형 문서 검증 재사용을 적용한 서비스와 Windows Release로 GUI 전체 44개를 실행해 모두 통과했다. 실제 OCCT, WSL2 openEMS, 출력 도구를 연결했다. 별도의 원문 작업 영역을 사본으로 복사해 실제 기록 필드 시험도 실행했다. 실행 취소와 재열기, 편집과 원문 보존, 측정 조건 미정을 각각 검사했다. 이 실행 뒤 출력 확인 창과 대비 테마의 사용성 검증을 별도로 수행했다.

서비스 회귀의 첫 실행은 저장소 루트에서 시작했다. 1435개 중 1278개가 통과했고 조건부 제외 153개와 작업 디렉터리에 의존하는 오류 4개가 있었다. Code를 작업 디렉터리로 둔 별도 재실행에서 세 모듈과 MCP stdio 항목의 11개가 모두 통과했다. Code 기준 수집 1442개에서 두 실행을 합쳐 1289개 통과, 환경 조건 제외 153개를 기록한다. 재실행은 작업 디렉터리를 Code로 바로잡아 수행했다. [실행 기록](203_대형설계_후속_윈도우_통합회귀_실행기록.json), [이전 통합 실행](184_윈도우_통합회귀와_화면합성_검증.md)
