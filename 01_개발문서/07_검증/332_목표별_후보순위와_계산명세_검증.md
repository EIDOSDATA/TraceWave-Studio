# 목표별 후보 순위와 계산 명세 검증

2026-11-23 KST. 연구 패널에서 보존 후보의 목표별 순위와 계산 명세를 조회한다. 두 조회는 프로젝트, 후보, 원본 평가와 결과를 수정하지 않는다.

- 한 목표에서 기준별 표본 통과 비율 중 가장 작은 값을 사용한다. 모든 목표에서 동등 이상이며 어느 한 목표에서 앞선 후보만 다른 후보를 지배한다. 기준 하나라도 표본이 비어 있으면 계산된 다른 표본과 함께 순위에 넣지 않고 제외 수에 남긴다. 계산하지 않은 후보, 실패, 목표 없음은 별도 집계한다.
- 독립 예상 벡터로 반대 목표 우세, 동률, 두 단계 이상의 지배 관계와 미정 기준을 검증했다.
- 실제 외부 직렬 저항망 연구에서 0 ohm 실패, 10 ohm의 두 목표 통과 및 50 ohm과 단위가 다른 동치 후보의 공동 순위를 대조한다. 저장 개정의 다시 열기에서도 봉인 데이터셋과 평가에 바탕을 둔 순위와 계산 명세 해시가 일치한다.
- 계산 명세 JSON에는 원래 사용자 단위와 정규화 입력, 설치 시나리오, 회로·자료 기반의 해시, 실행 환경, 개정과 스냅샷을 담는다. 보존 원본을 사용한 입력 대조에 쓰며 비대화형 복원·정합 및 솔버 실행은 별도 후속 작업이다.
- 결과는 명시된 주파수 표본에 대한 순위다. 연속 대역, 부품 공차 또는 제작·측정 사실은 아직 검증하지 않았다.

- 준비 통계가 없는 과거 실행이 시작 전에 실패하면 봉인 계획 격자로 예상 비용을 다시 계산한다. 중단 사유가 보존되고 명시적 재개에도 이미 접수한 해석 시도 횟수가 환급되지 않는지 확인한다.
- Windows WSL의 실제 PCB 스윕에서 단일 후보 계산과 해석 환경을 분리한 재열기를 통과했다.
- 연구를 저장한 뒤 현재 프로젝트를 편집해도 보존 개정에서 후보 3개와 그중 단위 동치 후보 1개가 같은 검토 해시로 다시 나왔다. 시험 환경을 바꾸면 정규 입력 일치를 유지한 채 엔진과 검토 해시의 차이를 표시했다. 재검토 전후 journal은 동일했다.
