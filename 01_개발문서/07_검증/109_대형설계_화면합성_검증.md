# 대형 설계 2D 화면 합성 검증

2026-11-21 KST. 완료 계획 12번 F1의 네 층·형상 10000개·매개변수 1000개 시험 설계에서 서비스의 표시 모델을 생성했다. 같은 mm/deg 장면을 Windows 시험 창에 넣고, Studio와 같은 DesignCanvas, wxGraphicsContext 및 확대 처리기를 사용했다. 실제 Windows Desktop Duplication의 출력 시각에 각 합성 표본의 번호를 연결했다. 실제 Studio의 편집·저장·재열기는 별도로 검증했다. [Studio 저장과 재열기](107_대형설계_윈도우_페이지_검증.md)

120 Hz, 144 DPI, 2560 x 1600 출력에서 1000 x 700 캔버스를 사용했다. 각 35초 동안 8 ms 고해상도 입력을 요청했다. 화면에 합성된 서로 다른 표식의 간격을 모두 사용했고 누락된 입력과 최대 간격도 기록했다.

| 구성 | 합성 간격 수 | p95 (ms) | p99 (ms) | 최대 (ms) | 입력-합성 p95 (ms) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 1회 | 1760 | 25.40 | 32.27 | 49.42 | 35.61 |
| 선 배치 1회 | 1929 | 25.16 | 25.57 | 33.05 | 33.60 |
| 기존 2회 | 1808 | 25.31 | 26.03 | 49.45 | 32.93 |
| 선 배치 2회 | 1706 | 25.42 | 32.21 | 41.27 | 37.86 |
| 선과 원호 배치 | 1812 | 25.28 | 25.69 | 33.90 | 34.27 |
| Direct2D와 경로 배치 | 1190 | 34.08 | 40.08 | 43.68 | 41.09 |
| 중복 동기화 제거 1회 | 1955 | 25.07 | 25.46 | 31.75 | 31.34 |
| 중복 동기화 제거 2회 | 1766 | 25.40 | 25.98 | 33.96 | 32.48 |

선 배치와 선·원호 혼합 배치는 p95 개선이 반복되지 않았다. Direct2D는 실제 context를 생성했으며, 이 장면에서 기존 방식보다 간격이 길었다. 그리기 명령이 추가됐을 때만 명시 동기화하는 개선을 반영했다. 같은 장면에서 최대 간격은 기존 49.42~49.45 ms와 비교해 31.75~33.96 ms였고, p95는 25.07~25.40 ms였다. **60 fps 기준 간격 16.67 ms에는 미달했다.** [원시 실행 기록](110_대형설계_화면합성_실행기록.json)

최종 Windows Release 빌드에서 형상 10000개의 저장·재열기, 선/원호 마우스 편집, 합성 시각 검증을 포함한 6개와 CTest 13개를 통과했다.

재현하려면 F1 시험 프로젝트와 서비스의 `project_canvas`를 사용해 표시 JSON을 만든 뒤 [Windows 합성 계측 도구](../../Code/tools/canvas_display_probe.cpp)의 `--scene`에 전달한다. 전경의 시험 창과 표시 영역을 유지한다. F1의 이동·드래그, 표 스크롤, 대표 3D와 전체 메모리 수용은 별도 시험이다.
