# Windows 내부 묶음의 외부 CAD와 해석 검증

2026-11-20 KST. 같은 내부 검증 ZIP을 별도 수신 폴더에 풀고 실제 Windows의 제품 실행 파일과 포함 서비스 소스를 사용했다. 설치해 둔 고정 OCCT 환경과 실제 WSL2 openEMS 런타임을 외부 경로로 연결했다. WSL 현장 감사 파일의 해시를 새 수신 폴더의 사본과 대조했다. [수신 ZIP과 기본 경로 검증](73_윈도우_내부묶음_수신검증.md)

| 실제 Windows 시험 | 확인 |
| --- | --- |
| 필수 두께 미정 | CAD 작업이 실패로 남고 STEP/표시 메시를 게시하지 않는다. |
| OCCT STEP 및 wxGLCanvas | 생성과 표시, 편집 및 저장, 취소 뒤 이전 결과 복원과 서비스 재열기를 확인했다. |
| WSL2 openEMS | 첫 결과를 저장하고, 다음 실행의 guest 연결을 확인한 뒤 취소했다. 영속 종료, 불명 상태 해소, 이전 결과 재열기를 확인했다. |

총 3개가 227.547초에 통과했다. 이번 실행은 수신한 코드가 이미 설치되고 확인된 선택 worker를 사용할 수 있다는 근거다. 새 Windows 설치 이미지의 worker 설치, F4 로그 부하의 지연 p95, RF 수렴과 제작·측정은 별도로 검수한다. [실행 기록](78_윈도우_내부묶음_외부환경_실행기록.json)
