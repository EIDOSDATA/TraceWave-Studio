# 곡면 전력의 삼각화와 실제 해석 격자 변화

2026-11-23 KST. 같은 원형 PCB와 단일 집중 급전, 동박 및 유전체, 8 mm 외부 여백으로 Windows openEMS 0.37.0을 실행했다. 10 GHz에서 복소 E와 H 체적을 각각 기록했다. 사용한 제품 투영과 덤프는 406의 동일한 보간 및 곡면 적분을 따른다. 중심 (0, 0, 2.8) mm, 반지름 0.9 mm를 고정하고 위 반구의 바깥쪽 법선 및 닫힌 구의 바깥쪽 법선을 확인했다. [406 적분](406_삼각_곡면의_복소장_전력적분_검증.md)

## 같은 장의 곡면 세분화

구면 위로 각 변의 중점을 투영해 삼각형을 4배씩 늘렸다. 0.35 mm의 같은 E/H에서 아래 값을 얻었다. 매끈한 곡면의 독립 적분은 SciPy 삼선형 성분 보간과 구면의 코사인 및 방위각에 64 x 64 Gauss 구적을 적용했다.

| 삼각화 수준 | 열린 위 반구의 W*s^2 | 닫힌 구의 W*s^2 |
| ---: | ---: | ---: |
| 4면 / 8면 | 3.598745e-31 | 3.255437e-33 |
| 16면 / 32면 | 4.978377e-31 | 7.120334e-33 |
| 64면 / 128면 | 5.351255e-31 | 8.815945e-33 |
| 256면 / 512면 | 5.447221e-31 | 9.982178e-33 |
| 매끈한 수치 적분 | 5.479207e-31 | 1.052252e-32 |

세밀한 반구의 면적은 5.025314e-6 m^2였다. 같은 장에서 매끈한 반구와의 차이는 0.584%였으며 세 격자에서 모두 0.59% 이하였다. 최종 삼각형의 정점 순서를 뒤집으면 반구 및 닫힌 구의 전력 부호가 각각 반전했다.

## 같은 곡면의 실제 격자 세분화

| 최대 Yee 간격 (mm) | 실제 격자점 | 반구 256면 (W*s^2) | 닫힌 구 512면 (W*s^2) |
| ---: | ---: | ---: | ---: |
| 0.50 | 152,100 | 6.977119e-31 | 2.746111e-32 |
| 0.35 | 456,000 | 5.447221e-31 | 9.982178e-33 |
| 0.25 | 1,164,870 | 5.121681e-31 | 4.871247e-33 |

세 계산 모두 에너지 종료 조건에 도달했다. 반구의 변화는 각 비교에서 세밀한 격자를 기준으로 28.09%와 6.36%였다. 소스가 바깥에 있는 닫힌 구의 순통과량을 같은 격자의 반구 통과량으로 나누면 각각 3.94%, 1.83%, 0.95%였다. 곡면 근사 오차는 독립 참조와 비교했고, 장의 격자 의존성은 마지막 두 격자에서도 남는다. 더 엄격한 수렴 판정에는 같은 반지름과 물성으로 더 세밀한 해석을 실행해 반구의 차이를 다시 확인한다. 0.25 mm에서는 E/H 기록의 4096점 한도에 맞춰 XY 기록 창을 줄였으며 검사 표면과 해석 영역은 동일하다.

## 재현

같은 설계 원본 해시는 `cf9f7e1751609312105a7bca44357401f1e21460ec960d415f446910e91082dc`다. 원시 파일, 실제 격자, 각 E/H의 영역과 검증 SHA-256을 계산 폴더에 보존한다. Windows native 계산과 고정 HDF5 독자는 각각 410의 CPython 환경을 사용한다. [410 Windows 실행 환경](410_아홉_급전과_분포_모드_원문_검증.md)

```powershell
Set-Location Code
$env:PYTHONPATH = 'src'
$env:OPENBLAS_NUM_THREADS = '1'
$native = '.local/native-win-037/Scripts/python.exe'
$numeric = '.local/rf-check/Scripts/python.exe'
$openEms = '.local/openems-win-037/openEMS/openEMS.exe'
foreach ($spacing in @(0.5, 0.35, 0.25))
{
    $run = ".local/curved-flux-$spacing"
    & $native tools/verify_pcb_curved_flux_convergence.py $run --executable $openEms --case fixtures/pcb_worker_smoke.json --grid $spacing
    & $numeric tools/verify_pcb_curved_flux_convergence.py $run
}
```
