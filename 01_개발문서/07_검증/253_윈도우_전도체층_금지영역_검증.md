# Windows 전 도체층 금지 영역과 후보 검증

2026-11-21 KST. PCB 금지 영역 폼에서 **모든 도체층에 적용**을 선택했을 때 전체 범위 플래그가 설정되고 개별 층 목록은 원래대로 유지됨을 실제 Windows 컨트롤로 확인했다. 기존 홀 편집, 단위 변경, 저장과 서비스 재시작도 같은 GUI 회귀에서 통과했다.

서비스 시험은 별도 목표나 연결 조건이 없는 PCB의 전층 금지를 실제 PCB 해석 계획에 적용했다. 계획 오류는 금지 영역과 도체 ID, 위반 위치를 반환했다. 개별 층 범위에서도 비아의 시작층뿐 아니라 통과하는 도체층과 종료층을 검사한다.

원호 템플릿 시험에서 추가할 도체가 해당 영역을 침범하면 적용 해시가 나오지 않았다. 동일한 입력에서 영역을 침범하지 않는 경우 후보 검토를 완료했다. 보드 원본과 제외된 조건, 미정 치수는 읽기 검토에서 보존했다.
