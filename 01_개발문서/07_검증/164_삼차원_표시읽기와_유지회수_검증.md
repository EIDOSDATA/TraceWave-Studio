# 대형 3D 표시 읽기와 30초 유지 정책

2026-11-21 KST. 전체 Windows Studio의 30초 유지 전환을 한 서비스에서 30회 완료했다. 매회 대형 설계, 삼각형 100만 개, 필드 단면 열 회, 복소 곡선 8개를 열었다. OpenGL 문맥 유지 조건을 30회 충족했다. 대기 상태의 초기 5회와 마지막 10회 합산 private commit 중앙값은 221.11 MiB와 377.79 MiB로, 증가 156.68 MiB가 32 MiB 기준을 초과했다.

유지 정책을 진단하기 위해 대형 설계와 3D만 여는 시험, 대형 설계와 필드·곡선만 여는 시험을 1초 대기로 각각 열 회 실행했다. Studio의 첫/마지막 대기 private commit은 3D 포함 131.86/141.94 MiB, 결과 포함 44.63/47.91 MiB였다. 이 두 실행은 모듈별 비교에만 사용한다. [150초 유휴 30회](144_통합_대형_프로젝트_유휴회수_검증.md)

3D 표시 파일의 정점과 삼각형은 한 행씩 검증해 연속 배열로 옮긴다. 같은 SHA256, 몸체 대응, 좌표와 인덱스, 렌더링 정밀도 계약을 적용한다. 거대한 중간 JSON 트리를 구성하는 단계를 줄였다. 변경 후 실제 Studio에서 표시 원본 100만 개, 축소 103040개, 선택 및 전체 맞춤 100만 개를 확인했다. Release CTest 13개에 압축 좌표 파싱, 오입력과 취소 회귀를 포함했다.
