# 선택형 측정 파일 비교와 빈 프로젝트 안내

2026-11-22 KST. 외부 측정 파일 비교를 선택 기능으로 적용한다. Windows Release의 새 프로젝트에는 측정 파일을 등록하지 않았다. 설계에서 일반 비교를 열고 측정 비교 탭으로 전환했다. 가져오기는 사용 가능했고 기록 추가 및 비교 확정은 원본이나 기록을 고르기 전 비활성 상태였다. 빈 목록의 안내가 화면과 Windows 접근성 트리에서 일치했다. 제작 및 측정 조건 미정도 확인했다.

Windows 측정 서비스·기록·정렬·폼 58개가 274.520초에 통과했다. 합성 Touchstone 보정 전후의 고정 기준면, 자료 분류, 시료와 교정, 불확도 원문과 과거 보고서를 대조했다. CTest 13개도 통과했다. 실제 안테나의 VNA/OTA 결과는 해당 사례에 파일과 조건이 있을 때 연결한다. [측정 기능 계약](../05_기능설계/04_해석결과/09_측정기록과_정렬비교.md)
