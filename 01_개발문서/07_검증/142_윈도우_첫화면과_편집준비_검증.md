# Windows 첫 화면과 편집 준비 계측

2026-11-21 KST. 완료 계획 12번 F0에서 실제 Windows Studio를 조작 가능한 DPI 144, 2560 x 1600, 120 Hz 화면에서 열었다. 같은 부팅, Python 실행 파일과 서비스 소스의 SHA256을 맞춰 준비 실행 1회 후 각 20회 수집했다. 첫 2D 화면의 실제 그리기 완료와 새 프로젝트 명령의 활성화를 Windows QPC로 기록했다.

서비스 병렬 시작과 탭 그룹 사전 배치를 채택했다. 결과와 연구의 화면은 시작할 때 준비하며 현재 업무의 탭만 처음부터 native 탭에 붙인다. 첫 화면 뒤에 숨은 작업 공간을 만들거나 첫 진입까지 늦추는 실험과 강제 그리기 실험은 편집 준비 p95가 늘어 채택하지 않았다. 같은 부팅과 서비스 소스를 사용했고 실험 뒤쪽에는 별도 장시간 수명 검증과 서비스 회귀가 진행됐다. 실행군 사이의 부하 차이가 수치에 영향을 줄 수 있다.

최종 p95는 첫 화면 1.770초, 편집 준비 1.976초였다. warm 목표 첫 화면 1.5초는 초과했다. warm 편집 준비 2초는 이내였다. 작업 영역은 매 실행군에서 분리했고 별도의 F5 반복 회수 시험 중 시작 시간을 계측했다. 서로 다른 물리 재부팅 직후의 cold 실행 5회는 남는다. [원시 실행 기록](143_윈도우_첫화면과_편집준비_실행기록.json)

채택한 구성으로 실제 Windows에서 시작 이정표, 서비스 실행 실패 처리, 스튜디오 탭 이동과 2D 편집·저장·재열기의 세 시험을 통과했다. Release CTest 13개도 통과했다.
