# R1 RC8 화면별 사용성 재진단

2026-11-24 KST. [RC6 설치본 진단](420_알원_설치본의_화면별_사용성_진단.md)과 [RC8 개선 기록](421_알원_설치본_사용성_개선과_재검수.md)에 이어, RC8 수신 GUI와 DLL을 Windows에서 직접 사용했다. 검수 사본의 GUI SHA-256은 수신 파일과 일치했다. 기준 소스는 `ad9f0a3fd687501aca9085e0442df4095b3dd9b3`이다. Windows 기본 openEMS 0.37.0과 CSXCAD 0.7.0, 검수용 CAD/교환 환경을 사용했다. 창은 1648 x 954 및 1128 x 767, Windows 표시 배율은 150%였다. 조작은 별도 프로젝트 사본과 합성 입력에서 수행했다.

점수 척도는 RC6과 같다. 85 이상은 주요 작업이 원활함, 70~84는 작지만 반복되는 마찰, 55~69는 순서나 문맥을 익혀야 함, 54 이하는 기본 경로에서 막히거나 결과를 발견하기 어려움을 뜻한다. 사용 편의성은 조작 및 복귀 경로, 가독성은 값과 기준을 판독하는 난이도, 기능성은 확인한 범위의 처리 결과와 보존을 평가했다. 축 안에서는 화면별 가중치를 같게 했고 종합은 세 평균을 같은 비중으로 계산했다. 검수자 한 명의 관찰치다.

## 동작 검증

- 기판과 도체층을 만들고 선의 끝점을 움직인 뒤 실행 취소했다. 설계 목표, 입력 진단 4건, DRC 결과, 제조사 카탈로그 조회, 저장 후보 비교도 시험했다.
- 실제 Windows 해석 결과의 네트워크 31표본, Smith, 전력 및 효율, 보존 NF2FF 방사 2D/3D와 편파를 조회했다. 새로 계산한 E 필드의 10 GHz Ex 단면 42표본과 복소 마커를 확인했다.
- 합성 Touchstone 원문 5표본을 가져오고 새 시료를 기록했다. 50 ohm 직렬 RLC 소자의 기준면을 지정하고 회로 검토, 사본 저장, 결합 계산, 새 결과 저장을 완료했다.
- PDF 두 쪽과 Gerber Job 묶음을 실제 생성했고, 인계 미리보기와 시험용 수렴 보고서를 조회했다. CAD에 저장된 3D와 YZ 단면을 바꾸고 새 갱신을 실행했다.
- 네이티브 및 지원 검증은 16건 중 15건 통과했다. 설계 7/7, 결과·출력 5/6, 네트워크·스윕 3/3이다. 결과·출력의 독립 RF 검증 1건은 '보고서와 다른 pin'에 관한 복합 단언에서 중단됐다. 어느 조건이 위반됐는지는 확인이 필요하다.

## 재개 조건

- 별도의 온라인 클린 Windows x64 PC를 확보하면 수신, 실제 설치, 시작 메뉴, Windows 해석과 표준 제거를 검증한다. 이 절차는 R1 최종 수용에서 필요하다.
- 실제 교정 원문과 VNA, 제작 검수용 기판이 준비되면 교정/측정과 제작 결과를 확인한다. 403 유전체 격자와 손실 PCB의 물리 정확성은 독립 기준과 별도 외부 결과로 확인한다.
- 외부 기본 PDF 뷰어와 운영체제 고대비, 스크린리더의 실제 동작을 해당 환경에서 다시 확인한다. 복구 상태는 별도 사본에서 복원 적용 및 원본 보존을 추가 확인한다.
- 제품 코드 수정은 이번 진단 범위에 포함하지 않았다. 화면별 점수 CSV, 캡처 색인, 이미지와 로그는 검수보고서 묶음으로 전달했다.
