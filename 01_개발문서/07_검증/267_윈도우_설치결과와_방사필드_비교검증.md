# Windows 설치 결과와 방사 필드 비교 검증

2026-11-21 KST. 같은 시험 PCB와 급전 구성을 유지하고 기판 단독과 하부 개방 유전체 케이스 설치 상태를 현재 Windows/WSL2에서 각각 계산했다. 개정이 고정된 두 결과를 다시 열고 공통 S11 31점과 10 GHz 방사 단면을 비교했다.

| 검사 | 확인한 근거 |
| --- | --- |
| 복소 반사와 방사 좌표 | 공통 주파수의 복소 S11과 VSWR, 급전 기준면과 Z0를 표시했다. 같은 방사 중심, 반경과 각도 표본을 요구한다. 중심을 1 mm 이동한 시험과 주파수를 1 Hz 옮긴 시험에서 기준 불일치 또는 미기록 상태를 유지했다. |
| 전력 및 방사 | Fourier 전력 W*s^2, 방사 효율의 수용 전력 분모와 총 효율의 입사 전력 분모를 확인했다. 지향성, 이득, 실현 이득의 각도별 곡선과 최대값을 선택할 수 있다. Etheta/Ephi 기저와 계산 종료 상태가 보인다. |
| 필드와 과거 조건 | 설치 fixture의 미기록 필드를 표시했다. 별도의 실제 기록 필드 프로젝트는 두 주파수에서 ROI를 10회 옮겨 복소 원문과 좌표를 대조했다. 저장과 다시 열기에서 선택 pin과 원문이 유지됐다. 결과의 과거 목표와 제조/측정 미정 상태를 보존했다. |

실제 Windows/WSL2 설치 시험 1개(79.351초), 기록 필드와 과거 결과 중심 회귀 3개(45.781초), 결과 계열 서비스 66개 중 64개 통과와 환경 조건 제외 2개, Release CTest 13개를 확인했다. 수렴, 독립 RF 정확도와 시료 측정은 각 단계에서 판정한다.
