## 실행 검수와 남은 조건

- 새 프로젝트 생성, 원호와 급전 선택, 끝점 이동 및 실행 취소, 작은 창에서 편집, 3D와 STEP 갱신, 8~12 GHz Windows openEMS 해석, Smith 및 방사와 편파 조회, PDF 출력 및 인계 미리보기를 실행했다. 합성 Touchstone 1포트 5표본을 읽어 등록했고, 별도 시험 부하에서 50 ohm 직렬 회로의 결합 후보 4표본을 계산했다.
- 설치본 실행 파일로 통합시험 8건을 실행했다. 목표와 문헌, 설계 규칙, 표면과 외부 STEP, 과거 복소 결과와 비교, RLC와 목표 평가, PCB/CAM과 KiCad 교환, 방사와 재시작의 7건이 통과했다. 스윕 시험은 회로 후보 3건 완료와 Windows 솔버 호출 0건을 확인한 후 실행 환경 식별자 단언에서 실패했다. 자동 연결된 Windows openEMS가 보존 정의에 기록되는 계약과 재개 조건을 함께 확인한다.
- 기록이 포함된 필드 단면, 실제 연구 진행과 수렴 보고서, 교정된 VNA 자료 비교 등의 직접 조작은 화면별 표에 적은 재개 조건으로 진행한다. VNA 자료와 교정 기록을 확보하면 합성 파일 시험과 별도로 실제 측정 조건을 검수한다. 응답 불명 복구는 복제 데이터와 격리된 서비스에서 캡처한다.
