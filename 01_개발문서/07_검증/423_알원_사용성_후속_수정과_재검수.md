# R1 사용성 후속 수정과 재검수

2026-11-24 KST. [RC8 화면별 사용성 재진단](422_알원_알시팔_화면별_사용성_재진단.md)의 개선 순서에 따른 검증 기록이다. 검수에는 Windows 네이티브 빌드와 별도 프로젝트 사본을 사용한다.

## P1-1. 해석 실행과 결과 연결

작업에서 수신한 완료 결과의 원본만 현재 해석으로 표시한다. 접수, 실행 및 새 원본 읽기 동안 결과 열기를 잠그고 아래에 남은 그래프가 이전 실행임을 표시한다. 취소, 실패 및 프로젝트 재열기 뒤에도 보존된 원본은 이전 해석으로 열 수 있다. 프로젝트, 결과 파일과 표본의 원본 ID를 대조한 뒤 화면을 바꾼다.

Windows wxWidgets 및 실제 openEMS 0.37.0에서 원형 PCB 입력 거절, 1포트 원형/원호 PCB 해석과 과거 결과 보존, 실행 중 취소 접수와 종료 및 재시작 3건이 통과했다. 네이티브 시험은 완료 시 버튼, 새 작업 접수 시 잠금, 취소와 재열기 시 이전 결과 버튼을 확인한다.

## P1-2. 3D 갱신 중 선택한 화면 유지

3D를 요청한 시점에 3D를 표시한다. 이후 다른 작업 공간으로 이동하면 CAD 완료, 실패 및 보존 형상 조회가 현재 작업 공간을 그대로 유지한다. 화면 밖에서 확인한 형상은 대기시키고, 사용자가 다음에 3D를 열 때 실제 렌더링을 시작한다. 렌더링 완료 뒤 확대 및 갱신 제어도 복원한다.

실제 wxWidgets, OpenGL과 CAD 작업자를 사용한 시험 2건이 통과했다. 출력이 실패해도 출력 작업 공간이 유지됐다. 출력 중 결과 작업 공간으로 전환한 뒤 완료까지 현재 화면을 유지했고, 3D로 돌아가 1512개 삼각형의 표시, STEP 내용과 해시, 취소와 재열기를 확인했다. 첫 진입 및 반복 전환 시간은 최종 화면 검수에서 비교한다.

## P1-3. 목표 편집에서 적용 응답이 유실된 경우

목표 편집을 유지한 채 '적용 확인'에서 서비스에 다시 연결한다. 명령 ID로 저장된 권위 개정과 변경 사유를 읽고, 같은 명령을 다시 보내지 않는다. 승인된 개정이 확인되면 해당 목표를 표시한다. 저장되지 않았고 기준 개정이 그대로면 대역과 변경 사유를 보존하고 편집을 다시 허용한다. 이후 개정이 있거나 다른 작업도 끊겼을 때는 재열기 경로를 안내한다.

Windows 앱과 격리 시험 서비스에서 목표를 기록한 직후와 기록 직전에 각각 연결을 한 번 끊었다. 기록한 시험에서 같은 대화상자 안에 LoRaWAN 목표 1건과 변경 사유가 돌아왔다. 기록하지 않은 시험에서는 Wi-Fi 대역 2412~2462 MHz와 사유가 남았고, 명시적으로 적용한 뒤에만 신규 목표가 1건 표시됐다. 목표 RPC 검증 16건도 통과했다.

## P2-1, P2-2. 기본 수량 입력과 결과 범위

목표와 설계 규칙의 수량은 입력 방식, 값, 단위를 같은 행에 표시한다. 미정 필드의 값 칸은 비어 있고 직접 입력을 선택하면 활성화된다. 시안과 출처, 기존 수치의 보존 방식은 동일하다. 결과 목록은 전체 보존 해석과 현재 개정 자료를 구분한다. 원본이 한 건 있지만 미선택, 빈 범위, 표시 원본이 이 페이지 밖인 상태를 문구로 구분한다. 해석에서 직접 여는 원본은 전체 보존 해석 목록을 사용한다.

Windows 네이티브 시험 4건이 통과했다. 다중 목표 저장과 순차 조회, 늦은 응답 방어, 제조 규칙 및 DRC 재열기와 원래 출처의 해시, 과거 결과의 선택과 Smith 및 내보내기를 확인했다. 목표 시작 주파수의 입력 방식/값/단위가 초기 폼에서 함께 표시되는지 검증했다.

## P2-3, P2-4. 수치 판독과 연구 기본 대역

Smith 마커와 끝점 입력에 짧은 표시값을 사용한다. Smith에서는 정확한 마커 원본을 복사하고 끝점은 편집 칸에 들어가 원래 값을 확인한다. 편파 표는 자주 확인하는 지표와 상태를 앞에 두고 행 상세에서 실제 값을 그대로 복사한다. 연구는 단일 유효 포트에 맞는 기본 주파수 범위를 제시하고 범위를 벗어나면 해당 입력으로 이동한다. 해석 조건 차이에도 주파수 단위를 표시한다.

Windows 네이티브에서 과거 원본과 Smith 마커, 원형 PCB 끝점 편집과 재열기, 실제 NF2FF 편파 표의 전환과 재시작, 물성 누락 시 연구 생성/실행 차단을 확인했다. 별도 조회에서 유효한 8~12 GHz 포트가 동일한 기본 범위와 근거를 제공하고 프로젝트 저장 바이트를 그대로 유지하는 것을 확인했다. 연구 중단/재개용 WSL 전용 시험은 이번 Windows 폼 검증에 포함하지 않았다.
