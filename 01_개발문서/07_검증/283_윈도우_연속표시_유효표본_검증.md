# Windows 연속 표시 표본의 판독과 단독 2D 계측

2026-11-22 KST. Windows 11 개발 PC, 내장 화면 2560 x 1600, 144 DPI, 120 Hz에서 7959227의 Windows Release 장면을 시험했다. 형상 10000개, 층 4개와 1000 x 700 캔버스에서 가운데 버튼 이동을 35초간 진행했다. 비교하던 WSL 해석은 종료된 상태였다. 현재 화면은 승인 기준 장비의 1920 x 1080 조건과 다르다.

PERF-006의 연속 조작 표본을 별도로 집계했다. 조작 종료 후 뒤늦게 표시된 입력은 전체 지연 통계에 두고, 연속 조작의 유효 간격 수에서는 제외했다. 이전 판독 필드를 유지하고, 연속 구간의 p95와 최소 30초 및 1000개 요건을 별도로 출력한다. 회귀 시험 6개가 통과했다. [판독 회귀](../../Code/tests/test_windows_canvas_display_trace.py), [승인 성능 명세](../12_보관이력/01_승인기준선/01_삼점사/26_화면_선정과_성능_설계.md)

표시 창에서 합성 프레임 2089개를 관측했다. 유효한 연속 간격은 2086개였고 p50 16.658, p95 17.109, p99 17.413, 최대 49.976 ms였다. p95는 개발 PC에서 16.667 ms 목표를 초과했다. 실제로 대응된 입력의 표시 지연 p95는 27.482, p99 29.045 ms였다. 공식 F1 성능은 기준 장비와 다른 조작군까지 포함해 판정한다. 원시 파일 SHA256은 f31fdd0b84fcaa709c3d9ce937d5bce52dc502c593ed0a1b048b1ff8408b6c86이다. [실행 원문](284_윈도우_단독_이차원_이동_실행기록.json)

화면 사각형 외부 선분의 교차 계산을 건너뛰는 시험 변경을 비교했다. 별도 메모리 DC의 전체/확대 화면 RGB는 기존 두 실행과 모두 같았다. 전체 보기 p95는 기존 두 번 16.088 및 20.135 ms, 시험 빌드 17.551 ms였고 확대 이동은 5.308, 5.568, 5.508 ms였다. 안정적 개선을 확인하지 못해 시험 변경을 제외했다.

해당 변경의 실제 이동 한 건과 기본 빌드의 도형 드래그 두 건은 입력 캡처 중단으로 종료됐다. 기본 빌드의 100000행 표는 두 번 모두 마지막 행 부근까지 이동했으며, 연속 계측은 전경 상태나 창 위치·크기 변경을 감지해 중단했다. 중단 결과에서 성능 값을 산출하지 않았다. 마지막으로 성공한 표 스크롤 결과의 p95 30.845 ms와 60 fps 목표 미달을 유지한다. [이전 표와 복구 검증](278_윈도우_표시성능과_복구_재검증.md)

재부팅 5회, 실제 두벌식 IME 조합, 스크린리더 오류 발화, 혼합 DPI와 기준 PC의 F0~F5는 해당 조건을 확보한 뒤 재개한다.
