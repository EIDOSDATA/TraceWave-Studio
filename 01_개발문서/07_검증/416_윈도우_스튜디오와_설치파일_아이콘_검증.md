# Windows Studio와 Setup.exe 아이콘 검증

2026-11-23 KST. 승인 시안의 파란 제목 표시줄 아이콘을 참고해 파란 바탕, 흰 RF 파형과 구리색 급전점으로 Studio 아이콘을 제작했다. 16, 20, 24, 32, 40, 48, 64, 128, 256 px를 하나의 ICO에 넣었다. 24 px 이하에서는 파형을 굵게 하고 급전점을 단순화했다. [재생성 도구](../../Code/tools/generate_windows_icon.py) [제품 아이콘](../../Code/ui/wxwidgets/tracewave.ico)

| 확인 항목 | 실제 결과 |
| --- | --- |
| 아이콘 재생성 | Pillow 13.0.0에서 같은 ICO 바이트를 생성했다. SHA-256 `52e2a8af06d78e59d9f41fe5ce40d491acf45abd3ef028637be8d5584feb2c5b` |
| Studio 창 | 실행 중인 창의 `WM_GETICON`에서 24 px 제목 표시줄 아이콘과 48 px 큰 아이콘을 읽었다. Windows에서 원본 ICO의 해당 크기를 그린 픽셀과 각각 일치했다. |
| 탐색기 파일 아이콘 | `tracewave_gui.exe`와 Setup.exe의 기본 아이콘을 각각 16 px와 32 px로 추출해 원본과 대조했다. 네 이미지가 모두 일치했다. |
| 시작 메뉴 | 후보가 푼 설치 스크립트의 등록 함수를 검증용 임시 메뉴 폴더에서 실행했다. `.lnk`의 실행 파일과 아이콘 위치가 설치된 `tracewave_gui.exe` 및 아이콘 인덱스 0을 가리켰다. |
| 새 경로 설치 | 실제 RC4 Setup.exe로 Windows 설치를 완료했다. 새 설치본의 Studio를 실행해 제목 표시줄과 탐색기의 아이콘이 원본과 일치하는 것을 다시 확인했다. |
| Release 회귀 | CTest 14개와 배포 묶음 Python 검사 4개가 통과했다. |

## 설치 후보

`r1-rc4`는 앱과 Setup.exe에서 같은 ICO를 쓰는 온라인 설치 후보다. 제품 개정은 `80f5015e7445fdc8350d8ccec2c556c8e72e17ef`다. Setup.exe는 15,301,120바이트이고 SHA-256은 `1eb106f77a7fa9655921feceaedd345403f8031796eddafd836fe5bb796db49c`다. 내장 ZIP은 SHA-256 `fca53e7bcbe9d4294d28a4cad311f78d14fdba4cd50f0fee37deccf98ac25acb`다. GitHub 게시 자산을 다시 다운로드해 Setup.exe와 SHA-256을 대조했다. [Setup.exe와 SHA-256](https://github.com/EIDOSDATA/TraceWave-Studio/releases/tag/r1-rc4)

별도 온라인 클린 PC에서 WSL2와 openEMS를 포함한 전체 설치 및 실제 해석을 검수한다. 이전 단일 설치 후보의 검수와 개발 PC WSL 상태는 415에 있다. [이전 설치 후보의 검수](415_단일_윈도우_설치_패키지_검증.md) [R1 작업표](../09_개발계획/04_현행버전_남은작업.md)
