# Windows PDF 재검수의 고속 로그 취소

2026-11-21 KST. Windows Studio Release에서 PDF를 생성하고 첫 재검수 결과를 게시했다. 이어 별도 PDF 재검수 worker가 실제 검수 함수를 반복하는 동안 표준 오류 파이프에 합성 로그 부하를 걸었다. 새 작업 영역 세 곳에서 2000행 이상을 배출한 뒤 실제 GUI의 취소 버튼을 눌렀다. 측정한 로그량은 초당 986.03~996.92행이다. [계측 도구와 형상·도면 생성 시험](242_윈도우_형상과_도면_고속로그_취소검증.md)

| 지표 | 중앙값 (ms) | p95 (ms) |
| --- | ---: | ---: |
| 취소 버튼 잠금 | 0.119 | 0.400 |
| Studio 접수 | 63.871 | 95.676 |
| Windows Job 회수 | 8.784 | 11.928 |
| Studio 종료 표시 | 182.410 | 219.395 |

세 회 모두 실제 트리 회수와 작업 상태의 순번, 이전 PDF 및 재검수 결과의 파일 hash를 확인했다. 저장 개정과 출처·미정값을 출력 worker 없이 다시 열었다. 표본 3회의 p95는 최댓값이다. F4의 규정 표본 수와 기준 호스트 수용은 남는다. [실행 기록](245_윈도우_도면재검수_고속로그_실행기록.json)

형상·도면 생성 계측 명령의 `--group cad --group pdf`를 `--group pdf-verify`로 바꾸고 새 시험 루트에 수집한다.
