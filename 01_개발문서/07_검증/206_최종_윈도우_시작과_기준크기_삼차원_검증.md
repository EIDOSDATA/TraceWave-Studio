# Windows 최종 Release의 시작과 기준 크기 3D 화면

2026-11-21 KST. 별도 회귀와 F5 실행을 마친 뒤 같은 부팅과 서비스 원본으로 실제 첫 2D 그리기와 편집 준비의 warm 각 20회를 관측했다. 대비 보강 전후의 2560 x 1600 데스크톱, 최종 Release의 1920 x 1080 데스크톱을 각각 기록했다. Windows 배율은 각각 150%와 100%였다.

| Windows 데스크톱과 빌드 | 첫 화면 중앙값 / p95 / 최대 | 편집 준비 중앙값 / p95 / 최대 |
| --- | --- | --- |
| 2560 x 1600, 대비 보강 전 | 3.502 / 4.145 / 4.435초 | 3.502 / 4.145 / 4.435초 |
| 2560 x 1600, 최종 Release | 3.552 / 4.212 / 4.346초 | 3.552 / 4.212 / 4.346초 |
| 1920 x 1080, 최종 Release | 3.191 / 3.822 / 4.327초 | 3.191 / 3.822 / 4.327초 |

세 실행군 모두 warm 목표 1.5초와 2초를 초과했다. 운영체제 재부팅 후 최초 실행은 수집하지 않았다. [이전 유휴 및 시작 기록](186_최신_윈도우_시작과_유휴_검증.md)

1920 x 1080은 Windows 데스크톱의 픽셀 모드였고 온보드 그래픽의 CIM 항목은 내장 패널의 2560 x 1600, 120 Hz를 계속 보고했다. 1920 데스크톱에서 전체 Studio의 OpenGL로 100만 삼각형과 축소 103040개를 보였고 객체 선택과 전체 맞춤에서 원본 표시로 돌아왔다. 실제 합성 계측은 창을 전경에 둔 재시도를 포함해 두 번 시행했으나 초기 표식이 대조되지 않았다. 이 해상도의 화면 간격 판정은 미확립이다. 앞선 2560 데스크톱의 35초 합성 p95 18.09 ms는 해당 실행의 근거로 유지한다. 검증 뒤 데스크톱 2560 x 1600과 150% 배율을 복원했다.
