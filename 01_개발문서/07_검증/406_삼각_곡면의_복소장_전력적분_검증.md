# 삼각 곡면에서 기록 전계와 자계의 전력 흐름 적분

2026-11-23 KST. 결과 화면의 곡면 파일 버튼 또는 `tools/integrate_recorded_field_power.py`의 `--surface`에서 XYZ 밀리미터와 0부터 시작하는 유향 삼각형 인덱스가 담긴 JSON을 읽는다. 예제는 `Code/fixtures/field_flux_octahedron.json`이다. 정점 순서가 법선과 출력 부호를 정한다. 구면이나 다른 곡면은 원하는 해상도로 삼각화하여 사용한다.

각 삼각형을 여섯 Yee 성분의 실제 보간 격자 경계마다 자른다. 각 조각에서 동일한 물리 좌표로 E와 H를 보간하고 `0.5*Re(E x H*)`의 법선 성분을 Duffy 변환과 4x4 Gauss 규칙으로 적분한다. W*s^2 단위, 면적, 삼각형 수, 모서리 닫힘, 적분점 수, 곡면 해시, E/H 원문 참조를 제공한다. 인덱스를 공유하는 모서리의 닫힘을 검사하며 방향 오류와 중복 삼각형을 거절한다. 외부 정점의 외삽은 금지한다. 정점과 면은 각각 4096개, 분할 조각은 32768개까지다.

- 기울인 평면 삼각형에서 일정 복소장의 투영 면적을 검산했다. 전체 법선을 뒤집으면 값이 정확히 반대로 바뀌었다.
- 비균일 비동기 격자의 선형장과 비평면 팔면체에서 발산 정리로 독립 검산했다. 면적과 부호 있는 전력의 절대 오차는 1e-19 이하였다.
- 실제 Windows/WSL 결과 `287b34b6-409d-486b-8fc2-829efeb8e71d`의 E/H로 같은 직사각면을 두 삼각형으로 다시 계산했다. 기존 면 적분은 5.348566042388832e-30, 새 적분은 5.348566042388833e-30 W*s^2였다. 저널과 E/H 참조가 보존됐다.
- 같은 봉인 결과와 JSON 예제 8면에서 면적 3.06270023942805e-6 m^2, 적분점 5248개 및 통과량 3.0870024416615374e-32 W*s^2를 출력했다.

Windows Release를 빌드해 CTest 14개가 통과했다. 개별 곡면 해석에서 실제 곡률 근사의 영향은 사용한 삼각화에 따라 달라지고, 필드 자체의 격자 수렴은 원래 풀이에 의존한다.
