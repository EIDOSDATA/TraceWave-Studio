2026-11-22 KST. 실제 Windows Studio와 WSL2 openEMS의 준비 입력을 원호와 IFA로 대조했다. Windows 검수 사본에서 설정 변경, 격자·형상 보기 및 IFA 실행 승인까지 확인했다.

두 사례 모두 모델 최대 간격 0.5 mm, 임계 구간 최소 2분할, 가변 공기 격자 0.8 mm, 성장률 1.5, 외부 여유 10.4 mm를 사용해 검토 격자 전체와 openEMS 준비 좌표를 대조했다. 상한 오류의 초점과 입력값 보존, 수정 시 실행 잠금, IFA의 성장률 오류 초점을 실제 Windows에서 확인했다. 두 사례의 기본 창과 최소 창에서 격자 규모와 설정을 표시하는 두 줄, 보기 조작이 겹치지 않았다. 격자점과 Yee 셀에 천 단위 구분을 표시했다.

## 실제 실행 승인

IFA 검수 사본에서 조건을 검토한 뒤 일반 메뉴에서 실행을 승인했다. 분석 계획 `06f1064b-19d2-41a3-aeb5-7ba35efbbaa3`의 개정, 설정 전체와 준비 입력 해시가 검토 값과 일치했다. WSL2가 준비한 X/Y/Z 좌표 전체의 해시와 격자점 861,930개도 일치했다. 준비 완료와 FDTD 작업의 실행 진입을 확인하고 검수 작업은 취소했다. 전자기 결과 판정은 이 검증 범위에 포함하지 않았다.

관련 Python 회귀는 Windows에서 31개가 통과했으며 WSL2 전용 native 준비 1개를 해당 환경에서 별도로 통과했다.
