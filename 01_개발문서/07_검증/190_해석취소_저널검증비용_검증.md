# Windows 해석 취소와 저널 검증 비용 교차 시험

2026-11-21 KST. 이전 해석 결과를 같은 작업 영역에 보존하면서 실제 WSL2 openEMS를 다시 실행했다. 초당 약 1000행의 로그를 받는 동안 Studio에서 취소했다. 대조와 시험 각 6회를 교차했다. 같은 Windows GUI 실행 파일을 사용했고, 시험 소스만 이미 SHA256을 확인한 동일 저널 상태에 엄격한 JSON 정규형 검사를 재사용했다. 매번 실제 바이트와 해시는 확인했다. 다른 Studio의 대형 전환과 Windows 빌드가 같은 PC에서 실행됐다.
