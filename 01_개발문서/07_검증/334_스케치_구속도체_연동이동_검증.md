# 스케치 구속 도체 연동 이동 검증

검증일 2026-11-23

## 편집 동작

2D에서 도체 몸체를 드래그할 때 저장한 끝점 일치, 중점, 선 위의 점, 접선 또는 상대 오프셋 관계로 연결된 도체를 함께 평행 이동한다. 적용 대기 중에도 같은 묶음을 함께 표시한다. 해당 개정의 모든 변경을 PCB 명령 하나와 역명령으로 저장한다.

급전 단자, 비아 패드, 매개변수 위치 또는 묶음 바깥의 명시 연결을 보존해야 하면 이동 전에 사유를 표시한다. 보존된 고정 좌표와 나머지 관계는 게시 전에 다시 검사한다. 물리적으로 접하는 도체를 자동으로 구속 묶음에 추가하지 않는다. 끝점 재형성 및 연결 설계의 자유도 탐색은 기존 계약을 따른다.

## 원호와 IFA 확인

- 원호 사본에 접선과 끝점 일치 관계를 가진 별도 시험용 원호와 직선을 만들었다. IFA 사본에는 끝점이 연결된 두 시험용 직선을 만들었다. 두 사례 모두 X 0.75 mm, Y -0.5 mm를 입력하여 두 객체만 같은 개정에서 이동했다.
- 변경 전후에 저장 구속, 기존 급전, 연결 기대와 기존 구동 치수의 원문이 일치했다. 실행 취소와 다시 실행에서 전체 도체 배열을 확인했다. 저장 후 서비스를 닫고 재열기하여 설계 원문을 대조했다.
- 원호의 기존 급전 도체에 일치시킨 시험 선은 장면에서 이동 불가로 표시되었고 적용 요청도 거부되었다. 실패 뒤 개정은 같았다.
- Windows Python의 스케치 및 PCB 피처 시험 23개가 통과했다. 제작과 실측 조건은 기존 미정값을 유지했다.
