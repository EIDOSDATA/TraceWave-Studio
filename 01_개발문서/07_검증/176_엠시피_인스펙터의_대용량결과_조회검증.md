# MCP Inspector의 대용량 결과 조회 검증

2026-11-21 KST. Windows Studio에서 저장·재열기한 대형 작업 영역의 독립 사본을 MCP Inspector 2.16.0으로 읽었다. Windows stdio 연결을 요청마다 새로 열어 등록 목록, 2 x 2 필드 단면의 복소값, 비교 곡선의 마지막 두 표본을 조회했다. [MCP Inspector CLI](https://github.com/modelcontextprotocol/inspector/blob/main/clients/cli/README.md)

- 목록은 1075856824바이트 필드와 20020480바이트 곡선 파일의 원문 이름, 저장 개정, 실제 SHA256과 일치했다. 두 자료의 제작·측정 조건은 null로 남아 있었다.
- 2 GHz 필드의 z 단면에서 복소 행 두 개가 각각 (9, 3), (10, 3)으로 반환됐다. 단위와 정규화는 각각 미정과 null이었다.
- 곡선 8개 모두 100000점으로 보고됐다. 인덱스 99998은 결측 mask와 null 복소값, 99999는 유효 복소값을 보존했다. 각 곡선의 주파수와 허수부를 원래 인덱스에서 확인했다.
- 별도 서비스에서 같은 저장 개정과 결과 등록을 다시 읽었다. 원문 등록과 프로젝트 해시는 실험 후에도 일치했다.

이 실행은 외부 클라이언트의 읽기 조회 검증이다. 발행·가져오기·영수증의 별도 왕복 시험은 기존 공식 SDK와 KiCad 기록에 있다. [실제 응답](177_엠시피_인스펙터의_대용량결과_실행기록.json), [SDK 왕복](47_키캐드재저장본_엠시피왕복_검증.md), [Windows Studio 자원 검증](158_대용량_결과의_윈도우_자원_검증.md)
