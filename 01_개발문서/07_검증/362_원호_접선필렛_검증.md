# 선과 원호의 접선 필렛 검증

2026-11-23 / Windows 개발 PC / CAD09

정밀 편집에서 같은 선폭과 도체 의미를 가진 두 중심선의 공통 끝을 선택하고 반경을 지정한다. 선–원호와 원호–원호에서 두 곡선에 접하는 해석형 원호를 생성한다. 원래 선과 원호의 ID는 유지하고 필렛 근처 끝만 줄인다. 원래 원호의 중심과 반경, 방향은 유지된다. 기존 급전 또는 기대 연결을 다시 정의해야 하는 형상과 해가 유일하지 않은 형상은 차단한다.

| 시험 | 필렛 반경 | 독립 중심 mm |
| --- | --- | --- |
| 선과 시계 방향 원호 | 1 mm | (19.0839202, 21.0000000) |
| 반경 5 mm의 두 시계 방향 원호 | 1 mm | (49.0721727, 20.9278273) |

두 시험에서 원래 원호 중심과 필렛 중심의 거리 6 mm를 확인했고, 원본 ID와 각도 방향, 선의 반대쪽 끝, 저장·재열기를 대조했다. 선폭의 절반 이하 또는 원래 반경 이상의 값을 거절했다. Windows 정밀 편집·곡선·구속 Python 시험 39건과 Windows Release CTest 14건을 통과했다.

범위는 끝점이 만나는 열린 중심선이다. 구속된 급전의 재연결, 곡선 모따기와 일반 윤곽의 오프셋은 추가 범위다.
