# Windows 서비스 지원 정보의 시작 지연 교차 검증

2026-11-21 KST. Studio가 초기 서비스 응답의 지원 메서드 목록을 반복 복사하는 부분을 한 참조로 바꾼 시험판을 만들었다. 같은 Windows 부팅과 서비스 소스에서 대조판과 시험판을 각각 10회씩 두 묶음으로 배열해 총 40회를 측정했다. 각 묶음 앞에는 준비 실행 1회를 별도로 수행했다. 같은 PC에서 대형 설계의 유휴 및 유지 회수 검증이 진행 중이었다.

| 실행군 | 첫 2D 중앙값 / p95 / 최대 | 편집 준비 중앙값 / p95 / 최대 |
| --- | --- | --- |
| 기존 GUI 20회 | 1.760 / 4.444 / 4.561초 | 1.907 / 4.444 / 4.561초 |
| 시험 GUI 20회 | 2.293 / 4.845 / 9.862초 | 2.369 / 4.845 / 9.862초 |

모든 표본에서 화면과 편집 준비 시간을 확보했다. 시험판의 실제 연결 성공·실패 구분과 저장·재열기 3개도 통과했다. 시험판에서 warm 목표 1.5/2초를 충족하지 못했고, 이 조건에서 시작 지연이 줄었다는 근거를 얻지 못해 변경을 제품에 적용하지 않았다. 기존의 유휴와 부하 완화 기록은 그대로 보존한다. [교차 실행 기록](195_서비스지원정보와_시작지연_실행기록.json), [이전 실제 Release](186_최신_윈도우_시작과_유휴_검증.md)
