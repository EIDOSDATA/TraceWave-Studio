# 게시 전 저장 실패와 Windows 재열기 검증

2026-11-21 KST. 완료 계획 12번의 복구 시나리오다. 프로젝트 열기 응답의 저장 개정을 Studio에 동기화한다. 서비스가 디스크 저장 실패와 게시 전 실패를 확인하면 상태 표시줄에 "저장 실패"를 표시한다. 사용자에게 기존 저장본과 현재 편집이 보존됐음을 알리고, 공간과 쓰기 권한 확인 후 저장할 수 있게 한다. 접수 여부가 불명확한 연결 장애는 기존 개정 확인 경로로 다룬다.

실제 Windows Studio에서 속성 입력과 실행 취소·다시 실행 후 저장을 실행했다. 격리한 Python 서비스에 `ENOSPC`를 한 번 주입해 새 저널 상태 파일의 쓰기를 실패시켰다. 게시되지 않았다는 진단, 유지된 저장 개정, 현재 편집 상태와 저장 메뉴를 대조했다. 같은 GUI 저장 메뉴를 다시 실행하고 스냅샷과 새 서비스 세션으로 재열기했다. 저장 실패와 완료는 같은 편집 원문을 가리켰다.

동일 빌드의 정상 저장, 속성·수식 편집과 2D 제스처를 포함해 실제 Windows GUI 4개를 통과했다. 저널·편집 서비스·요구 추적 회귀 33개, CTest 13개를 통과했다. 디스크 부족은 쓰기 지점에서 재현했다. 실제 볼륨 전체를 채우는 시험, 전원 중단과 복원 장치 검수는 남는다.
