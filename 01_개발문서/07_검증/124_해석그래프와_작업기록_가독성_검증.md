# 해석 그래프와 작업 기록 가독성 검증

2026-11-21 KST. 사용자 검토에서 해석 결과 축의 불규칙한 숫자, 구분하기 어려운 임피던스 곡선, 작업 코드가 반복되는 하단 기록을 확인했다.

- 결과 화면은 데이터 범위를 감싸는 읽기 쉬운 십진 눈금, 눈금 폭에 맞는 여백과 주파수 (Hz/kHz/MHz/GHz)를 사용한다. 임피던스는 실수부 (Re) 실선과 허수부 (Im) 점선을 범례와 함께 표시한다. 0을 지나는 결과에서 0 기준선이 보인다.
- 처리 중 상태는 실행/저장 가능 여부를 읽을 수 있는 문장으로 알린다. 작업 기록은 기본으로 접히며 펼치면 읽기 전용 문장 목록이 보인다. 내부 단계 이름, 식별자와 파일 경로는 기술 조회 영역을 사용한다.
- 그래프는 보존된 주파수와 값만 읽는다. 미정 표본에서는 선을 끊고 단일 표본은 점으로 나타낸다. 이전 개정 결과와 정확도 검증 전 안내를 계속 표시한다.

실제 Windows에서 해석기 없이 보존 프로젝트를 열었다. 결과 > 해석 결과에서 31개 주파수의 S11과 임피던스로 전환했다. 8~12 GHz 축, 임피던스의 -500/0/500/1000 ohm 눈금, 두 곡선 범례, 접힌 작업 기록과 펼친 뒤 한글 문장 표시를 확인했다. 별도 Windows/WSL2 GUI 회귀에서는 필수 입력 누락, 실제 실행 중 한글 상태, 취소와 기존 결과 재열기 2개를 통과했다. CTest 13개를 통과했다.

이 기록은 해당 해석 결과 화면의 검증 범위다. 전체 작업 영역의 고대비·IME·스크린리더·모니터 이동 검수는 별도다.
