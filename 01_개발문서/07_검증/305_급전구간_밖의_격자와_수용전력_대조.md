# RO4350B 급전 구간 밖의 격자와 수용 전력

2026-11-22 KST. N8에서 종전의 X 8~10 mm, Y 49~54 mm, Z 0.035~0.797 mm 안쪽 격자선만 N7로 되돌렸다. 공통 시각 4.210 ns, N8 시간 간격과 같은 물리 입력에서 세 구간 안·밖을 독립적으로 교체한 네 조건이 갖춰졌다. 공통 시간의 N7, 세 구간만 N8, 바깥만 N8, 전체 N8의 순서다. 새 native 보완 실행은 2277720셀, 30845 반복, 1029.706초였다. XML 및 원시 해시와 별도 진단 결과를 남겼다. [국부 통제 다섯 건](301_급전격자와_관통홀_표면손실_독립대조.md)

기준은 같은 시간 간격의 N7이다. 곱 기준의 상호작용은 네 수용 전력의 비 P(N8)*P(N7)/(P(국부)*P(바깥))-1이다. 입사율과 수용률이 곱으로 연결되므로 두 요인을 같은 방식으로 대조했다. 입력 리액턴스는 ohm의 차이로 비교했다.

원래 N7과 시간 간격만 줄인 N7의 원시 V/I를 표본 사이에서 선형으로 이어 공통 시간까지 직접 Gauss-Legendre 적분했다. 원래의 구간 합과 수용 전력 변화 차이는 최대 0.02356%p였다. 시간 간격만 조정했을 때의 약 1.7% 수용 전력 변화가 적분 방법을 바꾼 경우에도 유지됐다. 두 시간축과 입력 격자의 영향을 분리했다. [분해와 독립 파 적분 도구](../../Code/tools/verify_ro_grid_decomposition.py)

대역 상단에서 국부 구간은 입사 전력을 2.441% 낮췄다. 바깥 격자는 수용률을 2.691% 낮추고 리액턴스를 1.794 ohm 높였다. 두 격자 요인의 수용 전력 상호작용은 세 주파수 모두 절대값 0.063% 이하였다. 이 범위에서 입사 전력 변화에는 국부 격자, 반사와 입력 리액턴스에는 바깥 격자의 영향이 컸다. 포트와 원시 XML을 새 경로에서 다시 읽었을 때 입력·원시 해시와 복소 수치가 같았다.

## 같은 시간의 방사 도체 손실

보완 실행에서 봉인 N8의 손실 E·J·rotH 기록을 그대로 켜고, 같은 물리 시간 간격과 30845 step으로 맞췄다. 실제 HDF 좌표를 해당 실행의 연속 내부 Yee 구간으로 확인했다. 각 도체가 차지한 원시 전기 edge에서 복소 E와 반 시간 보정 rotH의 실수 일을 적분했다. 원래 N8의 전체 파워 기록에서 방사 도체 손실과 수용 전력을 각각 상대 1e-6 이내로 재현하고 같은 절차를 보완 실행에 적용했다. 다음 표는 전체 N8에서 국부 세 구간을 N7로 되돌렸을 때의 변화다. 세 구간을 되돌렸을 때 방사 도체의 절대 손실이 3.50~3.58%, 수용 전력이 3.10~3.16% 같이 증가했다. 수용 전력 기준 손실의 변화는 0.394~0.406%다. 이 범위는 세 구간만 바꿨을 때의 차이다. 보완 필드 재적분과 독립 포트 적분을 각각 반복해 동일한 실행 기록을 확인했다. 제품 기존 임계 구간 최대는 8이며 9분할은 E_RESOURCE로 거절됐다. N8의 기존 물리·공기·방사 기록면을 고정한 일반 격자 0.38 mm와 0.36 mm 계획은 각각 2584725점과 2703415점으로 기존 심화 예산 안에 들어갔다. 이 두 수준의 실제 계산은 별도 기록으로 진행한다.

국부 방사 도체 손실의 기존 차이 2.788446%와 승인 기준 2%는 유지한다. 추가 비교는 같은 openEMS의 격자 통제이며, 다른 풀이에서 전체 방사 도체 손실의 독립 수렴은 열린 검증 범위다. [기존 국부 손실 판정](../06_분석연구/11_고주파기판_도체손실_정밀연구.md), [보완 통제와 독립 실행 기록](306_급전구간_밖의_격자_실행기록.json)
