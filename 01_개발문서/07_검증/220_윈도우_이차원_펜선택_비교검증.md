# Windows 대형 2D의 연속 펜 선택 비교

2026-11-21 KST. 같은 색과 폭의 연속 선·원호에 대해 이미 만든 native pen을 반복 선택하는 호출을 한 번으로 줄인 시험판을 만들었다. 시험판은 직접 그리기와 선택 강조로 pen이 바뀌면 기존 순서로 복귀한다.

같은 Windows 모니터 2560 x 1600, 배율 150%, 120 Hz에서 대조판, 시험판, 시험판, 대조판 순으로 DesignCanvas를 실행했다. 네 층의 실제 F1 표시 모델은 선분 9800개와 원호 200개다. 각 실행은 35초로, Desktop Duplication의 표식과 화면 갱신 시각을 대조했다.
