# Windows 비접촉 금속 설치 해석

2026-11-21 KST. 유전체 케이스 해석의 PCB, 급전, 물성과 주파수 조건을 사용했다. 케이스의 오른쪽에 2 x 5 x 1 mm의 비접촉 금속 상자를 배치했다. 하단 원점은 (19, 4, 0.5) mm이며 케이스 외벽과 X 방향 간극은 1 mm다. 금속 모델은 PEC다.

| 10 GHz 관찰량 | 케이스 | 케이스와 비접촉 금속 |
| --- | ---: | ---: |
| S11 크기 (dB) | -4.5309 | -4.5673 |
| 방사 효율 | 98.326% | 98.330% |
| 총 효율 | 63.686% | 63.977% |
| 최대 실현 이득 (dBi) | 0.606 | 0.653 |

Windows Release Studio에서 금속을 추가하고 저장한 뒤 WSL2 openEMS로 실제 해석했다. 프로젝트를 다시 열어 같은 시나리오의 두 개정에서 S11 공통 표본과 효율 및 방사 단면을 확인했다. 준비 XML에서 프로젝트 객체 ID와 일치하는 금속 속성과 상자 한 개를 확인했다. 저장한 케이스, 금속 재료 출처, 해석에서 제외한 참고 물체의 미정 물성과 치수는 재열기 후 일치했다.

계획 시험에서 케이스 외벽에 닿는 금속은 차단했고, 해석 제외를 선택하면 기존 케이스의 계산 입력이 동일함을 확인했다. PEC에는 유한전도 손실이 없다. 접지 금속과 접촉 손실, 수렴 및 실측 판정은 미평가다.
