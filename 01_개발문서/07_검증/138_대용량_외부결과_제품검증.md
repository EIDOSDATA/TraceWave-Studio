# Windows Studio의 대용량 외부 결과 제품 검증

2026-11-21 KST. 완료 계획 12번 F3에서 Windows Release의 대용량 결과 등록 창을 실제로 열었다. 두 주파수 NXYZ 합성 필드 원문 1075856824바이트와 복소 곡선 원문 20020480바이트를 등록했다. 각 곡선은 독립 주파수 축의 100000개 표본을 갖고 곡선은 모두 8개다. [기능 및 HDF5 계약](../05_기능설계/04_해석결과/10_대용량_외부결과_등록과_비교.md)

각 세션에서 필드 주파수를 번갈아 선택하고 ROI와 단면 위치를 10회 바꿨다. 32 x 32 복소 표본, 기록 주파수와 단위 미정을 실제 필드 View에서 대조했다. 여덟 곡선의 전체 범위 극값과 마지막 두 원본 표본을 조회했다. 마지막 직전의 결측 상태와 마지막 허수부를 확인했다. 저장 메뉴로 저장하고 새 Studio 및 서비스 세션에서 같은 프로젝트를 다시 열었다. 두 등록 원문, 개정, 한글 출처, 미정값, 단면과 곡선 조회 응답이 일치했다. 별도 서비스 시험에서 실제 읽는 블록의 원문을 변조하면 거부하는지 확인했다.

| Windows 프로세스 자원 | 등록 및 조회 | 새 세션의 재열기 및 조회 |
| --- | ---: | ---: |
| 전체 표본 수 | 132 | 65 |
| 표본 간격 중앙값 | 111.5 ms | 112.6 ms |
| 같은 HDF5 런타임을 준비한 기준 private commit | 460.59 MiB | 460.70 MiB |
| 처리 중 같은 프로세스 집합의 관찰 최대 | 472.98 MiB | 472.45 MiB |
| 기준 대비 추가 관찰 최대 | 12.39 MiB | 11.75 MiB |
| 각 프로세스 OS peak commit의 합 | 476.75 MiB | 476.04 MiB |
| 같은 시각 프로세스 working set 합산 관찰 최대 | 192.32 MiB | 191.11 MiB |

조회는 서비스 프로세스의 HDF5 런타임에서 실행했다. OS peak 합은 각 프로세스의 개별 최댓값을 합한 값이다. working set 합의 공유 페이지는 중복될 수 있다. 최대 8 MiB 검증 블록 캐시를 적용한 이 실행의 추가 private commit은 512 MiB 예산 이내였다. GPU 메모리는 이 필드·그래프 계측에서 별도로 수집하지 않았다. [원시 실행 기록](139_대용량_외부결과_제품실행기록.json)

실행은 합성 성능 자료이며 실제 RF 계산이나 실측 판정으로 사용하지 않는다. 재현할 때 Release의 `RFAD_GUI_EXE`, `RFAD_TEST_F3_PRODUCT=1`, `RFAD_GUI_TEST_ARTIFACT_DIR`를 설정한 뒤 `test_large_results`를 실행한다. 과거 결과 비교와 기존 실제 기록 필드 재열기를 포함한 관련 시험 4개, CTest 13개가 통과했다.
