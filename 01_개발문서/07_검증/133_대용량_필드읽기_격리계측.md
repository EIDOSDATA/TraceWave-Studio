# 합성 1 GiB 필드의 Windows 읽기 격리 계측

2026-11-21 KST. 완료 계획 12번 F3의 큰 파일 경로를 검토하기 위해 Windows에서 NXYZ 복소64 성분 3개, 256 x 256 x 683 좌표와 주파수 1개의 합성 HDF5를 만들었다. 파일은 1074286688바이트다. 현행 제품 상한을 적용한 어댑터는 파일을 거절했다. 격리 계측 프로세스에서만 상한을 바꿔 원본 검증과 단면 읽기의 비용을 측정했다.

전체 파일 SHA256을 확인한 뒤 관심 영역 64 x 64의 복소값만 읽었다. 두 실행에서 각각 단면 10회를 원문과 대조했다. 매 요청 때 전체 해시를 검사하는 이 경로의 실행별 평균은 1.43초와 1.04초였다. 100 ms 목표 주기로 읽은 같은 Python 프로세스의 추가 private commit 관찰 최대는 각각 2.52 MiB와 3.15 MiB였다. 빠른 관심 영역 전환에는 대용량 원본의 검증과 부분 조회 구조를 보강해야 한다. [실행 기록](134_대용량_필드읽기_격리실행기록.json)

재현은 Windows에서 `tools/probe_large_field_reader.py prepare <새 시험 폴더>`로 합성 원문을 생성하고 `measure <같은 폴더>`로 별도 프로세스에서 계측한다. 호스트의 파일 캐시와 실행 상태에 따라 기록 시간이 달라질 수 있다. 이 실행은 합성 어댑터 진단이다. 1 GiB의 제품 등록·GUI 동작, 실제 계산 원문, 10만 표본 곡선 8개 및 전체 F3 메모리 수용은 별도다.
