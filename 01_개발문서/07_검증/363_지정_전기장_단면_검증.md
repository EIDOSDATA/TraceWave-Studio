# 지정 전기장 XY 단면 검증

2026-11-23 / Windows 개발 PC와 WSL2 openEMS / RF18, RF19

해석 전 검토의 조건 입력에서 기록 주파수 1개와 XY 범위, Z 높이를 지정한다. 종료 / 기록 출력에서 실제 격자에 맞춘 XY 범위, Z 및 점 수와 예상 출력 용량을 확인한다. XY는 입력 범위 안의 Yee 격자선만 포함하고, Z는 해석 내부에서 가장 가까운 격자선에 맞춘다. X와 Y가 각각 두 점 이상이고 전체가 4096점 이하인 경우를 지원한다. 범위나 대역 오류를 고르면 같은 입력으로 돌아간다. 저장한 해석 조건과 결과의 봉인 계획에 입력을 남긴다.

| 모델 | 입력 주파수 | 요청 X/Y/Z (mm) | 실제 X/Y/Z (mm) | 원문 배열 |
| --- | --- | --- | --- | --- |
| 원호 | 10 GHz | 5.2~10.6 / 4.1~8.2 / 2.1 | 5.5~10.5 / 4.5~8.0 / 1.928461538462 | 3 x 11 x 8 x 1 |
| IFA | 2.45 GHz | 5.2~10.6 / 4.1~8.2 / 2.1 | 5.5~10.5 / 4.5~8.0 / 1.910294117647 | 3 x 11 x 8 x 1 |

두 설계의 해석 조건을 저장하고 재열기했다. NF2FF와 손실 기록 없이 실제 준비 XML의 기록 형식과 FDTD 실행을 확인했다. 필드 탭의 공개 조회에서 Ex, Ey, Ez 각각의 88개 복소값을 h5py로 직접 읽은 HDF5 배열과 대조했다. 성분별 Yee edge 좌표, 기록 주파수 및 원문 SHA-256도 같았다. 엔진을 연결하지 않은 상태에서 결과를 다시 읽었고 저널과 정규화 결과가 보존됐다. Windows Release 빌드와 CTest 14건, 관련 Python 43건을 통과했다. 과거 손실 원문을 별도로 요구하는 환경 지정 시험 1건은 기본 실행에서 제외됐다.

지원 범위는 단일 주파수의 전기장 성분과 원문 펄스 Fourier 단위다. 독립 물리 정확도, 연속파 절대 전기장, 자계, 사용자 적분, 시료와 측정 환경은 후속 범위다. [openEMS 기록 속성](https://docs.openems.de/en/latest/python/CSXCAD/CSProperties/CSPropDumpBox.html)
