# 대형 설계 Windows 편집 메모리 검증

2026-11-21 KST. 형상 10000개·매개변수 1000개의 같은 시험 설계를 실제 Windows Studio에서 열고 프로젝트 속성을 변경했다. 저장·스냅샷 후 서비스를 재시작해 같은 개정을 열었다. GUI는 10000개 형상과 1000개 매개변수를 다시 표시했으며 생략은 0개였다. [Windows 저장 검증](107_대형설계_윈도우_페이지_검증.md)

Studio 실행부터 종료까지 GUI와 자식 Python 서비스를 합산했다. Windows가 보고한 프로세스별 private commit을 114회 읽었다. 서비스가 함께 관찰된 표본은 102개였다. 실제 간격의 중앙값은 0.297초, 최대는 0.355초다. 개별 프로세스 표본에서 합산값을 다시 계산했다. 관찰된 최대 합산 private commit은 **294.03 MiB**였다. [실행 기록](114_대형설계_편집메모리_실행기록.json)

측정 범위는 실제 Windows의 열기·편집·스냅샷·재열기 1회다. 이 관찰값은 F1 목표 768 MiB 아래에 있었다. 그 밖의 F1 표·검색과 연속 조작, OS peak, 기준 장비에서의 전체 예산 수용은 별도다.
