# 실제 기록 필드 단면 조회와 재열기 검증

2026-11-20 KST. 개발 완료 계획 12번 PERF-F3의 현재 지원 범위에서 Windows의 실제 필드 단면 조회와 저장 후 재열기를 검증했다. 동일한 읽기 전용 결과에 연속 조회를 걸어 서비스 작업과 GUI 보유 자료를 줄였다.

## 조회 비용과 원본 보존

- 세 실제 openEMS 기록 E, J, rotH의 파일 크기는 각각 6,228,968바이트였다. 실제 스냅샷과 결과 원본 pin에 연결한 상태에서 주파수, 성분, 단면과 ROI를 변경했다. 변경 전후 매 실행의 결과 식별, 설명 및 10회 단면 응답 canonical SHA256이 일치했다.
- 서비스는 한 응답의 256 KiB 검사에 필요한 직렬화를 한 차례 수행한다. ROI 점 수를 검사한 뒤 인덱스 목록을 만들고, 반환 좌표만 성분별 Yee 위치로 환산한다. 단면은 원래 복소64를 읽어 응답 숫자로 변환할 때까지 유지한다. 각 요청의 파일 길이와 전체 SHA256 검증, HDF5 shape/자료형 검사와 유한 hyperslab은 유지했다.
- wxWidgets 필드 화면은 기존 위치/복소값/크기/위상 마커를 유지한다. 그래픽 캔버스는 그리기에 필요한 좌표, 범례, 색 셀을 보관한다. 파일과 응답은 읽기 전용이며 색 범위는 현재 단면에서 서비스가 선택한 값을 사용한다.

| Windows 서비스 RPC | 단면 호출 | 중앙값 (ms) | p95 (ms) | 최대 (ms) |
| --- | ---: | ---: | ---: | ---: |
| 변경 전 | 50 | 150.95 | 177.95 | 218.47 |
| 변경 후 | 50 | 147.47 | 174.64 | 176.88 |

각 구성은 10회 단면 조회를 5번 연속 실행했다. 요청 직전부터 서비스 응답 객체 반환까지이며 응답 바이트와 함께 SHA256을 기록했다. 최대 단면 응답은 126,674바이트였다. 별도 프로세스에서 순차 실행한 진단값이며, 동시 부하나 메모리 예산 검증은 포함하지 않는다.

## 실제 Studio

필드 탭에서 기존 모니터의 두 기록 주파수를 번갈아 선택하고 실제 단면 조회 버튼과 마커를 사용했다. 24 x 24 이하의 유한 ROI를 10회 바꾸고 실제 캔버스의 저장 색 셀과 그리기를 확인했다. 저장 후 서비스 세션을 새로 열어 동일 입력의 응답 전체를 초기 표본과 대조했다. 격리 사본의 세 원문 파일 SHA256과 프로젝트 개정 및 제작·측정 미정 상태가 유지됐다. 새 FDTD 계산 없이 재열기했다.

서로 다른 원문 성분/단면의 실제 배열 27개 독립 대조도 수행했다. 서비스 34개 통과와 환경 조건 제외 1개, 결과 경로의 Windows GUI 2개와 별도 서비스 검사 1개, CTest 13개를 기록했다. 현재 필드 원시 파일은 공통 64 MiB 봉인 제한과 필드 배열 48 MiB 제한을 적용한다. F3의 1 GiB 단일 필드 파일, 100,000점 복소 곡선 8개 동시 표시, 100 ms 간격의 전체 메모리 계측과 F5 회수는 후속 수용 범위다. [성능 설계](../04_화면설계/02_화면_선정과_성능_설계.md), [필드 계약](../05_기능설계/04_해석결과/07_다중결과와_방사표시.md)

## 재현

Code 작업 위치에서 실제 openEMS 원문이 포함된 격리 작업 영역과 원래 결과 식별자를 사용한다.

```powershell
$env:PYTHONPATH='src;tests;.'
.venv/Scripts/python.exe -X utf8 tools/measure_recorded_field.py .local/field-workspace '원래-결과-UUID' .local/field-rpc.json --repetitions 5
$env:RFAD_TEST_FIELD_WORKSPACE=(Resolve-Path .local/field-workspace).Path
$env:RFAD_TEST_FIELD_ARTIFACT='<artifact-id>'
$env:RFAD_GUI_EXE=(Resolve-Path build/windows-release/bin/tracewave_gui.exe).Path
.venv/Scripts/python.exe -X utf8 -m unittest test_result_fields test_gui_results_process
```

[실행 기록](66_실제_필드단면_실행기록.json)에 원문 식별자, 질의별 응답 hash, 서비스 시간과 Windows 재열기 관찰을 남겼다.
