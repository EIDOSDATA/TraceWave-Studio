# 도면 치수 정렬과 수동 위치 검증

2026-11-23 KST. 원호와 IFA의 저번 단계 도면 설정을 읽어 자동 정렬한 뒤 외곽 X 치수를 옮겼다. 실제 Windows에서 프로젝트를 저장하고 프로세스를 종료한 뒤 다시 열었다.

## Windows 조작과 원본 대조

| 사례 | 수동 이동 | 치수값 | 재열기 종이 위치 X/Y (mm) | 축척 | 50 mm 막대의 종이 길이 |
| --- | --- | ---: | --- | --- | ---: |
| 원호 | 미리보기에서 치수 문자 드래그 | 20 mm | (132.227, 157.091) | 1.5:1 | 75 mm |
| IFA | 치수 위치 창에서 종이 X/Y 입력 | 40 mm | (142.250, 176.750) | 1.25:1 | 62.5 mm |

- 두 도면에서 자동 재배치가 일어났고 간섭 0건을 확인했다. 수동 위치를 저장하고 재열기한 뒤에도 수동 고정 한 개와 간섭 0건을 확인했다. IFA에서 자동 위치로 복귀를 눌러 고정을 해제하고 자동 정렬을 확인했다.
- 저장 개정과 원본의 기판, PCB 홀, 적층, 도체, 포트, 연결을 대조했다. 실제 모델 치수와 기준점 좌표는 동일했다. 재열기 전후 같은 뷰의 종이 배치도 일치했다.
- 동일 위치에서 시작해 문자·선·화살표가 겹치는 시험에서 자동 치수가 다른 위치로 옮겨지는지 확인했다. 두 치수를 강제로 같은 위치에 고정한 시험에서는 두 위치와 남은 간섭을 보존했다. 뷰 밖 수동 위치와 다른 뷰의 동일 원본 키는 별도로 확인했다.

## 출력 파일 수신 검증

Windows 출력 worker에서 두 프로젝트의 실제 저장 개정으로 PDF와 DXF를 생성했다. 파서는 네 패키지의 표시 치수값, 문자 X/Y, 치수선과 화살표 끝점, 종이 크기와 축척 막대를 다시 읽었다. PDF 좌표 허용치는 0.0001 mm, DXF는 0.000001 mm다. PDF의 가운데 정렬 치수 문자 X만 1 mm 바꾼 시험 파일은 거절했다.

회귀로 Windows CTest 14개, 관련 Python 테스트 109개와 문서 링크 검사를 확인했다. 후보 비교에서 개선될 수 없는 계산을 중단하도록 최종 보강하고 도면 및 파일 회귀 26개와 실제 GUI 저장본 출력을 다시 확인했다. [회귀 시험](../../Code/tests/test_drawing_dimension_placement.py)

현재 대상은 자동 치수가 적용된 기판 외곽과 도체층 뷰의 그래픽 치수다. 고정 위치끼리 겹치거나 주어진 종이 영역에서 후보를 찾지 못하면 남은 간섭을 표시한다. [연관 도면 계약](../05_기능설계/05_출력교환/04_연관도면과_출력재검수.md)
