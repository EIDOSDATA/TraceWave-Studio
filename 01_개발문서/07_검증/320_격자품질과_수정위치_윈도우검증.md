# 격자 품질과 수정 위치의 Windows 검증

2026-11-22 KST. 원호와 IFA의 기존 설치 설계 사본에서 과거 해석 조건을 읽었다. 급전 X와 Y의 국부 최대 폭을 각각 0.025 mm, 0.12 mm로 지정해 의도적으로 인접 셀 폭 차이를 만들었다. 두 사례는 아래 축별 품질 수치에 일치했다.

| 축 | 최소~최대 셀 폭 (mm) | 최대 인접 성장률 | 최대 모델 종횡비 | 최소 파장당 셀 수 |
| --- | --- | --- | --- | --- |
| X | 0.0125~0.8 | 39 | 40 | 79.87918 |
| Y | 0.1~0.8 | 5 | 5 | 79.87918 |
| Z | 0.035~0.8 | 13.285714 | 14.285714 | 79.87918 |

여기 상한은 3,662,625,000 Hz, 모델 파장은 약 39.93959 mm, 진공 파장은 약 81.851802 mm였다. 성장률 39가 보고된 X축 인접 쌍의 폭은 0.4875 mm와 0.0125 mm다. 원호의 X 24.9875~25 mm와 IFA의 X 8.9875~9 mm에서 실제 짧은 셀과 직교 방향의 0.5 mm 셀이 만들어 내는 종횡비 40을 대조했다.

Windows에서 성장률 경고를 선택한 뒤 해석 격자와 X 수치 표로 이동했다. 관련 설정 버튼이 해당 급전 국부 조건에 초점을 두었고 X 목표 0.025 mm가 그대로 표시됐다. 종횡비 경고는 비교 셀의 직교 방향 경계를 함께 표시했다. 해당 경고에서 모델 최대 격자 간격으로 이동해 검수 초안 값을 바꾸면 이전 품질과 실행 승인 상태를 지웠다.

| 사례 | 실제 격자선 X/Y/Z | 격자점 | 격자선 SHA-256 |
| --- | --- | --- | --- |
| 원호 | 119 / 165 / 42 | 824,670 | `eccf19716dc5d8e6bbff24b9b5ea8b74b2da2bca950aa128c7b115eae33ef9b3` |
| IFA | 119 / 173 / 42 | 864,654 | `ed8b962906f6b90b19c03979fe11bdbbfc3359558fd092c345e3a252e0d55dd4` |

Windows에 표시된 해시와 openEMS/CSXCAD 준비 시 실제로 사용한 모든 격자선을 대조했다. 준비 격자 좌표에서 독립 계산한 다섯 열의 수치가 Windows의 X/Y/Z 품질 표와 일치했다. 원래 프로젝트 포인터와 과거 결과의 등록 내역을 보존했다. 검증 범위는 FDTD 실행 전 해석 준비까지다.

Windows Release CTest 14개와 관련 Python 시험 44개, WSL2 전용 PML 및 도체 연결 준비 시험 한 개를 통과했다. 알려진 격자 좌표의 단위 시험에서 셀 폭과 파장 기준 이탈, 인접 구간 묶음, 최악 셀 및 직교 비교 위치도 확인했다. [품질 계산 계약](../05_기능설계/04_해석결과/03_사용자기판_단일포트_해석.md), [개발 순서](../09_개발계획/15_기능채택과_개발검증_순서.md)
