# Windows 기본 해석과 설치 검증

2026-11-23 KST. Windows 11 x64용 R1 기본 설치와 Studio에서 Windows openEMS 0.37.0을 사용한다. Setup.exe는 앱용 CPython 3.12.10과 해석용 CPython 3.14.7, Windows x64 openEMS와 CSXCAD 0.7.0 및 고정 wheel을 원 공급처에서 내려받고 해시를 검사한다. Windows 해석기는 앱의 전용 환경에서 실행하며 WSL2와 Ubuntu 설치가 필요 없다. [Windows openEMS와 CSXCAD 자산](https://github.com/thliebig/openEMS-Project/releases/tag/v0.37.0) [해석용 CPython](https://www.nuget.org/packages/python/3.14.7) [원본 및 의존성 고정](../../Code/runtime_profiles/python-openems-windows-x64.json)

완료한 결과와 원본은 현재 프로젝트 작업 영역에서 다시 열 수 있다. 해석 프로필은 `openems-windows-x64/0.1`이고 실행 방식은 `windows_native`다. 기존 WSL2 실행을 재현할 때는 설치의 `-WithWsl`과 개발 실행의 `--openems-wsl`을 사용한다. 이미 중단된 WSL FDTD 체크포인트의 이어서 계산은 기존 WSL 환경에서 지원한다. 이 경로의 새 실동작 확인은 해당 배포판과 native 감사가 준비되면 재개한다. [배포와 수신 절차](../08_운영환경/05_윈도우_내부검증_배포.md)

## 설치 후보와 독립 검수

후보는 `r1-rc5`다. 내장 소스 개정은 `ef17ba690f657160ce00a246ed296f088d5ce812`다. Setup.exe는 15,312,384바이트이고 SHA-256은 `5089f7740e44f4e93d4b699977449b7c6f5519ea6e3e279d54b4dae5a067b927`이다. 내장 ZIP의 SHA-256은 `751fcdfe7741e824de9bd7db5bcd4f3f1f77fab391ea85ed1f78eaf0b64887e8`이다. [Setup.exe와 SHA-256](https://github.com/EIDOSDATA/TraceWave-Studio/releases/tag/r1-rc5)

개발 PC의 빈 설치 경로에서 배포본 Setup.exe를 기본 해석 옵션으로 실행했다. 시작 메뉴와 자동 실행만 검증용으로 생략했다. 종료 코드는 0이고 설치 상태는 `windows_ready=true`, `simulation=ready`, `solver_platform=windows`였다. 그 경로에 실제 설치한 Studio로 PCB 해석과 실행 중 취소, 새 서비스 세션의 결과 재열기를 다시 통과했다. GitHub에서 게시한 두 파일을 독립 다운로드해 Setup.exe의 해시 및 원격 태그의 개정을 대조했다.

동일 작업 폴더에서 설치 잠금을 잡고 Setup.exe를 다시 실행했다. 두 번째 실행은 한국어로 설치 진행 중임을 표시하고 종료 코드 2를 반환했다. RC4와 RC5의 Setup.exe 및 새로 설치한 Studio 실행 파일에서 Windows가 추출한 32 px 아이콘은 픽셀이 일치했다. RC5 설치 파일은 Authenticode 서명 없는 검증 후보다.

R1 최종 수용에는 인터넷 연결이 가능한 별도의 클린 Windows 11 x64 PC가 필요하다. 후보의 기본 설치, 시작 메뉴 및 제목 표시줄 아이콘, 편집과 저장, 계산과 취소, 결과와 출처 재열기, 출력과 정상 저장본 복구를 해당 PC에서 기록한다. [R1 최종 검수 작업표](../09_개발계획/04_현행버전_남은작업.md)
