# 제조 자료의 배선과 넷 왕복 검증

2026-11-23 / Windows / KiCad 10.0.8 / EDA15, EDA16

## 가져오기

IPC-2581 Rev C 또는 ODB++ ZIP의 보드 외곽을 현재 보드와 대조한 뒤 파일의 도체층 및 넷을 현재 설계의 층과 넷에 지정한다. 대응을 모두 비우면 외곽과 내부 절삭만 반영한다. 층과 넷을 지정하면 지원하는 직선 및 원호 배선을 편집 도체로 가져온다. 일부만 대응하거나 같은 위치의 기존 배선과 넷이 다르면 적용할 수 없다.

- IPC는 양극성 CONDUCTOR 층에 직접 명시한 Line과 Arc의 원형 끝 선폭을 읽는다. 중심, 시작점, 끝점과 clockwise 속성으로 호의 방향을 정한다. 좌표 변환이 붙은 특징은 원문에 두고, 음극성 형상이 있는 층은 배선을 양극성 도체로 가져오지 않는다. [IPC-2581 원본 스키마](https://webstds.ipc.org/2581/)
- ODB++는 양극성 BOARD / SIGNAL 층의 L과 A를 읽는다. eda/data의 LYR, NET, SNT TRC, FID C가 실제 층 파일의 순서 번호를 가리켜야 한다. 둥근 표준 심벌의 폭은 mm 파일에서 마이크로미터, inch 파일에서 mil로 환산한다. [Siemens ODB++ Design Format 8.1](https://odbplusplus.com/wp-content/uploads/sites/2/2024/08/odb_spec_user.pdf)
- 같은 위치, 폭, 층, 넷의 기존 배선은 기존 객체 ID에 출처를 연결한다. 원호는 진행 방향이 뒤집혀도 양 끝과 중간점을 함께 대조한다. 파일 좌표 정밀도를 고려한 경로 대조 오차는 0.000003 mm, 선폭은 0.000002 mm이다. 기판의 기존 재료, 급전과 원본 바이트를 보존한다.
- 단일 직선 보드 프로파일에서 최대 128개의 지원 배선을 읽는다. 패드스택과 실장, 물성 적층의 편집 모델 반영, 음극성 합성, 면 채움과 사양 전체의 수신기 호환 검증은 후속 범위이다.

## 원호 및 IFA 왕복

제품의 PCB 출력으로 원호와 IFA 설계를 발행하고 실제 KiCad에서 IPC-2581 Rev C와 ODB++를 생성했다. 두 원본에 기존 수신 설계에는 없는 배선 (2, 3) - (6, 4) mm, 폭 0.274 mm를 추가했다. 별도 수신 프로젝트에서 각 파일을 가져와 원래 배선의 ID와 급전 연결을 유지하고 새 도체 하나를 반영했다. 새 개정에서 KiCad PCB 패키지를 다시 발행하고 KiCad의 두 제조 출력에서 새 도체의 좌표, 폭, F.Cu층과 넷을 다시 대조했다.

- 원호 설계는 기존 직선 2개 및 원호 1개, 추가 직선 1개를 확인했다.
- IFA는 기존 직선 3개와 추가 직선 1개를 확인했다. 패드와 평면 동박은 현재 설계의 원본을 보존했다.
- 로컬 매핑 및 판독 시험은 단위, FID의 층/도형 순서, 넷 충돌과 음극성 및 변환 처리도 검사한다. 고정한 소스와 실제 Windows 출력 worker를 사용한 시험 20건이 통과했다. 실행 항목은 test_manufacturing_exchange, test_manufacturing_copper, test_pcb_import_mapping, 기존 IPC 절삭 및 ODB 프로파일 시험이다.
