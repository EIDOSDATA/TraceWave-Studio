# R1 설치본의 통합 검수

2026-11-24 KST. 사용자가 기본 경로에 설치한 `r1-rc6`를 Windows 11 Pro 26H2 x64, 빌드 26300.9974에서 검수했다. 앱 내부 시험에는 검증 전용 프로젝트와 작업 폴더를 사용했다. 기존 사용자 작업 폴더는 제거 전에 복사하고 해시를 대조했다. [후보 배포 기록](418_윈도우_표준_앱_제거_검증.md)

| 순서 | 개발 PC의 검수 결과 |
| --- | --- |
| 1. 수신과 시작 | GitHub에서 Setup.exe와 SHA-256을 다시 내려받아 `a25f101d1e42e7e4b6b89009e72b188cf2b8d9d4edd710837843ab48bfc03bbc`를 대조했다. 태그의 소스 개정은 `d8fbcc48d23fb86f33785971f443b21106d35c80`이다. 시작 메뉴에서 실제 Studio를 열고 창 좌측 상단 아이콘과 Windows openEMS 준비 표시를 확인했다. [RC6 자산](https://github.com/EIDOSDATA/TraceWave-Studio/releases/tag/r1-rc6) |
| 2. 편집과 저장 | 한글과 공백이 포함된 작업 경로에서 GUI로 프로젝트를 변경하고 저장했다. 다른 서비스 세션을 열어 편집값과 저장 기준점을 확인했다. 속성 폼의 수식 편집과 오류 시 입력 보존도 검증했다. |
| 3. 실제 해석과 취소 | 원형 PCB의 openEMS 계산을 실행해 31개 주파수의 결과를 게시했다. 두 번째 해석은 실행 중 취소했고 서비스가 worker의 종료를 확인했다. 새 서비스 세션에서 기존 완료 결과를 다시 열었다. |
| 4. 결과, 출처, 출력과 복구 | 별도 출력 worker로 실제 PDF 도면을 생성하고 원본 출처와 출력 파일의 해시를 대조했다. 새 서비스 세션에서 저장한 출력 이력을 다시 열었다. 손상된 프로젝트 입력은 GUI가 `E_HASH`로 차단했다. 보존해 둔 정상 원문으로 복구한 뒤 저장 개정과 스냅샷을 다시 확인했다. |
| 5. 제거 | Windows 설정의 설치된 앱에서 TraceWave Studio, R1 RC6, 아이콘과 제거 메뉴를 확인했다. 해당 항목에 등록된 무인 제거 명령을 실행했다. 앱 항목, 바로가기, 설치된 버전과 전용 런타임 및 설치 캐시가 없어지고 사용자 작업 폴더의 파일 해시와 시험 결과 해시가 유지됐다. |

## R1 수용 조건

이번 검수는 기존에 설치한 개발 PC에서 수행했다. R1 최종 수용은 온라인 상태의 별도 클린 Windows 11 x64 PC에서 같은 RC6로 검수한 뒤 판단한다. 리팩토링 착수는 보류한다. [남은 R1 작업](../09_개발계획/04_현행버전_남은작업.md)
