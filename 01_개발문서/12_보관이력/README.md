# 승인 이력과 최초 제안

과거 승인 내용을 확인하려면 아래 사본을 연다. 현재 제품을 구현할 때는 [시스템 명세](../02_시스템명세/README.md), [기능별 계약](../05_기능설계/README.md)과 [실행 검증](../07_검증/README.md)을 함께 사용한다.

| 필요한 자료 | 확인할 위치 |
| --- | --- |
| RFAD-D0-3.4 승인 원문 27개, 기준 커밋, 파일 해시와 승인 기록 | [승인 기준선](01_승인기준선/01_삼점사/README.md) |
| 승인 당시 파일명을 현재 폴더에서 찾기 | [이전 경로 대응표](../10_문서목록/01_이전경로대응.json)의 `approved_baseline_paths` |
| 현재 영역별로 나뉜 원래 설계 문서 찾기 | [기존 설계 분류](../10_문서목록/04_기존설계분류.md) |
| 원호와 IFA, 제조사 재료 카탈로그를 처음 설계한 근거 | [최초 제안 두 건](02_초기제안/README.md) |

승인 사본 본문의 상대 링크는 승인 당시 저장소 구조를 가리킨다. 해당 구조와 개정에서 열려면 승인 기준선 안내의 커밋을 사용한다.
