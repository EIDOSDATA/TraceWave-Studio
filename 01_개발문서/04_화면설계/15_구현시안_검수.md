# 전체 구현 시안 검수와 사용 안내

문서 ID: TWS-SD-015. 작성일: 2026-11-17 KST. 범위: 정적 화면 설계와 문서 정합성. 실제 제품 GUI의 구현/수용 기록이 아니다.

## 결과와 사용법

[전체 화면 둘러보기](16_전체화면_둘러보기.html)에서 작업별 필터와 검색으로 화면을 선택하고, 클릭하여 확대한다. 이전/다음, 좌우 방향키, 원본 크기/화면에 맞춤, Esc 닫기를 제공한다. 개별 PNG는 확인용, SVG는 확대 및 벡터 편집용, DrawIO는 컨트롤/문자/기하 요소를 선택하여 수정하는 원본이다. DrawIO는 PNG 한 장을 붙인 파일이 아니며, 다각형은 벡터 stencil로 보존한다.

주요 화면, 기존 설정 창의 모든 하위 페이지, 추가 설계 탭과 복구/미기록 상태를 합쳐 84장을 작성했다. 공통 S10 프레임은 주요 작업 화면에 반복 적용하고 P13 CAD 출력은 S50.step 및 P11의 출력 상세에서 표현한다. UI-17의 승인 후속 분야는 지원 범위 안내로 표현하며 일반 3차원 안테나의 전체 편집기를 R1로 확정하지 않는다. OS가 제공하는 파일 선택/인쇄 대화상자의 외형은 Windows에 맡기며 별도의 제품 화면으로 복제하지 않는다.

## 실제 수행한 검수

- 84개 화면의 PNG/SVG/DrawIO, 총 252개 파일을 같은 도형 정의에서 생성했다. 83장은 1920 x 1080, 작은 창 1장은 1366 x 900 기준면이다.
- Windows Edge의 headless 렌더러와 맑은 고딕으로 전체 화면을 렌더링했다. 모든 텍스트의 실제 폭과 화면 경계를 검사했고 최종 초과는 0건이다. 렌더 입력 SVG hash를 기록하여 이전 그림의 검사 결과를 재사용하지 않는다.
- 84장을 각각 열어 배치, 표, 단위, 문구, 선택/비활성 상태와 시안 데이터의 의미를 검토했다. 수정된 화면은 다시 렌더링하여 확인했다.
- SVG와 DrawIO의 텍스트 대응, 고유 셀/화면 ID, 벡터 stencil의 압축 해제/XML, PNG 크기, 파일 hash, 화면 번호 01~84 및 승인 UI-01~24 대응을 검사했다.
- 둘러보기의 검색/작업 필터/확대/원본 크기/이전/다음/키보드 닫기와 로컬 이미지 경로를 검사했다. 최종 실행 결과는 [기계 검수 기록](17_구현시안_검증.json)과 함께 유지한다.
- 게시할 Git index를 별도 경로로 추출하여 구현 감사 생성/재검사를 수행하고, [감사 회귀 시험](../../Code/tests/test_implementation_audit.py) 14개를 통과했다. 기존 미커밋 정밀 편집은 이 시험과 커밋에서 제외하고 작업 트리에 보존했다.
- [전체 문서 연결 검사](18_문서연결_검증.json)는 새 링크와 파일/폴더 명명, 기존 승인 원문 27개의 hash를 검사한다. 이전 [문서 검수 기록](../11_검토기록/06_문서검증_기록.json)은 당시 기록으로 보존한다.

이번에는 새 wxWidgets 실행 파일의 실제 조작, DPI 150/200%, Narrator/IME/고대비, 60/30 fps, CAD/FDTD 또는 실측 검증을 실행하지 않았다. DrawIO 앱에서 저장/재열기한 native roundtrip도 수행하지 않았으며 XML/벡터 구조 검수와 구분한다. 그림의 배치가 native 창 장식의 픽셀 단위 일치나 전체 제품 수용을 보장하지 않는다.

## 데이터와 출처의 경계

모든 화면은 설명용 프로젝트다. 예시 기하, 숫자와 합성 곡선을 실제 프로젝트 기본값으로 채우지 않는다. 동일 자료/주파수의 곡선·마커·표는 서로 일치해야 하며, 자료가 없는 실제 제품 화면에는 예시 곡선을 대신 표시하지 않는다. 문헌 G001과 제조업체 관측 예시는 해당 원문 조건을 함께 표시하며 현재 프로젝트의 미정값과 별도로 둔다. 4층 검색 후보와 기존 2층 프로젝트의 편집 예시는 미채택 상태를 명시한다.

참고 원본, 승인 사본, 과거 runtime 기록과 미커밋 정밀 편집 작업은 보존한다. RO4350B 국부 손실 2.788446%/초기 2% 기준 미확립, GHz PTH 독립 정확도 미확립, 실제 납품/실장/교정/측정 조건의 미정은 이 화면 정비로 바뀌지 않는다.

## 재생성

저장소 루트에서 다음 도구를 사용한다. Node/Playwright와 Edge는 문서 렌더링용이며 제품 런타임 의존성이 아니다. 로컬 실행 환경에 맞는 실행 파일과 node_modules 경로를 명시한다.

```powershell
Code/.venv/Scripts/python.exe Code/tools/documentation/build_studio_visuals.py
$nodeModules = "C:/문서도구/node_modules" # 설치 환경의 실제 경로로 지정
$edge = "C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe"
node Code/tools/documentation/render_studio_views.cjs $nodeModules $edge 01_개발문서/04_화면설계/03_구현시안 Code/.local/screen-redesign/render-checks.json
node Code/tools/documentation/check_studio_gallery.cjs $nodeModules $edge 01_개발문서/04_화면설계/16_전체화면_둘러보기.html Code/.local/screen-redesign/gallery-checks.json
Code/.venv/Scripts/python.exe Code/tools/documentation/check_studio_visuals.py --render-report Code/.local/screen-redesign/render-checks.json --gallery-report Code/.local/screen-redesign/gallery-checks.json
```

생성 원본은 [공통 도형](../../Code/tools/documentation/studio_visuals/primitives.py), [주요 작업](../../Code/tools/documentation/studio_visuals/main_pages.py), [기판/환경/규칙](../../Code/tools/documentation/studio_visuals/settings_pages.py), [목표/연구/복구](../../Code/tools/documentation/studio_visuals/workflow_pages.py), [해석/측정/교환 상세](../../Code/tools/documentation/studio_visuals/detail_pages.py), [목표/포트/출처 상세](../../Code/tools/documentation/studio_visuals/workflow_detail_pages.py)로 분리했다. SVG/DrawIO를 직접 수정하여 채택하려면 원본 생성기에도 반영한 뒤 다시 검사한다.
