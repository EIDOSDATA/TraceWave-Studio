# 설계 스윕과 연구 화면

개발 완료 계획 6번의 유한 지원 화면 계약이다. 기존 84개 시안의 Studio 공통 배치와 연구 설정/진행 화면을 따른다. 실제 Windows 창, 초안/늦은 응답, 취소/재개 및 저장/재열기의 실행 시점과 범위는 [단계 검증](../07_검증/13_설계스윕과_연구_검증.md)에 기록한다.

## 1. 전환과 구분

Studio `해석 > 연구`는 연구 목록/후보/고정 조건의 3열 화면이다. 기존 해석 준비와 격자 수렴 연구는 유지한다. `새 연구`는 설정 대화상자로 이동하며 설정 창에서 native 실행을 시작하지 않는다. `후보 검토 -> 새 연구 저장 -> 연구 목록에서 실행`을 구분한다.

설계 변수 스윕, 수치 설정 다축 연구, 외부 회로 소자 스윕은 이름으로 구분한다. UUID/hex는 목록 이름이 아니며 상세 근거의 식별자다. 변수 이름은 기준 snapshot의 사용자 이름, 회로는 R1 등 소자 이름을 사용한다. 원본 설계로 복귀할 때 선택/초안/화면을 보존한다.

## 2. 네 탭의 새 연구 설정

| 탭 | 기능과 표시 |
| --- | --- |
| 유형과 변수 | 연구 이름/종류, 명시 변수 목록, 값 목록 또는 시작/끝/개수, Cartesian/paired/명시 행 |
| 해석과 대상 | 주파수/격자/경계/종료 수치, 선택적 방사/손실, 외부 회로의 원문 자료/기준면, 목표와 명시 포트 대응 |
| 실행 예산 | 후보 수/native solve 수/누적 시간/RAM/디스크/동시성 1. 예측과 실제 사용량 구분 |
| 후보 검토 | 총 조합 수/유효·미지원·중복 수, 처음 25개 후보/사유, 검토 hash가 같은 경우에만 저장 |

명시 행은 각 축의 실제 값으로 선택하며 사용자에게 0기반 인덱스를 입력시키지 않는다. paired는 모든 축의 목록 길이가 같아야 하며 자동 반복하지 않는다. 표현식 매개변수는 읽기 전용 사유를 표시한다. generic JSON 편집으로 기본 폼을 대체하지 않는다.

주파수는 GHz/MHz 등 지원 단위를, RAM/디스크는 MiB/GiB를 사용한다. 단위 해석은 서비스가 수행한다. 수정하지 않은 입력은 원본 SI/출처를 유지하며 표시 문자열을 매번 재파싱하지 않는다. 예산 전체 시간이 끝나면 현재 작업의 종료 확인을 거쳐 멈추는 의미를 안내한다.

NF2FF/임계 구간 분할/독립 손실은 처음에는 선택하지 않는다. 사용자가 선택할 때 수치 제안을 기준 설정에 복사한다. 독립 손실은 방사 기록을 필요로 하며 고정 잔차 기준과 초기 제안의 미검증 상태를 표시한다. 방사 주파수 1~3개, 각도/거리와 종료 조건은 실제 지원 값만 사용한다.

기준면/제작·측정 정보가 없으면 미정으로 남긴다. 목표를 선택했다고 포트/기준면을 자동 확정하지 않는다. 명시적 대응이 없는 성능 지표는 미평가로 저장한다. 현재 API 범위와 수용 상태는 [기능 계약](../05_기능설계/06_연구/01_명시적스윕과_실행계약.md)을 따른다.

## 3. 목록과 실행 화면

왼쪽에는 연구 이름/상태를 표시하고 연구 종류는 가운데 선택 상세에서 확인한다. 좁은 도킹 너비에서 불필요한 열을 늘리지 않는다. 가운데 후보 표는 순번/변수값/단계/판정/실패 이유/시도를 보여 주고 이전/다음 페이지로 조회한다. 아래에는 선택 후보의 상세 진단을 표시한다. 오른쪽은 고정 snapshot/개정, 원본 변경 여부, 전체 예산/누적 사용량, 미확립 조건이다. 전체 후보 배열을 GUI에 미리 만들지 않는다.

실행/취소/재개 버튼은 서비스의 `allowed_actions`에 따른다. 진행률은 실제 완료 수를 기준으로 표시하며 예상 시간으로 완료율을 만들어내지 않는다. 실패/미지원/미평가 행은 남긴다. 선택 후보의 결과가 실제 존재할 때만 곡선/표 보기로 이동한다. 결과 창은 현재 페이지의 실제 표본, 단위, 상태 및 당시 근거를 표시한다. 조건 탭은 읽을 수 있는 자료/포트/기준면과 목표 이름/판정 사유를 먼저 보여 주고, 상세 JSON 원문은 처음 접힌 읽기 전용 고급 영역에 둔다. 미정 포트 이름을 UUID로 대신하지 않는다.

연구의 왼쪽 도킹 제목과 내부 탭은 `연구 목록`으로 함께 전환한다. 후보 페이지 이동/결과 버튼은 좁은 너비에서 다음 행으로 감싸며, 결과 수치의 기본 표시를 8유효숫자로 정리해도 저장한 복소 원본은 변경하지 않는다. 주파수 표본은 서로 다른 값을 구분할 수 있는 표시 정밀도를 유지한다.

취소 요청과 취소 확정은 별도다. 종료 불명 상태에서 새 계산을 중복 접수하지 않는다. 서비스 재시작 후 자동 실행하지 않으며 고정 runtime/출처를 확인한 명시적 재개만 허용한다. 완료 후보 재사용과 native checkpoint를 구분한다.

## 4. 초안과 접근성

입력이 바뀌면 검토 hash를 무효화한다. 명시 값 목록과 범위 사이의 입력 방식을 바꾸어 기존 값을 버릴 때는 후보 행도 함께 폐기할지 확인한다. 거절하면 값/행/입력 방식이 유지되며, 승인하면 이전 인덱스를 새 값에 자동 대응하지 않는다. 조회 중 선택 변경, 창 닫힘, 프로젝트 전환과 이전 응답을 구분한다. 저장 결과 불명 시 입력을 잠그고 권위 상태를 다시 읽으며 같은 후보를 새 연구로 자동 생성하지 않는다. 성공한 저장 후 목록 재조회가 실패한 경우에도 중복 저장을 허용하지 않는다.

표와 상세 영역은 최소 높이와 세로 스크롤을 확보한다. 키보드 탭 이동, 적용/닫기, 미적용 입력 폐기 확인을 기존 공통 View 수명 계약으로 처리한다. 가려진 아래 버튼이나 0 높이 표를 시험 결과만으로 정상이라고 인정하지 않는다. 모든 해상도/DPI와 최종 프레임·메모리 성능 수용은 별도 검수다.
