# 다중 결과와 방사/필드 화면

개발 완료 계획 7번의 화면 연결 설계다. 2026-11-17 구현 범위와 [실제 Windows 검수](../07_검증/17_다중결과_표시검증.md)를 연결한다. [공통 화면 기준](12_구현화면_설계기준.md)과 기존 84개 시안을 따른다. 구현의 차이를 숨기기 위해 시안 그림을 변경하지 않는다.

기존 자료 가져오기/변환/RLC는 `자료 / 정합`, 기존 수렴 연구는 `수렴 연구`에서 계속 접근한다. 새 공통 결과 페이지를 추가하면서 기존 기능을 지우거나 빈 화면으로 대체하지 않는다. 상단 결과 작업은 공통 네트워크, 비교 작업은 실행/후보 비교로 연결한다. 각 탭과 상단 작업의 대응은 명시적으로 관리한다.

화면 전체를 큰 JSON 모달로 대체하지 않는다. wxAUI의 공통 좌우/하단 도킹을 유지하고 가운데 작업 페이지를 바꾼다. 좌측은 결과 선택, 가운데는 실제 그래프/표, 오른쪽은 선택 자료의 조건/근거를 보여 준다. 원문 ID/hash는 상세 근거로 제공하며 기본 목록은 사람이 읽을 수 있는 이름을 사용한다.

페이지 제목은 고정된 기능 이름을 사용하고 긴 원본 이름은 목록/tooltip과 오른쪽 원본 그룹에서 확인한다. 오른쪽은 원본/기준/검증 상태의 세 접기 그룹과 기본 접힌 고급 원문으로 구성한다. 각 본문 및 전체 영역의 세로 스크롤로 긴 조건을 보존한다. 조건 복사는 현재 표시한 문장을 복사하며 비교에서는 현재 조건 페이지만 포함한다. 원문 JSON 전체나 모든 조건 페이지를 한 번에 복사한다고 표시하지 않는다.

## 2. 결과 선택과 상태

기본 해석 결과 탭은 실행 상태를 한글 문장으로 표시하고 결과 개정과 주파수 개수를 그래프 위에 둔다. 주파수 축은 표시 범위에 따라 Hz, kHz, MHz, GHz를 선택한다. 임피던스의 실수부와 허수부는 색과 선 종류, 범례를 함께 사용한다. 화면 높이가 좁을 때 작업 기록은 접힌 상태에서 열 수 있다. 과거 설계와 정확도 검증 상태를 유지하고 누락 표본에서 곡선을 끊는다. [실제 Windows 해석 결과 검증](../07_검증/124_해석그래프와_작업기록_가독성_검증.md)

1. 좌측에서 자료 종류를 network/해석/연구로 선택한다.
2. network는 실제 개정/snapshot, 연구는 study를 선택한다. 빈 목록과 읽기 실패는 다른 상태다.
3. 목록의 자료를 고르면 describe가 source/pin과 가용 화면을 고정한다.
4. 표본/Smith/전력/방사/필드가 같은 고정 선택을 사용한다. 지원하지 않는 관측량에는 이유를 표시한다.
5. 다른 결과나 프로젝트로 전환하면 이전 그래프/조건을 먼저 지우고 조회한다. 실패했는데 새 이름 아래 예전 곡선이 남지 않는다.

선택 종류/개정/연구/자료, source pin, 채널과 페이지, 닫힌 View의 수명을 응답 수용 전에 확인한다. 이전 선택의 늦은 응답은 버린다. 읽기 실패를 새 계산 실행이나 자동 재저장의 신호로 취급하지 않는다. 저장되지 않은 설계 편집을 결과 조회가 덮지 않는다.

계산 완료, 수렴, 독립 물리 검증, 제조와 측정 상태는 각각 표시한다. 미정 조건은 빈 문자열이나 정상 배지로 감추지 않는다. 현재 개정과 다른 과거 결과에는 당시 개정을 표시하고 현재 목표가 달라졌더라도 과거 평가를 다시 계산하지 않는다.

## 3. 네트워크와 Smith

네트워크는 실제 표본 201개씩 표시하며 페이지 범위와 전체 개수를 알린다. 주파수 축/표/마커는 같은 Hz/kHz/MHz/GHz 단위를 사용한다. missing/singular/overflow는 선을 끊고 표에 이유를 남긴다. 연결선은 새 계산점이 아니다.

Smith는 왼쪽 큰 격자와 오른쪽 M1 수치 영역으로 구성한다. 단위원 밖 데이터도 유지하고 화면 범위 제한으로 보이지 않는 점의 수를 알린다. 마커는 실제 주파수/Gamma/입력 임피던스/입력 어드미턴스/Z0/정합 조건을 표시한다. 2포트 이상이면 다른 포트를 정합한 입력값이라는 설명을 붙인다. 단락/개방/영전계와 미정값을 0으로 통일하지 않는다.

## 4. 전력과 효율

가운데 표는 항목/단위가 포함된 기록 값/분모와 기록 범위/검증 상태 네 열을 사용한다. 방사 효율과 총 효율을 구분하고 각각 수용 전력/입사 전력이 분모임을 표시한다. 효율 곡선은 실제 기록 주파수만 사용한다. 한 점만 있으면 마커로 표시하며 없는 대역을 선으로 채우지 않는다.

펄스 전력은 `W*s^2`, 절대 W는 미정이라는 설명을 유지한다. 100%를 넘는 효율과 음수 손실도 값과 검토 상태를 함께 보여 준다. 독립 손실 미기록 및 초기 수치 기준/개별 정확도 미확립을 쉽게 읽을 수 있는 안내로 표시한다.

## 5. 방사 화면

가운데 2D/3D/편파 탭, 상단의 실제 주파수/관측량/표시 척도/기저와 3D 오른쪽의 범례/조작 안내를 사용한다. 주파수를 바꾸면 같은 주파수의 모든 페이지를 모은 뒤 완성된 패턴을 게시한다. 중간 페이지나 다른 주파수의 행을 섞지 않는다. 진행과 오류를 표시하고 실패 시 이전 패턴을 새 주파수 결과로 남기지 않는다.

2D 절단면은 선택 phi의 실제 theta 표본과 정확히 반대인 phi + 180 deg의 기록이 있을 때 그 표본을 구분된 선으로 표시한다. 반대쪽 기록이 없으면 대칭 복사나 보간으로 채우지 않는다. 각 곡선의 실제 phi를 범례에 적는다.

3D는 전용 wxGLCanvas/OpenGL View로 그리고 CAD ModelView와 데이터 경로를 분리한다. 마우스 회전/확대와 기본 시점 복귀는 표시 상태다. 반경의 정규화 방식과 색 단위를 명시하고 표시 하한이 원문 값의 삭제가 아님을 안내한다. mesh/색의 시각적 보간을 계산된 표본으로 표기하지 않는다.

편파 수치는 실제 theta/phi 표본을 선택하고 Etheta/Ephi RI, 상대 위상, RHCP/LHCP, 축비와 상태를 보여 준다. openEMS 기저, 바깥쪽 전파 방향과 시간 규약을 확인할 수 있게 한다. 기본 theta/phi를 임의 co/cross로 바꾸지 않는다. 영전계의 정의 불가와 직선 편파의 무한 축비는 별도 문구다.

`방사 관측 목표 선택`은 계산 스냅샷에 저장한 목표만 나열한다. 그래프 표시 조건과 별도로 목표에 지정한 주파수, 각도, 편파와 해당 실현 이득을 한 줄에 표시한다. 요구 표본 또는 결합 조건이 없으면 미평가 이유를 표시한다. 포트·기준면·실수 Z0와 정확한 기록 표본이 모두 일치하면 한계와 비교한다. [방사 목표 입력 계약](../05_기능설계/02_설계편집/06_대역목표_입력계약.md#9-단일-방향-및-편파의-실현-이득)

## 6. 필드 화면

가운데 단면 heatmap과 오른쪽 기록 성분/실제 주파수/단면/ROI/색 범례를 배치한다. 필드 자료가 없는 결과는 필요한 기록을 안내하는 빈 상태로 표시한다. 예시 heatmap을 실제 결과처럼 채우지 않는다.

Yee 성분의 실제 위치가 다르므로 초기 선택은 Ex/Ey/Ez 같은 개별 기록 성분이다. 기록하지 않은 abs(E)/일반 H/시간 필드를 선택 가능한 계산값으로 보이지 않게 한다. 좌표와 단위, 표시 stride와 ROI 범위를 함께 표시한다. 생략된 격자점과 미기록 값은 구분한다.

오른쪽 안내는 펄스 Fourier 원문 단위, 성분별 위치와 rotH 원문 시간/위상 유지 조건을 표시한다. 색 범위는 현재 반환 ROI에 한정된다는 안내를 유지한다. 기본은 최대 32 x 32개 원문 ROI와 stride 1이며 더 큰 영역은 명시 선택한다. 응답 예산 초과 때 입력을 유지하여 사용자가 ROI를 줄이고 다시 조회할 수 있게 한다. 표본 번호와 방향키로도 마커를 선택하며 크기 0의 위상 미정과 기록되지 않은 값은 구분한다.

단면 조회 버튼은 페이지 상단에 고정하여 ROI 입력의 스크롤 위치와 관계없이 접근한다. 가로/세로는 같은 물리 길이 비율을 사용한다. 비균일 격자의 타일 경계는 표시 구획일 뿐 새 계산 위치가 아니며, 단일 점은 임의 물리 면적 대신 점 마커로 표시한다.

## 7. 다중 결과 비교

위쪽 자료 목록에는 표시 여부/이름/종류/당시 조건을 두고 최대 8개를 선택한다. 가운데 실제 곡선과 아래 또는 오른쪽 비교값, 오른쪽 조건 차이를 연결한다. 긴 이름과 많은 범례가 그래프를 모두 차지하지 않도록 목록에서 자료를 식별한다.

각자의 곡선 표시와 수학적 차이 계산 가능 여부를 분리한다. 단위가 다른 자료를 같은 축의 값으로 섞지 않는다. 비교 불가 사유와 미정 조건을 보여 주며, 가까운 주파수를 대응하거나 없는 포트를 자동 종단하지 않는다. 형상/재료가 다른 연구 비교 자체를 오류로 막지 않는다.

비교 조건은 32개씩 조회하며 현재 시작/끝/총수와 이전/다음 버튼을 표시한다. 다음 페이지 조회 실패 시 이전 내용을 유지하고, 조회 중 다른 원본을 선택하면 이전 선택의 늦은 응답을 폐기한다. 목록의 선택 행과 오른쪽 조건은 같은 고정 source/pin을 가리킨다.

선택 결과의 내보내기는 실제 지원 형식을 골라 파일과 조건 sidecar를 함께 저장한다. 현재 개정으로 자료를 가져오거나 등록해야만 과거 결과를 내보낼 수 있는 흐름으로 만들지 않는다. 화면 선택의 source/pin을 검사하며 늦은 응답의 다른 자료를 같은 이름으로 저장하지 않는다.

## 8. 구현과 검수

ResultWorkspace가 source/pin/조회 세대와 공통 탐색 연결을 관리한다. 각 View는 표/곡선/카메라와 선택 이벤트를 담당한다. 프레임 한 파일에 모든 결과 조회나 계산을 모으지 않는다. 물리 계산과 원본 검증은 [서비스 계약](../05_기능설계/04_해석결과/07_다중결과와_방사표시.md)을 따른다.

실제 Windows에서 source 전환, 빈 자료, 과거 개정, 마커/페이지, 비교 조건, 방사 주파수와 회전, 필드 단면, 늦은 응답/창 닫기 및 저장/재열기를 확인한다. 스크린샷은 검증한 실제 빌드와 시점에 연결한다. 서비스 시험 통과와 시안 외형/사용성 수용은 분리한다.
