# 보고서와 인계 화면

상단 **출력 > 보고서 및 인계**는 [52번 시안](03_구현시안/52_보고서와_인계.png)의 네 번째 출력 탭이다. [DrawIO](03_구현시안/52_보고서와_인계.drawio)와 [SVG](03_구현시안/52_보고서와_인계.svg)에 편집 원본과 개별 배치가 있다. 기존 Studio의 wxAUI 도킹, 프로젝트 탐색, 출력 기준과 아래 작업 상태를 사용한다. 중앙에는 항목/자료/상태 세 열의 native 목록과 버튼, 오른쪽에는 고정 입력, 범위와 제작/측정, 파일 해시 검토를 배치한다.

형식 목록의 **읽기 전용 보고서와 인계**는 고정 스냅샷과 보고서를 사용한다. **편집 복원용 프로젝트 묶음**의 기준은 현재 적용 개정과 저장 기준점이다. 편집 복원용 형식에서는 스냅샷 선택 대신 등록 개정, 명령, 스냅샷과 원문 범위를 보여준다. 권한을 확인한 등록 원문을 포함할 수 있고, 미확보나 제외 상태는 포함 범위와 누락 검토에서 확인한다. 기록 목록도 선택 형식에 맞춰 갱신한다.

| 화면 상태 | 사용자가 할 수 있는 일 | 이어지는 화면 |
| --- | --- | --- |
| 입력 미선택 | 위에서 저장한 고정 입력을 선택하거나 현재 적용 개정을 고정한다. 예전 발행 기록은 그대로 조회한다. | 같은 탭의 근거 목록 |
| 근거 조회 | 항목을 읽고 페이지를 이동한다. 파일이 등록된 행을 선택하여 포함 또는 해제한다. 공유 권한을 확인한다. | 같은 탭의 검토 버튼 |
| 편집 복원용 선택 | 현재 적용 개정과 저장 기준점, 공유 가능한 등록 원문 포함 여부를 확인한다. | 인계 범위 검토 |
| 검토 완료 | 보고서 미리보기에서 개정과 근거 상태를 읽고, 파일 목록에서 이름/바이트/hash를 확인한다. 선택이나 권한을 바꾸면 검토를 다시 수행한다. | 해당 읽기 전용 대화상자 또는 발행 |
| 발행 완료 | 발행 기록에서 검토한 ZIP을 선택하여 작업 영역 밖 새 경로에 저장한다. | Windows 파일 선택기와 저장 결과 |
| 응답 불명 | 같은 요청의 결과를 확인한다. 기존 영수증을 확인할 때까지 생성이 잠긴다. | 발행 완료 또는 같은 상태 |
| 저장 오류 | 파일을 바꾸거나 기존 파일의 위치를 확인한다. 발행 기록에서 다시 저장할 수 있다. | 같은 탭의 발행 기록 |

화면 진입, 기록 선택과 미리보기는 설계 개정을 수정하지 않는다. 미적용 변경은 자동 반영하지 않는다. 파일명과 목록의 상태를 텍스트로 표시하고, 목록 행과 버튼은 키보드로 선택할 수 있다. 원래 설계, 발행 ZIP 및 전달 사본의 hash와 제작/실측 미확립 상태는 [인계 기능 계약](../05_기능설계/05_출력교환/06_고정설계_보고서와_인계.md)을 따른다.
