# 복소 결과와 회로 평가 화면

개발 완료 계획 5번의 서비스/표시 연결 계약이다. 외형은 [공통 화면 기준](12_구현화면_설계기준.md)과 기존 84개 시안을 따른다. 구현이 다른 것을 합리화하기 위해 시안을 다시 그리지 않는다. 그림의 설명용 곡선을 실제 결과로 표시하지 않는다.

S/Z/Y 및 Z0 재정규화는 결과 화면의 별도 변환 대화상자로 연결한다. 원본과 결과의 단위가 다르면 각자 단위가 있는 독립 축에 표시한다. 일반 다중 곡선 비교/Smith와 3D 방사는 계획 7번이며 여기서 가짜 곡선이나 비활성 완성 화면으로 대체하지 않는다.

결과 화면의 `해석 결과 등록`은 기존 봉인 계산을 선택하고 등록 후보를 검토한 뒤 공통 자료로 추가한다. 새 FDTD를 실행하는 버튼이 아니다. `계산 진단`은 선택 자료에 봉인 진단이 있을 때 활성화하고 32개씩 조회한다. 원본/파생 자료 삭제와 일반 다중 결과 비교 작업 공간은 이 화면에 추가한 기능이 아니다.

## 2. 공통 화면 전환

1. 프로젝트를 열고 결과 작업을 선택한다. 복소 자료가 없으면 가져오기와 기존 봉인 해석 자료 채택 안내를 표시한다.
2. 왼쪽 목록에서 자료를 선택한다. 같은 선택의 실제 표본과 오른쪽 조건을 함께 갱신한다. 조회 실패 시 이전 자료를 새 선택의 결과로 남기지 않는다.
3. 복소 채널과 크기/dB/위상/실수부/허수부/VSWR를 선택한다. 입력 Quantity의 SI 환산과 물리 계산은 서비스가 담당한다. 읽기 전용 주파수의 SI 접두어와 축 눈금 서식은 View의 표시 책임이며, 표시 문자열을 명령 원본으로 재사용하지 않는다. dB는 S 자료, VSWR는 S 대각 채널에만 의미가 있다. 해당하지 않는 값은 계산해 채우지 않는다.
4. 표본은 한 페이지 최대 201개다. 현재 범위/전체 개수와 이전/다음 버튼을 표시하고, 곡선도 현재 페이지라는 사실을 알린다. 비유효 셀은 선을 끊고 이유를 표시한다.
5. 설계로 돌아가면 기존 2D/3D 원본 선택과 편집 초안을 유지한다. 결과 화면의 좌우 패널 전환 때문에 설계 View를 파괴하거나 새 원본을 만들지 않는다.

표에서 선택한 실제 표본은 M1 마커로 확인한다. 곡선은 유한 값만 표시하고 완전 정합의 -inf dB, 개방의 +inf VSWR 및 정의 불가는 표의 상태로 구분한다. 선이 없는 값을 0으로 표시하지 않는다.

읽기 전용 주파수는 공통 표시 함수를 사용해 Hz/kHz/MHz/GHz로 표시한다. 자동 단위는 전체 자료 범위로 정하며 평가 표는 평가 당시 목표의 전체 요구 표본 범위를 우선 사용한다. 한 표와 대응 그래프는 같은 단위를 사용하고 201개 표본 페이지를 넘겨도 단위를 바꾸지 않는다. 범위의 양 끝에도 같은 단위를 사용한다. 표 머리글과 그래프 축에는 선택한 단위를 명시한다. 원본 파일/JSON의 Hz 수치, 표본 대응, 계산 입력, 출처 및 프로젝트 개정은 표시 단위를 바꿔도 변경하지 않는다. 기존 입력란의 주파수 단위는 별도 입력 계약을 그대로 따른다.

결과 조회/내보내기, 불변 결과 추가, 프로젝트 저장은 별도 동작이다. 적용은 현재 개정에 참조를 추가하며 저장 표시는 기존 프로젝트 저장 상태를 따른다. 회로와 결과의 이름은 사용자에게 보이는 이름으로 표시하고 UUID는 상세 근거에만 둔다.

## 3. 가져오기와 조건 채택

파일 선택 후 원문 일부와 실제 크기를 보여 준다. 원문 512 KiB 상한, 원문 미리보기 16 KiB 상한은 서로 다르며 잘린 미리보기 때문에 저장 원문을 자르지 않는다. Touchstone/CSV/정규 HDF5 지원 범위는 [파일 계약](../05_기능설계/05_출력교환/03_복소결과_파일교환.md)을 따른다.

CSV는 주파수 열/단위, 복소 표현, 각 행렬 채널 열, 무시할 열을 명시한다. 기준면/파 정의/시간 규약/포트 대응은 원문 유지가 기본이며 사용자가 확인한 값만 채택한다. 원문에 없는 내용을 이름이나 파일 확장자로 추정하지 않는다. 채택 후에도 원문 bytes와 원래 미정 조건 사본은 남는다.

파일/대응/조건/이름이 바뀌면 후보를 무효화한다. 검토 표와 실제 곡선을 확인한 뒤 적용한다. 닫힌 창의 늦은 응답은 폐기하고 중복 적용을 막는다. 적용 결과가 불명이면 입력을 잠그고 자동 재전송하지 않는다. 창을 닫은 뒤 프로젝트를 다시 열어 권위 상태를 확인하며 서비스의 영수증은 동일 요청 재실행을 방지한다. 성공 후 재조회 실패를 새 가져오기 허가로 해석하지 않는다.

## 4. 회로와 변환

회로의 입력에서 부하 방향으로 직렬/병렬 R/L/C 1~16요소를 표시한다. 실제 값/미정, 연결/open/short/DNP, 원문 출처와 EM 외부 가정을 구분한다. 값과 기준면이 미정이어도 회로 정의를 저장할 수 있다. 계산에 필요한 값이 없으면 결합 후보 생성을 막고 이유를 보여 준다.

정의 저장과 결합 결과 저장은 각각 한 명령이다. 기존 회로를 편집하면 새 불변 정의가 생기고 과거 결과가 사용한 회로를 덮지 않는다. 결합 결과에는 원래 안테나 효율을 복사하지 않는다. 회로 그림은 입력한 요소와 순서를 그리며 실제 제작/배선 기생을 그려 넣지 않는다.

변환 창은 `변환 조건 / 변환 후보 / 조건과 진단`의 세 탭이다. S/Z/Y 변환은 목표 종류를 선택한다. 재정규화 GUI는 빈칸에서 시작하는 양의 실수 Z0를 ohm 단위로 입력하며 모든 포트와 주파수에 같은 값을 적용한다. 현재 GUI에 단위 선택이나 새 출처 입력란은 없다. 서비스는 기존 Quantity 또는 값/단위/출처 입력을 받을 수 있으며 원래 입력과 해석한 Quantity를 파생 출처에 함께 보존한다.

원본을 덮는 버튼은 없다. 검토는 첫 11 채널의 앞 201개 이내 표본을 원본/변환 각각의 그래프와 실제 RI 표로 표시하고 전체 표본 수를 알린다. 진단 탭은 앞 8개 진단과 전체 진단 개수/보존 안내를 표시한다. 저장 후 네트워크 화면에서 모든 채널/표본을 선택하고 `계산 진단`에서 전체 진단을 32개씩 조회한다.

## 5. 목표 판정과 과거 결과

Studio 결과의 `목표 평가` 페이지에서 저장된 평가를 왼쪽 목록으로 선택한다. 가운데에는 지표/한계/평가 가능한 표본 수/판정/이유를 표시하고 선택한 기준의 실제 표본을 아래 표에 연결한다. 오른쪽은 평가 당시 목표, 현재 목표 개정 변경 여부, 대응 자료의 포트/기준면/Z0와 원문 출처를 보여 준다. 제작/측정 조건이 없거나 null이면 각각 미정으로 표시하며 object가 있다는 이유로 확정 상태로 표시하지 않는다.

가운데 평가는 세로 스크롤이 가능한 `wxScrolledWindow`로 구성한다. 기준 표의 최소 높이는 136 DIP, 실제 표본 표는 128 DIP로 유지한다. 창 높이가 작거나 글자/화면 배율 때문에 내용이 넘치면 표를 0 높이로 줄이지 않고 스크롤로 표본과 아래 조작에 접근한다. 일반 창에서도 기준 표와 표본 표를 확인할 수 있도록 중복 안내와 세로 여백을 줄인다.

`새 평가 / 재평가`는 기존 입력 대화상자를 연다. 현재 목표/자료 포트와 기준면을 명시하고 검토한다. 정확히 같은 주파수와 Z0만 판정하며 누락을 근접한 표본으로 채우지 않는다. 모든 요구 표본이 통과해도 전체 대역 합격 대신 조건부 표본 통과로 표시한다. 연속 대역/수렴/실측 검증은 별도다.

평가 저장 시 목표 개정/목표 원문/자료 hash/판정 조건을 고정한다. 이후 목표가 달라지면 과거 평가와 현재 목표가 다르다고 표시한다. 새 평가는 사용자가 다시 검토하고 저장해야 하며 자동으로 만들지 않는다. 과거 표를 현재 목표로 조용히 다시 계산하지 않는다. 저장 전 후보는 기준별 앞 8개 표본을, 저장된 평가는 201개씩 조회하며 전체 개수와 누락 상태를 유지한다.

본 화면은 저장 기록을 선택했을 때 먼저 기준별 앞 8개를 요약 미리보기로 표시한다. `전체 표본 보기` 또는 기준 행 선택으로 201개씩 조회하며 앞/뒤 페이지와 전체 개수를 알린다. 기록/개정이 바뀐 응답은 프레임에서 폐기하고 조회 실패 시 다른 평가의 값이 남지 않게 표시를 지운다. 당시 목표 원문이 커서 응답이 요약인 경우에는 요약과 전체 봉인 파일 참조를 표시하고 원문 전체를 화면에 읽었다고 안내하지 않는다.

## 6. 내보내기와 오류

선택한 자료의 Touchstone/CSV/정규 HDF5/보존 원문과 조건 sidecar를 별도 파일로 저장한다. 원본 workspace 안의 경로와 이미 존재하는 출력 또는 sidecar를 거절하고 다른 이름을 안내한다. 두 임시 파일을 모두 기록한 뒤 게시하며 실패 시 생성한 파일만 복구한다. 일부 파일만 남으면 성공으로 안내하지 않는다.

CSV/Touchstone 단독 파일에 기준면/출처/미정값을 전부 표현할 수 있다는 뜻이 아니다. 전체 보존은 프로젝트 원본/정규 HDF5와 조건 sidecar를 함께 사용한다. 텍스트로 표현할 수 없는 mask를 0이나 누락 행으로 바꾸지 않는다.

## 7. 구현 책임과 검수

NetworkPanel/NetworkChart와 NetworkAssessmentPanel은 표시와 선택, 각 대화상자는 입력 초안/검토 상태를 담당한다. StudioFrame의 network 연결 모듈은 revision/늦은 응답/수명/서비스 연결을 담당한다. 목표 평가 페이지는 직접 서비스 요청이나 계산을 하지 않고 평가 선택/표본 페이지/재평가 콜백만 프레임에 전달한다. 계산/Quantity/원문/명령/영수증은 Python service와 domain 소유다. GUI는 wxWidgets native 입력/표와 wxGraphicsContext 곡선이며 웹뷰나 Qt를 도입하지 않는다.

기능 시험과 외형 검수는 분리한다. 실제 Windows에서 빈 목록, 미정 조건, 파일 검토, RLC 정의/결합, 목표 평가, 저장/재열기와 출처 보존을 확인한다. 현재 페이지 데이터만 그린 화면을 전체 1001표본이나 전체 84개 시안 수용으로 확대하지 않는다.
