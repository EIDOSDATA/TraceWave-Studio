# 문서 정비와 새 채팅 인계 검토

2026-11-21 KST. 제품 기준은 d3ef05c, 승인 기준선은 RFAD-D0-3.4다. 문서 정비가 끝난 뒤에는 [새 채팅 개발 인계](../09_개발계획/08_새채팅_개발인계.md)의 첫 작업부터 이어간다.

## 확인 범위

- 기존 목록의 4,229개 항목을 실제 파일과 대조했다. 이 가운데 기존 개발문서 846개는 자기 참조를 피하는 목록·집계 두 파일을 제외한 수다. 참조 자료 3,336개와 과거 실행·환경 기록 44개는 보존했다.
- 개발문서 Markdown 전문을 UTF-8로 읽고 현재형·이전 경로·중복 본문 후보를 찾았다. 다음 작업과 직접 연결되는 계획, 상태, 화면·기능 계약, 개발 진입 안내와 추적표는 코드 및 보존 검증을 대조해 편집했다.
- 개발문서의 JSON/JSONL, DrawIO/SVG, 화면 PNG/JPG는 형식을 검사했다. 기존 84개 화면 시안과 12개 전환도 검사는 문서 도구로 실행했다. 바이트가 같은 두 쌍의 검증 사진은 서로 다른 기록의 링크가 있어 보존했다.
- 승인 설계의 바이트, 외부 PDF·수집 원본과 과거 시험 환경을 보존했다. 외부 PDF의 모든 페이지를 다시 읽거나 물성을 재검산하는 대신 기존 검토와 연결된 출처 및 파일 해시를 확인했다. 이번 문서 변경에서 제품 GUI, FDTD와 실측은 새로 실행하지 않았다.
