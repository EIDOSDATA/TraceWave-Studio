아래 명령은 Windows 개발 PC의 `Code` 폴더에서 실행했다. `.local/rf-check`는 [수치 환경 준비](../09_개발계획/08_새채팅_개발인계.md)에서 만든 CPython 3.12 가상환경이다.

## 확인 범위

- 기존 목록의 4,229개 항목을 실제 파일과 대조했다. 이 가운데 기존 개발문서 846개는 자기 참조를 피하는 목록·집계 두 파일을 제외한 수다. 참조 자료 3,336개와 과거 실행·환경 기록 44개는 보존했다.
- 개발문서 Markdown 전문을 UTF-8로 읽고 현재형·이전 경로·중복 본문 후보를 찾았다. 다음 작업과 직접 연결되는 계획, 상태, 화면·기능 계약, 개발 진입 안내와 추적표는 코드 및 보존 검증을 대조해 편집했다.

| 반복 정리 | 코드 안내의 반복 상태·시험 문단은 담당 문서 링크로 줄였다. 2026-11-16 요약의 중복 표는 당시 저장 버전과 상세 기록의 링크로 바꿨다. 수식 연결의 같은 문단은 요구사항에서 관리한다. |
| 실행 근거와 추적 | 제조사 261~263 검증을 검증 안내와 관련 FN에 연결하고, 지원한 환경/정밀 편집 자료와 남은 범위를 갱신했다. 요구 141개, AC 404개, 하위 사례 407개 및 기존 수용 판정과 식별자를 유지했다. |

문서 링크와 형식, 승인 해시, 감사 생성물의 재현성을 검사했다. 제품 변경이 있을 때의 시험은 [검증 선별 기준](../09_개발계획/05_현행버전_검증선별_기준.md)에서 선택한다. 현행 R1의 실제 종료 조건은 [잔여 작업표](../09_개발계획/04_현행버전_남은작업.md)에 둔다.
