# 문서와 참고 자료 전수 파일 집계

기준일: 2026-11-17 KST. 기존 `catalog_documents.py` 목록에 이번 개발 변경 파일만 증분 반영했다. 분류/파일 읽기와 전문 내용의 검토 수준은 다르며 각 파일의 review_scope를 함께 읽는다.

이번 갱신은 29개 파일의 현행 바이트/해시를 확인하고 신규 16개를 포함했다. 참고자료 3336개와 기존 runtime 39개의 record는 기존 값 전체를 보존했으며, 이번에 해당 원문을 재읽기/재해시하지 않았다. 변경하지 않은 다른 record도 기존 검토 범위를 유지한다.

기존 records의 순서를 유지하고 새 경로만 목록 뒤에 추가했다. 이번 마감에서 바뀐 검증/요구 추적/기능 계약의 hash를 반영했으며 이전 실행의 증거 시점을 변경하지 않았다.

전체 경로/분류/검토 수준/바이트/작업트리 SHA256과 이번 갱신 경로/이전 목록 hash는 [02_문서목록.json](02_문서목록.json)에 있다. PDF 전 페이지 의미 검토, RF 정확도, 외부 링크의 최신 유효성과 참고자료 전체 재검증을 이번 갱신 결과로 주장하지 않는다. 과거 승인/출처 hash와의 실제 비교는 [검토 기록](../11_검토기록/05_해석과_참고자료_검토.md)을 따른다.

02_문서목록.json과 이 요약은 자기 참조 hash를 피하기 위해 목록에서 제외한다. 원문/추출/기존 runtime 파일은 수정하지 않는다. 새 공통 복소 계산 환경의 runtime 2개만 이번 갱신에 포함했다.
