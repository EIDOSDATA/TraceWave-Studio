# TraceWave Studio 개발 문서

처음 구현하거나 다른 PC에서 재현할 때는 [제품 재현 안내](03_제품_재현_안내.md)에서 시작한다. 설계대로 만들었는지 판정할 수 있도록 각 단계에 입력 예제, 기대 동작과 실행 시험을 연결했다.

| 데이터와 시스템 구현 | [시스템 명세](02_시스템명세/README.md), [아키텍처](03_아키텍처/README.md) | 파일 형식, 서비스 통신, 모듈 경계, 오류와 복구 |

## 어느 기록을 기준으로 삼는가

- **요구를 확인할 때**는 RFAD-D0-3.4 승인 사본과 이후의 사용자 수용 결정을 함께 본다. 기존 설계 번호 00~25마다 현행 편집본과 승인 사본이 대응한다. [번호별 대조](10_문서목록/04_기존설계분류.md)
- **현재 동작을 확인할 때**는 기능 계약에서 지원하는 입력 범위를 읽고 해당 개정의 코드, 예제와 검증 결과를 대조한다. 설계 시안과 실제 Windows 화면의 증거는 각각 열람할 수 있다. [시안 목록](04_화면설계/13_전체화면목록.json) [실제 화면 검수](07_검증/425_화면_구분자와_문구_재검수.md)
- **옛 프로젝트를 재현할 때**는 원래 개정의 사용자 입력, 채택한 출처와 결과 파일을 사용한다. 기록에 남은 파일 경로가 바뀌었으면 경로 대응표와 당시 Git 개정으로 찾는다. [문서 관리](02_문서관리와_변경규칙.md) [이전 경로](10_문서목록/01_이전경로대응.json)
