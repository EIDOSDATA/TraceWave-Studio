# 분석과 연구 기록

## 현재 연구 판단

- **RO4350B 방사 도체 손실**. 2026-11-22 사용자는 이 고정 사례에서 7분할과 8분할 간 최대 상대 차이 2.788446%를 허용했다. 이 편차를 줄이기 위한 반복 계산은 종료했다. 원래 2% 기준의 판정은 당시 실행에 남는다. 8분할을 고정하고 일반 격자만 세 수준으로 세분화한 비교는 기존 기준을 충족했다. [국부 손실 연구](11_고주파기판_도체손실_정밀연구.md), [일반 격자 검증](../07_검증/307_팔분할_일반격자_손실_수렴검증.md)
- **도금 관통홀(PTH)**. 8, 10, 12 GHz의 합성 형상에서 패드, 접합층, 급전부의 손실을 독립 계산과 대조했다. 제품 해석에서는 비아 끝의 유한 접합층과 국부 간극 급전을 지정해 두 방식으로 손실을 검산했다. 원래 분포 급전 조건과 실제 제조 접합의 물성은 미평가다. [제품 접합층 검증](../07_검증/379_비아접합층과_급전전력_검증.md) [접합과 급전 참조](../07_검증/292_입사전력과_기가헤르츠_관통홀_접합검증.md), [표면 손실 독립 대조](../07_검증/301_급전격자와_관통홀_표면손실_독립대조.md)
- **설치 원호와 IFA**. 합성 외함과 이상 정합 회로를 고정하고 격자와 외부 여백을 한 가지씩 바꿔 두 후보의 2.400~2.4835 GHz S11 -10 dB 목표 충족을 확인했다. 관측 조건의 최악 상한은 IFA -13.621461 dB, 원호 -13.682548 dB다. 실제 SMA, 케이블과 실장은 미정이다. [격자와 외부 경계 대역 대조](../07_검증/311_설치후보_격자와_외부경계_대역검증.md)
