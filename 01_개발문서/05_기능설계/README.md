# 기능별 문서

[프로젝트](01_프로젝트/README.md), [설계와 편집](02_설계편집/README.md), [재료와 출처](03_재료/README.md), [해석과 결과](04_해석결과/README.md), [출력과 교환](05_출력교환/README.md), [설계 탐색과 수치 연구](06_연구/README.md)로 나누어 관리한다.

각 기능의 실제 지원, 입력/출력, 명령/이력, 오류/미지원과 근거는 해당 계약이 소유한다. 일반 UI 동작과 배치는 [화면설계서](../04_화면설계/README.md), 원본/버전/공통 DTO는 [시스템 명세](../02_시스템명세/README.md), 미래 구현의 승인 상세는 [승인 분류](../10_문서목록/04_기존설계분류.md)를 따른다.

공통 복소 결과/기본 RLC/Touchstone/측정 파일은 [복소 자료 계약](04_해석결과/06_공통복소자료와_회로평가.md), 명시적 다축 연구는 [연구 계약](06_연구/01_명시적스윕과_실행계약.md)을 따른다. CAM 등 후속 기능은 승인 설계 및 [R1 설계 준비표](../02_시스템명세/10_설계준비와_결정경계.md)에서 찾는다. 계약의 존재와 실제 실행/물리 수용 상태를 구분한다.
