# 사용자 PCB의 단일 포트 openEMS 해석

계약 대조일: 2026-11-16 KST. `rfad.openems.pcb-single-port/0.1`은 사용자가 저장한 PCB 입력을 WSL2 openEMS로 전달하는 초기 실행 profile이다. 승인 기준선 RFAD-D0-3.4를 유지한다. 아래 고정 IFA 연구의 수치 안정성 판정과 일반적인 IFA의 수렴/제작/측정 검증은 구분한다. 이번 문서 대조는 새 native 해석을 수행한 기록이 아니다.

## 입력과 원형 기판

사각 기판과 중심/반지름이 명시된 원형 기판을 지원한다. 외형은 구리 선/원호와 독립이다. 원형 PCB를 선택했다고 접지 원판, 패드, 동박이나 원호가 자동 생성되지 않는다. 기판 밖의 도체를 잘라 맞추지 않고 거절하며 선의 폭/둥근 끝과 원호 전체 범위를 검사한다.

기판과 도체는 같은 평면 좌표계의 불변 스냅샷에서 mm로 투영한다. 원형 유전체는 CSXCAD Cylinder, 사각 유전체는 Box로 생성한다. CAD의 원형 외곽과 고체는 Open CASCADE의 정확 형상을 사용하고, EM 도체 곡선은 명시한 허용 오차 안에서 polygon으로 근사한다. 이후 Yee 격자 오차가 별도로 존재하므로 CAD 곡선의 정확성과 RF 계산 정확도를 동일시하지 않는다.

유전체와 외측 도체 적층, 선/원호, hole을 가진 접지 polygon, 원형/회전 사각 pad와 명시적 through-PTH via, net/재료와 단일 lumped port를 지원한다. 층 위치/두께, 전도도, 물성 유효 대역과 포트 조건이 필요하다. 상대 유전율과 손실 탄젠트는 유전체에 필수이며, conducting sheet가 소비하지 않는 도체의 두 물성은 미정이어도 된다. 체적 via 도체에는 전도도와 상대 유전율이 필요하다. 미정값을 FR4/구리의 대표 상수로 채우지 않는다. 내부 동박, blind/buried via, 마스크/접착층, 비항등 좌표 변환, 다중 포트는 이 profile의 지원 범위 밖이다. 선택적 NF2FF 기록/후처리/조회는 [방사 계산 계약](04_사용자기판_방사계산.md)을 따른다. 형상/도금/급전의 상세 계약은 [도체와 IFA 확장](../02_설계편집/05_도체영역과_급전모델.md)을 따른다.

## 물성 및 급전 모델

[적층/외부 환경](../02_설계편집/12_적층과_외부환경.md)에 따라 지원하는 솔더마스크·보조 유전체와 간이 유전체 케이스·PEC 상자만 지정 조건에서 해석한다. 외부 STEP과 표시용 간이 물체는 CAD 경로에서 사용한다. `include_in_em=false`는 원본 항목과 생략 이유를 유지하고, 미지원 항목에 true를 요청하면 차단한다. 화면의 표시/STEP 포함과 해석 포함을 독립 상태로 표시한다.

선택적 독립 손실은 [개별 손실/PTH 계약](../../06_분석연구/09_개별손실_정밀도와_도금관통홀_분할.md)을 따른다. feature_subdivisions로 기존 임계 구간을 최소 1~8분할할 수 있으며 값이 없으면 기존 격자를 유지한다. 원본 프로젝트 schema, 직접 입력과 과거 planar 결과는 유지한다.

- 기존 유전체 `isotropic_constant`는 사용자의 독립 전도도에 대역 중심 주파수의 `2*pi*f*epsilon0*epsilon_r*tan_delta`를 더한다. 두 항이 같은 손실을 중복 표현하지 않는다는 입력 가정이 필요하다. 새 `isotropic_constant_total_tan_delta`는 총 Df만 등가 전도도로 변환하며 원본 전도도를 소비하지 않는다. 두 모델 모두 stop/start는 2 이하이고 명시한 적용 대역이 전체 평가 대역을 포함해야 한다. 상수 kappa는 중심에서만 입력 Df와 일치하며 광대역 분산 모델은 후속이다. 상세는 [재료 손실 모델](../03_재료/03_재료손실과_제조사물성.md)을 따른다.
- 동박은 인접 유전체 경계면으로 투영한 `AddConductingSheet`다. 사용자가 입력한 전도도와 실제 두께를 모두 전달하며 두께를 0으로 버리거나 PEC로 교체하지 않는다. 기하학적 체적 동박과 동일한 모델은 아니므로 sheet 위치/두께/전도도 및 근사 내용을 계획과 소비 보고서에 기록한다.
- 포트에는 양극/기준 도체 UUID, 저항, 기준면 설명, 유효 대역, 방향/극성 및 `excitation_box.start/stop`의 3D Quantity가 필요하다. 동일 sheet 면의 x/y 또는 서로 다른 sheet 면의 z 축 방향 1차원 gap, 극성 +1을 지원한다. 시작점은 기준 도체, 끝점은 양극 도체에 닿아야 한다. 모든 gap은 실제 Yee edge 두 개 이상으로 표현해야 하며 x/y gap은 설정 grid_mm의 두 배 이상이어야 한다. z gap은 양끝과 중간의 local mesh line을 추가해 검사한다. 임의 위치의 기본 포트를 만들지 않는다. 같은 net인 IFA도 실제 열린 gap과 접지/단락부/방사체의 연결이 맞으면 허용한다.
- native polygon에서도 단자 접촉과 열린 gap의 도체 침범을 검사한다. 다른 net 또는 재료의 접촉과 허용 오차 이내 간격은 보수적으로 거절한다. 이는 초기 형상 검사이며 최종 제조 DRC, 전류 경로 수용이나 일반적인 접속 엔진을 대신하지 않는다.

물성은 사용자가 지정하는 설계 변수이며 제품 기본값이 아니다. 내부 실행 fixture의 수치는 명시적 시험 가정으로만 저장한다. 승인된 최초 IFA의 미정 물성/제작/측정 조건은 그대로 남긴다.

일반 EM 입력 점검도 위 필수 물성 목록을 공유하고 급전 좌표 누락을 안내한다. 도체 sheet의 미사용 유전율/손실을 요구하지 않는다. 입력 문제가 없으면 input_status=valid지만 solver_ready=false이며, 실제 지원 형상/연결/격자 조건은 solver.plan에서 추가 확인한다. 후속 계획 검증이 필요하다는 사실 자체를 입력 오류로 표시하지 않는다.

## API와 실행

공통 준비/실행/취소/봉인/재접속 계약은 [solver worker](02_해석작업_계약.md)를 따른다. `solver.plan`에서 analysis_profile을 PCB profile로 지정하고 grid_mm 대신 settings를 전달한다.

```json
{
  "frequency_hz": {"start": 2400000000, "stop": 2483500000, "count": 101},
  "grid_mm": 1,
  "air_padding_mm": 30,
  "curve_tolerance_mm": 0.05,
  "max_timesteps": 30000,
  "end_criterion": 0.00001
}
```

`해석 > 설정 및 해석 실행`에서 `조건 검토`를 누르면 저장이나 작업 생성 없이 현재 개정의 단일 포트 계획을 읽는다. `해석 격자` 탭은 준비 단계에서 CSXCAD에 전달하는 모든 X/Y/Z 격자선과 인접 간격, 격자점과 Yee 셀 수, PML 시작면과 그 앞의 공기 여유를 보여준다. 그림의 XY는 형상 투영이며 XZ/YZ는 계산 형상의 높이 범위 투영이다. 수치 표는 화면 확대와 관계없이 선택한 축의 모든 좌표를 표시한다. `포함 형상` 탭에서 해석 계획에 포함된 원시 형상과 역할 및 제외 사유를 확인하고 포함 항목을 격자에 강조할 수 있다.

격자점 상한에 도달하면 제한값과 확인된 하한을 안내하고 `조건 입력`의 모델 최대 격자 간격으로 이동한다. 특정 설정의 범위 오류에는 그 항목으로 이동한다. 입력 초안은 같은 창에 유지한다. 조건을 바꾼 뒤에는 다시 검토해야 실행 버튼이 활성화된다. `종료 / 기록 출력` 탭의 개정 ID, 해석 입력과 격자 SHA-256으로 준비 입력을 대조할 수 있다. [원호와 IFA 실행 검증](../../07_검증/315_윈도우_해석전검토와_실제격자_검증.md)

재료 또는 급전의 차단 진단에 기존 편집 객체가 있으면 `문제 속성으로 이동`이 그 객체를 선택하고 해당 입력란에 초점을 둔다. 재료가 지정되지 않은 경우에는 적용 위치의 재료 선택란을 연다. 급전 객체가 없는 경우에는 추가 위치를 안내한다. `해석 검토로 돌아가기`를 누르면 기존 조건을 사용하고, 미적용 편집이 있으면 `변경 적용 후 해석 검토로`에서 적용과 재열기를 이어서 진행한다. 조건 검토를 누르면 수정한 개정의 격자와 포함 형상을 읽으며 그때까지 실행과 이름 저장은 잠긴다. [속성 이동과 조건 복귀 검증](../../07_검증/318_해석오류_속성이동과_조건복귀_검증.md)

### 객체별 국부 격자

`국부 격자`에서 현재 해석에 포함된 급전이나 비아를 선택한다. 좁은 간극은 이름과 기판 좌표계의 X/Y/Z 시작·끝을 mm 단위로 입력한다. 축마다 목표 최대 셀 폭(0.001~5 mm)을 설정하고, 빈 축은 이 규칙의 영향을 받지 않는다. 우선순위는 0~100이며 같은 축에서 겹치는 부분은 값이 큰 규칙을 적용한다. 동률에서는 더 작은 목표 폭을 적용한다.

급전은 실제 시작점과 끝점을 쓰고, 좌표가 하나인 축은 그 축의 목표 폭만큼 중심을 기준으로 펼쳐 해석 모델 내부로 자른다. 비아는 배럴의 외경과 상하 끝을 쓴다. 경계가 기존 격자선에 0.0001 mm보다 가까우면 기존 선을 유지한다. 기본 내부 격자선은 유지하고 필요한 선을 추가한다. 가변 공기 영역은 바뀐 계면 셀을 기준으로 전이 격자를 다시 계산하고 PML 조건을 검사한다. 기존 전체 격자 자원 상한을 적용한다. 평면 급전 간극이 전체 최대 폭의 두 배보다 좁을 때는 간극 전 구간에 간극 폭 절반 이하의 국부 목표를 적용해야 한다.

`조건 검토`의 결과표에서 선택한 규칙의 실제 좌표, 셀 수, 최대 셀 폭과 상위 규칙 적용 여부를 확인한다. `선택 구간을 격자에서 보기`는 실제 격자의 양쪽 선을 강조하고 대응하는 축의 셀을 수치 표에 표시한다. 이 격자는 Cartesian이므로 각 축의 격자선은 다른 두 축 전체를 가로지른다.

`settings.local_mesh`는 최대 16개의 선택 입력이다. 각 항목은 `kind`(`port`, `via`, `gap`), `priority`, `max_cell_mm`(x/y/z 중 지정한 축)을 담는다. 급전과 비아는 `object_id`, 간극은 `name`과 `bounds_mm`(X/Y/Z 순서의 시작·끝 쌍)을 담는다. 조건 저장·결과 재사용 시 함께 보존한다. 저장한 객체가 현재 해석 형상에 없으면 대상을 다시 선택해야 한다. 검토 DTO의 `mesh.local_mesh_report`와 준비 산출물의 같은 이름의 보고서에서 실제 격자선 인덱스(0부터 시작) 및 구간별 셀 수를 대조할 수 있다. [원호·IFA·PTH 검증](../../07_검증/319_객체별_국부격자_윈도우와_준비_검증.md)

### 격자 품질 검사

`격자 품질`은 실제 X/Y/Z 격자선에서 아래 지표를 읽는다.

| 지표 | 계산 및 검토 기준 |
| --- | --- |
| 셀 폭 | 같은 축의 연속한 두 격자선 차이에서 최소와 최대 폭을 읽는다. 0.0001 mm 미만, 모델 최대 격자 간격 초과 또는 공기 간격 초과를 표시한다. |
| 인접 셀 성장률 | 같은 축의 인접한 두 셀 중 큰 폭을 작은 폭으로 나눈다. 가변 격자의 성장률을 적용하며 일반 격자는 1.5를 사용한다. |
| 모델 종횡비 | 모델 범위와 겹치는 각 축의 짧은 셀과 다른 축의 넓은 셀을 대조한다. 짧은 셀이 속한 축에 비율을 표시하고 10을 초과하면 두 셀 경계를 보여준다. |
| 파장당 셀 수 | Gaussian 여기 상한의 파장을 실제 셀 폭으로 나눈다. 모델과 겹치는 축 구간에는 해석에 소비한 가장 큰 유전율 기준 파장, 바깥 공기와 PML에는 진공 파장을 적용한다. 10셀 미만을 표시한다. |

경고 표는 같은 지표, 영역과 수정 설정을 공유하는 인접 구간을 합치고 최악 셀을 보존한다. 경고를 고르고 `격자 위치로 이동`을 누르면 실제 격자와 수치 표가 해당 축의 셀을 가리킨다. 종횡비는 비교한 직교 방향 셀도 점선으로 표시한다. `관련 설정으로 이동`은 국부 규칙, 모델 최대 격자 간격, 임계 구간 분할 또는 가변 공기 입력으로 초점을 보낸다. 입력값을 바꾸면 다시 검토해야 한다.

품질 표는 입력 조정을 돕는 검토 경고다. 기존 해석 실행 조건과 격자 생성 방식을 그대로 적용한다. 파장은 `mesh.quality_reference`에서 읽으며, 유전체별 공간 분류 대신 모델 외곽의 축 투영을 사용한 보수적 추정이다. [원호와 IFA 검증](../../07_검증/320_격자품질과_수정위치_윈도우검증.md)

### 예상 실행 비용과 종료 원인

`해석 전 검토 > 종료 / 기록 출력`은 현재 격자로 예상 openEMS 실행 시간 범위, 추정 메모리와 원시 출력 용량을 표시한다. 시간 범위는 격자점 수에 최대 시간 단계 수를 곱한 값을 원호·IFA의 WSL2 4스레드 참조 처리율 1,700만~5,100만 격자점 단계/초로 나눈 값이다. 1~3스레드는 비례 환산하고 4스레드 이상은 같은 참조율을 적용한다. 에너지 기준에 먼저 도달하면 실제 시간은 이 범위보다 짧아질 수 있다. 계획의 허용 한도와 실행 요청에 지정한 시간 한도는 별도로 기록한다.

메모리 추정은 기존 격자 자원 모델을 사용한다. 원시 출력은 포트·로그·XML, 선택한 NF2FF 면, 독립 손실 기록의 대략적인 용량이다. 결과에서 openEMS 프로세스 실경과 시간과 Linux 최대 RSS를 읽고, 원시 파일의 봉인 바이트 합계 및 전체 보존 결과 용량과 함께 표시한다. 후처리 시간은 별도로 기록한다. 설치, 대기 및 WSL 준비 시간은 openEMS 실행 시간과 범위가 다르다.

`해석 결과 > 실행 비용과 종료`에서 에너지 도달, 최대 시간 단계, 실행 시간·출력 한도, 취소, 중단 또는 해석 오류를 확인한다. 최대 시간 단계에서 확보한 원시 바이트는 부분 출력으로 표시한다. 시간 한도나 취소로 native 계측을 얻을 수 없으면 미계측으로 두고, 감독 단계에서 확인한 WSL 관측 시간과 출력 관측 최대값을 제공한다. 미완료 시도는 마지막 완료 결과와 별도로 조회한다.

새 계산의 예상값과 계측값은 원시 manifest에 함께 봉인한다. 과거 결과는 봉인된 당시 계획에서 예상값을 다시 계산하고 당시의 실행 시간과 원시 바이트를 표시한다. 기록된 기존 RSS가 없으면 미계측으로 표시한다. [실행 비용과 종료 검증](../../07_검증/321_실행비용과_종료원인_검증.md)

### 해석 결과의 입력과 출처

완료된 사용자 PCB 결과에서 `해석 입력과 출처`를 연다. 해석 결과 도구줄, 공통 결과의 `결과 조건` 패널과 방사 패턴 창에서 접근한다. `당시 설계`는 계산 개정과 조회 시점 현재 개정, 스냅샷, 계획 ID 및 해시를 보여준다. `봉인 설계 원문 열기`로 당시 설계 전체를 읽는다. `당시 해석 조건`에는 대역, 격자, 종료 기준과 선택 NF2FF 등 계획에 저장된 수치 설정이 표시된다.

`재료와 급전`에서 재료, 급전, 신호·기준 단자 도체 및 적층을 선택한다. `계산 입력`은 계획이 해석기로 전달한 물성, 치수와 급전 조건을 표시한다. `설계 원본 값`은 봉인된 SI 값, 표시 단위, 상태와 연결된 당시 매개변수 및 표현식이다. `출처`는 입력 필드별 참조를 보여주며, 카탈로그에서 보존한 발췌가 있으면 원문과 SHA-256, 채택에 사용한 JSON 포인터를 읽을 수 있다. 문자열 참조만 저장한 경우는 그 문자열과 원문 사본의 보존 여부를 표시한다.

결과의 소유 프로젝트, 계획 해시, 개정 ID와 설계 해시가 일치해야 열린다. 설계 원문 조회는 실제 스냅샷 파일 해시도 확인한다. 현재 개정이 바뀌어도 표시되는 계산 입력과 출처는 선택 결과가 가리키는 당시 개정에서 읽는다. [원호와 IFA 검증](../../07_검증/322_해석결과_출처역추적_검증.md)

### 이름 있는 해석 조건과 과거 결과 재사용

`해석 > 설정 및 해석 실행`의 `조건 저장 / 재사용` 탭에 저장한 조건과 이 프로젝트에서 완료된 사용자 PCB 결과가 표시된다. 현재 본 결과에서 시작하려면 `결과 조건 다시 사용`을 누른다. 결과 항목을 선택하면 소유 프로젝트와 해석 계획의 원본 해시를 확인하고, 당시 계획에서 수치 설정을 읽는다. 비교표는 현재 편집 중인 해석 입력과 다른 값만 보여주며, 개정과 급전·설치의 변경 상태를 표시한다.

`선택 조건 불러오기`는 입력란에 설정을 복제한다. 주파수, 격자·PML 여유, 종료 기준, NF2FF 주파수 전체와 기존 고급 계산·기록 설정을 보존한다. 불러온 뒤 현재 설계의 형상, 급전과 설치를 사용해 다시 검토해야 실행할 수 있다. 저장은 유효한 검토를 마친 조건에 이름을 붙이는 명시 동작이다.

`solver.conditions`는 읽기 전용 조회다. `solver.conditions.save`는 기준 개정, 이름, 설정을 받아 기존 프로젝트 이력과 영수증에 새 개정을 기록한다. 최대 32개, 합계 32 KiB이며 이름은 중복을 거절한다. 직전 프로젝트가 저장된 상태에서는 조건을 추가한 개정을 저장한다. 적용 뒤 저장을 기다리던 설계가 있으면 프로젝트의 저장 버튼으로 저장 시점을 선택할 수 있다. [Windows와 실제 준비 입력 검증](../../07_검증/317_해석조건_저장재사용과_원호아이에프에이_검증.md)

위 값은 GUI 초기 수치 설정이며 특정 설계의 정확도를 보장하지 않는다. 계획에서 최소 도체 폭/급전 간격/파장, 층 수, polygon 점 수와 격자 자원 상한을 검사한다. 주파수는 1 MHz~50 GHz, 표본 수는 3~201, 격자 최대 간격은 0.05~5 mm, air padding은 1~200 mm이면서 10 grid 이상이다. 곡선 허용 오차는 0.001~0.25 mm이면서 grid/2 이하이며 최대 1500000 격자점과 도체 64개로 제한한다. 이 범위의 모든 입력을 검증한 것은 아니다. 수렴 확인에 필요한 격자/경계 거리 선택은 사용자의 후속 검토 대상이다.

[RO4350B 손실 정밀 연구](../../06_분석연구/11_고주파기판_도체손실_정밀연구.md)의 compute_profile을 명시한 경우에만 표준 2400000 격자점/900초 또는 심화 3000000/1800초와 1~8개 지정 스레드를 허용한다. 기본 계획은 1500000/300초/2스레드를 유지한다. 손실 필드는 기본/표준 48 MiB, 심화 96 MiB이며 단일 파일 64 MiB/패키지 128 MiB와 최소 격자 간격은 유지한다. 요청 시간은 해당 불변 계획의 상한을 넘을 수 없다. 스레드/시간 설정은 원본 물성이나 수렴 판정 기준을 변경하지 않는다.

명시 수치 튜닝에 한해 compute_profile 종류 tuning_refinement/0.1을 사용할 수 있다. 격자점 상한은 기본과 같은 1500000이며, 작업당 최대 900초와 1~8개 스레드를 허용한다. 손실 필드 설정은 별도로 요청한다. 지정 계산 예산은 연구 정의와 각 후보 실행 계획에 봉인되며 기본 계획과 기존 결과에는 영향을 주지 않는다.

수렴용 격자 확장은 optional `mesh_policy={kind: graded_air, air_cell_mm: 6, growth_ratio: 1.5}`로 모델 근처의 grid와 외부 공기의 간격을 구분한다. 기존 필드가 없는 계획은 원래 전역 격자를 유지한다. 말단 PML8은 고정 간격이므로 이 설정에서는 두께가 48 mm다. `air_padding_mm`는 계산영역의 바깥까지 거리이며 PML 시작면까지의 빈 공간이 아니다. padding 90/96/102 mm는 각각 PML 앞 42/48/54 mm 여유에 대응한다. 외부 공기와 계면은 실제 성장률 상한을 검사하지만 기존 내부 임계선은 보존하므로 모든 내부 cell에 1.5 상한을 강제하지 않는다. 실제 비율과 정책 근거를 계획/준비 metadata에 공개한다. 지원 범위와 비교 가드는 [IFA 수렴 계약](../../06_분석연구/05_역에프안테나_격자와_경계수렴.md#격자와-pml의-독립-제어)을 따른다.

grid_mm을 줄여도 이미 더 짧은 임계 구간은 그대로 남을 수 있다. 실제 cell 수 증가와 설정 series의 안정성을 모든 최소 특징의 국부 세분화 또는 점근 정확도의 증명으로 확대하지 않는다. 이번 비교에는 Richardson 외삽을 사용하지 않는다.

prepare는 실제 CSXCAD와 포트를 만들어 `pcb.xml`, 실제 mesh 통계, 소비 보고서, 정규화와 runtime 출처를 봉인하며 FDTD를 실행하지 않는다. analysis는 같은 XML 바이트를 실행하고 종료 조건을 검사한다. raw 파일은 `port_ut_1`, `port_it_1`, `openEMS_stats.txt`, `openEMS_run_stats.txt`, `native.log`, `pcb.xml`이다. 후처리 전용은 완료 raw를 재사용하고 solver를 다시 실행하지 않는다.

정규 결과는 `rfad.openems-pcb-result/0.1`이며 주파수별 복소 S11과 입력 임피던스, S11 dB와 VSWR를 포함한다. S11 크기가 1 이상이면 VSWR는 null, S11이 0이면 유한 dB가 없어 null이다. 해당 값을 0이나 임의 큰 값으로 치환하지 않는다. GUI도 계산 불가 구간을 이어 그리지 않는다.

assessment의 `status=computed_unvalidated`, `physics_validated=false`를 유지한다. `converged=true`는 요청한 시간영역 에너지 종료 조건을 충족했다는 뜻이다. 격자/경계/모델의 정식 수렴이나 안테나 성능 합격을 뜻하지 않는다. 최대 step 도달, 취소나 종료 조건 미달은 완료된 정상 결과로 게시하지 않는다.

## 검증과 후속 범위

`fixtures/pcb_worker_smoke.json`은 반지름 8 mm의 원형 기판, 선/원호와 2 mm 급전 gap을 사용하는 실행 fixture다. 8~12 GHz의 31점, epsilon_r=2.2, tan_delta=0.002, 도체 전도도 58000000 S/m는 시험 가정이며 FR4 또는 승인 IFA의 확정 조건이 아니다.

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/verify_pcb_worker.py --workspace .local/pcb-worker-verification/manual-001 --report .local/pcb-worker-verification/manual-001.json --exercise-cancel
```

이 도구는 공개 명령으로 설계를 만들고 저장/스냅샷/계획/준비/실행/독립 후처리/표시 조회/재시작을 확인한다. 선택적 취소 시험은 실제 guest 종료와 이전 결과 보존을 확인한다. 단위 시험에서는 누락/변조/외곽/접촉을, 실제 native 시험에서는 공식 LumpedPort.CalcPort와의 후처리 일치를 확인한다. 실제 실행 결과와 로그는 [개발 상태](../../09_개발계획/02_개발착수와_현재상태.md)에 기록한다.

`fixtures/ifa_feed_smoke.json`은 40 x 60 mm의 접지면/빈 영역/패드/급전선/단락부를 가진 IFA 실행 사례이며 `fixtures/pth_worker_smoke.json`은 중공 도금 비아의 별도 실행 사례다. 위 도구의 `--fixture`로 선택한다. 물성과 도금 치수는 명시적 시험 가정이다. 실제 급전 도체는 소비하지만 SMA/실장/케이블/디임베딩은 포함하지 않는다.

단일 포트 IFA의 격자/경계 거리 study는 [별도 수렴 계약](../../06_분석연구/05_역에프안테나_격자와_경계수렴.md)에서 관리한다. 이번 fixture의 사전 acceptance는 실제 mesh 최소 3수준, 마지막 비교의 max abs(Delta S11_complex) <= 0.02, 동일 공진 branch의 상대 변화 <= 1%다. 최초 study의 모든 run은 2.0~3.0 GHz의 같은 201점과 2.5 GHz 손실 환산 중심을 사용한다. 내부 공진 bracket이 없거나 대응이 불명확하면 해당 지표는 미평가이며 임의 0%로 처리하지 않는다. 임피던스 변화는 진단으로 함께 보존한다.

이 study는 `tools/verify_ifa_convergence.py`와 [고정 manifest](../../../Code/fixtures/ifa_convergence_study.json)를 사용한다. mesh 0.5/0.45/0.4 mm는 padding 102 mm에서, 경계 90/96/102 mm는 grid 0.4 mm에서, 종료 1e-5/1e-6은 grid 0.4 mm/padding 102 mm에서 비교한다. curve_tolerance=0.025 mm와 max_timesteps=100000을 고정한다. 8개 비교 행은 같은 anchor를 공유하므로 고유 FDTD 실행은 6개다. 모든 공개 solver.plan을 먼저 봉인/검증하고 하나라도 불능이면 FDTD를 시작하지 않는다.

`--resume`은 같은 입력과 현재 worker identity에서 기존 요청/완료 자료를 재사용한다. `--reassess-only`는 solver 환경 없이 완료 결과를 읽어 현재 판정기로 다시 평가한다. 원래 raw/plan/result와 개별 판정 기록은 immutable이며 진행 report와 파생 CSV는 갱신 가능하다. 정확한 CLI와 종료 코드 0/1/2의 의미는 수렴 계약을 따른다. 201점에는 목표 끝 2.4835 GHz가 없고 기준면도 local gap이므로 SMA 기준의 전 대역 -10 dB 목표 합격을 선언하지 않는다.

runtime identity는 제품 소스 묶음 전체를 포함하므로 판정기만 변경해도 이전 `--resume`이 거절될 수 있다. 완료 결과는 현재 판정기의 `--reassess-only`로 별도 평가할 수 있다. 이전 실행의 정확한 재개에는 당시 소스/설치 identity가 필요하고, 현재 소스의 새 native 계산은 새 workspace/report를 사용한다.

이 고정 study의 실행/재개/재판정은 CLI/JSON/CSV 경로다. GUI는 단일 완료 결과 그래프와 완료된 IFA/방사 연구 JSON의 읽기 전용 요약을 제공한다. 별도의 [프로젝트 연구 GUI](05_프로젝트_연구화면.md)는 현재 설계의 1~6개 grid 설정 실행/취소/재개를 제공하며, 이 고정 3축 manifest 전체 편집이나 자유로운 여러 run 겹침 비교를 구현한 것은 아니다.

공진을 포함하는 [별도 study](../../../Code/fixtures/ifa_convergence_resonance_study.json)는 1.6~2.6 GHz의 201점과 2.1 GHz 환산 중심을 사용한다. 이상적 port 대역을 명시적 가정으로 바꾼 별도 fixture/snapshot이며 최초 study를 덮어쓰지 않는다. 두 연구의 결과는 손실 환산/여기 조건이 달라 직접 비교하지 않는다. 동일 acceptance와 공간/종료 행렬을 각각 실행하며 실제 판정은 각 보고서로 확인한다.

최초 2.0~3.0 GHz study는 6개 native 실행을 완료했고 마지막 비교의 복소 S11 변화는 세 축 모두 0.02 이하였다. 표본 최소값이 2.0 GHz 대역 끝에 있어 내부 반사 최소점 추적은 미평가이고 전체 상태는 `not_established`다. 이 반사 최소점 정의를 X=Im(Z)=0의 전기적 공진과 동일시하지 않는다. 수치와 재판정/재개 근거는 [실제 결과 기록](../../06_분석연구/05_역에프안테나_격자와_경계수렴.md#최초-2030-ghz-연구의-실제-결과)을 따른다.

별도 1.6~2.6 GHz study도 6개 native 실행을 완료했다. 마지막 복소 S 변화와 반사 최소점의 보수적 bracket 이동이 기준 안이어서 세 축/전체는 `established`다. 표본 최소점 1.920 GHz는 X=0의 공진을 뜻하지 않으며 이 계산의 2.400 GHz 표본은 -10 dB 정합 목표를 충족하지 않는다. 이는 fixture 전용 수치 안정성으로 제한하고 물리/실측 상태는 그대로 유지한다. [별도 연구의 실제 결과](../../06_분석연구/05_역에프안테나_격자와_경계수렴.md#별도-1626-ghz-연구의-실제-결과)에 수치와 근거를 기록한다.

최종 판정기는 mesh series의 실제 외곽/PML 시작면 고정과 boundary series의 실제 확대/공통 내부 격자 보존을 검사하고 두 series의 PML cell 수/폭 일치를 확인한다. 두 완료 연구를 이 가드로 재판정해 모두 통과했으며 원래 지표/상태와 native 자료는 그대로 유지됐다. 새 판정 파일만 추가했으며 FDTD는 재실행하지 않았다.

시간 종료 민감도는 별도 series로 비교하고 PML cell 수 변화는 이 study에 포함하지 않는다. 원형 PCB/원호의 실행과 선택적 NF2FF/이득/효율 경로 및 별도 수치 연구는 [방사 계약](04_사용자기판_방사계산.md)과 [방사 수렴](../../06_분석연구/10_사용자기판_방사수렴.md)을 따른다. 실제 급전/재료/측정 조건의 대조와 독립 RF 정확도는 후속이다. 실행 fixture나 특정 수치 지표의 통과를 실물 정확도 및 전체 검증 순서의 완료로 간주하지 않는다.
