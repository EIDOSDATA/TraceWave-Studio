# 대용량 외부 결과 등록과 비교

Windows Studio의 **해석 > 대용량 결과 등록 및 비교**에서 필드 또는 복소 곡선 HDF5 원문을 선택한다. 등록이 완료되면 원본 파일명, SHA256, 등록할 때의 프로젝트 개정과 검증 상태를 볼 수 있다. 프로젝트를 저장하고 같은 작업 영역에서 다시 열면 같은 등록 결과가 나타난다.

## 외부 원본의 의미

- 등록은 프로젝트에 파일과 당시 개정을 연결한다. 설계 명령이나 해석 실행으로 처리하지 않는다. 기존 프로젝트 개정, 해석 결과 및 출처는 보존한다.
- 외부 필드에서 확인한 좌표, 주파수와 데이터만 표시한다. 기판과 필드를 자동 정렬하거나 Yee 중간 위치, 절대 단위, 제작·측정 상태 및 물리 검증 결과를 추정하지 않는다.
- 곡선별로 원본 이름, 출처, 기준 임피던스, 측정 조건을 표시한다. 명시하지 않은 조건은 미정이다. 다른 주파수 축을 그대로 표시하고 정렬, 보간, 정규화나 자동 목표 평가는 수행하지 않는다.

## 지원 HDF5 프로필

| 자료 | 상한 | 배열과 표시 |
| --- | --- | --- |
| 필드 | 파일 1056 MiB, 1~3개 주파수, xyz 좌표 합계 4096개 | openEMS 0.3의 primary Yee NXYZ 복소64, E/J/rotH. 축은 순증가하는 float64이며 `mesh_scaling=0.001`이다. 한 요청은 단면 하나, 최대 4096점과 256 KiB 응답을 지원한다. |
| 복소 곡선 | 파일 32 MiB, 최대 8개 곡선, 각 최대 100000점 | `rfad.large-complex-traces/0.1`. 전체 보기에서는 원본 순번 구간 64개까지의 실제 최소·최대 표본을 표시한다. 원본 표본 보기에서는 각 시작 순번부터 최대 101점을 표시한다. |

복소 곡선 파일의 root에는 속성 없는 `metadata_json`과 `traces`가 있어야 한다. `metadata_json`은 정규 UTF-8 JSON을 담은 uint8 배열이다. 키는 `profile`, `quantity`, `unit`, `curves`이며 물리량과 단위는 `S/1`, `Z/ohm`, `Y/S` 또는 양쪽 `null`이다. `curves`의 각 객체는 `label`, `source`, `reference_ohm`, `measurement`를 포함한다. 곡선 배열은 `traces/t0`부터 연속 번호를 사용한다. 각 그룹은 순증가 양수 float64 LE `frequency_hz`, [표본, 2] float64 LE `values_ri` 및 uint8 `valid`를 가진다. 마스크는 0 또는 1이며 0인 표본은 화면에 결측으로 남는다. 원본 파일의 전체 바이트를 복제본에 보존한다.

## 등록과 읽기 경계

사용자 선택 파일은 UI 스레드 밖에서 현재 프로젝트의 수신 폴더에 임시 복사한다. 요청은 원래 경로나 파일 본문을 전송하는 대신 프로젝트와 개정, 수신 UUID 및 표시 정보를 보낸다. 서비스가 별칭과 리파스 경로, 용량, HDF5 구조와 역할, 주파수 및 곡선 표본을 검증하고 등록 작업을 게시한다. 프로젝트별 최대 16개 원본과 8 GiB를 지원한다.

원문 전체 SHA256과 1 MiB 블록별 SHA256을 등록할 때 계산한다. 원문과 인덱스를 생략 없이 봉인하고 완료 이벤트와 같은 저널 트랜잭션에서 참조를 등록한다. 이후 조회는 HDF5가 읽는 블록을 대조한다. 파일 전체를 다시 메모리에 적재하지 않으며 조회당 검증 블록 캐시는 최대 8 MiB다. 외부 저장소, 링크 별칭, 필터와 VDS는 지원하지 않는다.

프로젝트 저장·재열기의 등록 범위는 같은 작업 영역이다. 작업 영역 간 이동에는 아래 결과 이관 파일을 사용한다. [Windows 제품 검증](../../07_검증/138_대용량_외부결과_제품검증.md)

## 작업 영역 간 결과 이관

목록에서 결과를 고르고 **선택 결과 이관...**을 눌러 새 `.rfadres` 사본을 저장한다. 대상 프로젝트의 같은 창에서 **이관 파일 등록**으로 연다. 파일 하나에 등록한 결과 한 건을 기록한다. 편집 프로젝트는 기존 64 MiB 편집 복원 ZIP으로 별도 이관한다.

이관본은 버전 서명, 최대 4096바이트의 정규 UTF-8 출처 기록과 그 SHA256, 원래 HDF5 바이트를 저장한다. 원래 프로젝트 ID와 당시 개정, 원본 파일명과 SHA256을 유지한다. 새 프로젝트의 현재 개정과 새 등록 ID를 별도로 연결한다. 이전에 등록한 이관 파일을 다시 내보내도 원래 출처를 유지한다. 원문에 있는 곡선 조건과 결측, 제작·측정 미정 및 독립 검증 전 상태를 유지한다.

서비스가 원본을 확인하고 결과별 이관 파일 하나를 준비한다. Studio가 1 MiB 버퍼로 사본의 전송 SHA256을 확인하고 새 경로에 게시한다. 수신 시 길이, 머리말과 본문의 SHA256을 확인한 뒤 기존 HDF5 등록 계약을 적용한다. 손상된 사본은 등록되지 않는다. SHA256은 바이트 무결성 확인에 사용한다. [Windows 작업 영역 왕복](../../07_검증/148_대용량_결과_이관과_재열기_검증.md)
