# 제조사 PCB 안테나 라이브러리

Studio의 PCB 원문 가져오기에서 제조사와 패턴 이름을 선택한다. 해당 원본 또는 공식 ZIP을 고르고 원문 전송, 보존 원문 읽기를 누른다. 별도 교환 worker가 선택한 개정의 바이트와 SHA256을 대조한다. 자료의 공식 주소, 원래 멤버 이름과 검토한 동박 범위는 [대역별 원본 검토](../../06_분석연구/13_제조사_피시비_안테나_원본과_대역별_검토.md)에 있다.

1. 현재 PCB와 좌표계를 확인하고 각 원문 동박층을 기존 동박층에 대응시킨다. 원본의 서로 다른 층에는 별도 대상을 지정한다. 파일에 없는 넷은 미할당을 선택할 수 있다.
2. 배치 기준의 X/Y와 회전을 입력한다. Renesas는 원본 원점, TI는 독립 동박 경계의 왼쪽 아래가 기준이다. 보드 외곽을 벗어나는 도체는 후보가 차단된다. 보드 외곽과 적층은 유지한다.
3. 편집에서 생략하거나 근사한 부분을 확인하고 변경 이유를 입력한다. 2D 후보와 현재 원본을 검토한 뒤 적용하면 한 개 이력 명령으로 편집 영역과 출처가 추가된다.
4. 생성된 동박은 2D에서 선택·이동하고 저장할 수 있다. 같은 원본을 재열기할 때 현재의 편집 좌표와 등록 당시 동박을 각각 확인할 수 있다. 기존 물성, 포트, 공구와 제작·측정 미정값은 유지된다. 새 동박의 EM 포함은 초기 꺼짐이며 급전·접지·적층을 검토한 뒤 편집에서 지정한다.

| 예제 | 입력 | 적용 범위 |
| --- | --- | --- |
| Renesas AN-B-027 Rev. 2.5, 2.4 GHz | 공식 DXF ZIP 또는 ant_ifa.dxf, ant_ifa-v1.dxf, ant_ifa-v2.dxf, ant_ifa_ss.dxf, ant_zor.dxf | 문서와 대응한 mm 평면 동박 폐곡선. ZOR·전폭·축소 예제의 하부 동박은 별도 층에 대응한다. |
| TI CC2511 USB IFA 및 CC25xx 접힌 다이폴, 2.4 GHz | 참조 설계 공식 ZIP 또는 IFA_USB.spl / CC25xx_Folded_Dipole.spl | inch 선언의 독립 상부 도체. 다이폴 파일의 IC 연결 패드와 지원 aperture macro 포함. |

DXF 원호는 최대 현 오차 0.002 mm의 직선 경계로 표시한다. 한 영역에는 외곽과 내부 경계 합계 64점까지 들어간다. 넘는 영역은 동박 면적을 유지하는 여러 편집 영역으로 나뉜다. 같은 층의 넓은 동박에 완전히 포함된 동박 폐곡선은 중복 생성하지 않는다. 패드·비아 블록, 마스크, 풋프린트 경계 및 전체 기판·정합은 원본에서 확인하고 편집 적용에서는 생략한다. 이 범위는 미리보기 손실 목록에 명시한다.

TI SPL은 region, 원형 stroke, 원형/사각 flash를 명시 동박 면적으로 결합한다. 다이폴의 확인된 aperture macro는 가산 outline과 원형 부분을 적용한다. 둥근 경계 최대 현 오차는 0.002 mm, 면적 결합 좌표 격자는 0.0000001 mm다. 원래 inch 좌표를 mm로 변환한 배치 전 위치와 앵커는 parser 근거에 남는다. [Windows TI 검증](../../07_검증/262_텍사스_인스트루먼츠_안테나_가져오기_검증.md)

보존된 원본은 ZIP 또는 선택한 멤버의 바이트다. 적용 기록에는 원문·parser 보고서 ArtifactRef, 공식 주소, 문서 개정, 멤버 해시와 형상 대응이 들어간다. 원문 좌표는 보고서에, 이후 편집 좌표는 프로젝트 형상에 남는다. 새 파일의 동박은 생성 시 RF 성능, 수렴, 제조 또는 실측 합격으로 평가하지 않는다. [Windows Renesas 검증](../../07_검증/261_레네사스_안테나_원문_가져오기_검증.md)
