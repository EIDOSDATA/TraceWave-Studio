# 설계 탐색과 수치 연구

개발 완료 계획 6번의 정의, 후보, 자원 예산과 실행 수명 및 9번의 명시 후보 채택을 관리한다. 기존 격자 수렴 연구와 설계 변수/수치 조건/외부 회로 스윕, 별도 프로젝트로 채택하는 동작을 구분한다.

- [명시적 스윕과 실행 계약](01_명시적스윕과_실행계약.md)
- [연구 화면과 전환](../../04_화면설계/20_설계스윕과_연구_화면.md)
- [후보 채택과 새 작업 사본](02_후보채택과_새작업사본.md)
- [후보 검토와 새 사본 화면](../../04_화면설계/23_후보채택과_새사본_화면.md)
- [원호/IFA 유한 실행과 원본 보존 검증](../../07_검증/21_후보채택과_원호아이에프에이_검증.md)

현재 채택 범위는 완료된 grid_sweep의 리터럴 매개변수 후보다. 원본 프로젝트와 선택 Quantity/출처, 실제 계산 pin을 보존하고 새 프로젝트에 한 명령으로 적용한다. 명시 원호/IFA 계산과 사본 재계산, 전용/기존 GUI 자동시험을 확인했다. 실제 IFA 24 mm 후보의 Windows 사본 채택/저장/재열기와 설치 조건 미정 보존도 별도로 확인했다. 이상 간극 포트의 원래 목표 판정을 보존한다. 합성 외함에서 이상 회로로 재정합한 대역 결과는 [설치 후보 검증](../../07_검증/303_설치후보_단일축_재실행과_정합대조.md), 격자와 바깥 여백을 독립적으로 바꾼 결과는 [대역 검증](../../07_검증/311_설치후보_격자와_외부경계_대역검증.md)에 있다.

명시적 스윕 외에 요구 대역과 설치 제약에서 원호와 IFA의 초기 후보를 제안하고, 계산한 결과를 사용해 다음 시도를 정하는 경로를 검증했다. [설치 제약과 구조 제안](../../07_검증/385_설치영역과_요구조건_구조제안_검증.md), [반복 탐색의 종료 근거](../../07_검증/394_원호와_역에프의_반복탐색_종료근거.md)

공정 표본의 수율을 검증하려면 같은 시료의 공정 치수와 목표 판정 기록이 필요하다. [표본 수율과 합성 사례](../../07_검증/376_요구대역_초기치수와_후속후보_탐색.md)
